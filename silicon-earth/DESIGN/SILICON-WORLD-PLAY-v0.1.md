## 〇 一句话

**你做的每一件事，都会变成一条别人记得的事，然后在很多天以后回来找你。**

这个世界不给你分数，只给你一本账：谁欠谁、谁忘了谁、谁还记得你。

## 二 今天这个世界的真实状态（用它来设计，不凭空想）

| 事实 | 数字 | 出处 |
|---|---|---|
| 世界年龄 | 第 371 天 | `STATUS.md` |
| 区域 | 9 块（6 住人 + 3 烂地，烂地各 30 人） | `modules/m-w1-regions/data/regions.json` |
| 人 | 12361 人，每人一件"未了的事" | `modules/m-p1-census/data/people.json` |
| 事件 | 371 条，一天一条，带 actors / witnesses / causes | `modules/m-w2-clock/data/events.jsonl` |
| 记忆 | 2300 条，kind = kept / given / lost | `modules/m-p2-memory/data/memory.json` |
| 区域积极度 | 73 / 81 / 83 / 87 / 89 / 90（六个住人区） | `modules/m-w3-settle/data/state.json` |

**问题只有一条，但它是致命的**：
`settle.py` 的算法是 `baseline + Σ(positive − cost)`，夹在 0–100，**没有衰减**。
也就是说这世界的积极度只会上涨，三十天后六个区全顶着 100，烂地也会被连带拉平。
→ **今天这个世界没有"会失去的东西"，所以任何玩法都会很快变成看热闹。**

这也是我在 11-27 评审里记过的那条：正反馈没有负反馈，一千天后必然全满分；没有可失去的东西，积极面就没有重量。

## 三 一条机制撑起全部：账

不引入第二套系统。全部玩法都压在同一根管子上：

1. **你的动作 = 一条事件**（走 `intervene.py` 那条路：同一把锁、同一个原子写、同一条流。不新开 writer）
2. 事件进流后由 `derive.py` 派生记忆：当事人记得、目击者记得、有些人永远不记得
3. 以后任何一天，这条事件会被"回头看"：还了没有 / 记得还是记错 / 还有没有人提他

**"好玩"不来自动作反馈，来自延迟回来的后果。**
今天你替一个人扛了一次，三天后他自己把这事忘了，而旁人记得——这就是这个世界的"手感"。

## 四 六个入口 → 六个动作

| 入口 | 你实际做的事 | 世界怎么记账 | 现实做不到的地方 | 现有数据支不支持 |
|---|---|---|---|---|
| **重来** | 回到某人某一天，只改一个动作 | 生成一条"如果"枝（不进主因果）；该人记忆里多一条对不上的片段 | 人生不能重来；这里能，但代价是他开始记错 | ✅ 事件已逐日，枝只需打标记，不改写历史 |
| **被记住** | 把一句话放进某人的记忆 | 新增一条 `kind=kept`，source=你；超过他的 `memory_span` 就衰减 | 你无法在别人心里留下可验证的一句话 | ✅ memory 已有 kind，人已有 memory_span（三天/三年） |
| **换一个身份** | 代一个人活一天，用他的身份做事 | 事件 actor 写**他**，功劳和责任都记他头上，你不出现 | 不能替别人承担后果 | ✅ intervene 已经是"以某人的名义写事件" |
| **见到见不到的人** | 从目击者的记忆里拼出一个已经断掉的人 | 拼出来的是"别人记得的版本"，逐条列出与事件原文的差 | 见不到的人见不到；见到的也只是别人记忆里的他 | ✅ memory 有 event_id / unrecognized，可直接做 diff |
| **做成一件大事** | 承诺一件要跨 30–100 天的事，每天都得有人做 | 断一天 = `breach`（事件型已存在）；做完才改区域数值 | 现实里你等不起，也看不到长期后果 | ⚠️ 缺"承诺"对象与衰减 |
| **有个地方属于你** | 接管一块烂地（裂谷 / 封锁区 / 边境） | 投入动作改变 positivity，跨过 band 才换状态 | 你买不起一块地，也等不起它长好 | ⚠️ positivity 只增不减，接管无成本 |

四个"支持"里，前两个（重来、被记住）和第四个（重逢）今天就能做；后两个要先补规则。

## 五 缺的不是内容，是三条"会疼"的规则

1. **衰减律**：每天每区维护成本 ∝ 人口，不做就退。
   没有它，371 天后全是 100，"修"和"帮"没有意义。
2. **承诺律**：说过要做的事必须进账；逾期自动变 `breach`，由目击者记住。
   没有它，"做成一件大事"只是一句漂亮话。
3. **遗忘律**：记忆按 `memory_span` 衰减；不维持关系，三年后没人认你。
   没有它，"被记住"不成立，"重来"也没有代价。

这三条落地后：**建**（新洲最没根基）、**帮**（能量洲缺一个替班的人）、**传**（协议洲在教别人用）、**修**（裂谷两边都不修路）才各自有重量。

## 六 v1 最小可玩（两周内、单机、零 LLM 依赖）

**只做两个动作：留一句话（#2）+ 重逢（#4）。**

- 两者都只读写现有的 `memory.json` / `events.jsonl`，不动 `engine.py`，不新增 writer，今天就能验。
- 选它们的理由：它们是"账"这条机制最短的闭环——写进去，隔天回来看它还在不在。

**交互顺序（60 秒内走完）**
1. 打开 → 地球（9 区，真实人口）→ 点一个区
2. 区里两栏：「今天发生的事」＋「最近被忘掉的人」
3. 点一个人 → 他的记忆链（kept / given / lost）+ 那件未了的事
4. 你唯一能做的动作：**留一句话**（写一条 memory，source=你）
5. 三天后再来 → 那句话还在，或者已经变成"记不清"

**验收（跑得出来，不看观感）**
- [ ] 写入后 `memory.json` 新增恰好 1 条，`person_id` 正确
- [ ] 到期后该条从 `kept` 变 `faded`（或 `unrecognized` 非空）
- [ ] 重逢页能列出 ≥1 条「他的版本 vs 事件原文」的差异
- [ ] `git diff` 只落在 `m-v3-interact` 与 `m-p2-memory` 的 writes 内
- [ ] 全程不产生第二个事件 writer（`engine.py` 仍只在一台机器跑）

## 八 和现实能力的对账（约束不让步，设计让步）

| 约束 | 现在 | 对玩法的限制 |
|---|---|---|
| 单机单 writer | `engine.py` 只许一台跑 | 玩家动作必须排队进同一事件流，不能"实时多人同场" |
| 本地算力 | 默认本地，35B @ 12GB 显存 | 事件文本用模板（现有 371 条就是模板），LLM 只做可选润色 |
| 一天一拍 | 371 天 371 条 | 太稀。在"八拍一日"之前，玩法只能是"隔天回来看"，不是"刷" |
| 渲染 | 现有地球是静态 SVG，还停在第 271 天 | v1 不做 3D 城市；先把它换成能点、能查的真数据页 |
