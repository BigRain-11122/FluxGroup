## 二 十一条合成结论（跨路共识，按重要性排）

1. **世界不围着你转，不靠聪明的 NPC，靠四件低成本装置**：独立时钟（离屏结算）、会过期的支线、会自己传播的后果、你先到之前就存在的历史。全是状态加排序。
2. **故事不是生成的，是「带名字与因果的记录被二次引用」。** 不写文本库，只写「触发条件 → 模板槽 × 目击者」。
3. **成功即负债。** 名声/资产越高，别人向你索取越多、满足门槛越高（RimWorld：财富→袭击点数、期望上调）。这是治「三十天后全满分」的正药，比单纯衰减更有戏。
4. **记忆按类型分档衰减**，不是统一淡出：伤我 −15/10 天、救我 +15/30 天、手术失败 −20/90 天。类型决定半衰期。
5. **传闻要存三版**：目击 / 转述 / 档案。加上 SAC 的「无共谋模仿者」，阴谋会自己长出来，不需要脚本指定谁撒谎。
6. **记忆上屏只靠三招**：空间分界（跨区即换可见记忆集）、色温骤变、物件锚。做「读心面板」＝表单，直接判负。
7. **深时的载体是记忆地层，不是日历。** 1190 个「记不住」的人就是活地层；每天再自动生成一句「后来的人怎么评这一天」。
8. **可学但慢，不可不可知。** 规则不必解释成因，但必须让违反者付出代价（Breach 重于谋杀）；学不到规则的模拟＝没有 agency。
9. **按人口上 LLM 出局。** 斯坦福 25 个智能体 × 2 天 = 数千美元；12GB 只常驻 4B–9B-Q4，单句 5–8 秒。LLM 只做「点一个人，他说一句」与可选润色。
10. **没有「可失去」的经济只是商城。** 但零经济也能活（动森/VRChat）——所以经济排 v3 是对的，前提是先把「灭失/损耗」做出来。
11. **three.js 不是瓶颈**（一万实例 = 1 个 draw call），瓶颈是「谁写世界」：必须留在 Python 单写者，前端只读快照。

## 三 接到九套系统（每条都是可验的）

| 系统 | 接什么 | 怎么验 |
|---|---|---|
| **1 在场** | 离屏 tick；能力阶梯（进某区看体征/额度，不看等级）；Slow Club 延时视角 | 离线推 3 天，某区控制权或某人位置必变；回流给「你错过了什么」清单，条目对得上事件流 |
| **2 体征** | 周期重置：断电即断一段记忆，「那天门关了」不可补 | 断电后该人新增 lost，且事后无法补看当天 |
| **3 建造与损耗** | positivity 加 decay；成功→期望上调；物品先有损耗/灭失 | 30 天无维护必跨 band；名声翻倍后同一善举满意度增量下降；30 天里至少一件东西真的消失 |
| **4 关系与账** | 死亡按关系分权重；欠账到期自动 breach；离场者可带账回来 | 同一人死亡，目击者记忆强度按关系分档；第 100 天走的人第 200 天带账出现 |
| **5 记忆与名声** | 按类型分档衰减；二次引用（社交开场白引真事）；「记不住」者当活地层 | 一次 breach 在第 10/30/90 天回访，见其是否还认得；问同一往事，不同跨度者给不同年代锚 |
| **6 产能与交换** | 九方按「能拿到什么材料」分（Feed/Seed）；平台抽成不平台定价 | 同一物品在不同区 ≥2 个价格，差价来自势力不是随机数 |
| **7 势力与秩序** | 站队不是开关：内化 N 天后生效、可被反证推翻 | 站队有生效日期与理由；被反证后数值回落 |
| **8 传闻与真相** | 三版（目击/转述/档案）；模仿者让阴谋自长 | 一件真事在 3 区出 3 个版本，都能追到同一 cause |
| **9 纪年与大事** | 大事命名年代；每日一句「事后题词」自动生成 | 任取第 N 天，题词与当日 cause 对得上且语气属后来者；每个年代边界有一条可查大事件 |

## 四 明确不要学（合并去重后的判负表）

| 判负 | 理由 |
|---|---|
| 全实体 tick 级模拟 | 判负点不是「人少」——矮人要塞是两个人做的；是 12361 人 × 每 tick 必崩。人用记录，天用 tick |
| 逐个 NPC 上 LLM / 万人可对话 | 25 人 2 天数万美元；12GB 装不下，人格一致性也会崩 |
| 图标清单化 | 奖励＝清掉一个标记，正是「点菜单加一个数」，探索退化为填表 |
| 程序化广度当内容 | 无人深空首发/星空千星：没有留下的理由，几小时就走 |
| 跨代跳跃（Foundation/Accelerando） | 371 天跳不动，一人团队养不起每章新术语 |
| 「世界不可知」（Solaris） | 小说里是美德，模拟里是灾难：学不到规则就没有 agency |
| 机制不仲裁（Hyperion） | 瞬时传送与相对论老化并存，可信度直接失败 |
| 把所有权当玩法（Decentraland/Sandbox） | 产权只制造交易，不制造回去的理由，日活停在三位数 |
| 先平台后内容（Horizon） | 不到 9% 的世界曾被 50 人以上访问——平台规模＝空房率 |
| 在线异步 / 多人同场 | 单机单写者没有后端，还要审核；只能退化成「前人留下的痕迹」 |
| 无缝流送 + 上万动画角色 | 12GB 与单 writer 双不过 |
| 分支树 | 组合爆炸；改成状态变量 + 文本尾声 |

## 五 对 v0.2 的三处修正（已就地改）

1. **系统 6 顺序倒过来**：先做损耗/灭失，再做价格。没有「会丢」的东西，经济只是商城。
2. **v1 加一条反向 KPI**：一期结束时，被 ≥50 次访问过的地点占比 **> 9%**，否则视为空房（用 Horizon 的失败刻度当验收线）。
3. **判负口径改写**：不是「一两个人做不到」，而是「不做全实体 tick 模拟」。表演层（动捕/配音/无缝流送）做不出，模拟层做得出。

## 六 落地顺序（按成本从小到大，前四件都不碰渲染）

1. **给 positivity 加衰减**——一行公式加一个验证（30 天无维护必跨 band）。这是所有玩法的前提。
2. **记忆按类型分档衰减**——把现在的统一 fade 换成按事件类型的半衰期表。
3. **目击者链**——一个动作断言三留痕：≥1 条 witness 记忆、≥1 条走形转述、≥1 个区数值变化。
4. **事后题词**——每天自动一句「后来的人怎么评这一天」，接纪年系统。
5. **第一屏**——three-globe 九区壳 + InstancedMesh 点位（1 draw call）+ 点区下钻 + 点人看记忆链。
6. **前置基准**——先在本机跑一次 llama.cpp（4B/9B-Q4，pp512/tg128），把「对话预算」从推算换成实测，再决定要不要给 NPC 一句台词。
