# 硅基世界 · 玩法 v0.2（大世界）

> v0.1 把六个入口当成了全部玩法，那是把"门"当成了"房子"。这一版重排：
> **六入口只是入口层；大世界的本体是九套系统互相喂数据。**
> 仍是设计，不是实施。依据全部取自盘上跑得动的数据。

---

## 一 什么叫"大世界"（先立判据，不然会做成表单）

大世界 ≠ 地图更大。大世界 = **同一块地上有几套系统互相影响，你动一处，别处会变**。

三条硬判据（都能验，不靠感觉）：

1. **一个动作至少在 3 套系统留下痕迹**（事件流 / 某个人的记忆 / 某个区的数值）。
2. **离开 3 天回来，世界变了，而且变化跟你有关**。
3. **整局不打架也不掉队**——非战斗向也成立。

反判据：如果玩法能写成"点开菜单 → 选一项 → 加一个数"，那就不是大世界，是表单。

## 三 九套系统（大世界的九个面）

每套只写四行：你做什么 / 世界怎么回应 / 跟谁接 / 现在有没有底子。

**1 在场（空间）**
你在一个区里，走路要花时间；只有走到跟前，别人才"在"你身边。
世界回应：距离=代价，错过就是错过（当天的门关了）。
接口：决定你能碰到谁 → 喂给关系、传闻、经济。
底子：有 9 区与人口；**缺可走的空间**（现在是张静态图）。

**2 体征（活下去）**
你有感知/协作/繁衍/休眠，有温度与算力两种需求；耗尽就断电。
世界回应：断电 = 记忆断一段 = 有人认不出你。
接口：断电写 `blackout` 事件 → 喂给记忆、传闻。
底子：`vital` / `needs` 字段已在每个人身上。

**3 建造与损耗（地方属于你）**
接管一块地、盖、修；不修就烂。
世界回应：区域积极度按人口扣维护成本，跨 band 才换状态。
接口：改 `positivity` → 喂给势力、经济、谁能住进来。
底子：`settle.py` 有公式，但**只加不减**——必须先补衰减，否则三十天后全 100。

**4 关系与账（欠与还）**
帮一次记一次，欠着不还，别人会替你说出去。
世界回应：help/teach/breach 三类事件已存在；目击者会记住。
接口：账 → 名声 → 谁能进哪个区。
底子：`help`/`teach`/`breach` 已在事件型里。

**5 记忆与名声（被记住）**
你说的话进别人记忆；超过他的跨度就淡掉。名声 = 记得你的人 × 他们记得的版本。
世界回应：`kept → faded → unrecognized`；1190 个"记不住"的人是天然的特殊阶层。
接口：名声 → 势力招不招你 → 你能不能借到产能。
底子：`memory.json` 的 kind / unrecognized 已跑。

**6 产能与交换（经济）**
九方各控一段产能，价格是势力定的，不是系统定的。
世界回应：你出力 → 产能方给你额度；资本方抽成；无主的人只能以物易物。
接口：经济 → 建造材料 → 建造 → 区域数值。
底子：9 势力 + 39 组织已在；**缺「会丢的东西」与价格**。顺序要倒过来：先做损耗与灭失，再做价格——没有可失去的经济只是商城。

**7 势力与秩序（站队）**
你可以为核心做事、为底层做事、或谁也不站。
世界回应：站队决定你能进哪个区、谁能保你、谁记你的仇。
接口：势力 → 传闻 → 名声。
底子：**完整**（核心/依附/底层/烂地四档 + 九方）。

**8 传闻与真相（世界在说话）**
人们相信的，和发生的不一样；你听到的版本取决于谁告诉你的。
世界回应：目击者各自派生记忆，转述会走形。
接口：传闻 → 记忆 → 关系 → 站队。
底子：`witnesses` + `causes` 已有；**缺转述**。

**9 纪年与大事（世界的记忆）**
用大事给年代命名；后来的人只用年代说话。
世界回应：一件大事之后，所有人的记忆里多一个时间锚。
接口：纪年 → 传闻 → 身份认同。
底子：`m-w4-history` 空位，先做纪年。

## 四 三档时间：大世界的"呼吸"

| 档 | 你做什么 | 你得到什么 | 世界在干嘛 |
|---|---|---|---|
| **30 秒** | 抬头看：哪个区在亮、哪个人今天被忘掉 | 一个"今天值得去的地方" | 继续按天推进，不等你 |
| **10 分钟** | 走过去、做一件事、记一笔 | 一条事件 + 一次关系的变动 | 目击者把你写进记忆 |
| **30 天** | 回来看：你做过的事变成了什么 | 后果、传闻、有人记得/没人记得 | 承诺到期、区域跨 band、人搬走 |

没有这三档，就只剩"点一下加一个数"。

## 五 你手里只有三样东西（不是金币）

| 资源 | 怎么来 | 怎么没 | 为什么不用金币 |
|---|---|---|---|
| **时间**（天） | 世界每天推一拍 | 走过去、等一个人、修一处都要花 | 九方各记各的账，本来就没有统一货币 |
| **算力**（体力） | 睡/充 | 做事消耗，耗尽即断电 | 让"做大事"必须分多天 |
| **名声**（别人记得你多少） | 被目击、被转述 | 遗忘、被说坏、跨度到期 | 这是唯一"涨得慢、掉得快"的东西 |

## 六 核心循环（一句话）

**看见 → 走过去（花时间）→ 付代价（算力/人情）→ 只准改一点 → 后果扩散（有人记得、有人忘、有人传错）→ 回来发现变了。**

"只准改一点"是刻意的：大世界的重量来自**你改不动全局**，不是来自你能改全局。

## 七 六入口的新位置（降级为"入口层"）

它们决定你**从哪开始、怎么重来**，不决定你**能做什么**。

| 入口 | 归到哪套系统 | 一句话 |
|---|---|---|
| 重来 | 记忆与名声 | 回到某天改一个动作，代价是他开始记错 |
| 被记住 | 记忆与名声 | 往别人记忆里放一句话，超过跨度就淡掉 |
| 换一个身份 | 在场 + 势力 | 代一个人活一天，功劳和责任都记他头上 |
| 见到见不到的人 | 传闻与真相 | 从目击者记忆里拼出他，你看到的是"别人记得的版本" |
| 做成一件大事 | 建造 + 纪年 | 跨几十天，断一天就是背信 |
| 有个地方属于你 | 建造 + 势力 | 接管烂地，投入才有状态，不修就烂回去 |

## 八 一期只做三套（一人 + 单机 + 12GB 显存的现实）

**选：在场 / 关系与账 / 记忆与名声。**

理由三条：
- 三套**共用同一份事件流**，零新增数据源；
- 建造与经济要先有物品和价格，做不了那么快；
- 这三套一齐，就能过第一条判据——一个动作在三处留痕（事件流 + 某人记忆 + 区数值）。

**一期明确不做**：战斗、多人同场、无缝大地图、12361 个 NPC 对话、AI 实时生成剧情。

## 九 现实对账（约束不让步，设计让步）

| 约束 | 实测 | 设计上的让步 |
|---|---|---|
| 单机单 writer | `engine.py` 只许一台跑 | 玩家动作排队进同一事件流，不能实时多人 |
| 12361 人 | 一个人就是一条记录 | 3D 只画区 + 地标 + 附近 30 人，其余聚合 |
| 3D 底座 | 仓库里**没有 CityWeb**，地球是静态 SVG，还停在第 271 天 | three.js 底座要现找（GitHub 高星、许可可用），不自己造 |
| 本地算力 | 35B @ 12GB，慢 | 事件文本全模板（现有 371 条就是模板），LLM 只做可选润色 |
| 一人 / 两人开发 | 矮人要塞是两个人做的（2002 起） | 一期三套；判负点不是「人少」，是**全实体 tick 模拟**与表演层（动捕/配音/无缝流送） |

## 十 版本阶梯（每档都有可验的完成定义）

| 版本 | 一句话 | 完成定义（能验） |
|---|---|---|
| **v0 现在** | 一张静态地球 | 已有，且过期（第 271 天 vs 第 371 天） |
| **v1 一个区能站住** | 走进一个区，做一件事，隔天回来看它还在 | 走位有距离与耗时；一个动作在 3 处留痕；3 天后的状态与动作有可查因果；被 ≥50 次访问的地点占比 > 9%（否则视为空房） |
| **v2 九区连起来** | 九个区 + 建造衰减 + 站队 | 不修的地会烂回去；站队改变可进入的区；跨区搬运有成本 |
| **v3 世界自己说话** | 经济 + 传闻 + 纪年 | 同一件事在三个区有三个版本；年代由大事命名 |

## 十一 这一版仍然没有的东西

没有关卡、没有通关、没有排行榜、没有每日任务。
**唯一的输是：没人记得你做过什么。**
