# 第一屏原型（Design Prototype）

**双击 `entry.html` 即可打开。不需要服务器、不联网、不登录。**

这是「普通人进入」的第一版实物：一个球 → 一块地 → 一个人 → 一件事。

## 怎么玩

1. 打开：一颗会转的球，九个大陆，12361 个光点是**真实人口数据**（第 371 天）。
2. 拖动可以转球；点一块大陆，右边（手机是下面）滑出这块地。
3. 面板里先给这块地今天的一件事，再给**一个人**和他那件未了的事。
4. 三个按钮：帮 / 问 / 记。点完会看到「事件 / 记忆 / 数值」三处同时记账。
5. 右上角「日 / 夜」切换两套气质。

## 深链

- 直接打开某块地：`entry.html?r=R03`
- 直接夜间：`entry.html?theme=night`
- 截图用（关动画）：`entry.html?r=R03&still=1`

## 哪些是真的

- 九个区名、说明、人口、状态、今天的事件：全部读自 `silicon-earth/modules/`（第 371 天真实数据）。
- 每个人的名字、编号、「未了的事」：真实居民记录；今天这件事的当事人会优先出现在卡片上。
- 「他记得：……」：读自真实 `memory.json`（kept / given / lost）。
- 「后来的人说……」：按事件类型套模板生成的事后题词，不调用模型。
- 「帮 / 问 / 记」的三处记账：**演示用**，只弹卡片，不写世界数据（不碰 `events.jsonl`）。
- 「三天后」：按这个人的真实记忆跨度给结局（三天→忘了 / 三年→还记得 / 记不住→记错了），是规则推演，不是世界真跑了三天。
- 「册子」存在浏览器 localStorage，刷新还在，但不进世界。

## 哪些还是假的

- 这不是三维城市，只是一个可转的球；「镜头推进」用放大 + 高亮代替。
- 没有真实的位移、距离、时间消耗；三天后的区域数值是推演，不是结算结果。

## 怎么重新生成

改完 `entry.template.html` 后：

```bash
cd D:\FluxGroup\silicon-earth\DESIGN\proto
python build_entry.py
```

`build_entry.py` 读真实数据并注入 `entry.html`，只读不写世界文件。

## 这里的边界

原型放在 `DESIGN/proto/`，**不属于任何模块的 writes**，不参与 `guard` 与交付流程；
接进世界时走 `m-v3-interact` 的任务单，不在原型目录里长产品代码。
