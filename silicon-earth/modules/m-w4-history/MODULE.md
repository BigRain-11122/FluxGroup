# m-w4-history · 历史与纪年

- **域**：世界　**状态**：usable（v0.1 · 2026-11-27 · bm-c）
- **职责**：把事件沉淀成历史——哪一天发生了什么
- **输入**：`events.jsonl` + `time.json` + `regions.json`
- **输出**：`history.json` —— 用大事划出的纪年
- **独占写**：`modules/m-w4-history/data/history.json`、`history.py`、`check.py`
- **怎么跑**：`python modules/m-w4-history/history.py`
- **怎么验**：`python modules/m-w4-history/check.py`（rc=0 才算过）
- **下一步**：给每纪补一句「这一纪留下什么」（从该纪事件里挑一条代表事件，不另编故事）

## 口径（写死，改口径＝改契约）

| 项 | 规则 |
|---|---|
| 大事 | `blackout`（断电）/ `breach`（失守） |
| 边界 | 大事发生的那一天开新纪；第 1 纪从第 1 天起 |
| 纪元名 | `<段号>·<该段事件最多的区域名>的<触发词>`（首段＝开城，断电后，失守后） |
| 覆盖 | 各纪首尾相接、无空段、合计事件数＝事件总数 |
| 不编造 | 名字里的区域与触发词都必须能从事件流查出来 |
