# m-p4-behavior · 需求与行为

- **域**：人　**状态**：usable（规则版 v0.1 · 2026-11-27 · bm-c）
- **职责**：每天做什么——根据记忆与关系决定动作
- **输入**：`memory.json`（记忆链）+ `bonds.json`（关系账）+ `people.json`（人）
- **输出**：`behavior.json` —— 每人一条动作 + 一句理由 + 目标人
- **独占写**：`modules/m-p4-behavior/data/behavior.json`、`behavior.py`、`check.py`
- **怎么跑**：`python modules/m-p4-behavior/behavior.py`
- **怎么验**：`python modules/m-p4-behavior/check.py`（rc=0 才算过）
- **下一步**：把「守」再拆一层——按 `needs` 决定守什么（温度 / 算力 / 归属）

## 规则（写死在代码里，改规则＝改契约，须走总控）

优先级从高到低，一人只出一条：

| 动作 | 条件 | 目标人 |
|---|---|---|
| **修** | 有 `lost` 记忆（记忆断了） | 无 |
| **还** | 收 − 给 ≥ 1（欠账） | 给过他的最多的那个人 |
| **帮** | 给 − 收 ≥ 1（有余力） | 他帮过的最多的那个人 |
| **守** | 以上都不成立 | 无（理由写他未了的事） |

- 目标人**只从关系账里挑**，不许凭空生成；平账（给=收）不算欠也不算余。
- ties 规则：次数多者优先，同次数按人 id 字典序——保证同输入必同输出。
