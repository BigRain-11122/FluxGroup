## 二、出厂闸（每条声线必须过）

1. 单人可辨：F0 四分位距 / 中位数 < 0.75（多人有声剧一律不收）
2. 语料 ≥ 8 分钟才准训练，≥ 20 分钟才算达标品
3. 背景：`bg_ratio`（静音段/说话段能量比）≤ 0.30
4. 合成验收：ASR 回读匹配率 ≥ 0.90；高频能量占比、噪声底、削波帧数随样带落盘
5. 样带格式：44.1 kHz WAV + 192 kbps MP3，loudnorm -16 LUFS

## 三、音色矩阵（365 行 → 可执行分桶）

按「年龄 × 性别 × 音色质地 × 职业语域 × 地域」五维取样，首批目标 60 席：

- 年龄：少年 / 青年 / 中年 / 老年 / 童声
- 性别：男 / 女
- 质地：清亮、低沉、沙哑、磁性、软糯、干硬、鼻音重、气声
- 语域：播音、说书、讲解、唠嗑、叫卖、课堂、客服、方言、电台、评书
- 地域：普通话标准 / 川渝 / 东北 / 粤语 / 吴语 / 西北 / 中原

优先收**有声书与播客**（录音棚、无伴奏、长时段），其次纪录片旁白、方言教学；多人有声剧、直播切片、带 BGM 的一律降级。

## 四、产能（单机 RTX 3070 8G，单车道）

- 语料构建（ASR 4× 实时）：30 分钟素材 ≈ 8 分钟
- 预处理 + 20 epoch 训练：≈ 15 分钟
- 样带 + QC：≈ 3 分钟
- **一条声线约 25 分钟**，一夜 ≈ 20 条
