# 这妖我收了游戏软件 V1.0 软件设计说明书

## 1. 软件概述

这妖我收了是一款东方神话题材收妖塔防放置游戏，运行于Unity引擎，面向Android与iOS小游戏平台。玩家扮演收妖师，以放置挂机积累资源，在妖潮攻防战中布设封印防线抵御妖物进攻，将战力妖物封印入册，逐步集齐八妖图鉴。

游戏采用放置与塔防双核心循环：IdleSim在后台持续计算挂机产出；妖潮攻防模块（YaotideSim）驱动每局战斗，妖潮沿S形折线进攻，玩家在图鉴轮换的塔位上布防，战斗中随赚随布，妖物推进至穷奇斩杀线即定胜负，精英妖可中途封印入册。种子机制决定每局妖灾词条与波次内容，保证离线与在线一致的确定性体验。

命名空间为Sy.P04，运行时代码共24个.cs文件，有效代码行3641行。

## 3. 系统架构

游戏启动流程由BootRunner驱动，依次执行BootSequence中的场景切换，注入BootServices注册的单例服务。核心服务包括IdleSim（放置产出）、SealCharmWallet（封印符经济）、YaoCodex（八妖图鉴）、AdHubBoot（广告聚合中枢）。

妖潮攻防模块由YaotideLauncher统一调度：YaotideLevel按种子加载妖灾词条与波次，YaotideSim执行每帧的妖物推进、封印塔攻击与结算，YaotideView负责战场渲染，YaotideFormationCodec负责布阵序列化，YaotideRunResult输出战局结算。妖契日局由DailyRift驱动，RiftOfflinePay负责离线符结算。

```
BootRunner → BootSequence → BootServices
                           ├── IdleSim（放置产出）
                           ├── SealCharmWallet（封印符经济）
                           ├── YaoCodex（八妖图鉴）
                           └── AdHubBoot（广告聚合）
YaotideLauncher → YaotideLevel（妖灾词条/波次）→ YaotideSim → YaotideView
                → YaotideBattleLaunch → YaotideRunResult
                → YaotideFormationCodec（布阵码）
DailyRift（妖契日局）→ RiftOfflinePay（离线符）
MainUI（五入口）→ TdTutorialFlow / TdTutorialData（新手教学）
```

## 4. 核心模块设计

### 4.1 放置挂机系统

IdleSim在后台持续计算封印符与养成资源的产出。产出速率由已封印妖物与防线等级决定，退出游戏时记录时间戳，再次上线时由RiftOfflinePay结算离线符收益。挂机层为塔防局提供经济基础，形成"挂机攒符—布防消耗—封印增值"的循环。

### 4.2 妖潮攻防系统

YaotideSim是核心战斗模块。每局妖潮沿S形折线路径进攻，玩家在塔位上布设封印防线：

- **图鉴轮换布防**：可用封印塔随八妖图鉴的收集进度轮换解锁，构筑方向由收集进度驱动
- **战斗中随赚随布**：战斗进行中持续产出符资源，可即时增补防线，无需暂停
- **穷奇斩杀线**：妖物推进至穷奇斩杀线即触发失败判定，防线布局需兼顾路径覆盖与输出节奏
- **中途精英封印**：精英妖可在推进途中被封印入册，直接进入图鉴，形成战斗与收集的联动

波次内容与妖灾词条由YaotideLevel按种子加载，同一种子在任意设备上复现一致的战局。

### 4.3 妖灾种子局系统

每局战斗附加妖灾词条（共五类），由种子决定当局生效组合。词条改变妖物血量、速度、波次密度等参数，配合穷奇斩杀线形成局局不同的压力曲线。种子决定一切随机内容，离线与在线行为完全一致。

### 4.4 八妖封印图鉴系统

YaoCodex记录已封印的妖物。图鉴共八妖，每妖有独立的属性面板与封印背景描述。图鉴进度驱动布防轮换池的解锁，集齐系列触发图鉴完成度奖励。封印入册的妖物同时反哺放置层的产出加成。

### 4.5 封印符经济系统

SealCharmWallet管理封印符的获取与消耗：挂机产出、战局结算、妖契日局奖励为主要来源；布防增补与图鉴解锁为主要去向。SealDisclosure负责封印过程的披露与结算展示。经济曲线按种子框架值锚定，全部持久化于本地。

### 4.6 妖契日局与新手教学系统

DailyRift驱动妖契日局三件：日历种子局（按日期生成当日契约战局）、灰度门（按进度分级开放内容）、开放数据榜（微信开放数据域单键KV驱动的好友排行）。TdTutorialFlow与TdTutorialData承载塔防教学切片，NewbieConfig配置首局引导节奏，TutorialFlow保留通用引导流程。

## 5. 数据持久化

全部持久化采用PlayerPrefs本地存档，零服务器依赖。YaotideFormationCodec将布防布局序列化为紧凑码串存档：

```json
{
  "seed": 20261010,
  "charms": 320,
  "codex": ["yao_qiongqi", "yao_hunta", "yao_bifang"],
  "formation": "a3b1c4d2e0f5",
  "riftDate": "2026-10-10",
  "offlineStamp": 1760000000
}
```

存档在每局结算与退出游戏时自动写入，加载时按种子与版本号做兼容校验。

## 6. 社交与增长

好友排行榜由微信开放数据域单键KV驱动，无需自建服务器。AdHubBoot聚合广告点位调度，广告收益与离线符、日局奖励挂钩，转化数据随战局结算上报。分享内容随封印入册与图鉴达成生成。

## 7. 技术特点

- 放置与塔防双循环融合，挂机经济直接供给战斗布防
- S折线路径+穷奇斩杀线的攻防判定，战斗中随赚随布的即时策略
- 种子决定论架构：妖灾词条、波次、离线收益全量可复现
- 八妖封印图鉴驱动布防轮换，收集与战力成长联动
- 妖契日局三件（日历种子局/灰度门/开放数据榜），零服务器红线下的每日内容框架
- 代码基于Unity引擎C#编写，命名空间Sy.P04统一管理
