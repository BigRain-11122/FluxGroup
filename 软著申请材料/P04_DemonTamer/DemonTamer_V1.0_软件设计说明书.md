# 这妖我收了游戏软件 V1.0 软件设计说明书

## 1. 软件概述

这妖我收了是一款东方神话题材放置养成游戏，运行于Unity引擎，面向Android与iOS小游戏平台。玩家扮演收妖师，在妖界地图中探索封印各类妖灵，通过放置挂机积累资源，养成妖将阵容，挑战爬塔副本与领地争夺。

游戏采用放置挂机核心循环：IdleSim在后台持续计算资源产出与妖将经验，BattleLauncher驱动爬塔与领地战斗，BuildService管理妖将养成与装备强化。玩家上线时收取挂机收益，消耗资源强化阵容后挑战更高层数。

命名空间为Sy.P04，运行时代码共14个.cs文件，有效代码行1965行。

## 3. 系统架构

游戏启动流程由BootRunner驱动，依次执行BootSequence中的场景切换，注入BootServices注册的单例服务。核心服务包括SaveService（本地存档）、IdleSim（放置计算）、BuildService（养成强化）、ShareService（微信分享）。

战斗模块由BattleLauncher统一调度：传入TowerState当前爬塔层数与TeamState已上阵妖将，BattleView负责渲染战斗动画、伤害飘字与技能特效。战斗采用自动回合制，妖将按速度顺序释放技能。

```
BootRunner → BootSequence → BootServices
                           ├── SaveService
                           ├── IdleSim
                           ├── BuildService
                           └── ShareService
MainLoop → IdleSim（后台产出）→ BattleLauncher（爬塔/领地）→ BattleView
         → BuildService（养成）→ CollectionBook（图鉴）
```

## 4. 核心模块设计

### 4.1 放置挂机系统

IdleSim在后台持续计算资源产出。产出速率由已上阵妖将的总战力与领地建筑等级决定。挂机收益上限为8小时，超过后不再累积，鼓励玩家定期上线收取。

资源类型包括：妖力（升级妖将）、魂晶（抽卡货币）、灵石（通用货币）、领地贡献（联盟玩法）。IdleSim每帧更新产出计时器，退出游戏时记录时间戳，再次上线时计算离线收益。

### 4.2 妖将收集系统

妖将分为五个品级：凡品、良品、上品、极品、神品。每个妖将有独立的属性成长、技能组与阵营标签。阵营分为：妖族、鬼族、仙族、人族、魔族，同阵营上阵触发羁绊加成。

抽卡系统由GachaSim驱动，消耗魂晶进行单抽或十连抽。保底机制：每10次抽卡必出上品及以上，每80次必出神品。已拥有的妖将自动转化为碎片，碎片用于升星。

### 4.3 妖将养成系统

BuildService管理妖将的升级、升星、觉醒与装备。升级消耗妖力，提升基础属性；升星消耗同名碎片，提升属性成长率；觉醒消耗觉醒石，解锁新技能或强化已有技能。

装备分为六个部位：武器、护甲、头盔、靴子、项链、戒指。装备有品质与随机词条，BuildService提供装备强化与洗练功能。

### 4.4 爬塔挑战系统

BattleLauncher驱动无尽爬塔。每层有固定的敌方阵容，层数越高敌方战力越强。战斗采用自动回合制，玩家可在战斗前调整阵容与站位，战斗中可手动释放大招。

每5层为一个Boss层，Boss有独特的技能机制。通关Boss层获得大量魂晶与装备奖励。TowerState记录当前最高层数，每日重置后可快速扫荡已通关层。

### 4.5 领地争夺系统

领地玩法为轻度SLG元素。玩家拥有个人领地，可建造资源建筑提升产出速率。领地可被其他玩家攻击，防守成功获得保护时间，防守失败损失部分资源。

联盟系统允许玩家组建联盟，联盟成员可互相支援防守。联盟战每周开启，联盟之间争夺领地控制权，获胜方获得专属奖励。

### 4.6 图鉴收集系统

CollectionBook记录已收集的妖将、已通关的层数、已解锁的阵营。每解锁一个新妖将弹出CodexFlowCheck校验的动画反馈。图鉴完成度在MainUI显示百分比，完成特定成就解锁头像框与称号。

## 5. 数据持久化

SaveService使用PlayerPrefs存储关键进度，BuildSnapshotCodec序列化妖将与装备数据：

```json
{
  "towerLevel": 45,
  "demonForce": 125000,
  "soulCrystal": 8600,
  "spiritStone": 230000,
  "team": ["demon_001_lv80", "ghost_003_lv75", "xian_002_lv70"],
  "collection": {"demon_001": 5, "ghost_003": 3},
  "lastOnline": 1728500000
}
```

存档在每次收取收益与退出战斗时自动写入，离线收益根据lastOnline时间戳计算。

## 6. 社交与增长

ShareService封装微信分享接口，玩家获得神品妖将或通关高层数后弹出分享卡片。WxOpenDataBoard驱动微信开放数据域的好友排行榜，FriendBoardPanel展示好友最高爬塔层数。

AdPointFunnel控制广告点位：挂机收益翻倍、抽卡折扣、快速扫荡、加速建造四个点位，由LauncherTelemetry上报转化数据。

## 7. 技术特点

- 后台放置计算，离线收益精确到秒
- 妖将系统50+可收集妖将，5阵营5品级差异化
- 自动回合制战斗，技能特效与阵营羁绊系统
- 爬塔+领地双玩法，轻度SLG社交元素
- 代码基于Unity引擎C#编写，命名空间Sy.P04统一管理
