一、软件概述

《我想开个医院》是一款挂机当院长的医院经营模拟休闲小游戏。游戏口号为「从小诊所卷到三甲盖章——你的疯狂医院人生」：玩家扮演院长，从一间无证小诊所起步，开科室接诊、雇佣奇葩医生、应对考察事件流，一路冲过一级、二级、三级医院评审，最终拿到三甲盖章；全程喜剧包装，挂机也可推进。

核心玩法循环：开科室接诊（挂号自动产金币）→ 升级科室 / 招奇葩医生 → 声誉值随考察与事件波动 → 医院等级评审晋升（小诊所→一级→二级→三级→三甲盖章五阶）→ 解锁更离谱的科室与事件族。每次循环的院长决策不超过三个：开哪个科室、雇谁、升哪级，单决策 60 秒内可完成。

二、运行环境

软件环境微信客户端（需支持微信小游戏运行时）；游戏为纯离线可玩，无服务器依赖
硬件环境iOS / Android 智能手机，竖屏触屏操作，无特殊硬件要求
分辨率竖屏设计分辨率，自动适配

三、安装与启动

本软件为微信小游戏，无需下载安装：在微信客户端内搜索名称或扫描分享二维码即可打开游玩。首次进入自动进入开局引导（T+3 秒内出现像素医院立面与病人长龙钩子画面）；退出后再进自动加载本地进度。

四、界面说明

游戏采用像素医院立面竖卷界面（随医院等级竖向生长，立面即进度条）：

  • 医院主页：像素医院立面场景 + 金币 / 声誉双面板 + 科室槽位 + 事件卡弹层；
  • 评审演出层：等级评审节点触发盖章仪式或翻车喜剧动画（同场景覆盖层）；
  • 图鉴页：病症 / 医生 / 药品三册 Tab + 荣誉墙 + 分享卡生成；
  • 结局页：三甲盖章动画 + 荣誉墙长图生成 + 二周目按钮；
  • 回访弹层：「你不在时」离线摘要（夜间急诊潮推进结算）。

五、基本操作

  • 开科室：预设槽位制，院长只选「开什么」不选「放哪里」；科室树随医院等级解锁；挂号与床位费双线自动产金币（挂机无死局，冷清只是差评喜剧）；
  • 雇医生：卡牌雇佣奇葩医生（三秒医生、偏方郎中、摸鱼主任、王大力骨科、夜班小护、变美研究所主任），各带被动加成与「乱来」副作用（喜剧演出而非管理负担），值班表自动排班；
  • 升等级：硬指标（科室数 / 治愈率 / 声誉）达标 + 考察事件表现双轨评审；评审不过触发整改喜剧，冷却后可再评——等级是新玩法门票，不是卡人墙；
  • 应对考察：卫生大检查（突击装忙）、领导视察（彩排式痊愈表演）、神秘病人暗访等考察大事件与日常喜剧事件以事件卡弹出，点卡选择化解方式，考察分结算为声誉值 ±；
  • 医生十连抽：可选增益位（每日 3 次上限，当日第 4 次在播放前拒绝），不付费、纯激励视频；
  • 离线收益：离线时段医院照常运转（夜间急诊潮），回访时领取「你不在时」摘要，可选观看激励视频将离线收益翻倍；
  • 二周目：三甲盖章结局后开启二周目继承（专家团队跳槽跟随）。

六、分享与荣誉

医院立面即进度条：等级越高立面点亮越满，三甲全点亮即荣誉墙长图，可生成分享卡炫耀（从零证小诊所到三甲盖章的疯狂医院人生）。分享为离线卡面形态，无联网对抗、无诱导分享依赖。

七、常见问题（FAQ）

  • 医院冷冷清清没病人？——病人流量是声誉的函数：考察过关、化解喜剧事件可以提升声誉，声誉走高后病人排起长龙、锦旗挂满墙；
  • 医生「乱来」了怎么办？——奇葩医生的乱来副作用是喜剧演出（例如偏方治出离谱效果），不影响经营数值安全，值班照常；
  • 等级评审没过？——触发整改喜剧动画（评审专家被怪药副作用送进自家病房），冷却后重新评审即可，不存在锁死；
  • 离线收益怎么算？——离线时段按夜间急诊潮推进，回访弹层一次性结算；翻倍收益为可选激励视频位；
  • 换手机进度会丢吗？——进度采用本地权威存档（四态存取 + 版本迁移 + 坏档自动降级），本版本未启用云同步（零服务器设计）。
