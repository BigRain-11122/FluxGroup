软件功能与技术特点（七条）

1. 挂机经营核心挂号收入引擎（病人流量 = 声誉函数，挂号 / 床位费双线产金币）+ 科室预设槽位制（院长只选「开什么」不选「放哪里」）+ 医生值班表自动排班；单决策 60 秒内完成，挂机无死局。
2. 五阶评审晋升无证小诊所→一级→二级→三级→三甲盖章五阶（R1-R5），晋升门 = 硬指标（科室数 / 治愈率 / 声誉）+ 考察事件表现双轨判定；评审不过触发整改喜剧（冷却重评），等级 = 新玩法门票而非卡人墙。
3. 考察系统事件族卫生大检查（突击装忙）/ 领导视察（彩排式痊愈表演）/ 神秘病人暗访等考察大事件 + 日常喜剧事件流（调度、连锁、阶段限定池），考察分结算为声誉值 ±（0-100 分段双向波动），失败 = 翻车喜剧可恢复。
4. 奇葩医生与图鉴医生卡牌雇佣（三秒医生 / 偏方郎中 / 摸鱼主任等，各带被动加成 + 乱来副作用）+ 病症 / 医生 / 药品三册图鉴 + 三甲盖章结局与二周目继承（专家团队跳槽跟随）。
5. 零服务器离线结算夜间急诊潮离线推进 +「你不在时」回访摘要 + 离线收益可选翻倍；本地权威存档（四态存取 / 版本迁移 / 腐坏自动降级永不丢失进度），全玩法零联网对抗。
6. 确定性仿真内核纯 C# 零随机数运行时（全库实测零 Random 调用），事件轮转 / 值班派生 / 判决结算全确定性、同输入可回放，支撑全自动化回归门禁（专项断言族 12+ 族全绿，含判决律 Oracle 族 11 断言、事件引擎 18 断言、评审门 16 断言）。
7. 遥测与广告合规35-id 事件埋点注册表与代码双向对账零漂移；广告全为可选增益位（医生十连抽 3 次/日上限、离线翻倍、救急 Offer），无插屏打扰前窗，纯激励视频变现。
