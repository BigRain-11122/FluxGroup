# 守夜人游戏软件 V1.0 软件设计说明书

## 1. 软件概述

守夜人是一款冰雪末日题材生存经营游戏，运行于Unity引擎，面向Android与iOS小游戏平台。玩家扮演极寒营地的守夜人，管理柴粮铁三类资源，建造与升级营地设施，派出名将凿冰采集，在寒潮之夜维持炉火与营地运转，通过守夜中枢统筹昼夜经营。

游戏采用昼夜循环结构：白天由CampBuilder管理城建与工位派遣，ResourceBank结算三资源产出；夜晚进入寒潮引擎（ColdWave）驱动的生存阶段，炉火（FurnaceSim）持续消耗燃料抵御低温。每完成一个昼夜周期，NightOffline结算离线收益，NightWatchHub守夜中枢汇总面板状态。

命名空间为Sy.P05，运行时代码共17个.cs文件，有效代码行2120行。

## 3. 系统架构

游戏启动流程由BootRunner驱动，依次执行BootSequence中的场景切换，注入BootServices注册的单例服务。核心服务包括ResourceBank（三资源库）、CampBuilder（城建）、ColdWave（寒潮引擎）、FurnaceSim（炉火生存）与NightWatchHub（守夜中枢）。

生存模块由FurnaceSim统一调度：传入当前天数与营地状态，每帧计算温度衰减与燃料消耗，FurnaceView负责渲染炉火特效、温度仪表与暴风雪粒子。寒潮引擎ColdWave按30分钟夜的节奏驱动双倍消耗阶段。

```
BootRunner → BootSequence → BootServices
                           ├── ResourceBank（柴粮铁）
                           ├── CampBuilder（城建与工位）
                           ├── ColdWave（寒潮引擎）
                           ├── FurnaceSim（炉火生存）
                           └── NightWatchHub（守夜中枢）
DayCycle → CampBuilder（白天建造/工位派遣）→ ResourceBank（产出结算）
         → ColdWave（夜晚寒潮）→ FurnaceSim（温度维持）
NightOffline（离线结算）→ MainUI / NewbieConfig / TutorialFlow
```

## 4. 核心模块设计

### 4.1 炉火生存系统

FurnaceSim是核心生存模块。营地温度由炉火等级与燃料量决定，温度低于阈值时开始积累寒冷惩罚。燃料分为多档品质，燃烧效率依次提升。温度衰减随暴风雪强度上升，保温类建筑提供衰减减免。FurnaceSim每帧更新温度值，FurnaceView渲染炉火与温度仪表。玩家需在燃料储备与温度需求之间做平衡决策。

### 4.2 三资源库系统

ResourceBank管理柴、粮、铁三类核心资源。柴是炉火燃料的主来源，粮维持工位与名将体力，铁用于城建升级。资源产出由工位派遣与建筑等级决定，消耗路径覆盖建造、升级、燃料与采集加速。资源曲线按数值包锚定，存量与产率在守夜中枢实时汇总。

### 4.3 城建系统

CampBuilder管理营地的建筑建造与升级，共十座设施，覆盖产出、保温、仓储与功能性建筑。建造成本按幂律曲线增长，避免后期资源溢出；每座建筑关联工位池，派遣状态影响对应资源线的产率。CampBuilder在建造时校验资源可用性，升级提升产出效率或功能效果。

### 4.4 名将挖冰系统

HeroDig驱动名将凿冰采集玩法。共八名可派遣名将，每将有独立的采集属性与加成方向；名将具有双态（工作态与休整态），凿冰设有加速窗口（配合广告点位），高窗口时段产出显著提升。名将派遣与工位系统联动，构成白天经营的主要操作面。

### 4.5 寒潮引擎系统

ColdWave是夜晚生存的节奏引擎。寒潮以30分钟夜为单位降临，期间资源双倍消耗；寒冷惩罚设有封顶，避免不可逆崩局；连续生存困难时提供48小时豁免缓冲；守夜塔与关羽减免提供两条对抗路线。寒潮参数由NightConfig数值包逐项锚定，强度曲线随天数推进。

### 4.6 守夜中枢与离线结算系统

NightWatchHub是营地的统一面板中枢，汇总温度、资源、工位、名将、寒潮倒计时等状态。NightOffline负责离线结算：退出游戏时记录时间戳，再次上线时按离线时长与建筑状态计算离线产出，离线收益精确到秒。

## 5. 数据持久化

全部持久化采用PlayerPrefs本地存档，零服务器依赖：

```json
{
  "day": 23,
  "temperature": 18,
  "bank": {"wood": 150, "food": 320, "iron": 80},
  "buildings": {"furnace_lv3": true, "sawmill_lv2": true, "tower_lv1": true},
  "heroes": [{"id": "guanyu", "state": "work", "stamina": 90}],
  "coldwave": {"nightStreak": 4, "exemptUntil": 1760000000},
  "offlineStamp": 1760000000
}
```

存档在每个昼夜结束与退出游戏时自动写入，加载时做版本号兼容校验。

## 6. 社交与增长

好友排行榜由微信开放数据域单键KV驱动，无需自建服务器。AdHubBoot聚合广告点位调度，名将加速窗口、离线收益翻倍等点位与经营节奏挂钩。NewbieConfig配置新手引导流程，TutorialFlow通过高亮交互区域完成教学。

## 7. 技术特点

- 实时温度模拟系统，炉火与寒潮双引擎动态对抗
- 三资源库+幂律城建成本+工位池，长线经营曲线可控
- 名将挖冰双态机制，采集与加速窗口联动
- 寒潮30分钟夜节奏：双倍消耗、惩罚封顶、48小时豁免的容错设计
- 守夜中枢统一面板，离线结算精确到秒
- 代码基于Unity引擎C#编写，命名空间Sy.P05统一管理

## 8. Steam买断分支说明

本项目规划Steam买断制分支。Steam版移除广告点位，改为纯单机生存经营体验：移除全部IAA广告点位与加速窗口，增加深度内容（更多建筑类型、名将技能树、寒潮事件线），支持Steam成就与云存档，定价策略为买断制，后续DLC扩展内容。
