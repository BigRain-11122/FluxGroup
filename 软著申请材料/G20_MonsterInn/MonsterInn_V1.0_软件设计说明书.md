# 今夜有妖游戏软件 V1.0 软件设计说明书

## 1. 软件概述

今夜有妖（MonsterInn）是一款中式志怪客栈经营游戏。白天筹备经营（采购、扩建、研习菜谱），夜晚接待各有习性来历的妖客；治愈与微恐平衡，妖客图鉴与志怪故事构成收集长线。国内微信/抖音双栈为主盘，海外H5渠道候选。

## 2. 运行环境

- 硬件环境：ARM四核及以上移动处理器，2GB以上内存，支持触控。
- 软件环境：Android 8.0及以上/iOS 12.0及以上，微信/抖音小游戏平台。
- 开发环境：Unity引擎（团结引擎2022.3），C#脚本，UGUI界面系统。

## 3. 系统架构

Unity引擎C#单工程架构，模块包括：昼夜循环、客房经营、妖客接待、图鉴收集、志怪剧情、存档系统。

## 4. 核心模块设计

- 昼夜循环模块：白天筹备（物资采购/房间扩建/菜谱研习），夜晚营业接待，双时段构成经营节奏。
- 妖客接待模块：每位妖客有习性与忌口，接待满意度影响报酬与图鉴解锁；微恐氛围点到即止，保持治愈基调。
- 图鉴模块：妖客图鉴收录来历故事，构成收集长线。
- 剧情模块：客栈主线随经营进度推进，志怪单元剧与图鉴联动。

## 5. 数据持久化

PlayerPrefs本地存档（客栈状态/图鉴/剧情）；排行榜走平台开放数据接口。

## 6. 社交与增长

妖客图鉴卡片分享；好友排行榜比拼客栈声望；广告激励点设置于离线收益翻倍与图鉴补抽。

## 7. 技术特点

零服务器架构；妖客与剧情数据驱动配置，运营期零代码扩充志怪内容池；题材微恐分级控制在平台审核安全带内。
