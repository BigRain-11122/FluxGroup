# 爆护游戏软件 V1.0 软件设计说明书

## 1. 软件概述

爆护（ReelRiot）是一款荒诞钓鱼游戏。「爆护」是钓友圈黑话——鱼护爆满的丰收时刻。玩家抛竿收线，通过张力控制钓起拟真与离谱混合的鱼种——从普通鲫鱼到离谱道具鱼，收录百种鱼典。"张力诚实"为核心设计律：线绷太紧会断，鱼会脱钩，收线手感真实；"首笑离谱"提供传播记忆点。

## 2. 运行环境

- 硬件环境：ARM四核及以上移动处理器，2GB以上内存，支持触控。
- 软件环境：Android 8.0及以上/iOS 12.0及以上，微信/抖音小游戏平台及Web平台。
- 开发环境：Unity引擎（团结引擎2022.3），C#脚本，UGUI界面系统。

## 3. 系统架构

Unity引擎C#单工程架构，模块包括：抛竿收线控制、鱼行为状态机、张力模拟、鱼典图鉴、经济升级、关卡深度带、存档系统。

## 4. 核心模块设计

- 收线张力模块：收线速度与鱼拉力实时对比，张力条可视化，超限断线；不同鱼种有各自的挣扎模式。
- 鱼行为状态机：咬钩-挣扎-疲乏-上岸四态，拉力曲线按鱼种参数化。
- 鱼典模块：百种鱼种图鉴，普通与离谱鱼混合投放，离谱鱼提供高奖励与传播素材。
- 深度带模块：渔场按深度分层，深层投放稀有鱼种，驱动渔具升级循环。
- 渔具升级模块：竿/线/轮三件套升级改变张力上限与收线速度，构成经济出口。

## 5. 数据持久化

PlayerPrefs本地存档：鱼典进度、渔具等级、货币、设置；排行榜走平台开放数据接口。

## 6. 社交与增长

离谱鱼获卡片分享是核心传播面；好友排行榜比拼鱼典完成度与最大鱼获；广告激励点设置在渔具折扣、离线收益翻倍等位置。

## 7. 技术特点

张力模拟参数化，保证"绷断诚实"手感一致；鱼种数据驱动投放，运营期可零代码扩充；单包体满足平台限额，冷启动小于3秒。
