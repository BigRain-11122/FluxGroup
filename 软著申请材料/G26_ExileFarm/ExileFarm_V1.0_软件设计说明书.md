# 归园田居游戏软件 V1.0 软件设计说明书

## 1. 软件概述

归园田居（ExileFarm）是一款种田文放置经营游戏。取陶渊明《归园田居》意境：玩家扮演流放者从荒地开垦起步，经历寒暑季节生存挑战，一路把流放地建成归园田居的田园之家；女性向叙事基调配漫画式演出（漫剧皮），放置挂机产出适配碎片时间。国内微信首发为主盘（女性向种田文+放置经营=微信女性/银发留存盘本位），抖音双栈第二位。

## 2. 运行环境

- 硬件环境：ARM四核及以上移动处理器，2GB以上内存，支持触控。
- 软件环境：Android 8.0及以上/iOS 12.0及以上，微信/抖音小游戏平台。
- 开发环境：Unity引擎（团结引擎2022.3），C#脚本，UGUI界面系统。

## 3. 系统架构

Unity引擎C#单工程架构，模块包括：季节循环、开垦建造、种植生产、剧情演出、离线结算、存档系统。

## 4. 核心模块设计

- 季节循环模块：寒暑季节轮转影响产出与生存压力，冬季构成阶段性挑战。
- 开垦建造模块：荒地逐步开垦为农田与家园建筑，版图成长肉眼可见。
- 放置产出模块：挂机产出按离线时间如实结算，适配碎片时间节奏。
- 剧情演出模块：种田文叙事线（流放-扎根-兴旺-昭雪）以漫画式分镜演出推进。

## 5. 数据持久化

PlayerPrefs本地存档（家园/季节/剧情/经济）；排行榜走平台开放数据接口。

## 6. 社交与增长

家园全景截图分享；好友排行榜比拼家园规模；广告激励点设置于离线收益翻倍与季节加速。

## 7. 技术特点

零服务器架构；IP红线词面机检（原剧名全串/敏感词禁入对外文案）；季节与剧情数据驱动配置，运营期零代码扩充。
