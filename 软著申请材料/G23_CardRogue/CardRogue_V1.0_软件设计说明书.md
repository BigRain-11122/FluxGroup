# 这张牌有诈游戏软件 V1.0 软件设计说明书

## 1. 软件概述

这张牌有诈是一款卡牌肉鸽游戏——单局内玩家构筑卡组逐层闯关，卡牌遵循常识规则（加减攻防、抽牌、能量），但「乘区」机制让弱牌组合叠出爆炸收益：一张不起眼的牌，配对乘数后翻盘——每张牌都有诈。递归事件、精英战与遗物构成肉鸽循环。单局15-30分钟，主打微信、抖音小游戏双平台。

## 2. 运行环境

- 硬件环境：ARM四核及以上移动处理器，2GB以上内存，200MB以上存储空间，支持触控。
- 软件环境：Android 8.0及以上/iOS 12.0及以上，微信小游戏/抖音小游戏平台。
- 开发环境：Unity引擎（团结引擎2022.3），C#脚本，UGUI界面系统。

## 3. 系统架构

采用Unity引擎C#单工程架构，按功能划分模块：卡组构筑与抽牌、乘区计算引擎、层图与事件生成、敌人行为、遗物系统、存档系统。竖屏设计1080×1920基准。

## 4. 核心模块设计

- 乘区引擎模块：伤害与效果按「基础值×乘区叠加」计算，同源乘区叠加、异源乘区相乘，构筑方向决定乘区路线——常识规则被乘区颠覆即玩法内核。
- 构筑模块：局内战斗奖励卡按稀有度发放，卡池数据驱动可扩充。
- 层图模块：每局按层图分支生成事件（战斗、商店、休息、随机事件），路线选择构成策略面。
- 敌人行为模块：敌人按意图预告出招，回合制对局，精英与首领带专属机制。
- 遗物模块：被动遗物改变乘区与规则，与卡组构筑形成组合轴。

## 5. 数据持久化

存档采用本地持久化（PlayerPrefs），解锁进度与图鉴本地保存；排行榜走平台开放数据接口，无自建服务器。

## 6. 社交与增长

构筑分享码一键复刻牌组；无尽层排行榜；广告激励点设置于开局祝福与失败复活。
