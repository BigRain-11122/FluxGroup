## 三、剩余 31 套怎么修（每套 2 分钟）

```bash
python Tools/softcopyright_docgen.py \
  --project <该项目 Unity 根> \
  --name "<申请表里的软件全称>" \
  --ver V1.0 \
  --out "软著申请材料/<目录>/<原文件名>_软件设计说明书.pdf" \
  --md  "软著申请材料/<目录>/<原文件名>_软件设计说明书.md"
python Tools/softcopyright_audit.py --only <目录>
```

- 软件全称从各自 `申请表填写指南.md` 的「软件全称」一行取，必须与源程序页眉逐字一致。
- 7 套 C2 行数不足的项目，需重新切页（每页 55 行）后重出源程序 PDF。
- `G09_医院大当家` 先补 512×512 图标。

## 四、流程规则（防再犯）

1. **提交前必跑** `softcopyright_audit.py`，红一条不许送审。
2. 说明书由 `docgen` 生成，禁手写页数不足的短文档。
3. 全称/版本只在 `申请表填写指南.md` 定义一次，其余文件引用，禁各自维护。
4. 4 套 CCPC 格式单独建规则，不与提交格式混用同一套判据。
