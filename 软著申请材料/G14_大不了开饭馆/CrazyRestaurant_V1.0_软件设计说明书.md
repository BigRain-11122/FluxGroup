# 大不了开饭馆游戏软件 V1.0 软件设计说明书

## 1. 软件概述

大不了开饭馆（CrazyRestaurant）是一款餐厅经营喜剧游戏。"阶层晋升即剧情"为本源：玩家从路边摊起步，一路晋升到大排档、酒楼、连锁集团，每次晋升解锁新剧情——小人物翻身故事与经营玩法一体推进。

## 2. 运行环境

- 硬件环境：ARM四核及以上移动处理器，2GB以上内存，支持触控。
- 软件环境：Android 8.0及以上/iOS 12.0及以上，微信/抖音小游戏平台。
- 开发环境：Unity引擎（团结引擎2022.3），C#脚本，UGUI界面系统。

## 3. 系统架构

Unity引擎C#单工程架构，模块包括：接单烹饪、顾客流、雇员管理、装修扩张、剧情晋升、存档系统。

## 4. 核心模块设计

- 烹饪模块：按订单菜谱备料烹饪，火候/时序操作构成轻度动作要素。
- 顾客流模块：顾客按口碑与时段生成，耐心值超时流失，好评积累驱动客流。
- 雇员模块：厨师/服务员雇佣培养，分工解放玩家双手，向挂机经营过渡。
- 装修扩张模块：店面装修与桌位扩张提升容量与客单价。
- 剧情晋升模块：营收里程碑触发阶层晋升（路边摊→大排档→酒楼→连锁），每次晋升解锁对应剧情章节。

## 5. 数据持久化

PlayerPrefs本地存档（店铺/雇员/剧情/经济）；排行榜走平台开放数据接口。

## 6. 社交与增长

店铺晋升截图分享；好友排行榜比拼店产规模；广告激励点设置于加速烹饪与离线收益翻倍。

## 7. 技术特点

零服务器架构；顾客流与剧情数据驱动配置；晋升线数值诚实（营收里程碑如实累计），成长可预期。
