# 这一箭稳了游戏软件 V1.0 软件设计说明书

## 1. 软件概述

这一箭稳了是一款射箭物理超休闲游戏——拉弓放箭命中目标即过关，拉力决定射程、抛物线与风力构成物理判定。每次放箭前都笃定「这一箭稳了」，下一秒往往翻车——故意失败演出与挑衅式文案构成喜剧钩，失败位复活构成变现位。单局15-45秒，主打微信、抖音小游戏双平台。

## 2. 运行环境

- 硬件环境：ARM四核及以上移动处理器，2GB以上内存，100MB以上存储空间，支持触控。
- 软件环境：Android 8.0及以上/iOS 12.0及以上，微信小游戏/抖音小游戏平台。
- 开发环境：Unity引擎（团结引擎2022.3），C#脚本，UGUI界面系统。

## 3. 系统架构

采用Unity引擎C#单工程架构，按功能划分模块：弓箭物理、目标与关卡梯度、失败演出与挑衅文案、皮肤收集、难度自适应、存档系统。竖屏设计1080×1920基准。

## 4. 核心模块设计

- 弓箭物理模块：拉弓力度映射初速度，箭矢受重力与风力影响按抛物线飞行，命中判定按接触面计算。
- 关卡梯度模块：目标距离、移动目标与风况组合生成难度梯度，难度曲线按连中/连失自适应微调。
- 失败演出模块：失手瞬间镜头拉近+慢放+挑衅文案（「就差一点」「下次一定」式话术），构成分享素材。
- 皮肤模块：弓与箭皮肤按成就解锁，皮肤试用与广告激励位绑定。
- 变现模块：失败位复活广告为唯一变现位，15-30秒规格，零弹窗干扰。

## 5. 数据持久化

存档采用本地持久化（PlayerPrefs），关卡与皮肤进度本地保存；排行榜走平台开放数据接口，无自建服务器。

## 6. 社交与增长

失败瞬间短视频一键分享（挑衅文案即传播点）；好友连中纪录比拼；广告激励点设置于失败复活。

## 7. 技术特点

零服务器架构；关卡与文案数据驱动配置，运营期零代码扩充；红线词面机检（原对标名全串/敏感词禁入对外文案）。
