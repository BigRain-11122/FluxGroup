## 一、价格锚：不是"便宜"，是"回到 2016–17"

> **2026-11-16 修正（读到一手开盘价与 20 笔成交后）**：9,000 起是 **13# 公寓（40 年产权、50–60㎡）** 的价格；**住宅高层 9#（85/129/141㎡）2016-09 一手开盘就是 19,000–20,000 元/㎡**。所以本套不是"回到 2017"，而是**比 2016 年一手发行价低 35%**。同时按同面积段成交比，本套只便宜 9–11%（详见 `COMMUNITY-20261116-yunjiaoyuan.md`）。

天鸿尹山湖韵佳苑均价（安居客历史）：

| 时间 | 均价（元/㎡） | 相对本套 12,727 |
|---|---|---|
| 2016-09 住宅高层一手 | **19,000–20,000** | **−35%** |
| 2016–17 公寓 13#（40 年） | 9,000–11,000 | — |
| 2023-11 | 23,001 | −45% |
| **2023-12（峰值）** | **23,154** | **−45%** |
| 2024-12 | 19,618 | −35% |
| 2025-11 | 17,470 | −27% |
| 2026-08（本轮低点） | 15,820 | −20% |
| 2026-11 | 17,106 | −26% |
| **本套** | **12,727** | — |

**三个判断：**

1. **从峰值跌了 45%，跌回 2017 年**。这不是"小幅回调"，是一轮完整周期的回吐。
2. **比 2026-08 的低点（15,820）还低 20%**，比近一年成交下限（12,953）还低 2%。**这个价不是市场价，是"个例价"**。
3. **租金却是 2026 年的**：同小区 98㎡ 三房租 3,675–4,300，135㎡ 估 4,600。**价格回到 2017、租金留在 2026，租售比因此被"时间差"抬到 3.2%（整租）/ 5.2%（改两套）**——这是它唯一真正的价值来源。

**最容易被忽略的两个角色：银行（评估价）和税务（满五唯一）。** 这两个直接改变首付和总成本，各差 3–8 万。

## 五、推荐工作流（七步 SOP，每步都有工具）

```
① 筛房    板块评分 → 小区清单 → 总价/面积/楼层
          工具：sector_score.py（板块七维）
② 体检    价格分位 / 户型 / 楼层 / 房龄 / 流动性
          工具：analyze_listing.py
③ 尽调    五查：产权 / 原始户型 / 硬伤 / 税费 / 急售
          工具：人工 + 产证附图 + 现场三时段看房
④ 估值    银行评估价 → 实际首付 → 税费
          工具：本表 + 银行预审
⑤ 改造    轻改 / 分间 / 两套 → 成本与工期
          工具：gen_drawings.py（12 张图）+ plan_dxf.py（DXF+算量）
⑥ 持有    现金流 / IRR / 盈亏平衡涨幅
          工具：hold_model.py + rental_econ.py
⑦ 运营    定价 / 渠道 / 带看 / 留存
          工具：LANDLORD-PLAYBOOK-v1.md
```

**每步的"过/不过"判据：**
① 板块评分 ≥70；② 单价 ≤ 小区均价 85%；③ 五查全过；④ 首付不超过可动用现金 70%；⑤ 改造回本 ≤ 持有年限；⑥ 盈亏平衡涨幅 ≤ 你的房价预期；⑦ 出租率 ≥85%。

## 八、出价与决策

**五查全过：**
- 出价：挂牌 172 万 → 首轮 **162 万**，目标 **165–168 万**。
- 首付：**30–50%**（15% 的 IRR 高 0.5 个点，但月补 2,300，现金流压力大）。
- 改造：持有 ≥8 年 → **改两套**；只持 5 年 → **不改，简装整租**。

**任何一项不过：**
- 压到 155–160 万；压不下来就放弃。**便宜 10 万不值得背一个卖不掉的硬伤。**
