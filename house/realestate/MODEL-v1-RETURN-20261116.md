# 房产投资回报模型 v1（机构口径 · 方法论）

> 2026-11-16　｜　执行器：`Tools/house/return_model.py`　｜　配置：`model-config-*.json`
> 目标：把"拍脑袋算回报"换成**可复算、可审计、可压力测试**的现金流模型。

---

## 一、为什么说它是"机构级"

模型采用的指标与口径，都是行业与监管的通用语言：

| 指标 | 定义 | 谁在用 | 本模型阈值 |
|---|---|---|---|
| **NOI**（净营运收入） | 有效租金 − 运营费 − 增值税/房产税（不含所得税、融资、资本支出） | NCREIF / ULI / CCIM | 越高越好 |
| **Cap Rate** | NOI ÷ 总成本 | 商业地产估值通用 | 住宅 2–3.5%；>3.5% 优秀 |
| **DSCR** | NOI ÷ 年还本息 | 银行审贷 | ≥1.25 安全；<1 需自补 |
| **Cash-on-Cash** | 税前现金流 ÷ 权益 | 私募地产基金 | ≥0 为好 |
| **IRR** | 使 NPV=0 的折现率 | CFA/CFA Institute 标准 | ≥5% 跑赢理财；≥8% 优秀 |
| **NPV** | 按目标收益率折现的净现值 | DCF 通用 | >0 才创造价值 |
| **Equity Multiple** | 累计分配 ÷ 权益 | 基金业绩披露 | ≥1.5x / 10 年 |
| **压力测试** | 房价/租金/利率/空置/超支 单因素冲击 | 银保监房地产贷款压力测试思路 | 看 IRR 变化 |

**关键：本模型不发明指标，只用行业标准指标，且每个指标都写清分母。**

## 二、模型结构（六段流水）

```
① 收入   单元租金 × 12 × (365−空置天数)/365 × (1−坏账率) × (1+租金增长)^(t−1)
② 运营   物业费(元/㎡·月) + 维修(租金%) + 家电准备金 + 保险 + 管理费(租金%) + 招租成本 + 空置水电
③ 税费   增值税(1.5%) + 个人所得税(10%×经营净额) + 房产税(参数，苏州住宅为 0)
④ 融资   等额本息：月供 = P·i(1+i)^n / ((1+i)^n−1)；评估价系数影响实际可贷额
⑤ 资本   初始改造 capex + 大修准备金（每 N 年 × 元/㎡）
⑥ 退出   卖出价 = 买入价×(1+g)^n；净得 = 卖出价 − 剩余贷款 − 卖出税费
```

**现金流分层：**
- **NOI**（运营层）→ 用于 Cap Rate、DSCR
- **CF** = NOI − 所得税 − 还贷 − 大修 → 用于 CoC、IRR
- **退出净得** 加在最后一年 → 用于 IRR、NPV、EM

## 四、自检（每次运行都做）

```bash
python Tools/house/return_model.py --self-test
```

三项断言：
1. **摊还归零**：30 年后贷款余额 ≈ 0（误差 <1 元）。
2. **NPV@IRR ≈ 0**：IRR 定义自洽（误差 <1 元）。
3. **无杠杆一致性**：全款时，CF 应等于 NOI − 所得税。

> 本轮三项全部通过。**模型改动后必须先跑自检，再谈结果。**

## 五、本套结果（首付 30%、二套 3.3%、持有 10 年、g=2%）

### 5.1 不改（整租 4,600）

| 指标 | 数值 | 判据 |
|---|---|---|
| NOI（首年） | 3.85 万 | — |
| Cap Rate（总成本 / 房价） | **2.14% / 2.24%** | 偏低（住宅常态） |
| Cash-on-Cash（首年） | **−4.29%** | 负，需自补 |
| **DSCR** | **0.64** | **<1，租金覆盖不了月供** |
| IRR（10 年） | **3.70%** | 低于 5% 门槛 |
| NPV @5% | **−8.00 万** | 负，未创造价值 |
| 权益倍数 | 1.51x | 一般 |
| 总损益 | 30.24 万 | — |
| 盈亏平衡涨幅（10 年） | 0.38% | 横盘略亏 |

### 5.2 改两套（7,400/月，改造 22 万）

| 指标 | 数值 | 对比不改 |
|---|---|---|
| NOI（首年） | 5.76 万 | +1.91 万 |
| Cap Rate | **2.90% / 3.35%** | +0.76pp |
| Cash-on-Cash | **−1.05%** | +3.24pp |
| **DSCR** | **0.96** | **接近覆盖** |
| IRR（10 年） | 3.25% | **−0.45pp** |
| NPV @5% | −12.41 万 | 更负 |
| 总损益 | 30.30 万 | 基本持平 |
| 盈亏平衡（5 年） | 1.80% | 更高（改造成本拖累） |

**核心结论：改造把 DSCR 从 0.64 拉到 0.96（现金流安全性大幅改善），但 IRR 反而降 0.45pp（22 万 capex 拖累）。**
**改造买的是"扛得住"，不是"赚更多"。**

## 六、敏感性：哪个变量最要命

| 冲击 | 不改 IRR | Δ |
|---|---|---|
| 房价涨幅 −4pp | −7.14% | **−10.84pp** |
| 利率 +100bp | 2.39% | −1.31pp |
| 租金 −10% | 3.15% | −0.55pp |
| 空置 +30 天 | 3.21% | −0.49pp |
| 改造超支 +30% | 3.56% | −0.14pp |

**排序：房价 > 利率 > 租金 > 空置 > 改造成本。**
**这解释了为什么"改造能力"不能作为投资主线——它影响最小，房价才是决定性的。**

## 七、蒙特卡洛（2000 次）

假设：房价涨幅 ~N(2%, 5%)、租金增长 ~N(2%, 1.5%)、空置 U(−10, +30 天)、改造成本 ×0.9–1.35。

| 分位 | 不改 | 改两套 |
|---|---|---|
| P10 | **−30.5%** | −21.4% |
| P50 | **3.1%** | 2.4% |
| P90 | 14.7% | 12.8% |
| **亏损概率** | **39.6%** | 40.6% |

**读法：在"房价年化 2% 上下浮动 5%"的假设下，有四成概率亏钱。**
这不是模型悲观，是**波动率决定的**——房价 ±5% 的年度波动，10 年复合后足以吃掉全部回报。

## 十、局限（诚实边界）

1. **不含房产税**：苏州未开征，参数留 0；试点城市需填 0.4–1.2%。
2. **个税按核定 10%**：实际可能按 1–2% 综合征收或据实扣除，**会高估税负**。
3. **不含土地增值税**：个人住宅转让暂免，若为非住宅需补。
4. **不含装修带来的溢价**：改造只体现在租金，不体现在卖出价（保守处理）。
5. **房价涨幅是外生假设**：模型不给预测，只做情景与概率。
6. **未含季节性空置**：按年均天数处理。

## 十一、结论

1. **模型可用**：自检通过、指标齐全、可适配任意房源与改造方案。
2. **本套不加杠杆改造**：IRR 3.70% < 5% 门槛，NPV@5% 为 −8 万——**按机构标准，这笔投资不达标**。
3. **改造不改变结论**：改两套 IRR 3.25%，现金流更安全但回报更低。
4. **要让它成立，必须满足其一**：①买入价再降 10–15%；②房价年化 ≥3%；③利率回到 3.0% 且首付降到 20% 以下。
5. **下一步**：用同一模型扫描 10 个候选房源，按 IRR/NPV 排序，只对前 3 名做现场尽调。

---

## 十二、一句话

**机构不看你"觉得能赚多少"，只看三件事：NOI 能不能覆盖月供（DSCR）、折现后是不是正价值（NPV）、压力下会不会爆（蒙特卡洛）。**
**这套房的三项答案分别是：0.64、−8 万、40% 概率亏。**
