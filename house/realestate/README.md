# 地产线 · 研究部（house/realestate）

本目录存放地产线的研究与决策文件。改造工程、施工图、产品手册在同级 `house/rental-conversion/`。

## 正典（先读这一份）

**`LOGIC-v1-20261116.md` —— 地产线底层逻辑 v1。** 本目录其余文件都是它的应用与数据，引用不复制。
一句话：**房子不稀缺了，好房子才稀缺；租金是锚，增值是判断，杠杆是放大器；唯一能靠自己赚的是改造。**

**`PANEL-v1-20261116.md` —— 专家团（14 席 / 47 条判据 / 三态打分 / 一票否决）。** 任何"该不该买"的结论必须过它；技能入口 `.codely-cli/skills/realestate-panel/SKILL.md`，执行器 `Tools/house/panel_review.py`。

## 使用纪律

1. 政策条款以官方原文或银行/公积金中心书面答复为准（决议 R-09）。
2. 任何测算不得假设房价上涨，按"横盘 + 12 个月无法变现"做压力测试（R-02）。
3. 本纪要结论有效期 3 个月，到期复核。
