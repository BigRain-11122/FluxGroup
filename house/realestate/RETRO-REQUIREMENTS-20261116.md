## 四、接地气版结论（一页，大白话）

### 这套房（韵佳苑 135㎡，172 万）

**一句话：这套房赚钱靠"8 年后卖"，不靠"每月收租"。**

| 问题 | 答案（人话） |
|---|---|
| 每月要贴多少？ | 首付 30%：**每月贴约 1,000 元**（一年 1.2 万）；首付 15%：每月贴 2,300（一年 2.8 万） |
| 租金够还贷吗？ | **不够**。租金到手约 4,300，月供 5,274（30% 首付） |
| 8 年后能拿回多少？ | 房价年涨 2%：卖出 201 万，还完贷款到手 **约 98 万** |
| 净赚多少？ | 98 万 − 首付+税 56 万 − 8 年补贴 9.4 万 = **约 32 万** |
| 相当于年化多少？ | **约 5.6%**（比理财 3% 强，比炒股稳） |
| 什么时候不赚？ | 房价跌 2%/年 → 8 年亏约 20 万 |
| 改造做不做？ | **不做**。花 22 万，每月只少贴 1,500，8 年回不来 |
| 什么时候卖？ | 8–10 年；或房价涨到 2.2 万/㎡（市值 297 万） |

### 三个"不买"的条件

1. 中介查不到"满五唯一" → 多 1% 个税，砍价 2 万。
2. 物业书面说"不许分租" → 影响的是改造，不影响自住/整租。
3. 产证附图不是 3 室 2 厅 → 直接放弃。

### 江浙沪怎么选（一句话）

**要现金流：无锡、常州、南通（回报 2.4–2.5%）；要增值：上海、杭州；苏州靠通勤，排中间。**
