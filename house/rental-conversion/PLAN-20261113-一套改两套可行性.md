## 〇 三句话结论

1. **这套房子拆成两套独立一室户，采光能达标（8 个空间 8 个采光口：4 直接 + 4 借光），真正的硬约束只剩「第二户门」**：唯一的入户门在北墙中部，东、南都是外墙；唯一的排污立管在东侧；套 B 走东侧通道会把卫1 的东窗挡掉、卫1 要缩到 1.0m。硬拆的结果是「4 个借光口 + 一条 1 米通道 + 卫1 变极限卫」，改造 19–24 万、回收 20 年以上。
2. **真正该做的是「三居室合租 + 新增 1 个独卫」**：三个卧室全部有外墙窗（这才是真正的全明），原厨原卫各有一扇窗，改造 12–15 万，租金能到整租的 1.40–1.45 倍，回收 6–9 年。苏州条例还明确允许「12㎡ 以上的客厅隔断出一间居室」——这条路是**写在法条里的**。
3. **要「两套独立一室户」这个资产形态，正确做法是买两套现成小户型，不是把这一套切开。** 改造解决的是使用形态，买小户型解决的是资产形态，两者不在一个层级。

## 二、采光判定：按「每个空间一个采光口」的标准

**标准（2026-11-13 修订）**：每个功能空间至少有一个采光口即可，不要求每个空间都有独立外窗。采光口分两类：

- **A 直接外窗**：真正的外墙窗/阳台落地窗；
- **B 借光口**：室内窗（长虹玻璃）、玻璃砖、经阳台门的间接采光。

本户现有外窗 5 个：北墙 2（卧室A、厨房）、东墙 2（卫1、卧室B）、南墙 1（阳台）。

### 2.3 修正说明与代价

- **上一版按"每个空间必须有独立外窗"判定，口径过严**（8 个空间 5 个外窗，判"不可能"）。按行业与租客口径——"空间里有窗、白天不用开灯"——**两套是可行的**。
- 借光口不是白来的，有四个代价：
  1. **要开洞**：室内窗只能开在非承重墙上（卧室A 与客厅之间），承重墙一律不许，需现场核实；
  2. **要缩卫**：套 B 走东侧通道会挡掉卫1 的东窗，卫1 需缩到 1.0m 宽并改玻璃砖借光（1.8–2.2㎡，极限卫）；
  3. **要防潮**：借光口必须用长虹/磨砂玻璃，卫浴侧加排风，否则水汽串到卧室；
  4. **不能宣传"全明"**：借光写在图上，文案只能写"每个空间有窗/有光"，避免交付争议。
- **采光不再是障碍，剩下的唯一硬约束是第二户门**（见 §四.2）。

## 三、合规边界（先说清楚，再动手）

### 3.1 上位法：《住房租赁条例》（国令 812 号，**2025-09-15 施行**）

- 第七条：出租住房应符合建筑、消防、燃气、装修的强制性标准；**厨房、卫生间、阳台、过道、地下储藏室、车库等非居住空间，不得单独出租用于居住**。
- 第七条第三款：单间租住人数上限、人均最低租住面积，**由设区的市级以上地方政府规定**（即看苏州）。
- 第十一条：承租人**不得擅自动承重结构、不得私拉乱接水电燃气管线**。
- 第三十九条：违规出租非居住空间 / 超人数超密度 → 责令改正 + 警告；拒不改正，个人罚 **2,000–10,000 元**，单位罚 2–10 万，**没收违法所得**。
- 第八条：**必须实名签约并向房产部门备案**（不备案，纠纷中房东基本必输）。

### 3.2 地方口径：《苏州市出租房屋居住安全管理条例》第十一条——**这条是本案的钥匙**

原文要点：

1. 最小出租单位 = **一间设有外墙窗户的卧室、起居室（厅）**。
2. **卧室和使用面积不满 12㎡ 的起居室（厅）不得隔断出租。**
3. **使用面积 12㎡ 以上的起居室（厅），可以隔断出一间居室出租**（县级市/区另有规定的除外）。
4. 隔断要求：**轻质不燃材料固定围护**；隔断后**必须具备直接天然采光和自然通风条件**；不得影响疏散逃生和消防救援。
5. **厨房、卫生间、阳台、车库、地下储藏室不得出租用于居住。**
6. 第十二条：**每间居室人均使用面积 ≥4㎡，每间 ≤2 人**。

**本案客厅 23.6㎡ ≥ 12㎡ → 依苏州条例，可以合法隔断出 1 间居室。** 这是本案唯一一条「既合法、又能提租金」的路。

> **县级市例外**：常熟已明令「商品房屋起居室（厅）不得隔断出租」（2023 年 12 月规定）。昆山、太仓、张家港未见同等禁令，但**必须先查当地区政府口径**。若在常熟 → 本条关闭，只能整租或不合规分隔。

### 3.3 三条产品形态的法律定性

| 形态 | 定义 | 合法性 | 风险 |
|---|---|---|---|
| **A 真两户** | 2 扇户门、2 套独立厨卫、2 个水电表 | 无独立产权/门牌，本质是「擅自分割搭建 + 改变房屋结构」 | **高**：举报即整改，罚款 + 恢复原状 + 无法备案 + 火灾保险可能失效 |
| **B 一门两户** | 共用入户玄关，内部 2 套完整厨卫，各自独门 | 定性模糊：介于「合租」与「分割搭建」之间 | **中**：被投诉时按分割搭建处理；消防上南套疏散穿共用玄关，物业多半不认 |
| **C 合规合租** | 原户型房间（含合法隔断出的 1 间）分间出租，共享厨卫 | **明确合法**（苏州条例第 11 条） | **低**：唯一要守的是人均 4㎡、每间 ≤2 人、隔断材料与采光 |

### 3.4 如果不在苏州

| 城市 | 关键差异 | 影响 |
|---|---|---|
| 上海 | 以「原始设计或经批准改建的房间」为最小出租单位，**客厅一律不得隔断** | 方案 C 的隔断路关闭，只能原房间合租 |
| 成都 | 2026-08-15 新规：起居室不得单独出租，不得隔断室内空间 | 同上，更严 |
| 其他 | 逐案查市级住房租赁管理办法 + 区级补充规定 | 不要用「别的城市能做」当依据 |

### 3.5 绝对不可动清单

1. **承重墙、剪力墙、构造柱**——任何开洞、开槽、拆除都不行。
2. **外墙立面**——开窗、开门、装外机架、封阳台（若原为设备平台）均需审批，高层基本不批。
3. **燃气管道与表具**——只有燃气公司能动；私改是刑事责任量级。
4. **公共烟道**——不得封堵、不得改向；第二厨房禁止接入公共烟道（风压与串味）。
5. **疏散通道**——不得被隔墙、家具、储物阻断；不得让一套的疏散穿越另一套的私密空间。
6. **主立管、总表、配电总箱**——不得移位、不得私接。

### 4.1 布局（详见配图下半幅）

| | 套 A（北套）≈ 34㎡ | 套 B（南套）≈ 34㎡ |
|---|---|---|
| 卧室 | 卧室A 8.4㎡（北窗·明） | 卧室B 约 9.0㎡（东窗·明） |
| 客厅 | 餐客一体约 14㎡（**借光，非直接采光**） | 客厅约 12.5㎡ + 阳台 5.3㎡（南向·明） |
| 厨房 | 原厨房 5.6㎡（北窗·**明厨**） | 新建，与客厅一体（**暗厨**，电磁灶 + 强排） |
| 卫生间 | 原卫**缩至约 2.2㎡**（东窗·**明卫**） | 新建 3.8㎡（**暗卫**，背靠背借管 + 玻璃砖 + 强排） |
| 入户 | 原入户门（北墙中部） | **需新增第二户门**（只能开在北墙最东 1098 段，待核实） |

### 4.2 三项代价，一项都躲不掉

1. **东侧要拉一条 1.0m 通道**给南套走（约 6㎡），而东侧正是唯一的两扇东窗——通道会把卧室B 北段的东窗遮掉。
2. **原卫从 3.9㎡ 缩到 2.2㎡**（把 1.7㎡ 让给通道），北套的明卫变成「能转身但摆不下洗衣机」的极限卫。
3. **南套的厨卫都是暗的**；北套的厅是借光的。**全明不成立。**

### 4.3 换 E-W 切行不行

不行。东套能拿原厨卫 + 卧室B，但西套的新卫生间**没有立管可接**（唯一立管在东侧，横管 6–8m，必须抬地坪 15cm 且在楼板/梁下穿行，堵塞与漏水风险极高）；若新增立管则要楼板开洞，高层不可行。

### 4.4 结论

> 方案 A 的唯一价值是「资产形态像两套」。作为出租产品，它牺牲了采光、面积和合规性，却只换来 1.7–1.85R 的租金（整租是 1.45–1.65R）。**投入 19–24 万，回收 20 年以上，不建议做。**

## 五、方案 B：三居室合租 + 新增 1 个独卫（**推荐**）

### 5.1 产品结构

| 单元 | 组成 | 面积 | 采光 | 租金系数 |
|---|---|---|---|---|
| **主卧套（卧室B）** | 卧室B + **新建独卫 3.8㎡**（背靠背借原立管） | 10.9 + 3.8 = 14.7㎡ | 东窗·明 | 0.85R |
| **南向大间（卧室C）** | 客厅靠阳台段隔断 + 阳台 5.3㎡ | 10.1 + 5.3 = 15.4㎡ | 南向经阳台·明 | 0.80R |
| **北向单间（卧室A）** | 卧室A | 8.4㎡ | 北窗·明 | 0.55R |
| **共享区** | 厨房 5.1（明厨）+ 卫1 3.9（明卫）+ 餐客厅约 14㎡ + 走道 | 约 23㎡ | 厨明 · 卫明 · 厅靠室内窗借光 | — |

**合计租金 2.20R。** 三间卧室**全部有外墙窗**——用户要的「全明」，在这个形态下反而 100% 达成。

### 5.2 为什么是「隔断客厅靠阳台那一半」

苏州条例要求：隔断出的居室必须**直接天然采光 + 自然通风**。客厅只有南侧（阳台）一个采光方向，所以：

- 隔出的那一间必须**贴着阳台**，隔墙落在客厅中段，阳台门保留在该间内；
- 剩下那半（靠北、无直接采光）**只能做共享餐厅/起居**，不能单独出租——这是合规底线，不是设计偏好；
- 隔墙用 **75 系列轻钢龙骨 + 双面双层 12mm 石膏板 + 50mm 岩棉（≥80kg/m³）**，属「轻质不燃材料固定围护」，符合条例要求。

### 5.3 施工工序（12 步，45–55 天）

| # | 工序 | 关键控制点 |
|---|---|---|
| 1 | 调档 + 复尺 | 竣工图、产证附图、承重墙确认；现场复尺与图示差 >5% 要重排 |
| 2 | 报备 | 物业装修备案（含隔墙、排水点位图）；苏州需同步做租赁备案准备 |
| 3 | 拆除 | 只拆轻质隔断与非承重门洞；建筑垃圾袋装外运 |
| 4 | 新增卫2 排水 | **背靠背**接原立管，横管 0–1.2m；墙排式（壁挂马桶 + 隐藏水箱）优先 |
| 5 | 新增卫2 给水/防水 | 冷热水走墙内；地面 + 墙面 1.8m 两遍防水，**闭水 48h** |
| 6 | 卫1 翻新 | 同层排水复核；地漏坡度 1–1.5%；排风接管到公共风道或外墙风口 |
| 7 | 厨房翻新 | 原烟道位置不动；双灶 + 大单槽 + 烟机；燃气点位**一律不动** |
| 8 | 隔断墙 | 龙骨内预埋 40mm 线管；岩棉满填；下水管包 2mm 隔音棉 + 阻尼片 |
| 9 | 全屋水电 | 分路、弱电（每间独立网口/AP）、计量模块（只采集不改回路） |
| 10 | 墙地顶 | 出租档：乳胶漆 + 强化地板/SPC + 铝扣板（厨卫） |
| 11 | 家具家电 | 一房一配：床、衣柜、书桌、空调；共享区配大冰箱分格 + 独立橱柜上锁 |
| 12 | 验收 | 闭水、通电、排水、隔声、消防（烟感×3、灭火器、应急灯）、门锁 |

### 5.4 关键工艺：借管法（本案唯一可行的新增卫做法）

| 做法 | 说明 | 适用 |
|---|---|---|
| **墙排式（推荐）** | 壁挂马桶 + 隐藏水箱 + 90/110mm 墙内立管，接原立管；地面不抬高 | 与原卫背靠背/同墙时最优 |
| 垫层式 | 抬地坪 8–12cm 敷设横管 | 横管 1–3m、层高允许 |
| 降板式 | 楼板下沉 | 新建/大改，旧房基本不适用 |

**硬约束**：横管 ≤1.5m（超过必须复核坡度与通气）、坡度 1.5%–2%、每 1m 降 1.5–2cm、必须设存水弯与通气、**不得在梁下穿孔**。

## 八、二房东极致改造 17 条（技能手册）

**结构 / 管线**

1. **先定门，再画图。** 能不能开第二扇户门，决定这套能卖什么产品。开不了，就别谈「两套」。
2. **立管是天花板，不是障碍。** 新卫必须与原卫**背靠背或同墙**，横管 ≤1.5m；超过就必须抬地坪或墙排，成本与风险同步上升。
3. **同层排水三选一**：墙排式（壁挂马桶 + 隐藏水箱，最推荐）/ 垫层式（抬 8–12cm）/ 降板式（旧房基本不用）。
4. **绝不自建新立管。** 楼板开洞要原设计单位 + 物业 + 楼下三方同意；高层几乎必拒。唯一例外：顶楼或有天面。
5. **烟道比水道更刚性。** 公共烟道只能服务一个厨房（风压 + 串味）；第二厨房一律**电磁灶 + 独立排风到外墙风口**，不接公共烟道。
6. **燃气一根手指都不要碰。** 第二户申请独立燃气表在公寓楼几乎必被拒；电磁灶/电陶炉是行业标配，成本 300–800 元，还省掉一道报批。
7. **隔墙三件套**：75 龙骨 + 双面双层 12mm 石膏板 + 50mm 岩棉（≥80kg/m³），实测 Rw ≥45dB。**下水管必须包 2mm 隔音棉 + 阻尼片**——夜里冲水声是最常见的退租理由。
8. **一堵墙干三件事**：分户 + 隔音 + 走管线。龙骨里一次预埋 40mm 线管，不要事后开槽（开槽即破坏隔声与防火）。

**采光 / 通风**

9. **「全明」的三种合规替代**：玻璃砖借光（暗卫借相邻明卧）、上部玻璃隔断（暗厅借北窗光）、光导管（仅顶楼/有天面）。都不改外立面。
10. **暗厨的正确做法**：电磁灶 + 侧吸大吸力（≥20m³/min）+ Φ150 硬管排风到外墙风口，加装燃气/CO 报警器防串味。
11. **开放式厨房是暗厨的解药**：不与客厅砌墙，厨房就能「看见」客厅的窗，视觉与使用都成立；但不得声称「明厨」。
12. **暗厅靠家具分区，不靠砌墙。** 砌墙即分割搭建，一堵墙就能把整案定性改掉。

**水电 / 计量**

13. **不要私装电表。** 这是判例里最高频的加重情节。正法：分项计量模块/智能插座**只采集数据**，合同约定按实际用量分摊并公示账单。真要分户只能走供电公司。
14. **水可以加子表。** 总表后加子水表是行业通行做法（200–400 元/个），但要让物业知情，不动主立管。

**防水 / 消防**

15. **防水是唯一不能省的钱。** 新卫地面 + 墙面 1.8m，两遍，闭水 48h。**楼下漏一次，赔偿超过整个改造利润。**
16. **消防三件套按间配**：独立烟感、灭火器、应急照明；疏散通道净宽 ≥1.1m，不得上锁、不得堆物。

**运营**

17. **定价必须拉开梯度 + 把空置算进模型。** 三间不要同价（同价必互相比较、砍价、退租）；改造房空置按 30–45 天/次、年空置率 8–12% 计，不要按满租算回报。共用设备（洗衣机/冰箱）是最大投诉源，能一房一配就一房一配。

## 十三、学习后的修订（2026-11-13 夜）

依据：`RENOVATION-PLAYBOOK-v1.md`（二房东改造与单身公寓产品手册 v1）。学完之后，原结论有两处要改、三处要加强。

### 13.1 改一：独卫是刚需，第 3 间是弱产品

- 数据：**卧室 + 独立卫生间是刚需**；会客/学习可以挤、**厨房「可以不用但不能没有」**（北京 1800 份问卷）。95 后 **80.4%** 把通勤排第一（清华×贝壳 2023）。
- 后果：全屋最多 2 个卫生间（原卫 + 新卫），所以**最多只能做 2 个"自带独卫"的单元**。三居室合租的第 3 间必须共享卫 1，只能按 **0.55–0.60R** 定价，且退租率更高。
- 修正：**"三居室合租"从首选降为 C 案**。

### 13.2 改二：产品排序换了

| 排序 | 方案 | 独卫 | 租金 | 改造 | 回收 | 门槛 |
|---|---|---|---|---|---|---|
| ① | **B 双主卧双卫**（2 间各带独卫 + 共享客厅厨房） | 2 | 1.85–1.95R | 11–14 万 | 7–8 年 | 可执行 |
| ② | A 两套独立一室户 | 2 | 1.70–1.85R | 19–24 万 | >20 年 | 需第二户门 |
| ③ | C 三居室合租（原推荐） | 1 | 2.10–2.20R | 12–16 万 | 6.5–7 年 | 第 3 间弱 |

C 案租金最高，但**产品体验最差**（一个卫生间两人抢）。年轻人市场里，"独卫"值钱、"多一间"不一定值钱。
**建议：如果你要的是"年轻人愿意住、退租少"，做 B；如果只算现金回报、能接受高流转，做 C。**

### 13.3 加强一：钱花在墙 / 地 / 灯（视觉黄金三角）

原预算里"基础硬装 4.1 万"太笼统。学到的行业口径：**钱只花在看得见、能议价、显档次的地方——墙面、地面、灯光**；墙体能不动就不动（老小区砖混拆改风险大、成本高、耽误出租时效）。
修订后的单单元成本卡见 `D-03`：经济档 **≈4.07 万**、标准档 **≈6.37 万**，与"3–5 万/套"的行业口径吻合。

### 13.4 加强二：无主灯 + 通体柜 + 半墙长虹玻璃

图纸已按此改：
- **A-03**：卧室加 **K1/K2/K3 通体柜到顶 + 顶柜/行李柜**；卧室C 做 **地台 +150**（台下抽屉）；客厅 **K4 吧台兼餐桌**；卫1 朝走道做 **半墙长虹玻璃**；每间加 **全身镜**。
- **A-05**：取消主灯，改 **无主灯**（筒灯做基础照度 + 周边灯带洗墙 + 客厅轨道射灯），全屋 3000K。
- **D-03（新增）**：18 件配置标准、K1–K7 收纳系统、成本卡、三案对比。

### 13.5 加强三：采光的正确顺序

**先借光（拆非承重 / 开室内窗）→ 再透光（玻璃砖 / 长虹玻璃）→ 最后补光（镜面 / 灯带）。** 顺序不能倒——先买灯不如先开口。本项目受结构限制不能外墙开洞，所以只做后两步。

### 13.6 一句话总结这次修订

**原来按"能收多少租金"排序，学完之后按"年轻人愿意住哪套"排序。** 租金最高的 C 案，恰恰是独卫最少的那套。
