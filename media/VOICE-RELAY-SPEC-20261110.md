# 配音素材登记与交接规范

## 1. 核心流程：BM-B to BM-C
*   **源库归档 (BM-B)**：完成录制后，源文件上传至 BM-B 存储集群。由数据运维自动触发快照任务（保留最新 24 小时及每日增量），确保原始音频无损保存，不可修改。
*   **任务分发**：作业调度器读取 BM-B 待处理队列，根据项目 ID 将任务路由至对应节点 BM-C。
*   **目标写入 (BM-C)**：BM-C 接收任务后，执行“校验 - 转码 - 入库”流水线。若源文件损坏，自动触发熔断并通知人工介入；否则生成成品包上传至 BM-C 项目空间，同时同步更新状态标记为 `READY_FOR_REVIEW`。

## 2. 清单字段标准 (Source Audit List)
*所有物料入库必须附带结构化元数据，缺失任意一项视为未归档：*

| 字段名 | 类型 | 内容说明 | 校验规则 |
| :--- | :--- | :--- | :--- |
| **路径** | String | 相对于 BM-C 根目录的绝对路径 (S3/NAS) | 需唯一且符合命名规范，禁止硬编码 IP |
| **大小** | Long | 文件原始字节长度 (Byte) | 偏差不得超过 0.5KB |
| **时长** | Float | 音频总时长 (秒)，保留两位小数 | 误差容忍度 ±0.05s |
| **SHA256** | String | 文件内容的 SHA-256 哈希值 | **强制校验**，必须与 BM-B 源文件一致 |

## 3. 质检与交接回执 (QC Return Ticket)
质检环节由人工或自动脚本完成后，必须返回以下字段至工单系统：

*   **卡 ID**: `string` — 关联录音工程卡片唯一标识，用于追溯原始素材。
*   **结果**: `enum` — 可选值为 `PASS`, `FAIL`, `DEFERRED` (待重录)。
    *   *Pass*: 符合声优标准，无瑕疵，进入下一流程。
    *   *Fail*: 出现明显口误、爆音或语调不符，需整改后重交。
*   **问题样本**: `string[]` — 列出具体错误点（如：“第 28 秒‘困难’发音模糊”），若为自动质检需提供对应时间戳索引。

## 4. 异常处理机制
1.  **哈希不一致**：BM-C 在读取文件后立即重算 SHA256，与清单记录比对。若不一致，立即丢弃文件并生成 `ALERT` 日志至监控大盘。
2.  **超时未交**：若在 BM-B 停留超过 T+48h 未完成分发或处理，自动触发消息队列通知 PM 介入检查是否发生任务死锁或存储故障。
