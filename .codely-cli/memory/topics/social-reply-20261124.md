## 一、平台租约（`Tools/fleet/res_alloc.py` → `may()`）

- 90 分钟片轮转，一次只放一条实战线。**瓶颈是 browserd 单线程，不是内存**。
- 返回码语义固定：`0` 放行 / `75` DEFER（非本时段让位，**退出码退 0、不进 24h 退避**）/ `76` 资源拒绝 / `77` 未知平台（必报错，不许默认放行）。
- 五条负控：need-login 必拒、未知平台必报错、DENY-NEW 时即便轮到也不放行、非本时段必 DEFER、本时段必放行。
- 新增平台要同时进 `PLATFORMS`（可为 0 权重），否则 `may()` 报 77 而不是静默排班。

## 二、两套标定互相覆盖 → 取交集 + 冲突留痕

- 实锚：`voice_band`（原型字数带 23–37）**整条覆盖**发帖闸带（10–20），后写者赢 → 闸整天全拒且理由泛化，acct1 一整天零发帖。
- 正法：`if _vb: _lo,_hi = max(_vb[0],lo), min(_vb[1],hi)`；交集为空（两套标定真矛盾）退回闸带并记 `band-conflict`。
- 实测落带率 **0/N → 4/5**。**任何"同一个数字在两处被写"的场合都适用**：先取交集，再谈谁对。

## 三、browser_daemon 单线程禁忌（本会话踩四次）

- `browser_daemon` 是单线程服务端，**任何导航类动作**（开空间页 `ownworks`、`roots` 内部 `goto` 视频页）都会把唯一线程挂住，发帖全局停摆。
- 正法三条：①导航类一律撤出 daemon（留注释警告）；②`roots2` 改成不导航取评论 + 解析失败重试一次；③回复线改**独立短命会话**（自己起浏览器、跑完关），不与发帖智能体抢同一 profile（抢了会"连得上但不回话"）。
- 计时必须拆三层：锁等待 / daemon 服务 `svc_ms` / daemon 内排队。混在一起只会去优化错误的环节。

## 四、去 AI 感闸（`Tools/fleet/deai_check.py`）

- 词表**运行时解析上游 md**（`cph4/fleet/social/deai/qu-ai-wei` + `cn-humanizer`），不硬编码；读不到**抛错**，不许静默降级。
- 分级：一级词出现即红；二级词（`SOFT`）≥3；开头式/连接词 ≥2；`NEG_PREFIX=("不","无","没","禁","别","免","杜绝","避免","零")` 前 6 字跳过。
- B 站专节机器化：`\d{1,2}:\d{2}` 时间轴、`第N秒/分钟` 假装看过、机械玩梗词。
- 三个必踩的解析 bug：上游标题带括号后缀（"一级高频词（铁证）"）→ 改前缀匹配；词条带 `...` 占位符 → 取 `...` 前部分并去尾标点；括号注释混进词表 → 正则去括号。
- **软词单点判死会误杀真评论**（"作为""近年来"是正常中文），这是必须分级的原因。

## 五、回复线四道闸 + 两条中文相关度坑

- 四道：长度 8–30 / `cg.gate(face="reply", taste_gate=False)` / `dz.check` 去 AI 腔 / `_fabricates`（回复含评论里没有的数字或英文即拒）+ `_ontopic`。
- **品味闸不能当及格线**（4/4 全拒，已记过的坑）。
- **无样例时 4B 会跑题**（"20241210"、"切好给你，别硬切老人"）→ 3 条真实语气样例 + 两条硬约束 → 4/4 过。
- 相关度：正则切"实词"得到整段连写长串，两边**永不交集**（误杀 7/8）→ 改**汉字二元组共享 ≥2**。
- 敏感面：**对陌生人年龄外貌接话是冒犯**（自动回了"36 岁确实容易走样"）→ 加 `SENSITIVE`；且必须用**词组**不用单字（"美"会命中"美好"）。
- `dry=True` 默认会造假绿（`sc._post_in` 两条"成功"实为演练）→ 显式 `dry=False`，并把假绿行从台账剪掉（不剪会被去重逻辑当"已回"，那两条永远没人回）。

## 六、训练侧两条（与 `lora-train-quality-20261118.md` 互补）

- **val_loss 跨数据集不可比**：换数据集后只能比任务级评测（段 avg / pass / 人味）。
