# 面孔素材「挑选」判据与批量备料现实值（2026-11-13）

> 背景：CEO 令「筹备所有训练素材，并挑选好，真正的训练等我下班后」。
> 正身文档：`cph4/fleet/mv-album-001-jay/LORA-FACE-LIB-PLAN-v1.md`
> 工具：`Tools/face_lora_prep.py curate` / `Tools/face_source_batch.py`

## 一、人物一致性判据（本次最重要的方法论）

**问题**：图片搜索会混入同族名人、网红、合影。混进别人的脸比素材少更糟——LoRA 学到的是「多张脸的平均」。

**错解（已废弃）**：用「到质心的余弦距离」剔除离群脸。
实锚：张柏芝 44 张只剔掉 1 张，而抽检板肉眼可见 5-8 张是别人。
原因：混入的也都是亚洲女星，与质心的余弦普遍 >0.6，单阈值分不开。

**正解**：**kNN 一致性分** = 每张图与最近 8 张的平均相似度。
混入者与目标人「互相不像」，所以天然被压到底部，不依赖全局质心。

**阈值标定（张柏芝 44 张实测）**：
- 分布：p0=0.403 / p25=0.596 / p50=0.630 / p75=0.675 / max=0.709（连续、无双峰）
- 最低 6 张（0.403~0.575）经人眼确认：至少 5 张是别人（戴帽网红 / 蓝吊带 / 短发女等）
- 取 **0.58** 剔除 6 张 → 38 张；二次迭代剔除 0 张、中位升到 0.642（收敛）

**辅助判据**：合影直接跳过（检测到第二张脸且面积 > 主脸 40% → 主脸可能不是目标人）。

**兜底**：阈值后不足 20 张说明素材本身就是「几个人混在一起」，仍按 kNN 取前 20，不假装达标。

**人眼关**：每人生成抽检板 `media/faces/_boards/<key>.jpg`（6 列拼图），机器判据之外必须能一眼看出是不是同一个人。

## 二、四个静默失败坑（都踩过）

1. **SFace 模型截断下载**：`Tools/models/face_recognition_sface_2021dec.onnx` 曾只有 25.7MB（应为 38.7MB），
   OpenCV 报 `Failed to parse ONNX model` / `Cannot determine an origin framework`。
   真因是文件不完整，不是 OpenCV 版本问题。修法：重下 + 校验体积 + `cv2.FaceRecognizerSF.create` 能加载。
2. **`cv2.imwrite` 不建父目录** → 抽检板静默不落盘，脚本照样打印「已生成」。
3. **`cv2.alignCrop` 要 1×15 数组**：传裸 15 维会抛 cv2.error；`except cv2.error: continue` 一吞，
   症状变成「全员不可用 / too_few_faces」，完全看不出真因。异常必须记前 3 条并打印。
4. **pythonw 下 `sys.stdout is None` → `print` 抛 AttributeError → 计划任务一触发就静默死**。
   入口必须先接管 stdout/stderr 到日志文件（`face_lora_train.py` 与 `face_source_batch.py` 都已修）。

## 三、批量备料现实值（180 人 · 单机白天）

- 名单：`casting-pool-v1.json` 的 **`internal_index_only` 字段**（不是 `people`），10 族 × 20 = 200 人；
  `kr` 韩系族按 ANTI_K 反韩锚**整族跳过** → 实备 180 人。
- 命中率：360 图源约 **23%~29%**（比必应稳）；老照片人脸常偏小，闸线是 200px 硬下限。
- **target 45 不够**：挑人后掉 15-25%（张柏芝 44 过闸 → 38 挑后 → 34 建成），应设 **60**。
- 达标判定必须用**建成的训练图数**，不能用过闸数（否则假达标）。
- 每人耗时（2 轮采集 + 挑人 + 建集）约 **4-5 分钟**；每 8 分钟 4 人一轮，实际约 10-14 人/小时。
- 结论：**180 人白天（6-7 小时）备不完**，需过夜继续；凑到 20 张保留（能训但会偏），40 张以上才算好料。

## 四、训练与备料的分工边界

- 备料 = 网络 + CPU（SFace/YuNet 推理），白天可跑，不占 GPU。
- 训练 = GPU，19:05 起每 15 分钟巡检，两道守卫：让路态（pausedLite）→ 不跑；显存 < 6.5G → 不跑。
  所以「等 CEO 下班」不靠定时，靠守卫：他还在用机就自动跳过，真正空闲才开训。
- 批量训练走 `face_lora_train.py batch`：扫描 `media/faces/*-ds`，一次只训一个（单卡防 OOM），产出即跳过。
