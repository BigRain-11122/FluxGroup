## 两个可复用教训

**① `TestMetaProgress` 不是 NUnit fixture。**
它是 `public static class`，`-runTests -testFilter` 扫不到：日志出 `Scan Filter Count: 0`、
`No tests were executed`，而结果 XML 里 `result=Passed` + `total=0` —— **这是假绿**。
判据：跑测试必须同时看 `total > 0`，只看 `result` 会被骗。
这类静态测试只能靠读源文件比对（本次用 Python 正则抓两表数组确认一致）。

**② 用脚本批量替换代码时，`// 注释` 写在分号前会把分号注释掉。**
本次把 `new Color(...)` 替换成 `new Color(...)   // 注释`，原行的 `;` 变成注释的一部分，
Bootstrap.cs 与 ProjectBuild.cs 各报一次 `CS1002: ; expected`。
规则：替换的 new 串若含注释，注释必须放在**整个语句之后**，或只替换参数部分不跨语句。
