# 本地 SDXL LoRA 训练的三个致命坑与性能基线（2026-11-15 实测）

> 场景：RTX 4070 SUPER 12G / Windows / torch 2.11+cu128 / kohya sd-scripts / SDXL base 1.0
> 正身工具：`Tools/face_lora_train.py`（batch 训练器）
> 结果：修前 36 小时 0 产出；修后 35-40 分钟出一个 LoRA

## 一、坑 1：fp16 训 SDXL 从第 1 步就 NaN

**症状**：`steps: 0%| | 1/1400 [110.84s/it, avr_loss=nan]`，不是训练后期发散，是开局就 NaN。
**根因**：SDXL + fp16 在 torch 2.11 上的数值溢出。
**修法**：`--mixed_precision bf16 --save_precision bf16`（4070S/Ada 支持 bf16）。
**验证**：改后 20 步冒烟 `avr_loss=0.125`，权重可正常落盘。

**教训**：看到 NaN 先查精度，不要先怀疑数据或学习率；NaN 从第 1 步出现几乎一定是数值问题。

## 二、坑 2：`--cache_latents` 把 12G 卡顶爆，速度掉 12 倍

**症状**：`18.46 s/it`，1400 步要 7 小时；显存占用 11915/12282（97%）。
**根因**：latents 缓存到内存（显存）后逼近上限，WDDM 在临界点频繁换入换出，性能暴跌。
**修法**：`--cache_latents_to_disk`（缓到磁盘），配合 `max_bucket_reso 1280`。
**实测**：**1.51 s/it**（快了 12 倍），1400 步从 7 小时降到 32 分钟。

**教训**：显存占用超过 ~90% 时不是"还能跑"，是"已经在抖动"。宁可缓到磁盘。

## 三、坑 3：Ollama 模型周期性抢显存，卡死训练启动

**症状**：训练器每 15 分钟检查一次显存，一直报「显存仅剩 4200 MiB（下限 6500）」，
连跑几十轮都不开训；手动卸载后能跑，过一会儿又被占回去。
**根因**：
- `qwen3:4b-instruct` 加载后占 **7.0 GB**（12G 卡的一半以上）
- 有计划任务周期性把它拉起来（`MiniGameOllamaKeepWarm`、`HQ-OllamaOrphanWatch`）
- 一次历史遗留还把 `keep_alive` 设到了 2319 年（永不过期）

**修法（组合）**：
1. 训练器启动前自动调 `/api/generate {keep_alive: 0}` 卸载所有已加载模型
2. 训练期间禁用 Ollama 预热类计划任务（`MiniGameOllamaKeepWarm`、`HQ-OllamaOrphanWatch`）
3. 训练结束/批次完成后恢复

**原则**：显存冲突时，**长任务优先于可重载的短任务**。训练跑 40 分钟不能中断，模型随时可重载。

## 四、性能基线（可直接用来估工期）

| 项 | 值 |
|---|---|
| 单步耗时 | 1.5-2.0 s/步（SDXL 1024 / rank32 / bf16 / grad ckpt / latents to disk） |
| 1400 步 | 35-40 分钟/人 |
| 显存占用 | 训练中约 9.2 GB / 12.2 GB |
| GPU 利用率 | 46-88% |
| 显存可用下限 | 6.5 GB（低于此判拒跑） |
| 一夜（12 小时）产能 | 约 15-18 个 LoRA |

## 五、两个流程坑（与训练无关但同样致命）

1. **计划任务 RepetitionDuration 到期 = 静默停摆**：备料任务设了 18 小时期限，
   11-14 早 7 点到期后 `NextRunTime` 变空、任务仍是 Ready 状态但再也不会跑，
   36 小时只推进了 26/180 人。长期任务必须给足 duration（Windows 上限约 31 天），
   并定期核对 `NextRunTime` 是否为空。
2. **build 不清理输出目录 = 数据集逐轮累积**：ql01 训练集涨到 107 张，
   而实际挑选后只有 45 张。每轮 build 前必须清空目标目录，否则早期未挑选的图一直留在训练集里。

## 六、会话日期不可信

CLI 会话头的「Today's date」是会话开始时的快照。本次实测：会话头写 11-13，
而系统实际已到 **11-15 凌晨**（跨了近两天）。任何与时间相关的判断
（任务是否该跑、产出是否过期、几天没动）必须 `Get-Date` 取实时值。
