## 一、简介被拦：个人号的硬墙（重要，别再试）

**现象**：点简介的「修改」→ 弹窗
> 未授权使用切换账号能力，请退出后扫码登录其他账号。
> 登录时需勾选「允许切换登录我的其他公众号、服务号、小程序」，才能切换账号。

**试过的所有办法都失败**：
1. 点「退出登录」→ 无效（没真正退出）
2. 清空 cookie 重新扫码（新 token 306073815）→ 仍被拦
3. 直接访问 `setprofile` / `modifysignature` URL → HTTP 失败

**结论**：这不是登录态问题，是**个人主体账号没有「切换账号」权限**。
简介只能**CEO 手动改**，自动化永远做不到。

**同类风险**：头像/微信号可能同样被拦（未验证）。

**五条规律**（可用于任何公众号）：
1. **极短**：4–27 字，中位 **12 字**
2. **给利益**：选车省心 / 每天60秒懂汽车 / 提升效率
3. **中文对偶**：选车省心 买车省钱
4. **说人话**：**没有一家写哲学抽象**
5. **晚点最妙**：`晚一点，好一点` 6 字双关

**核心结论：格局在内容里，不在简介里。简介只干一件事——让读者知道关注你能得到什么。**

## 五、调性三条铁律

1. **断言，不铺垫**（❌「随着新能源的发展」✅「这块屏的字重错了」）
2. **给改法，不只批评**（❌「很丑」✅「违反对比原则，该这样改」）
3. **数字带来源**（❌「续航很长」✅「CLTC 标 700 公里（工信部公告）」）

**去 AI 味**：一级词出现即红（赋能/闭环/抓手/颗粒度/对齐/链路/值得注意的是/随着…的发展）。

## 六、GitHub 工具选型（只装一个）

| 仓库 | ⭐ | 许可 | 结论 |
|---|---|---|---|
| **doocs/md** | **13,556** | WTFPL | ✅ **已装**（含 `md-cli` + `mcp-server`） |
| littlecodersh/itchatmp | 1,586 | MIT | ❌ 需公众号 API 权限（个人号拿不到） |
| jiji262/wechat-publisher | 300 | **无许可** | ❌ 法律风险 + 需 API |
| RogerLiNing/wechat_mp | 53 | MIT | ⚠️ 与 silent_browser 重复 |
| likemaoke/wechat-article-to-md | 41 | MIT | ⚠️ 采集通道全封 |
| italks/md-wechat | 7 | 无 | ❌ star 太低 |

**为什么只装一个**：排版是**唯一能全自动且无权限门槛**的环节；
采集（搜狗/Bing/profile_ext 三通道全封）和发布（2026-03 非真人自动化条款 + 个人号无 API）
都被平台锁死，装工具 = 假进展。

**doocs/md 的意外收获**：
- `packages/md-cli`（bin=`md-cli`）→ 命令行批量转换
- `packages/mcp-server`（bin=`md-mcp`）→ MCP 服务器，AI 可直接调
