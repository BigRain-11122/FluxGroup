## 新补的 6 个 skill

| skill | 一句话 |
|---|---|
| `game-greenlight` | 立项裁决：七问 + 裁决矩阵 + kill_criteria；**无 kill_criteria 的 GO 判无效**；裁决必须自反驳一遍 |
| `game-store-assets` | 五平台物料清单 + 截图五段结构 + 十条自查 + 36 款三态扫描（READY / HAS-BUT-BAD / MISSING）；红线=用渲染图冒充实机截图 |
| `game-market-sizing` | TAM/SAM/SOM 三级口径分开写；数据分 A/B/C/D 四级，**D 级不得单独作依据**；至少三条可推翻假设 |
| `game-analytics` | 埋点先于上线；口径单点定义（改口径要写变更记录）；不采 PII |
| `game-monetization` | 卖关系与回忆，不卖进度与优势；五条红线=不卖关卡钥匙/体力/抽卡/数值优势/广告解锁 |
| `game-car-hmi` | 驾驶态限制 + 三输入（触摸/旋钮/方向盘键）+ 光环境双工况 + 座舱联动四样 |

## 用法

主控按环节编号派 `task` 并加载对应 skill：

```
A5 → task(加载 game-greenlight，输入 A1-A4 结论)
G4 → task(加载 game-store-assets，输入某款游戏的 production/launch/)
F3 → task(加载 smoke-check，输入最新构建)
```

每个席位的产物必须落盘到项目 `docs/` 或 `production/` 下，不接受只在对话里存在的结论。
