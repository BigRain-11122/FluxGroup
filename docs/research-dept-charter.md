# 集团调研部门建制律 v1.0（Research & Frontier Intelligence Charter）

> **委托令**：CEO 令 2026-09-26 ~23:0x「各子公司实验室都要成立有关调研的部门，也可以复用之前组织架构相近的，要敏感的去学习业务前沿技术，统计信息，落地执行等，我说的很凌乱，你们思考后落地」（U247·模糊令三段律：盘点→定谳→立制派发）。
> **法位**：集团九实体（HQ/MiniGame/FluxVerse/BigMoney/BigStream/BigLife/BigDomain/BigCompute/CPH4）**常设调研建制**的组织律——与《四级条线治理章程》（任务条线）/《patrol-charter》（巡检）/fleet-allocations（资源条线）并立：**巡检查存量健康·调研部盯外部增量**。
> **CEO 三意图拆解**：①**组织面**=每司有正式调研部门（可复用既有相近架构正名·X068 零新车道）；②**敏感面**=对业务前沿技术保持**定时扫描的敏感度**（不是等派单才调研·是常设雷达）；③**闭环面**=统计信息→调研件→落地执行（只出报告不落地=违例）。

## 一、组织建制律

1. **每司一调研部**：各部门命名「<司名>·调研部」，**复用优先**——已具备调研职能的既有组织按「正名+扩权」处理，不另起炉灶：
   - **MiniGame**：复用`Design/research/调研学习/`线（44 件 R-件传统）+对标改进总账+radar 快照线 → 正名**游戏前沿调研部**
   - **BigLife**：复用`docs/research/`线（数字生命/居民智能研究件）→ 正名**生命智能调研部**
   - **CPH4**：本身就是集团研究中枢（判据定标/研究件/进化轮）→ 正名内部**前沿技术调研组**（兼集团调研统合席）
   - **HQ**：复用 patrol/gap-audit/对标总账机制 → 正名**集团情报调研组**（集团级统计与对标归口）
   - **FluxVerse/BigMoney/BigStream/BigDomain/BigCompute**：各司自评既有相近架构（回测池/内容研究/平台调研等）回执时声明「复用件或新设件」——**复用优先·新设须说明为何无相近可复用**
2. **席位律**：调研部=该司常设部门席位（入该司组织面/看板行）·部门可虚可实（一人多岗合法·判据先行），**但必须有名有台账有节律**（无名无节律=没建）。
3. **节律律（敏感度的实现）**：每司调研部**周轮一次前沿扫描**（进本司 OS 循环或周轮班·X068 复用既有 cadence 面）——扫描面=本司业务前沿技术/竞品动态/工具链新版本/方法论新知；**外部检索路数=web_fetch 定向直查**（web_search 已 410 停用·今日九调研 agent 实证）+radar 快照+行业页。
4. **产出规范**：调研件统一 **R-YYYYMMDD-<司>-<序>-<题>** 命名+**P-65 三件套**（立项三问：为什么现在查/查给谁/查完谁执行——**立项时必须答「落地承接人是谁」**；应用表：查到的每条东西映射到既有机制/工单；验证声明：外证/内知如实标注）。**无应用表=调研未完成**（只报告不映射=白调研）。

## 二、职能三件套（CEO 令的三能力·每部门配置）

1. **敏感学习前沿技术**：周轮扫描+**即 hot 即报**机制（发现与本司业务相关的重要新事物=不等周轮·立 24h 内速报行·P-行/FE 通道）。
2. **统计信息**：每调研部维护**本司业务统计面板**（产出量/里程碑/健康度/配额面——复用各司既有台账数据·汇总成调研部月度统计注记·供集团月对账 M5 直读）。
3. **落地执行**：调研件的每条应用表条目**必须挂承接**（既有机制翻格/新工单/新 P-行三选一）——**挂对标改进总账类台账的·翻格必填证据指针**（禁只翻不证·U195 律承继）；无承接条目=删除或转「观察位」（观察位不得超过条目半数）。

## 三、闭环与汇报线

```
周轮扫描 → R-件（立项三问+应用表+验证声明） → 落地承接（翻格/工单/P-行）
                                                    ↓
月度：各司调研部统计注记 → CPH4 统合判据 + HQ 情报调研组归口 → 集团月对账（M5/U178）呈 CEO
```
- **统合席=CPH4**（判据定标承继）：跨司调研件的质量抽查（P-65 三件套齐备性）+月度集团前沿综述。
- **归口席=HQ 情报调研组**：patrol 巡检「台账/数据新鲜」维联动调研部统计面板（巡检查健康·调研部盯前沿·职责互不吞并）。
- **回执纪律**：建制回执 ≤09-28 12:00（与既有 U231 块面调研件同窗——**块面件=各调研部第一件正式接产任务**·P-2026-09-26-04 承接归口）。

## 四、执法与防退化

- **防「挂名空转」**：patrol 巡检七维新增联动判据——「调研部台账 >7 天无新增且无观察位注记」=任务面维黄牌。
- **防「只学不落」**：应用表无承接条目=违例（§二-3）。
- **防「重复调研」**：立项三问第一问=「集团既有 R-件库里是否已有」——先查库再立项（44+件在库·跨司共享引用合法）。
- **法无禁止即可为**（U222 承继）：调研选题自由=本司业务相关即合法·无需逐题请示·月度统合时交叉验收。
