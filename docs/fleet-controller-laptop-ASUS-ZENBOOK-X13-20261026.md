## 四、适配你的架构

- **算力/agent 常驻**：放台式机/机队，不在这台笔记本上跑重活。
- **笔记本角色**：远程终端（Tailscale + RDP/SSH/Parsec）、客户演示、通勤。
- **16G 是这台的主要限制**：板载不可加；如果 agent 全在远端，够用；如果要本地 Docker + 多 agent + 模型，会紧。
- **无 USB-A/HDMI**：需要 USB-C 扩展坞/转接头；演示接大屏要 USB-C→HDMI。
- **非触控**：客户要触控演示，外接触摸屏/平板；不要为触控换机。
- **13.3" 偏小**：单人对谈/桌面演示没问题；多人演示建议外接大屏。

## 五、到手验收清单（7 天内做完）

1. **型号/配置**：系统信息确认 R7-6800U、16GB、1TB、Radeon 680M；SN 与底部标签一致。
2. **电池**：`powercfg /batteryreport` 看设计容量/满充容量/循环；卖家标 75–80%，低于 75% 考虑退/压价。
3. **屏幕**：纯白/纯灰/纯黑/红绿蓝；查 OLED 烧屏、坏点、涂层脱落、泛红；确认 2880×1800 60Hz。
4. **键盘/触控板**：全键、背光、触控板、NumberPad（如有）。
5. **接口**：3 个 USB-C 逐个测数据/视频/充电；3.5mm、摄像头/IR、Wi-Fi 6E、蓝牙。
6. **SSD**：CrystalDiskInfo 看健康/通电/温度；确认 1TB。
7. **压力**：Cinebench R23 + 双烤 10 分钟；看 25–28W、温度、降频、风扇噪音；1kg 机身可能降频。
8. **系统**：干净重装 Windows 11；装 MyASUS/驱动；确认无 BIOS 密码、无企业 MDM/监管。
9. **配件**：65W 原装/同规格 USB-C 电源、线材、USB-C 转 HDMI/USB-A 转接；箱说是否齐。
10. **保修**：保留转转订单/验机报告/1 年质保凭证；7 天无理由期内完成以上测试。
