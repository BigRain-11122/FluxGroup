## 范式一：**先验探针有效性**（本会话最常用、也最救命的范式）

**规则**：**探针报零 ≠ 健康**。任何"零命中/零异常/无差异"的结果，**必须先用一个已知阳性样本证明该探针能触发**，才允许把零当结论。

**本轮使用记录**（4 次，其中 2 次救了错误结论）：
| 场景 | 若不做会怎样 | 做了之后的真相 |
|---|---|---|
| 禁开方向闸报 60/83 拒绝 | 会误判"公司大规模违规" | 全假阳（"参数网格"术语）→ 收紧后降到 0，且仍能抓真声称 |
| 禁开方向闸收紧后报 0/83 | 会误判"闸太紧/失效" | 用真声称文件（`EXIT_OVERLAY_P1`"ETF 网格交易"）验证 → **闸有辨别力，0 是真结论** |
| 低PE 五档压力测试结果全同 | 会误判"无退市暴露" | 先验 `distress` 标记（命中 940 次/245 只）→ **确认压力面生效，全同是真结论** |
| 摘要器 `bannedHit=44` | 会误判"44 件违规" | 逐件抽验 → **假阳**（预注册本就引用禁开清单） |

**模板**：
```
## 探针有效性先验
- 探针：<名称>
- 已知阳性样本：<文件/日期/标的>  预期：命中
- 实测：命中 / 未命中
- 结论：探针有效（零可解释）/ 探针失效（零不可解释）
```

## 范式二：**偏差窗口定界**（"半验证"·本会话原创）

**规则**：当某因子必然含未来函数且**暂时拿不到点位时点数据**时，**用缩短窗口把偏差限制成可控**，并观察结果如何随窗口变化。

**判据（跑前写死）**：
- 若收益随窗口缩短**稳定下降** → 收益含偏差但可能有真溢价（给下界）
- 若收益随窗口缩短**大幅波动/上升** → 高收益主要来自偏差（**判定不可信**）
- 输出**逐年分布**：收益集中在个别年份 → 疑似偏差或单一风格 → 不可信

**本轮使用记录**（低PE，`docs/audits/pe_halfvalidate.py`）：
```
10年 28.35% → 5年 33.12% → 3年 38.24% → 1年 13.04%   （大幅波动）
3年窗逐年: 2024 +48.0%｜2025 +65.8%                    （高度集中）
裁定：降级，真实上界 ≈13%（且这 1 年仍含偏差）
```

## 范式三：**跨起点 + 滚动窗口**（D-41 §1.3 的执行法）

**规则**：**禁报单一起点**。对每个可能起点跑同窗口，输出全分布。
**必报**：最差 / p5 / p25 / 中位 / p75 / 最好 / **正比例** / **跑赢基准比例**。

**本轮使用记录**（`docs/audits/cross_start_validation.py`）：

## 范式四：**分口径记账**（防混同）

**规则**：同一现象存在多个偏差/多个口径时，**必须分开记账**，不得合并或相互抵消。

**本轮使用记录**：
- **偏差**：低PE 同时有①退市尾巴（暴露 ≈0 ✅）②未来函数（主导 ❌）——**分开记账，不得因①通过就认为②也通过**
- **试验量口径**：`ledger_total_after` = **362,083**（累计）vs `cells_ledger_delta` 合计 = **82,750**（增量）——**引用须标明口径**

## 范式一·强制附款（2026-09-30 Round 11 升格）

**任何基于正则/关键词的合规指标，发布前必须附「人工校准的假阳率」。**

**依据（本会话 6 次自我更正，其中 4 次同型）**：
| # | 事件 | 同型错误 |
|---|---|---|
| 3 | `bannedHit=44` 假阳（预注册引用禁开清单） | ✅ 词形匹配 |
| 4 | PowerShell 中文正则静默失效 | ✅ 词形匹配 |
| 6 | 基线"跨起点 50.7%"四倍虚高（"滚动"指滚动窗口） | ✅ 词形匹配 |
| — | `DSR` 出现在"N/A"表述中亦被计入 | ✅ 词形匹配 |
| 1 | 低量选股跨起点不过 | 否（方法错误） |
| 2 | 低PE 未来函数主导 | 否（偏差错误） |
| 5 | 退市偏差"致命"表述过重 | 否（措辞错误） |

**条款**：
1. 关键词型合规指标**一律先标"提及口径"**，不得直接称合规率。
2. 发布前须抽样核验上下文，给出**真实率 = 真做 / 命中**。
3. 真实率 <60% 的指标**不得单独使用**，须改为"真做"判定式（要求方法学动词共现）。
4. **校准结果须与原始读数并排发布**，禁只发校准后数字（防"修完就看不见原始误差"）。
