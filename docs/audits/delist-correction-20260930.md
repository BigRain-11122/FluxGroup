## 三 判读与更正

1. **量级 ≈ 0.4~0.8pp/年。** 外审此前称"**致命**"**属表述过重，予以更正**：
   幸存者偏差在**宽基/长多/低频**策略上是**约 0.5pp/年**量级的噪声，**不改变结论方向**。
2. **但仍不可忽略的两个场景**：
   - **极端输家类策略**（买最跌的、低价、困境反转）——偏差**集中打击**这类，读数偏乐观方向不变。
   - **精确到 1pp 的判线**——0.5pp 足以把边缘策略从"过线"推成"不过线"。
3. **本估计的性质（如实标注）**：这是**一次性剔除口径**（退市时一次性损失 L）。严格说**不是上界**——
   若退市股在退市前长期阴跌且未被剔除，真实拖累**会更大**。故本值应理解为**量级估计**，不是界。
4. **解除条件**：取得退市股行情（`docs/audits/delist_bias_quant.py` 已标 `DATA_GAP`）后可精算。

## 四 对既有结论的影响
- **四资产策略**：标的是 ETF，**不受退市偏差影响** → 结论不变。
- **低PE / 低量选股**：受影响，但**两者已因更严重的偏差（未来函数 / 跨起点不成立）被降级** → 本项不改变其裁定。
- **等权基准**：修正后 9.26%~8.92%（原 9.68%）——**引用基准时应用修正值**。
