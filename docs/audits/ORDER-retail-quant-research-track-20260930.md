# 交办令：散户量化研究轨道的科学重构（外审出件 · 2026-09-30）

> 发起：CEO 令「给你的 AI 让他去改，你务必监督他在正确的轨道上，不要浪费时间和精力；尤其是如果已经有机构验证过的真实可信的数据就不要自己跑；你缺什么告诉他让他给你」
> 性质：**研究轨道的重构令**。不是新增策略，是**停止无效算力、把算力搬到唯一有效的地方**。
> 载体：BigMoney 自领（T- 票号司内定）· CPH4 负责**轨道监督**（见 §6）
> 效力：本令**不覆盖**既有判负线与在跑的预注册；**只约束新增研究的方向**。

---

## §0 一句话

**停止"海量试验找信号"；改为"引用机构已验证的因子 + 只回测本账户独有的三件事（成本/换手/行为），并对每个结论做跨起点与多重检验校正"。**

**依据**：本会话十五轮实验——362k 次试验产出 0 过门；而唯一站得住的两条（四资产配置 5.87%/−14.4%/71%、低量选股 14.80%/8-10 年胜）**都不是"更聪明的信号"的产物，而是"配置＋排除"的产物**。

## §1 铁律（**四条·违者该批作废**）

### §1.1 【不重复机构】已有机构验证的结论，**只引用，不重跑**
- **禁止**：在无新增数据、无新增机制主张的情况下，重跑已被权威机构系统性验证过的因子/结论。
- **理由**：该司账本 N=**362,083**、过门 **0**——**重复验证是这台机器最大的浪费**。
- **例外（可自跑）**：①该结论**用到本账户独有约束**（成本结构/换手预算/税收/资金规模）②该结论**在本市场未验证或有争议** ③**样本外新数据**。

**可直接引用的机构结论（本令附件·来源已核）**：
| 结论 | 来源 |
|---|---|
| 估值、动量、反转、市值、流动性的**长期胜率不佳（≈50% 或更低）**；**低波因子胜率最高** | 申万宏源金工 2026-01 |
| 市值、反转、低波因子自 **2025Q3 起走平或反向**；2026-01 量价因子集体失效 | 申万宏源金工 2026-01 |
| 公募 300/500/1000 指增 2018-2025 **年化超额 = 3.90% / 4.88% / 11.06%** | 东方证券 2026-03 |
| **连年超额 ≥10% 的产品：227 只中仅 9 只**；2024 起 432 只中仅 51 只 | 私募排排网 |
| 2024-01 小微盘踩踏：500 指增单周超额回撤 **−6%~−10%**，根因"模型对市值因子过度依赖" | 展恒基金 |
| 沪深300 全收益近 20 年 **≈9.1%/年**（价格指数 ≈7.1%） | 东方财富 |
| **85.3% 基民跑输自己持有的基金，平均 −7.43%** | 盈米基金 2025（8,152 只基金） |
| A 股除短期动量外，多数因子指数跑赢 BMI | S&P DJI 中国 A 股 Smart Beta |

### §1.2 【只测独有】新增回测必须能回答"我凭什么赢"
- 每份预注册**必须**在 §1 明确：**该决策维度上散户凭什么赢？**（速度？数据？容量？制度？行为？）
- **答不出 = 批不受理**。
- **已否证方向（禁止再开）**：ETF 横截面动量/反转 · 1–15 天单标的时序反转/动量 · 均线/动量择时 · 风格延续性押注 · 网格 · 大盘水温前置 · 个股确认型前置 · 小市值/低价因子 · 缓冲降换手。**证伪记录见 `docs/audits/retail-quant-conclusions-v2-20260930.md` §三。**

### §1.3 【跨起点】任何策略结论**不得只报单一起点**
- **必须**报告：**全起点分布**（最好/最坏/p25/中位/p75）+ **滚动 3/5/10 年窗口的最差结果**。
- **只报一个起点数字 = 结论无效**（本会话"低量 14.80%"即犯此错，须补验）。
- **理由**：单起点是"靠运气"最典型的伪装。

### §1.4 【扣搜索】每份结论必须做**多重检验校正**
- 报"最好变体"前须给 **试验次数** + **DSR** + **PBO（CSCV）**；不得以"扫了很多里最好的那个"充当发现。
- 沿用既有 `science_gates` 口径（DSR≥0.95 / PBO≤0.25），**不新立数值**。

## §2 只回测这五件事（**优先级即顺序**）

| # | 事项 | 为什么只属于你 / 机构不覆盖 | 产出判据 |
|---|---|---|---|
| **1** | **跨起点 + 滚动窗口稳健性检验** | 机构不报"全起点分布"给个人；这直接决定结论是否运气 | 对既有两条结论出分布；**多数起点成立才留，否则撤回** |
| **2** | **配置政策扫描**（权重区间 × 再平衡规则） | **可赢、容量无限、不拥挤**；机构受负债与考核期限约束 | 滚动 5 年最差为正 + 一年内见 −20% 的概率 + 起点敏感度 |
| **3** | **排除规则边际值扫描** | **"排除"是机构因仓位要求做不到的动作**；已实测该司第一铁律＝alpha（5.63%→14.80%） | 每条排除规则的**边际收益/边际代价曲线**，找最优点 |
| **4** | **本账户成本-换手-税收一体化核算** | 机构成本模型与个人完全不同（个人免所得税、有 5 元佣金底、T+1） | 往返成本 bp 表 + 换手预算下的净收益上限 |
| **5** | **行为护栏的制度化**（测不了，只能写死） | 基民行为损耗 −7.43%/年，**这是最大单项漏损** | 定投/阈值再平衡规则 + 年度评估制 + 放弃条件存档 |

**明确不做**：§1.2 已否证清单内的一切；任何"确认型"择时；任何小市值/低价因子；任何日内。

## §6 监督机制（**外审保留·务必执行**）

**CPH4 负责轨道监督**，按以下方式：

| 机制 | 内容 | 频率 |
|---|---|---|
| **A 引用率核查** | 抽查新预注册：**引用机构结论的比例**是否上升、"重跑通用因子"是否停止 | 每周 |
| **B 单起点检查** | 机器扫新交付件：**是否含全起点分布**；缺则**退回** | 每周 |
| **C 试验量闸** | 统计新增试验数；**>500 或单批 >100 无归因 → 点名** | 每 30 天 |
| **D 否证清单闸** | 新预注册标题/机制段比对 §1.2 清单，命中即**不受理** | 逐批 |
| **E 数据缺口台账** | §3 六项的到手状态，**缺项须显式 `DATA_GAP`** | 每周 |

**失守定义（触发点名）**：
- 连续 2 周出现"只报单一起点"的交付件
- 30 天内新增试验 >500
- 出现 §1.2 清单内方向的新批
- §3 缺项被静默跳过（未标 `DATA_GAP`）

**外审承诺**：我按同一律约束自己——**我自己犯过 §1.3（单起点）与 §1.4（未扣搜索）两条，已在 `retail-quant-conclusions-v2` §五自认**。**该件中所有结论在补验前一律只算候选，不得对外。**
