# 全球头部对标与规律检查规则 v1.0（外部专家出件 · 2026-09-30）

> 目的：把七条业务线**逐线对标全球头部（Top-1 或该领域公认标杆）**，产出**AI 可直接执行的检查规则**（机器可判）。
> 方法：①先用**我方自己的数**做基线（可复跑）；②对标只取**"哪条机制让他们赢"**，不比规模；③每条规则给**判据＋阈值＋失败后果**。
> 诚实标注：【事实】＝有公开出处且本轮已核／【待核】＝待两份对标取证回执校准／【推断】＝我的判断。
> 纪律：本件**不新增审批层级**；规则并入既有闸（五闸/探针/裁决面），冲突时以实测为准。

## 〇 一句话诊断（七线同构）
我方七线的**产能端（上游）普遍过剩，而"被真人触达"的下游普遍为零**：25 件成片 0 发布、1 款可玩 0 上线、10,030 居民 3 仓消费、48,992 件资产 3 个脚本、36.2 万次试验 0 过门、GPU 利用率 14–17.6%。
**头部公司的共同点不是"做得更多"，是"只做能被市场验证的那一条，然后拉到极限"。**

## 一 逐线对标与检查规则

### 1 Biggame（休闲/超休闲小游戏）
- **对标**：Supercell（小细胞自治）、Voodoo（超休闲工业化）、Playrix/Zynga（休闲）【事实·常识级】
- **他们赢在哪（机制）**：**用市场测试筛款，不用评审筛款**——大量原型→买量测试（CPI/留存）→只放大过关的那一款；**未过关就不投产能**。
- **我方基线【实测】**：已发布 **0** 款；可玩成品 1 个（吸嘟嘟 V0.9.0 Win64）；近 7 日 2834 commit 实物率 30%。
- **差距**：产能投在"做款"上，**从未投在"测款"上**——没有一条可买量素材与测试数据。
- **检查规则（AI 可执行）**
  - `R-G1` 每款**投产前**必须有 ≥1 条可投买量素材（图/视频）＋1 份测试结论（CPI/留存）入册；**无素材＝该款 stage 不得越过原型**。
  - `R-G2` 已可玩成品必须**有外部可达入口**（链接或包体+二维码），缺入口＝不计入"出货"。
  - `R-G3` 季度内**已测款数 ≥ 已做款数 × 0.5**（治"只做不测"）。
  - 阈值【待核】：Voodoo 类原型→测试量级与 CPI/D1 门槛。

### 2 BigStream（AI 内容/自媒体）
- **对标**：MrBeast 团队（内容工业化）、头部 MCN 数据化产线【事实·常识级】
- **他们赢在哪（机制）**：**用"点击率×留存曲线"驱动选题与剪辑**——缩略图/封面多版测试、开头 3 秒定型、按留存曲线砍中段；**发布是生产的一部分，不是终点**。
- **我方基线【实测】**：独立成片 **25 件 / 已发布 0 条**；`accounts.md` 11 平台全"未注册"；`analytics.md` 全"未测量"。
- **差距**：**没有发布面＝没有真实数据面＝无法迭代**。现在的"质量"是自评，不是市场反馈。
- **检查规则**
  - `R-S1` **发布比闸**：`已发布 / 成品 ≥ 0.3`（月度）；低于即冻结新增成品产能，转投发布。
  - `R-S2` 每条发布**必回写**：封面点击率、3 秒留存、完播率三项；缺一项＝该条未完成。
  - `R-S3` 封面/开头**A/B ≥2 版**（治"一版定生死"）。
  - 阈值【待核】：MrBeast 类留存/点击效率目标与迭代节奏。

### 3 FluxVerse（元宙城/3D 世界）
- **对标**：Epic（Fortnite 模块化关卡＋引擎管线）、Roblox（UGC 生态）【事实·常识级】
- **他们赢在哪（机制）**：**模块化套件＋程序化拼装＋可见结果**。资产**数量不是资产**，"可复用模块＋装配器＋验收截图"才是。
- **我方基线【实测】**：48 包 **48,992 件**；`City3D/Assets/Scripts` 仅 **3 个脚本**；正典与 README/DESIGN 仍写"禁一切 3D"（文档冲突未清）。
- **差距**：**资产堆成库，装配没进管线**；且**入口三分**（City / City3D / staging）无单一可见物。
- **检查规则**
  - `R-F1` **模块复用率**：装配产出中引用同一模块 ≥2 次的件占比 ≥0.4；低于即"仍在堆资产"。
  - `R-F2` **装配必须过装配器**：`ui-layout.json`（或等价 layout 数据）实例数 > 0，且运行时不得硬编码建城（同 UI 的 G7 教训）。
  - `R-F3` **每周 ≥1 张 L0 全景截图**入证据链（可见即验收）。

### 4 BigMoney（量化）
- **对标**：Renaissance Medallion（数据与执行碾压）、AQR（研究规范与"何时认输"）【事实·常识级】
- **他们赢在哪（机制）**：**不对外募资＋把资源砸在数据质量与执行成本上＋对"策略数量"极度克制**；且**有明确的认输机制**（某类信号长期不成立即永久关线）。
- **我方基线【实测】**：过门 **0**；试验账本 N=**362,083**，技能线 **1.1958**，被动 0.3792；GPU 利用率与成本口径未对账；**修复后 6 员中 2 员已跌破自身 OOS 门**。
- **差距**：**账本规模世界级、可信度与产出为零**；成本模型存在"13bp 口径 vs 分层实现"的待证差异。
- **检查规则（本线我已另立附录 B，此处只列对标增量）**
  - `R-M1` **"更少更大"闸**：新增一族前须证明"该族比现有族信息增量 > 0"（相关性 <0.7 且独立事件窗 ≥40）——**禁为凑数扩容**（N 每涨都在抬自己的门）。
  - `R-M2` **成本对账**：任何对外收益数与回测数，须附**逐笔成本对账**（回测口径 vs 纸盘口径差 ≤1bp/边）。
  - `R-M3` **认输机制**：每类信号设"永久关线"判据（如连续 2 轮 pre-reg 判负即关类），入册且**禁改名重提**。
  - 阈值【待核】：头部量化的数据/执行投入比与 TCA 做法。

### 5 BigDomain（硅基域/共创平台）
- **对标**：Roblox（创作者经济）／Discord（社区留存）【事实·常识级】
- **他们赢在哪（机制）**：**先有"可进入的地方"，再有创作者，再有分成**；`可访问前台` 是一切的零点。
- **我方基线【实测】**：可访问前台 **0**；真实用户/订单/收入 **0**；BLUEPRINT 承诺 19.9 算力包/大厅/门票。
- **差距**：**平台未开门**（服务器/备案/商户号是 CEO 物理件）。
- **检查规则**
  - `R-D1` **北极星＝可访问前台数**（≥1 才算开线，禁以文档/沙盒替代）。
  - `R-D2` 每个功能件上线前须有**外网可达 URL 或本地隧道 URL**＋一次真实点击录屏。
  - `R-D3` 创作者侧：**先跑通 1 个"外部人可完成"的闭环**（注册→产出→被看见），再谈规模。

### 6 BigLife（数字生命/人口资产）
- **对标**：Duolingo（留存机制）／游戏行业"资产→消费"律【事实·常识级】
- **他们赢在哪（机制）**：**留存靠机制不靠内容量**；**资产的唯一价值是被消费**。
- **我方基线【实测】**：户籍 **10,030**；下游 wired **3 仓**；强冻令执行中。
- **差距**：**库存思维**（卡数增长）而非**消费思维**（每个居民被谁用了几次）。
- **检查规则**
  - `R-L1` **消费率闸**：新增批次必须标注"消费方＋消费形式"；**零消费批不入册**（或标记 `unconsumed`）。
  - `R-L2` **千人千面可验**：同一 seed 同脸机检（已有此判据，须真跑）。
  - `R-L3` 每居民**至少 1 项被下游读取**（behavior/形象/台词任一）才算"活的"。

### 7 BigCompute（算力商业化）
- **对标**：CoreWeave／Lambda Labs／Together AI／Vast.ai【事实·常识级】
- **他们赢在哪（机制）**：**利用率是命**（公开讨论多在 70%+ 区间；长期低于 50% 即结构性亏损）＋**预留/按需/按 token 的产品化分层**＋**客户来自 AI 训练/推理的真实需求**。
- **我方基线【实测】**：GPU 平均 **14.0% / 17.6%**（S4 面）；成交/商业 tokens/云端账单/借算工单**四源全零**；净窗 10/10 BLOCKED。
- **差距**：**利用率与商业化双低**；且"唯一出口"无收款面（商户号）。
- **检查规则**
  - `R-C1` **利用率 KPI**：7 日均值 **<50% 即判结构性失败**（不是优化问题，是模式问题）；≥70% 为目标【待核阈值区间】。
  - `R-C2` **不得以"被兄弟司占用"掩盖**：自家 GPU 净窗被占必须计入"服务兄弟司"的内部计价（内部转移价），否则利用率无意义。
  - `R-C3` 产品化分层：**按小时/预留/按 token** 三种计价至少实现一种并可对外报价。

## 二 跨线共性规律（治根的两条）
1. **下游第一**：任何产线的第一优先不是"做得更好"，而是"**先让它被真人触达**"。规则：各线北极星统一含**一个外部可达指标**（发布数/上线数/到账额/可达 URL）。
2. **只放大过关的那一条**：**未过市场测试不得投产能**。规则：产能投入前须有测试结论（游戏＝素材测试／内容＝数据回流／量化＝过门／算力＝成交）。

## 三 规律检查的执行方式（AI 可准确执行）
- **载体**：并入既有 `Tools/deliverable-probe.ps1`（三指标）与各线闸；**每条规则一条机器判据**，输出 `pass/fail + 证据指针`。
- **节律**：周轮出"对标差距表"一行/线；月轮复核阈值。
- **失败后果**：并入既有诚实律与点名机制，**不新增惩罚**。
