## 三 为什么测不出——**错在我的测量工具，不在模型**（第 5 次同型）

**T1 我的断言写错了两处**：
1. **切片错位**：我把 `R[3]` 的期望值算成了 `R[4]` 的（先被模型"报错"暴露）
2. **标准差口径错**：我按**总体标准差(÷n)**，而通用惯例是**样本标准差(÷n−1)**——导致期望值和模型实现不一致

**验证方式**：我用**自己的参考实现**跑同一断言，**也没通过** → 证明**断言错，不是模型错**。

**T2 我的判分也不公平**：
- 旧模型返回 `ValueError`（输入不足两点时抛异常）被记 FAIL——但**抛异常其实是合理设计**，我的判分太严
- qwen3:8b 那次是**我的超时设置**（思考模式更慢），不是模型答不出

## 六 我的建议（不再试了）

1. **本地模型定位为"判定类杂活的工人"**，不是"coding 接手者"。这个定位已实测成立。
2. **不要让它写你的策略代码**——它写错了你不会发现，而策略代码错了要花钱。
3. **它可以干**：把 391 份文档做字段抽取、给预注册打标签、批量分类、语义去重。
4. **要真测它的 coding 能力**，得用**你项目里的真实历史任务**（有已知正确答案的那种），而不是我现编的题——**我现编的题已经证明我自己会编错。**
