# 数据缺口处置方案 v1.0（D-20260930-41 §3 · 外审出件 · 2026-09-30）

> 目的：把六项数据缺口从"要什么"收窄为"**最小必要集**"，并标明**哪几项可自算、哪几项必须外部供给**。
> 本轮关键发现：**PE/PB 不需要外部供给**——可由已有面导出。

## 一 关键收窄：PE/PB 可自算（**不必索取**）

**已实证**（`docs/audits/pe_factor_probe.py`）：
```
PE = 收盘价 × outstanding_share ÷ np_ttm
实测：平安银行 PE=5.23｜贵州茅台 PE=19.25｜宁德时代 PE=15.27   （均与真实市场一致）
可用面：outstanding_share 覆盖 100%（Money02/data/bars parquet 内含）
        np_ttm 覆盖 98%（data/fundamental/eligibility.csv，ttm_ok=True 11,448 / False 187）
PB 顺带可得：PB = PE ÷ (ROE × 100)   ← 需 ROE
```

**⇒ 原 §3 第 1 项"PE/PB/ROE/股息率"应收窄为：**

| 原索取 | 收窄后 | 理由 |
|---|---|---|
| PE | **不需** | 可自算（价×股本÷净利润） |
| PB | **不需**（有 ROE 即可） | `PB = PE ÷ (ROE×100)` |
| **ROE 或 历史逐期净利润** | **★ 必须供给** | **唯一无法自算、且决定估值因子能否验证** |
| 股息率 | 需分红数据 | 可后置（低优先） |

## 二 为什么历史逐期净利润是**不可替代**的（本轮最重要的方法论结论）

**现有 `np_ttm` 是"当前"净利润，套用到全历史＝未来函数。**

**方向性探测结果**（`pe_factor_probe.py`，调仓 60 日、TOP20、成交额>5 亿、含成本）：

| 策略 | 年化 | 最大回撤 | 年度胜率 |
|---|---|---|---|
| **低 PE** | **+25.65%** | **−10.7%** | **9/10** |
| 高 PE | −13.07% | −83.7% | 2/10 |
| 低量（对照，同宇宙同期） | +6.82% | −46.0% | 4/10 |
| 低 PE + 低量 | +11.97% | −36.5% | 4/10 |

**如实判读**：
- **低 PE 与高 PE 单调分离** → **方向性证据成立**：估值在 A 股有分离度（与申万宏源"估值长期胜率≈50%"并不冲突——那是**胜率**，这是**多空分离度**）。
- **但 +25.65% 与 −10.7% 回撤被未来函数严重美化**：等于"知道哪些公司后来赚了钱，再回到过去买它便宜的年份"。**低 PE 正是该偏差的最大受益者。**
- **⇒ 本结果只能作方向性探测，不得作为验证结论、不得对外、不得据以建仓。**

**唯一解**：取得**点位时点（point-in-time）历史净利润**（财报逐期，含公告日，避免用未公布数据）。

## 三 六项缺口的处置路径（按 可自算 / 需外部 / 可后置 三分）

| # | 缺口 | 处置 | 依据/工具 |
|---|---|---|---|
| 1 | ~~PE/PB~~ | **可自算，撤回索取** | 本轮实证 |
| 1b | **历史逐期净利润 / 历史 ROE（点位时点）** | **★ 必须外部供给** | akshare 财报接口或该司采集器 |
| 2 | 上市/退市日期 + 退市股行情 | **需外部**；akshare `stock_info_sh_delist`/`stock_info_sz_delist` **已实测可用**（沪 153 / 深 208，含日期） | 本轮已取到名单，**行情需补** |
| 3 | 逐日历史 ST 状态 | **需外部**；现有 `b_layer_mask` 用"今天 ST 套全历史"（其 caveat 自认） | 可先做**方向性上界**（当前偏差方向已知：过杀今疑） |
| 4 | 指数成分史（含权重） | **需外部**；仅用于"跑赢被动"验收，非因子必需 | **可后置** |
| 5 | 2016 前 ETF 日线 | **需外部**；用于把配置回测样本从 6.7 年扩到 15+ 年 | 中优先 |
| 6 | 真实成交回报 | **需该司实盘** | 纸盘 5 日已有，0 差异 |

## 四 可立即执行的三件（不等外部数据）

1. **#2 退市名单已到手** → 可立刻把"面板零退市"的偏差**从定性变定量**（已有 361 只名单，含退市日期）
2. **#3 可做方向性上界**：ST 判定偏差方向＝"今天的 ST 名单套全历史"＝**过度剔除**（今天不是 ST、当年是 ST 的股票被误纳）。可据此给出**保守上界**
3. **PE 因子可做"半验证"**：用**最近 N 年**（净利润近似稳定期）跑，缩小未来函数窗口——**仍是近似，须标明**
