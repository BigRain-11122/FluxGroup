## 六 本会话沉淀的六条方法（建议入章程）

1. **外审前置三步**：先 grep 官方索引件 → 再查既有立法 → 最后才提新立法。
   （实证：我几乎自造"投递层统一"新律，而 `cph4/evolution.md:43-46` 09-24 早有「落台账≠送达」律＋三司合规先例）
2. **跨司交付验收最省做法**＝"把同一个数自己测一遍"（同法同数＝无造假空间）。
3. **"发现问题就改口径"是危险动作**：无 ground truth 的口径修改只换偏差（v1.1 照我投诉改后过冲：BigMoney 1.2%→53.3%）。
4. **冻结类令必须写"禁什么/不禁什么"**，否则次日被读成"不许提交"而瘫痪收口（RW-5 判据细化）。
5. **探针"全 OK"≠状态健康**：哨兵三探针全绿时集团正处 1:1086——**探针阈值须与律同源＋覆盖面须显式声明**（建议"探针自证表"）。
6. **核查工具的口径必须与所依律原文一致**：我两次收窄口径换来"一次放过＋一次冤枉"。
