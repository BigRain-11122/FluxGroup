# 散户量化研究结论 v2（十五轮实验汇总 · 2026-09-30 外审出件）

> 对象：100 万级散户 · 只做多 · 无杠杆 · 无期货 · 硬铁律（不买亏损/ST/退市/暴雷/北交所）
> 本件=**十五轮实测的总账**，含**被否证的路径**与**业界真值对照**。所有数字可复跑。

**三条最容易造假的维度（我已逐条核对）**：①费前/费后 ②超额/绝对（2025 年 45% 回报里约 2/3 是指数 beta）③样本期（2025 风格极端友好，2026 年初 500 指增**全部跑输 2.5%**）。
**⇒ 百万散户小资金量化的现实长期年化中枢 ≈ 4-8%（费后）；单年波动 ±30%+；跑输指数的年份必然存在。**

## 二 被证实的路径（可实盘）
### 2.1 四资产等权 + 区间自适应频率（**主力仓**）
- 标的：510300 / 511010 / 518880 / 513500（4 类真独立资产；4 只宽基替身相关 >0.9 只留一只）
- 规则：低谷（<MA200 且距 250 日高点 ≤−10%）**每周**、中性每两周、高峰**每季度**检查；权重按区间分档；单标的偏离目标 <15% 不动
- **实测（2020-01→2026-09·1,634 交易日）**：年化 **+5.87%**｜最大回撤 **−14.4%**｜**年度胜率 5/7 = 71%**｜换手 **0.30×/年**｜成本 **3bp/年**｜沪深300 同期 **−1.53%**
- **"低谷加频"有效、"低谷加重仓"反效果**（加重仓版：年化 3.62%、回撤 −26.9%、胜率 57%）

### 2.2 低量选股（**卫星仓**·需按时换仓）
- 信号：`近20日均成交额 / 近120日均成交额` 最小的 TOP20，20 日调仓，等权
- 过滤：**第一铁律**（剔 1,705 只亏损/ST）+ 成交额>5000万 + 价>2 元 + 非涨跌停
- **实测（2016-01→2026-09）**：年化 **+14.80%**｜最大回撤 −25.8%｜**年度胜 8/10**（2018 −19.91%、2026 −3.55%，其余年份为正）｜换手 **31.6×/年**
- **可执行性已验证**：选中标的成交额中位 **0.86 亿/日**、最低 0.5 亿；5 万元一笔占其日均成交额 **0.06%**，**无冲击**
- **第一铁律本身是 alpha**：同一信号不过滤时年化仅 **5.63%**（回撤 −43%），过滤后 **14.80%**（回撤 −25.8%）

## 三 被否证的路径（**十五轮实验·勿再投入算力**）
| 路径 | 实测结果 | 否证原因 |
|---|---|---|
| ETF 横截面动量（周频·31 只） | 年化 −7.65%｜回撤 −55.1% | 窄截面洗噪声；A 股追涨负期望 |
| ETF 横截面反转（周频） | −2.81%｜−28.7% | 同上 |
| 反转 + 无交易带 | −2.05%｜−30.1% | 换手反升 |
| 单标的时序反转/动量（5/10/20 日） | −2.7% ~ +2.8%，胜率 45~51% | **"1–15 天短线"在 ETF 上无正期望** |
| 均线/动量择时（MA200、20/60 同向） | 42.1% vs 44.7%；20/60 同向 **反向** | **趋势类择时在 A 股宽基上无信息** |
| 风格延续性（追上年最强） | 6 年中 4 次次年排名后半 | **风格延续性不存在，只能分散不能押注** |
| 网格交易 | 上证50 +11.9% 超额，**黄金 −142% 机会成本** | 网格赚震荡、输趋势；标的极难选 |
| **低价/小市值（"26.8%"）** | **提高流动性下限即归零**：>0.5亿 13.42%→>10亿 **0.80%**→>20亿 **0.40%** | **小市值+幸存者偏差幻觉**；与申万宏源"市值/流动性因子已走平反向"一致 |
| 大盘水温前置（广度/量比/MA200） | 全部劣于无前置（14.80%→3.46%~13.64%） | **低量信号本质逆势，加确认即自我消灭** |
| 个股级前置（站上MA20/前20日为正） | 14.80%→**−0.91%** / 1.58% | 同上 |
| 缓冲降换手（+10/+20） | 14.87%（但年度胜 6/10）/+20 崩至 10.74%、回撤 −41.5% | **信号衰减快，换手压不下来** |

**核心机制结论**：**"低量 + 第一铁律"是真实、稳定、但高换手的逆势信号；它不能通过加任何"确认"条件变温和——温和化即消灭。**

## 四 关键数据缺口（**唯一还没堵上的提升路径**）
- **`data/fundamental/eligibility.csv` 只有净利润（np_annual/np_interim/np_ttm），无 PE / PB / ROE / 股息率**
- 而 A 股公认最稳健的因子恰是**低估值、红利、质量、低波**：申万宏源金工实测「**估值、动量、反转、市值、流动性的长期胜率不佳，在 50% 附近或更低**；长期胜率较高的是**低波因子**」
- **⇒ 在补齐估值/质量数据前，无法构建这些因子，"提高收益"这一诉求在现有数据面上已到顶。**
- 补救路径：补 PE/PB/ROE/股息率（akshare 可取，或该司 `data/basic` 扩展）
- **另`b_layer_mask` 用"今天的盈利状态"判定并**套用全历史**（其 caveat 自认）→ "当年盈利、现在亏损"的股票被整段剔除，构成第二重偏差
