# QA Smoke Test Charter — 每司自验手册 v1.0

> 核心原则：**写文档不算完成，跑起来并截图证据才算。** 每轮commit后必须自验，缺一项=该轮白干。
> 苦力自己干，AI自己跑脚本，不许等CEO看。

---

## 通用流程（所有司都一样）

每轮结束前跑一遍：
1. **Build**：能不能编译/启动？报错=P0，立刻修。
2. **Smoke**：启动后跑固定脚本（见各司清单），看会不会崩/卡死/黑屏。
3. **Screenshot**：关键帧截图存 `qa/smoke-<r编号>.png`。
4. **Log**：错误日志存 `qa/smoke-<r编号>.log`。
5. **Self-judge**：对照验收清单逐条打勾，缺项=下轮第一优先级修。
6. **不许自己说"完成了"**——验收清单全打勾+截图在=完成。

## 各司验收清单

### FluxVerse（硅基城市·团结引擎）
- [ ] 编辑器能打开，Scene不报错
- [ ] Game视图能看到地面tile（不是黑屏）
- [ ] 至少有一条黄浦江（蓝色水面层）
- [ ] 白玉兰脑塔在画面里（北岸制高点）
- [ ] 至少5个居民prefab在场景里，不是全空
- [ ] 切白天→黄昏→夜晚，画面确实变色
- [ ] 跑10分钟无Unity报错
- **截图要求**：俯视视角一张全景、黄昏一张、居民走动一张

### Biggame（游戏项目）
- [ ] 游戏能build出exe/webgl
- [ ] 启动后主菜单能点进去
- [ ] 玩家能控制角色移动（WASD不报错）
- [ ] 至少一个关卡能跑完不卡墙
- [ ] 死亡/重生能触发
- [ ] 跑10分钟无崩溃
- **截图要求**：主菜单一张、 gameplay一张、死亡一张

### BigMoney（量化）
- [ ] 策略脚本能跑通一次完整回测
- [ ] 回测结果有数字（不是空DataFrame）
- [ ] 收益曲线能画出来存png
- [ ] 实盘信号生成不报错
- [ ] 数据拉取正常（market-fetch.log无错误）
- **证据要求**：回测报告md+收益曲线图

### BigStream（内容）
- [ ] 脚本能跑完一集/一篇
- [ ] 产出文件真的存在（视频/图/文案，不是auto-save聊天记录）
- [ ] 产出文件>100KB（空文件=没产出）
- [ ] 内容不含乱码/中文乱码/半截句子
- **证据要求**：产出文件路径+大小+第一行内容截图

### BigLife（硅基生命体）
- [ ] poolgen脚本跑通一轮
- [ ] 居民census有新条目（时间戳更新）
- [ ] 居民有位置字段（不是null）
- [ ] 居民一天的行为链能生成（起床→上班→回家）
- [ ] heartbeat.txt在3h内更新过
- **证据要求**：census最新条目+行为链样例

### BigCompute（算力）
- [ ] GPU监控脚本能跑，输出利用率数字
- [ ] Ollama能响应一个query（不是挂着）
- [ ] 任务队列不空（至少3条待办）
- [ ] 成本账本在更新
- **证据要求**：nvidia-smi截图+Ollama响应测试

### BigDomain（市场调研）
- [ ] 每天至少爬一个新数据源
- [ ] benchmark表在更新（不是停更15h）
- [ ] 调研结论有数据来源（不是编的）
- [ ] 发现的信号写进intelligence-wall
- **证据要求**：最新调研文件+数据来源链接

### CPH4 Labs（实验室）
- [ ] 实验脚本跑通一次
- [ ] 对比结果有数字（实验组vs对照组）
- [ ] 实验结论可复现（脚本在git里）
- [ ] 技术交易所里至少有一条新工具
- **证据要求**：实验报告+脚本路径

## 红灯规则
- 任何一条build不过=P0，立刻修，不许往下走。
- 连续两轮smoke不过=该司自循环有问题，CPH4接管重写。
- 自验造假（截图P图/日志伪造）=诚实律红线，P1。
