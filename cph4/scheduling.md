# Scheduling — 集团算力与时间调度机制（CPH4 Labs）

> CEO 令（2026-09-23 原话）：「建立集团顶层机制，所有子公司合理分配算力和时间，调度科学，缺资源可以汇报给ceo。云端算力目前无限，最大化并行利用，做好技术基建，尤其是本地化的能力！」

## 0. 三原则

1. **云端无限，并行优先**：当前云端 API 算力无上限——「排队等云端」是伪约束；任务默认并行开跑，禁串行化等待（一台机器忙≠集团忙）。
2. **本地是基建**：本地算力=基建能力（`local-first.md` L1/L2 阶梯），建设优先级高于省钱；**只有本地任务需要调度**（显存/RAM/物理核有限），云端任务不需要。
3. **调度=机制约定，非调度守护进程**：不建中央调度器——调度以「规则 + 心跳台账 + 裁决」落地，防官僚层。

## 1. 算力与时间分配规则（科学调度）

- **配置分配表**：机器群按配置归属各子公司+空余算力可借池——配置面= `fleet-allocations.md`（CEO 令 2026-09-23「机器群根据配置合理分给各子公司+空余可借+云算力未指令前并行全量」·本文件姊妹件）。
- **verdict 驱动放置**：开工前读全机队心跳 verdict（fleet/machines、FleetStatus 范式）——GPU 空闲 ≥6GB（GPU_ML_READY 档）才开 LLM 重活；RAM<4GB 禁新开重活；CPU 并行合计 ≤ 物理核-2（既有 fleet §10 律，全集团适用）。
- **双通道并行律**：云端（L3）与本地（L1/L2）不互斥——同一循环内「云端推理 + 本地渲染/生成」并行开跑（BigStream m2-local-stack 四工位 PoC 为范式）。
- **节律互不抢占**：各司 OS 循环（10min tick）独立运转；共享机时段冲突=心跳 verdict 协商，后到让路。
- **拆批默认并行**：可拆批任务（回测批/素材批/渲染批）默认拆并行（BigMoney worker 上限 `min(12, 空闲GB/0.5)` 为范式）；机器闲置且有 open 任务单=可认领（跨公司借算合法，fleet §5）。

## 2. 缺资源汇报通道（escalation → CEO）

- **常规**：各司资源缺口（显存不足/缺权重/需装机/需组网/需账号）→ 记 `HQ-FEEDBACK.md`（标 `P0-Resource`）或本司任务单 → **周进化轮收取汇总进周报「资源缺口清单」** → CEO 一句话裁决。
- **紧急**：P0 缺口阻塞主线 → 当下任一会话直接呈报 CEO + 台账留档，**不等周日**。
- CEO 物理件域照旧：装机授权 / 账号域 / 大额采购 / Tailscale 组网。

## 3. 本地化基建（尤其项）

- 各司按 `local-first.md` 阶梯建设 L1/L2；**集团共享能力一处建**（禁双建律）：本地 LLM 栈（Ollama 模型库+keepwarm）、TTS/STT/FFmpeg 工具链、AIGC 管线——建在谁的域，`cph4/README` 注册表登记托管方，他司引用复用（借算或远程调用）。
- **模型资产统一登记**（防各司乱拉权重占盘）：现役 bm-a=qwen2.5:7b（Biggame 系保温）+ qwen2.5:14b（BigStream m2 计划）——新权重入列先登记。
- 测量照旧：token 计量（BigMoney 已开）各司跟进，进化轮周报聚合集团趋势。
