## 一、五条总则

1. **一域一正身**：同一件事只允许一个执行依据；出现第二份即退役或降为参考。
2. **快照非现行法**：文件名带日期或 `-vN` 的审计/总图/计划/复盘，一律历史记录，除非本件点名收录。
3. **阈值只进配置**：任何数字（租约、槽位、响度、帧率、抽卡上限、并发位、版本区间）只写在 JSON 配置或规则引擎常量里；文档只解释，不复述数值。
4. **配置即法律，文档即解释**：机队行为以 `cph4/fleet/*.json` 与 `Tools/fleet/` 的执行体为准；文档写错不等于系统错，系统错不能靠改文档修。
5. **整理必须有据**：任何删除/归档只能由 `Tools/fleet/docs_curate.py` 的分类规则产生（受保护面、被引用、完全重复、过期一次性报告四类判据），不接受手工拍脑袋清理。

## 四、文档库规则（2026-11-11 立）

- **受保护面永不动**：`cph4/registry/`、`cph4/fleet/*.json`、`cph4/fleet/stations/`、`Tools/`、`docs/governance.md`、`docs/orders.md`、`README/RULES/BRAND/AI/CODELY`、`.codely-cli/`。
- **被代码或配置引用的一律保留**（路径出现在 `.py/.json/.sh/.ps1/.plist/.cmd` 里）。
- **只允许三类动作**：空文件（<40B）删除；与另一份内容完全相同（sha 相同）删除多余份；过期一次性报告（`R-*`/`REPORT*`/`AUDIT*`/`RECAP*`/`daily-*` 且 >60 天无人引用）移入 `docs/_archive-<日期>/`。
- **执行与复核**：`python3 Tools/fleet/docs_curate.py --scan`（看计划）→ `--apply`（动手）→ `--check`（正典指针可解析 + 重复清空）。
