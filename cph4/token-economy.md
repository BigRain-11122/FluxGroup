## 〇、一句话

**Token 是集团的水电与口粮：放开烧（速度优先）+ 计量可见（每轮一行）+ 本地替换（结构性下降）——省 token 靠换机制，不靠省着用。**

## 二、机制五律（集团法）

1. **计量先行律**：一切优化先计量。各司 OS 循环轮账本带一行标准 token 面：`tokens: local=<次数> api=<次数> api_reason=<一句话|->`（本地按次计、API 有 CLI 数据精确无则粗估标注）；周轮周报聚合三面趋势各一行，升/降如实（禁粉饰）。
2. **路由三问律**（local-first §1 铁律的执法化）：任何**新增** LLM/生成触点先过三问——L1 确定性可解？L2 本地够用？必须 L3？——接线位=各司提案/立项门+CPH4 提案审核面。**存量不追杀**（grandfather），随迭代自然迁移。
3. **L3 留痕律**：云端 API/纯生成调用在本司轮账本留一行原因（谁/为何/粗估）；不建中央台账（调度=机制约定非守护进程同源），审计=周轮抽验。
4. **结构性替换律**：禁「省着用」式优化（砍任务/降频/憋需求）；只认结构性替换（L3 任务→L1 脚本/L2 本地模型承接）。落地证据=季度「本地化覆盖清单」进周轮（local-first §4 续用）。
5. **速度优先律**（CEO 原话锚定「token 可以烧」）：token 费用不是现阶段约束——禁以省钱为由降速/停轮/砍 P0；优化永不伤害主归属任务与资源倾斜态 P0。
