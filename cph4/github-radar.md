> 性质：T2 立法·否决窗 7 天（至 2026-10-06）。本件 ≤60 行·季度法熵审视随周轮。

## 一 职能定谳（三面）

1. **业务理解底座**：研究室=全面理解城市+七司业务的常设持有者——锚件清单=AI.md（组织/机制总览）+FluxVerse BLUEPRINT/DESIGN/TECH+BigLife CODEX/SILICON-LIFE+BigMoney PLAN+fleet+BigStream PLAN+BigDomain BLUEPRINT+BigCompute BLUEPRINT+MiniGame 产品仓族+cph4/city-lab+README 注册表。**每轮研究必带司域映射一行**（发现→哪个司哪个业务面），零映射=未交付。
2. **持续赋能**：创新/技术/工具产出走既有落点强制律（接线单/采用登记/结论应用表）——闭环率=唯一 KPI（city-lab 同律），产出量=虚荣指标。
3. **风向雷达**：GitHub 风向与技术的集团横切面——高频点赞项目（trending/高星好评）务必研究落实（见 §三判据）。

## 三 「高频点赞=务必研究落实」判据（CEO 原话即约束）

1. trending 榜内与七司业务**契合**的项目 → **必研究**：R- 切片或 OH 切片承载·五门评估（oss-harvest §四）·api.github.com 逐件直验（限流时 git ls-remote/raw 直读换源律）。
2. 契合且过五门 → **必落实**：接线单/采用登记（oss-harvest §五）/转目标司任务单——无落点=未交付。
3. 不契合 → **一句话判负留痕**（诚实律·禁止硬凑）。
4. 三红线不变：GPL/AGPL 禁入产品交付链（工具环境例外注记）/许可逐件验原文/外部工程资产不搬。
5. **即 hot 即报**：star 暴涨级/爆发性项目（日增千星族）→ 当窗即报夜轮/值守轮线，不等 72h 窗。

## 四 节律与台账

- **每窗（72h·OSS 轮）**：CPH4 切片必含风向面 ≥1（trending 扫描实录+候选判读）——OH-<date>-cph4.md 切片承载。
- **周轮**：风向简报一行入进化轮五议程（本周榜内契合件/已落实件/判负件计数）；**《风向简报》=CEO 可读呈递件**（CEO 令 2026-10-04 原话锚定「有意思的、有趣的分享之类的」——有趣发现优先呈现+业务契合处置表+诚实面；R-<date>-radar-digest-NN.md 承载）。
- **回访**：研究→落实→生效闭环率随周轮抽验（audit-office 同向无效功面咬合）。

## 六 路由闭环（v1.1·CEO 令 2026-10-04 ~23:0x「过目+认领」机制·P-2026-10-04-01）

### 6.1 全领域扫描面（禁偏科）
每窗按分区清单逐域实搜（search API 组合·结果全录）：**核心七域每窗必扫**=①游戏/引擎/美术管线（Biggame·FluxVerse）②量化/金融数据（BigMoney）③媒体内容生成（BigStream）④商业化/增长（BigDomain·BigCompute）⑤数字生命/多模态（BigLife）⑥治理/协同工具（HQ·council）⑦AI 基建/本地推理（全司）；**扩展四域轮换扫**（每窗 ≥2）=⑧开发者工具/自动化（CPH4·机队）⑨3D/渲染/shader（城 3D 线）⑩音频/TTS/ASR（BigLife·BigStream）⑪有趣/创想（CEO 分享面）。

### 6.2 深研分级
L1 榜单判读（每窗全录）→ L2 五门+司域映射（契合件入候选表）→ **L3 深研件**（高价值+高不确定性候选：R-<date>-radar-<slug> 专项=机制拆解/许可深验/与现役对比/落地判据预注册——「深入调研」的承载件）。

### 6.3 过目双通道（寄宿零新循环）
- **窗级·各司过目**：候选清单随 OH-<date>-cph4.md 切片落库——各司 OS 循环每窗本就要交自己切片（同目录天然过目点）；强契合件标 @司名（哨兵唤醒模式同款·复用 OrderSentinel 不另建）。
- **周级·委员会过目**：风向简报入进化轮五议程+附决策轮上报包一路输入（decision.md 上报面）——委员会秘书处分级转发：强契合→点名转办/跨司冲突→仲裁/均不契合→判负背书。

### 6.4 认领制（「设置领取」）
- 候选表逐件带**认领位**：`| 件 | 司域映射 | 建议级 | 认领（空=待领） |`
- 各司认领动作=**在己方 OH-<date>-<司slug>.md 写固定格式认领行**（`认领|<件名>|来源=雷达窗<date>|转任务单指针`）——各写各文件零写撞·审计可扫（固定格式）。
- 认领后转司内任务单/OH 接线单（既有落点律）。**两窗未领**=研究室周轮三态处置：判负留痕/转学实现池/升呈 CEO。
- 雷达自身高契合件沿用「接线单」直派制（哨兵唤醒）——认领制是补充通道非替代。

### 6.5 闭环计量（周报一行）
候选 N/认领 M/落地 K/判负 J/悬空 W——认领率与落地率首月测基线后定标（预注册禁拍脑袋）；审计部消费缺失探针可扫认领后未落地件。

## 六 收益导向校准（2026-10-04 CEO 令 P-2026-10-04-02·append 修订批）

- **判据透镜加权**：风向判读以「商业化/自动化/创新绩效」为第一透镜——可变现件（自动化商业管线/营收工具/降本增效件）升权优先，纯玩具/纯趣味类降权（有趣面保留在简报娱乐节但不占处置资源）。
- **落地链四段制**：研究→接线→**执行→收益**——闭环不能停在派单：接线单必须含「预期收益形态」（省 token/省工时/直接营收三型）+收益回访时点（部署后随周轮回访实际收益）。
- **收益记账**：已落地件的收益实况随周轮进「风向简报收益面专节」（#2 起常设）：本期新增部署 N 件/省 M 工时或 M 轮 token/直接营收 X 元（BigCompute 中枢出口记账）。
- **绩效口径**：创新绩效=可量化（禁「采用了」式空转宣称）——每件过门后 30 天内须有第一笔可测收益（三型任一），否则接线单降级 parked 留痕。
