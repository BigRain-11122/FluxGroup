> 性质：T2 生效+7 天否决窗（至 2026-10-01）。与 retention.md §9（备份三级）/errors.md（E 分级）/onboarding.md（身份密钥律）同源引用不重复。
> 适用：自建后端主机（硅基域公共商业面唯一承载）。**内部面功能（机队/探针/tick/git 流）永禁迁上此机**（红线修正案护栏）。

## 〇、一句话

**公网资产按银行金库管：最小暴露面 + 密钥隔离 + 日日快照 + 探针守夜 + 变更全走 git——AI 远程运维，人只看报告。**

## 一、最小攻击面律（上线前门禁·未过禁公网）

1. 对外仅开 **443**（TLS）——SSH（22）限源 IP 白名单（bm-a 出口+CEO 常用地），或改高位端口+密钥制；其余端口全关。
2. SSH：**禁 root 直登、禁密码登录**（`PermitRootLogin no` + `PasswordAuthentication no`）——密钥走 onboarding 身份律。
3. 服务栈：docker-compose 单栈（Nginx 反代唯一入口·API/DB/worker 全不对外·容器无特权模式）。
4. 数据库（SQLite）与弹幕 worker 永禁对外监听；管理面不部署 web 面板（运维=SSH+脚本，不装宝塔类面板=减暴露面）。

## 二、密钥律（onboarding.md 身份律的服务器版）

1. SSH 私钥与 API 密钥（微信支付/开放平台/B站开放平台）=**环境变量或 /etc/fluxvault/ 密管文件**（权限 600·root 属主）——**永禁入任何 git 仓、永禁入对话、永禁入日志**。
2. 密钥轮换：季度制（每季度首周换 SSH 密钥口令+API 密钥复核）；泄露疑似=E0 直呈 CEO 即时轮换。
3. 备份面密钥刻意不备份（FLEET-OPS 三级模型同源——泄露面最小化；重建走重新授权）。

## 三、备份与恢复律（retention §9 一级）

1. 云快照每日自动（保留 7 天滚动）+重大变更前手动快照锚。
2. **全部配置 IaC 化入 git**（docker-compose/安全基线脚本/nginx 配置——脱敏模板入仓·密钥占位符）：恢复=新机跑 bootstrap 15 分钟重建整机。
3. 业务数据（SQLite+事件 jsonl 导出）每日离机备份（云对象存储或 bm-a 拉取双通道）。
4. 月度恢复演练（retention §9 范式·夜轮提案面记账）。

## 四、监控与告警律（task-health 五信号的服务器版）

1. 可用性探针 5min（外部位探测 443+API 健康）——连续 2 次失败=微信通知通道告警（CEO 可见面）。
2. 告警分级沿 errors.md：**CEO 可见面宕机=E0 直呈**（禁等轮次）；API 异常率/CPU/磁盘水位=E2 台账处理。
3. 日志：接入日志/操作日志/WAF 日志留存 **≥6 个月**（法定·云日志服务）。

## 五、变更纪律（单执行体的服务器版）

1. 生产变更一律走 **git→服务器拉取→compose 重启**（禁手改生产文件）；变更=小步+回滚快照锚。
2. AI 机队经 SSH 远程运维（bm-a 出发）——**每次运维留一行台账**（时间/机器/动作/结果）。
3. 发布锚律：对外公测先 tag（versioning §3.4）。

## 六、补丁与维护窗

1. 每月一次安全补丁窗（自动 apt upgrade 安全级+内核外的常规更新·先快照后执行·失败回滚）。
2. 大版本升级（OS/数据库引擎）=单独立项呈批。

## 七、边界与红线（护栏三条）

1. **内部面永禁迁上**：机队控制/探针/tick/集团 git 流永不部署此机（红线修正案款原文）。
2. **真金与代币边界不变**：代币=纯内循环双式账本（每日对账脚本）；真金操作永禁全自动（集团红线·支付回调只记账不动资金策略）。
3. **内容安全前置闸不变**：UGC/大厅/弹幕回流水走 msgSecCheck 先行（BigDomain §五.3）。
