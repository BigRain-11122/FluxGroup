## 一、中国法边界（Q1：民法典/深度合成/生成式AI/标识办法+案例）
- ✓ 民法典第994条（B/C·ahdhf、vlaws、法信faxin、头条等 5+ 独立源逐字一致，官网直读两败后多源互证采信）：「死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母有权依法请求行为人承担民事责任；死者没有配偶、子女且父母已经死亡的，其他近亲属有权…」。性质=近亲属事后维权请求权，非美国式遗产商业授权机制；「声音」未列明（第1023条声音参照肖像→逝者声音保护系类推🟡）。
- ✓ 深度合成管理规定（网信办/工信部/公安部令第12号·2023-01-10施行，A·原文）：第14条提供人脸/人声等生物识别编辑功能→须告知被编辑个人并取得单独同意（逝者无法自诺→实操转近亲属授权系推断🟡·法无明文）；第17条智能对话/仿声/人脸生成等须显著标识；第18条禁删改隐匿标识；全文无逝者专门条款。
- ✓ 生成式AI暂行办法（七部门令第15号·2023-08-15施行，A·原文）：第4条(四)「尊重他人合法权益…不得侵害他人肖像权、名誉权、荣誉权、隐私权和个人信息权益」；无逝者专门条款。
- ✓ AIGC标识办法（A·原文）：显式+隐式标识（第3-5条）、传播平台核验（第6条）、用户主动声明（第10条）、须符合强制性国家标准（第11条）；第14条：2025-09-01施行。
- ✓ 最高法《关于依法审理涉人工智能纠纷案件的意见》（2026-09发布，B·人民日报2026-09-18）：对「AI换脸拟声」「AI复活逝者」依法保障自然人人格权益并延伸至死者人格利益保护；人格权侵害禁令制度引入AI场景；AI仿冒名人带货构成欺诈→支持惩罚性赔偿。
- ✓ 案例（均B·主流媒体）：乔任梁（2016-09逝）2024-03被博主AI复活，父亲称未经同意、要求下架（红星新闻）；李玟（2023逝）2024-03-28母亲委托广东梦海律所声明限7日下架，2025-03-31侵权方删内容+公开致歉+赔偿（星岛/中华网）；江歌母亲江秋莲公开反对AI复活（潇湘晨报via凤凰）。
- ✓ 全国首例AI生成声音人格权案（2024-04-23北京互联网法院宣判·殷某案，B·北京普法网bj148+判决书全文ciplawyer+金诚同达解读）：声音具可识别性→AI生成声音受自然人声音权益保护；后判「孟帅案」提出技术容忍义务（B·律所解读）。
- ✓ 监管动态：中央网信办2026-04-30部署「清朗·整治AI应用乱象」专项行动（为期4个月），重点整治不当使用AI「复活逝者」（B·网信中国via腾讯新闻）。

## 二、域外边界（Q2：美/日/韩·爱因斯坦遗产与鸟山明 IP 归属实况）
- ✓ 美国·加州 Civil Code §3344.1（A·leginfo原文）：死后形象权=财产权、可依遗嘱/信托转移，保护至死后70年（(g)款）；无转移且无配偶/子女/父母→权利终止（(e)款）；2024年AB 1836修正（2025-01-01生效，(a)(2)）：未经授权在视听作品/录音中制作、传播死者「数字复制品」（digital replica）→赔偿≥$10,000或实际损失；豁免=新闻/评论·批评·学术·讽刺·滑稽/纪录片式再现/一瞬附带——AI复活逝者被州法直接点名。
- ✓ 美国拼图（C·wiki Right of publicity）：1985 Celebrities Rights Act 延至死后70年（回应1979 Lugosi 案「不继承」判决）；各州差异极大（印第安纳/俄克拉荷马100年；Monroe案2008：住所纽约州→当时无死后保护）——同一逝者受不受保护取决于住所地州法。
- 🟡 爱因斯坦实况：主流记载=遗嘱将姓名/形象权留予希伯来大学、经 GreenLight 代理商业授权（本轮两度检索遭反爬未成源→待防线二重访）；落州分析（基于加州3344.1(b)(q)原文的推测）：若行为发生在加州，其死后权视为存续并按遗嘱归属执行。
- ✓ 日本·鸟山明IP（C·wiki Dragon Ball infobox）：Owner=Bird Studio/集英社，漫画1984-1995连载于集英社《周刊少年Jump》→作者2024年逝（溯源头）不改变授权需求：龙珠角色形象/名称须向集英社等权利方取得授权；日本著作权保护期死后70年（2018修法）🟡未本轮核；日本无成文publicity right（2012 Pink Lady案最高裁驳回上诉，C）。
- ✓ 韩国·先例（B·Reuters/半岛/Telegraph/MBC官网）：MBC纪录片《Meeting You》2020-02播出，VR重现母亲张智星（Jang Ji-sung）2016年病逝的7岁女儿Na-yeon（HLH病）；片段观看超1300万次并引发偷窥伦理争议——正当性建立在亲属自愿+非商业+纪录片性质，与国内未授权商业案例成对照。

## 三、虚构角色与致敬边界（Q3：影视 IP 归属+原创致敬的安全做法）
- ✓ 林正英（1952-12-27~1997-11-08逝，C·wiki）：「道长」形象来自1985《僵尸先生》及系列（Mr. Vampire II 1986/III 1987/Vampire Vs Vampire 1989/Magic Cop 1990）——银幕角色著作权归影片权利方，不随演员死亡消灭；出品公司主流记载=洪金宝宝禾（嘉禾体系）🟡本轮未直核。

- ✓ 豁免红线：加州3344.1明文豁免评论/批评/学术/讽刺/滑稽（parody），但限表达性场景且以同意机制为前置；商业虚拟城市内复刻道长造型/桥段=无豁免商业使用；中国法对parody无明文豁免（推测·未见判例）。
- ✓ 安全做法=原创致敬：不复制可识别角色特征组合（黄袍道长+桃木剑+独有桥段）+不冒用片名/人名→自有原创角色；确需历史真人（李白）走L1口径。

## 五、结论应用表（research-protocol §二.1 强制·落点四选一）+三问一句话直答
- Q1 一句话：中国法给的是近亲属（配偶/子女/父母优先，无人时其他近亲属）事后维权请求权+深度合成单独同意/显著标识强监管，无「遗产商业授权」机制，未经授权商业化已实际获赔（李玟案维权闭环）。
- Q2 一句话：域外是州际拼图——加州70年且2025-01-01起AI数字复制品直接侵权（≥$10k）；龙珠类IP归Bird Studio/集英社，作者逝去不解放授权；韩国先例全建立在亲属自愿之上。
- Q3 一句话：角色归制片方IP、真人归近亲属维权，两条授权线独立并行；商业场景无parody豁免，原创致敬（不复制可识别特征组合）是唯一安全做法。
- 最重要法律边界三条：①无近亲属/权利方书面授权，不做已故真人数字居民（994+深度合成14条；加州$10k起赔）；②同意须事前+单独+成文，标识显式+隐式双轨（2025-09-01强制）；③角色授权与真人授权分别拿齐，缺一即下架级红线。
