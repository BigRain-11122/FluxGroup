## §1 路线选型（云服务器主案·物理机诚实评估）

- **主案=云 VPS（国内区域）**【确认·唯一可行路径】：ICP 备案必须挂接入商（云厂商代办通道成熟）；弹性升配；DDoS 基础防护自带；上海区域（与集团同域·延迟面最优）。
- **物理机路线否决记录**【确认】：家宽/办公室宽带无固定 IP、接入商不收备案、80/443 常被运营阻断——**公服不可行**；仅两条出路=①机房托管/租赁机柜（月成本数百起·Phase 3 再评）②作为内部面机器入机队（与本件无关）。若 CEO 本意是物理机，一句话告知，建造书按托管路线改版。
- **配置阶梯（价格=腾讯云轻量官网 2026-09-24 验证·85 折年付）**：Phase 1 主推=**通用型进阶 2核4G·100G SSD·7Mbps·1TB 流量包=1020 元/年**（官方定位"小程序/小游戏后端"=正中场景）；入门档 2核2G=459 元/年（内存紧·不推荐省）；扩容档 4核8G·12Mbps·2TB=2499 元/年——触发升配判据=大厅并发>500 或 CPU 均值>60% 持续一周；另有锐驰型峰值 200Mbps 无限流量档（突发带宽场景）。首单常有更低活动价（六周年 1.4 折起）——下单页同配置选便宜者。

## §2 架构蓝图（单机最小可行·docker-compose 一键部署）

```
用户（微信小游戏/小程序参观端+直播间）
        │ HTTPS 443（唯一开放端口）
   [Nginx] —— TLS 终结 + 静态资源 + 反代
        │
   [API 服务 FastAPI/Node]
   ├── 大厅聊天：WebSocket 房间（Phase 1 百人级单机内·万人级再扇出）
   ├── 19.9 支付：微信支付商户 API + 回调端点（对账台账）
   ├── 代币账本：纯内循环双式账本（只增不改·每日对账脚本）
   ├── UGC 管道：msgSecCheck 先行（合规前置闸不变）→ 入库 → 路由到对应线
   └── 身份/月卡/围观：权益标记+订单
   [弹幕回流 worker]：B站直播开放平台 WebSocket 客户端（常驻进程）→ 公共事件流
        │
   [SQLite WAL]（Phase 1 主案·R-2 §3.3 备选转正）—— 单写者+按日导出 jsonl
        │
   公共面事件方言=内部六字段核+evt_id 超集（R-2 §4 P3 预对齐）
   → 每日 jsonl 导出 → bm-a 拉取入城（world-events 内部总线零改动·P-43 案 2 不受影响）
```

- 关键裁决沿既有法：代币永不提现（合规律不变）；真金隔离（实盘开闸=CEO 唯一门）；公共面事件只进摘要+状态禁内容载荷（脱敏律不变）。
- **内部面红线护栏**：自建主机只承载公共商业面，**内部面功能（机队/探针/tick/git 流）永禁迁上**——修正案文本护栏，写入安全治理立法。

### 3.3 网络日志留存 ≥6 个月（法定）：云日志服务开箱即用（接入日志/操作日志/WAF 日志）。

## §4 安全治理立法（集团首个常驻公网资产=新治理面·T2+否决窗 7 天·随本批立项）

1. **最小攻击面**：仅开 443（+SSH 走密钥·禁密码·禁 root 登录）；数据库/worker 不对外。
2. **密钥律**：SSH 私钥与 API 密钥走环境变量/密管文件（入 onboarding 身份律——永禁入 git）；轮换季度制。
3. **备份**：云快照每日自动 + 全部配置 IaC 入 git（bootstrap 可 15 分钟重建整机）；恢复演练入月度提案面（retention §9 范式）。
4. **监控**：可用性探针 5min（外部位）+微信通知通道；异常=errors.md E 分级（CEO 可见面宕机=E0 直呈）。
5. **更新窗**：每月安全补丁窗（静默自动+回滚快照）；AI 机队经 SSH 远程运维（静默律=本机弹窗面，远程运维天然合规）。
6. **单执行体**：服务器侧变更一律走 git+部署脚本（禁手改生产）；台账=每日一行健康行。
