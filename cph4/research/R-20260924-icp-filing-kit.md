# R-20260924-icp-filing-kit · ICP 备案材料包（CEO 到手即用版）

> 溯源：ledger P-2026-09-24-47 实验室件③·建造书 infra-6 §3.1。备案=自建后端关键路径（1-4 周）——本件把「要准备什么、怎么填、哪里容易驳回」一次备齐。
> 流程主体：腾讯云备案系统（你买服务器/域名的同一家=免换接入商·材料直达管局）。**信息日期 2026-09-24；以备案系统页面实时要求为准【待证】。**

## 一、要准备的材料（一次备齐·拍照件）

| # | 材料 | 说明 |
|---|---|---|
| 1 | **营业执照**（拍照/扫描） | 企业主体备案（建议与未来微信支付商户号**同一主体**——省一次材料） |
| 2 | **法人身份证**正反面（拍照） | 清晰四角完整无反光 |
| 3 | 法人手机号+邮箱 | 接收核验码+管局短信（保持畅通） |
| 4 | 备案服务码 | 腾讯云控制台→轻量服务器实例页一键获取（免费） |
| 5 | 域名（已购+**实名认证通过**） | 实名未过=备案提交不进去——先在域名控制台确认 |

## 二、入口与流程

1. 腾讯云控制台 → 搜「**网站备案**」→ 开始备案 → 选**企业备案**
2. 填主体信息（营业执照上传后自动带出大部分）→ 填网站信息 → 提交腾讯云**初审**（约 1-2 个工作日·有电话回访）
3. 初审过 → 提交**管局审核**（1-4 周·关键路径）→ 期间法人会收**短信核验**（按短信指引人脸/拍照）
4. 通过 → 备案号下来 → 域名解析到服务器 IP → **才可开 web 服务**（备案未过前 80/443 对域名不开——开发测试走 IP 直连）

## 三、网站信息填写模板（降低驳回率）

- **网站名称**：建议用公司名或「硅基域」产品名——**避开**：「博客/论坛/社区/下载/搜索」等敏感词与个人化命名
- **服务内容**（勾选+描述，模板文案）：
  > 「AI 算力验证服务平台：为用户提供人工智能算力服务的在线工具网站，提供 AI 生成结果展示与算力使用记录查询。」
  - 只勾**信息服务类**相关项；**不勾**：交易类/社区论坛类/新闻类（勾了=多一道前置审批）
- **备注**（管局看的一句）：> 「本网站为工具类服务平台，无用户生成内容公开发布功能，无论坛社区功能。」（若 Phase 2 开 UGC 再办增项——**首版备案从简**，先让 19.9 主链路通）

## 四、常见驳回点（三条防雷）

1. 网站名称含敏感词/与主体不符 → 用模板命名
2. 服务内容描述含「平台型业务」字样（如「交易平台/商城」）→ 用工具类描述
3. 主体信息与营业执照不一致 → 全部自动带出·手填处勿改

## 五、备案后两件（挂账勿忘）

1. **公安备案**：上线后 30 日内（全国互联网安全管理平台 beian.mps.gov.cn 注册提交·免费）
2. **备案号挂底**：网站页脚展示备案号+链接到工信部备案系统（模板由 bootstrap 侧 nginx 配置带）
