## 一、规格面（Q1）——三项定谳+两项到货待证
- **TDP 裁决=150W 胜【确认】**：Tesla T10 16GB=**TU102-890-KCD-A1**（12nm·754mm²·3584 CUDA/448 Tensor/56 SM·基 1065MHz·16G GDDR6 256bit=403.2GB/s）TDP 150W·1×8-pin·单槽（BenchGame+HMC 双源 B·2026-10-14 读）+**nvidia-smi 实拍「37W/150W」功率帽**（cyberbus C·驱动 580.105.08·2026-01）+igene 实测满载 150W/闲置 18W（C）。**250W 表格派=SKU 张冠李戴定谳**：市面另有 **GRID RTX T10-16**（TU102-875·4608 CU·**260W**·12.6 TFLOPS·cputronic 摘要 B）同名混卖，内容农场文再讹传「250W 封顶」（CSDN 七卡文·M）→ **Tesla T10 16GB 无任何持证 250W 源**
- **供电/尺寸【确认·B 双源】**：1× 8-pin（标准 PCIe 型·PG150=2080Ti 同板族）·PCIe 3.0 x16·单槽全高被动 111×267×20mm·无视频输出（igene C）——零 SXM2 转接/特线风险成立；次要表格噪声如实录：Boost 库 1395 vs igene 实测上限 1590MHz·CUDA 3584（库）vs 3072（HMC）分歧→到货 nvidia-smi 一显定
- **ECC=矛盾【待证】**：HMC 表「No」（B）vs igene 实测主张「支援 ECC」（C·优缺点列原文）vs nvidia-smi ECC 字段渲染「Off」而非 N/A（cyberbus C·暗示可开）——三源打架，同血统 Tesla T4（Turing）有 ECC 先例 → **到货 `nvidia-smi -q`+尝试 `-e 1` 一测定谳**；可开=24/7 位翻转硬件兜底闭环·不可开=memtest_vulkan 月检+token 一致性抽查入 ops 补偿
- **vBIOS/GRID license=无锁【C 多源】**：标准 Linux 驱动 550.127.08（igene）/580.105.08（cyberbus）、Windows 591.59 免修改直装（CSDN 驱动贴·C·2026）、AWS Cloud Gaming/GRID/标准三分支任选（B站·C）——个人推理用途不涉 GRID/vGPU license；NVIDIA vGPU 16.0 起撤销 C 系列云游戏卡 vGPU 支持（docs 摘要·B）→ 对 compute 用途无影响
- **云游戏 24/7 磨损验卡清单（到货五关）**：①SKU 核验（nvidia-smi 应显 Tesla T10/150W 帽——**防 260W GRID 版混发击穿散热假设·不符即退**）②`-q` 温度墙/P0/ECC 字段 ③memtest_vulkan 显存过夜全测 ④无 ECC 兜底前唯一黑盒法=长跑 token 一致性抽查 ⑤物理查金手指/散热器压痕/日期码。**温度纪律实锚**：被动单槽满载 86°C 即降频（igene C·B站 27B 三档功耗实测 86/81/72°C·C）→ **T7910 塔式导风罩+强制风冷=必要项非可选项**（SPEC §4.1 ¥100 改造维持）

## 二、吞吐面（Q2）——Marlin 矩阵 A 级坐实·双卡锚成立·单卡待证
- **vLLM Marlin×sm75 支持矩阵【A 级·PR#29901 直读·2025-12-02·jinzhen-lin·已 merge·v0.14.0 起】**：权重 **GPTQ✓/AWQ✓/FP8✓/NVFP4✓/MXFP4✗（需 BF16 激活·Turing 无）**；激活 FP16✓/INT8（限 GPTQ·AWQ）✓；**MoE✓（PR 标题即含）**；Turing 代价=无 cp.async 同步替代+m16n8k8 双拼+FP16 累加器。**运行纪律【C 双源实证】**：--dtype float16（config.json bfloat16→float16 手改·mokieli）+--enforce-eager（无 BF16→cuda graph 编译崩·PR 评论+cyberbus）+VLLM_MARLIN_USE_ATOMIC_ADD=1+FLASHINFER 后端；**首调 API 冷启 4-10 分钟**（mokieli C·CPU 单核相关）
- 社区实测矩阵（全 T10·C 级）：单卡 8B Q4_K_M=52-62 t/s@512-8K ctx（igene·llama-bench）——403GB/s 带宽模型自洽；**双卡 27B Q6=36-46 t/s（B 站锚·SPEC 在案维持）**+双卡 27B Q4 llama.cpp 分层≈20.3-20.5 t/s 且速度几乎不随功耗档变（B站 BV16taH6LE2J·C）；**MoE 补证**：4×T10 TP4 Qwen3-30B-A3B W4A16·256K=**单并发 76 t/s**（cyberbus C·2026-01）·Qwen3-Next-80B-A3B AWQ 80K=28 并发总 590 t/s·**35B-A3B 同级跑通实证**：mokieli 4×T10 Qwen3.5-35B-A3B-FP8 256K·32 并发部署成功（t/s 在图不可取·C·2026-03）·姊妹篇 27B-FP8 32 并发总吞吐 519.87 t/s（标题级·C）——**FP8 on sm75=PR 矩阵的实证闭环**
- 我们主活（Qwen3.6-35B-A3B Q4_K_M 22.12G）：双卡全驻留算术成立（10.8G/卡+KV≈12-13G<16G·仓内 alternatives-01 §一）→ 双卡单并发【推测 35-50 t/s：806GB/s÷激活读~1.8G+KV+TP 折损·27B Q6 36-46 锚自洽验证·4 卡 MoE 76 锚半减】；**单卡 --cpu-moe 直测数据全网缺席【待证】**（3 次检索未得）→ 按 SPEC 30-40 推测带+双路 E5v4 RAM 带宽算术收 25-40 档——**建议双卡起步·不承诺单卡速度**
- 验收换算：SPEC §4.1「双卡全驻留 ≥35 字/秒」与锚带相容**但无 2 卡 35B-A3B 直测**——到货 72h 实测定生死

## 三、双卡/多卡面（Q3）——P2P 免补丁成立·T7910 拓扑到货一验
- **Tesla 级 PCIe P2P 开箱即用（GeForce 需破解补丁）（cyberbus C）**：4×T10 于 PEX8796 switch 底板 topo=PIX·`topo -p2p` 全 OK·NCCL 日志 `via P2P/CUMEM`；all_reduce 2 卡 x16 实测：**P2P 开 11.15GB/s@1G vs 关 2.36（4.7 倍）**·均值 busbw 5.02 vs 1.15——TP 延迟增益实锤
- TP2 前提：P2P 需同 root complex（PIX/PXB 拓扑）·跨 PHB/SYS 退 SHM 过内存仍可 TP（慢档）；mokieli 4 卡每 CPU 2 卡跨 NUMA「有一定损耗」仍 519 t/s 总吞吐（C）→ **T7910 双 x16 是否同 root：到货 `nvidia-smi topo -m` 一验【待证】**·NUMA 绑核可减损
- **4 卡整机案配置抄录（两真两伪·基座修正）**：①cyberbus（C·2026-01·**稳定运行近 1 年·10 个月 1.2T tokens**）：PEX8796 底板（3×x16 余 x8·TP 负载不瓶颈）·整机待机 280W/峰值 700W/日 9 度电·4CM 暴力扇 48dB 压 4×150W 烤机·实跑 vLLM TP MoE 单卡 <60W 发热低·CPU/RAM 型号未载明；②mokieli×2（C·2026-03）：**HP ML350 Gen9+双 E5-2630v4+Ubuntu 24.04.3+vLLM nightly**·RAM/PSU 未载明；③④devpress 与 CSDN 七卡文=**内容农场（M 级弃用**：「GP102/Ampere compute_80/768GB/s/TP 按层切分」等硬错与 A 级 PR·多源实拍冲突）——**SPEC §3 引用四案实际仅两案可承重**
- **NVLink 暗门【待证·两源】**：HMC 表「Multi-GPU: 2-way NVLink」（B）+cyberbus 评论区「PG150 换 2080Ti 涡扇后露出 NVLink 接口·疑芯片层未屏蔽」（C）→ 若实证可用 2080Ti 桥升级 TP2——到货 `nvlink -s`+拆散热器一验（低预期高收益·不改决策）

## 四、结论面（不设防版）
- 四条标准逐判：①**稳定成立**（云游戏 24/7 血统+cyberbus 近 1 年零故障+标准 PCIe/8pin 零转接）——前提=散热纪律（86°C 降频墙·导风罩必要）；②**不出错成立**（官方圈：llama.cpp 原生/vLLM 官方+Marlin PR merge/580.105.08 实跑 CUDA 13.0）——**唯 ECC 待证是残留硬件风险**（不可开则无位翻转硬件兜底·黑盒法补偿）；③**可拓展成立**（单槽×3-4 两真案+P2P 免补丁+NVLink 暗门）；④速度弃权轴相容（双卡推测 35-50 t/s ≥ 验收线 35）
- **推翻判据（四条任一触发即推翻）**：①到手验出 260W GRID 混发 SKU ②memtest_vulkan 报错/一致性抽查失真 ③双卡 35B-A3B 调参后仍 <35 t/s ④市价涨破 ¥1400/张（现锚 ¥1000-1400 稳定：cyberbus 1100→「1000 出头」2026-01·igene 1350·卡贩控价 1350·2026-10 知乎摘要）
- **若推翻则推荐：切 2×V100 16G 成套路线（SPEC §4 备选转正）**——速度更快（同款 55 t/s kit 锚）+**ECC/Retired Pages 硬件验卡面=「不出错」轴唯一硬件级优势**+双卡全驻留冷启 13s；代价=SXM2 转接三重风险+1Cat fork 自编税（SPEC §7 清单在案·¥1800-2600 带内）；若 V100 同枯→不动作（bm-a 夜窗过渡+3090 ≤¥4200/A40 ≤¥5000 蹲线）——**不建议 2080Ti 22G 魔改做文本主活**（无并发余量+静默坏块·SPEC 判负维持）
- 保留意见：①SPEC §3「四案在案」须修「两真两伪」——cyberbus+mokieli 承重足够但引用卫生须修；②单卡 --cpu-moe 证据不足以承诺速度→双卡起步或夜窗过渡
- **总判：主案 T7910+2×T10 经终审维持推荐**——150W/8pin/单槽被动/P2P 免补丁/Marlin MoE 全实证坐实；ECC·NVLink·T7910 拓扑三待证项均为到货一验型（改验收清单不改采购决策）；未见任何 A/B 级证据支持推翻
