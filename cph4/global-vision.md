# Global-Vision — 全球视野与执行标准机制 v1.0（CPH4 Labs）

> 溯源：CEO 令 2026-09-24 ~16:00「ceo命令，各子公司和实验室，对自身业务和研发等，全面建立全球化的视野和执行标准，适合AI执行的，全面调研，各方面采集，不准闭门造车，且要按周期去更新。每条线都要。」
> 定位：**反闭门造车律的机制化**——每条线建「全球基准面」（视野）→ 落成「AI 可执行标准」（判据/门禁/配置）→ 按周期刷新（活性）。与诚实律（governance §10）同源：外部锚定=防幻觉的采集面。T2 生效+7 天否决窗。

## 〇、一句话

**不准闭门造车：每条线一份全球基准面文件——看得见业界最优（视野）·学得成可执行标准（落地）·刷得动按周期（活性）。**

## 一、反闭门造车律（五款）

1. **外部锚定律**：一切标准/设计/门禁宣称须有外部出处——源分级沿 BigStream research-protocol（A 官方/B 权威转载/C 社区/D 弱源/M 待证）·零断言（存疑即标注）。
2. **基准面制**：每线在其仓 `docs/global-benchmarks.md` 维护一份基准面文件（格式=§二）——无基准面的设计宣称=闭门造车嫌疑，评审面可驳回。
3. **周期活性律**：基准面按 §三 周期刷新·超期=stale 旗标（司轮自刷新·周轮点名·夜轮不新增扫描项=禁机制自耗）。
4. **AI 可执行律**：采集必须落成机器可执行面（判据/门禁配置/规范行/规格条款）——**纯散文综述=未完成**；每条发现须有「落地指针」。
5. **禁空泛律**（CEO 令 2026-09-24 ~16:15「标准要适配各业务 技术 团队 部门 子公司，不要写大而空泛的！」）：每条执行标准**三件齐备**——①点名本司具体机制/文件（如某司门禁链/某配置参数/某探针）②**数字化判据**（阈值/时长/次数/比例·能量化的必须量化）③落地指针精确到文件；**禁形容词式标准**（「提升/加强/完善/优化 XX」开头=评审面直接驳回）；**标准适配四层**——每条标注归属层：L0 团队（轮内纪律）/L1 部门（门禁评审）/L2 子公司（台账判据）/L3 集团（治理律）——decision.md §8 四层同源·不另造层。

## 二、基准面文件格式（各线 `docs/global-benchmarks.md`）

| 节 | 内容 |
|---|---|
| ①视野面 | 业界全景·全球对标对象（前 3-5 家）·近期动态（带日期） |
| ②执行标准表 | 发现 → 可执行标准 → 落地指针（指向本司门禁/配置/规格文件·含生效状态 ✓/⬜） |
| ③采集源清单 | 每域≥1 源·标分级（A/B/C/D/M）·通道（web/官方文档/API）·零 key 优先 |
| ④更新记录 | 每次刷新一行（日期+要点+下次到期）——stale 判据以此为准 |
