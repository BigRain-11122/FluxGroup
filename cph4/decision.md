# Decision — 集团决策体系正典（链条统摄 + 决策轮章程 · CPH4 Labs）

> CEO 令（2026-09-24 原话）：「建立起集团决策能力，子公司的问题每天晚上11点统一上报，每天晚上12:00，集团对子公司和集团问题进行统一思考，外部调研后，获取关键信息后，科学理性拍板，要站在集团层面，然后各子公司执行，各子公司也需要对决策审核，否则继续下一次报请并说明理由。」+「统一梳理决策链条，合理规划，合理实施。」
> 立法级=T1（CEO 令直接落地）+7 天否决窗。定位：**本件=全集团决策链唯一正典**——问题来了走哪条路、谁拍板、时效多少、如何升级、如何闭环，一张表管全部；决策轮=链条中的日频执行环。

## 0. 决策路由总表（链条核心——先定级再定路）

| 问题级 | 典型例 | 决策通道 | 时效 | 升级线 |
|---|---|---|---|---|
| **CEO 保留域** | 方向变更/红线裁决/资源大调配/命名与人设权/P1 署名/实盘开闸/删仓删史 | CEO 令 → `docs/orders.md`（集团）/各司令牌台账 | 令到即行 | —（最高位·一切让路） |
| **紧急 P0** | S0 红线警报/密钥泄露/数据险情 | 任何会话直呈 CEO + 台账留档（禁等轮次） | 即时 | — |
| **集团重大（T0/T1 级）** | 跨司规则/拓扑变更/治理条款 | 决策轮拟案（`ceo-pending`）→ **委托决策令 v2 默认科学自决**（调研依据+预注册判据+T1 否决窗 7 天+台账落行——2026-09-24 午后 CEO 令「等我ceo拍板的事，我要求自行科学决策，除非是现实世界非要我个人去做的」；**例外两类=现实物理件[常设提醒面]/创造性保留面[人设/命名——CEO 保留域行不变]**） | 日轮内落决 | CEO 随时复查过问（否决窗 7 天） |

| **通用授权面（CEO 明示委托）** | 「你自己决策」域/既定方针内推进 | 执行体自调研自决 + T1 否决窗（BigLife 定名案范式） | 即时 | CEO 随时复查过问 |
| **司域重大** | 司章程/门禁/登记簿变更 | 各司自治机制（U 号批件/门禁链/自审律）+报备集团 | 司内节律 | 与集团法冲突以集团为准（更严者胜） |
| **司域常规** | 日常开发/内容/资产 | 各司 OS 循环 mandate 自决 | 10min 轮 | 司内升级 → HQ-FEEDBACK → 决策轮 |

- **路由三问**（问题进门先问）：①是不是 CEO 保留域？（是=呈 CEO，禁自决）②是不是授权面内的既定方针？（是=自决+否决窗+溯源）③剩下的=按级走表。
- **一问题一通道**：同一问题禁多通道并行报（禁双报）；升级只沿本表升，禁跳级。
- **委托决策令 v2 执法注记（2026-09-24）**：`ceo-pending` 队列与各正典「待 CEO 裁」项默认走科学自决（T1 否决窗）；物理件落 `docs/orders.md` 常设提醒面（禁自决——现实世界必须 CEO 本人动作）；创造性保留面（人设权/命名权）仍按 CEO 保留域行执行。
- **闭环总律**：一切决策最终都要落到可回查的台账行（orders/decisions/司级登记簿）——无台账行的决策=未发生。

## 1. 节律四拍（决策轮=日频执行环）

```
23:00  上报截止  各司当日问题写入自己仓根 HQ-FEEDBACK.md（既有反馈面零新通道；当日 23:00 前落行=当日批次）
00:00  集团思考  决策轮收取全部当日行+集团自身问题面 → 统一思考 → 外部调研取关键信息 → 科学理性拍板
轮内    执行审核  各司 OS 循环读决策新行 → 科学判断闸：合理=执行+回执；不合理=不执行+写明理由 → 自动进次日批次再报请
升级    终裁线    同一问题两轮被驳回或集团坚持 → 第三次直接升级 CEO 终裁（防循环空转·效率平衡律）
```

## 2. 拍板方法论（CEO 原话拆解立法）

1. **外部调研**：关键且不确定的问题先 web 检索（业界实践/数据/先例），取**关键信息**后拍——禁拍脑袋；查证不到=存疑即标。
2. **科学理性**：决策行必带「依据」列（调研要点/数据/先例指针）——无依据的拍板=无效（诚实律证据对律在决策面的形态）。
3. **集团层面视角律**：局部服从整体——司级收益与集团收益冲突时以集团为准，本位主义拍板=违规。
4. **分级拍板**（evolution §2 接线·委托决策令 v2 修订）：T2/T3 域=轮内直接拍（否决窗照旧）；T0/T1=**默认科学自决**（§0 集团重大行：调研依据+预注册判据+T1 否决窗+decisions.md 落行）；例外两类仍呈 CEO（现实物理件/创造性保留面）——**决策轮不越 CEO 保留域**。

## 3. 决策台账 = `docs/decisions.md`（唯一决策面）

`| 日期 | 问题 | 来源 | 依据（调研要点） | 决策 | 分级 | 状态 |`——状态：`pending / executed（司回执）/ overruled（司驳回·附理由）/ refiled（再报请）/ escalated（CEO 终裁）`。落 git 即全集团生效（同令流法理）；CEO 复查过问入口=本台账+orders。

## 4. 子公司审核权（CEO 原话正典化）

- 各司循环读到决策新行**必须过科学判断闸**：合理→执行+回执（状态 executed）；不合理→**有权不执行**，但必须写明理由（HQ-FEEDBACK 一行引用决策号）——无理由的驳回无效，视同执行。
- 驳回即自动进次日 23:00 批次；第三次冲突=升级 CEO 终裁，双方案并呈。
- 这是「决策-审核-再报请」的制衡环：集团不盲拍，子公司不盲从。

## 6. 纪律

静默律 VBS 包装；单实例锁 30min；集团仓外只读；轮首脏树定向 add；超时优雅收尾（已拍落行，未完留下轮）；决策详情超 200 字落 research，台账只留指针（versioning §4.3 同源）。

## 7. 执行追踪与决策回访（链条闭环·2026-09-24「统一梳理决策链条」补法）

1. **回执 SLA**：decisions.md 行各司 24h 内必回执（executed/overruled）——**超 24h 无回执=夜轮点名催办**（与 transferred 件同式，夜轮 mandate 已接）。
2. **决策回访律**：T1/T2 级决策生效 7 天后，决策轮当夜回访一行（效果实况/是否需修法）——evolution §7「立法后必回访、禁感觉良好式立法」在决策面的同源；回访结论落该决策行尾。
3. **链条健康年检**：周进化轮季度法熵审视附「决策链条审视」——路由表是否与现实机制漂移（新机制加入=§0 表同步加行）。
4. **链条可视化**：DECISION_MADE/DECISION_OVERRULED 事件族 T2 登记（FluxVerse 事件登记簿）→城内=脑塔拍板光脉冲（CEO_ORDER 白脉冲之外的青色决策光）——转办 DevLoop 自领。

## 8. 分层级决策结构（团队/部门/子公司/集团·2026-09-24 CEO 令「建立起分层级决策的机制，团队，部门，子公司，集团，都要科学理性决策」·T2+否决窗 7 天）

**四层结构表**（实例全引用既有机制·不重立）：

| 层 | 是谁（既有实例） | 决策面 | 科学纪律（同律·仪式按层适配） | 时效 |
|---|---|---|---|---|
| **L0 团队** | DevLoop 自领池/机队工作单/BigLife OSLoop/各司轮内会话 | 工单内技术路线/实现选型/任务认领 | 反重复+先读后写+判据先行（预注册）+轮账本留痕 | 轮内即决 |
| **L1 部门** | MiniGame 专家池+门禁链（X026/G1/G2）/BigMoney 门禁链 G1'/G2/BigStream dept-review（B1-B6 效率平衡） | 司内标准/评审验收/优先级排布 | 评审 rubric+verdict 留痕+两轮上限升裁+效率平衡条款 | ≤24h |
| **L2 子公司** | 司级自治机制（Biggame U 号批件/BigMoney fleet O 号/BigLife T 单/BigStream R 轮次） | 司域重大（章程/门禁/登记簿）+超权事项上报 | 司内机制自决+报备集团；超权=日清上报（§1 23:00）→执行审核权（§4） | 司内节律/日批 |
| **L3 集团** | 决策轮（本件 §1）+CEO 保留域（§0 最高位） | 跨司规则/T2-T3 直拍/**T0-T1 默认科学自决（委托令 v2）+例外两类呈 CEO** | §2 拍板方法论全套（外部调研+依据列+集团视角）+decisions.md 台账 | 00:00 日拍 |

**五律（各层同律——「科学理性决策」的统一形态）**：
1. **依据列**：无依据的决策=无效（诚实律证据对律在各层的同源形态）。
2. **先调研后拍**：L0/L1=先查台账正典与先例；L2=先查本司登记簿；L3=外部 web 调研取关键信息——按层适配、同律不同仪式。
3. **判据先行**：预注册判据再执行（跑到达标为止=违规的决策面防线）。
4. **留痕**：各层落自己台账（L0 轮账本/L1 verdict 记录/L2 司级登记簿/L3 decisions.md）——无台账行的决策=未发生（§0 闭环总律）。
5. **升级只升不跳**：沿 §0 路由表逐级升，两轮驳回=第三轮升 CEO 终裁；一问题一通道禁双报。

**底层优先原则（ subsidiarity）**：一切决策落在**有能力的最低层**——低层能解的事高层不接管（禁把工单级技术上纲到集团带宽）；反之低层解决不了（超权/跨司/红线）必须升层，禁闷头自决。

**落点**：各司一周内在自己章程/mandate 落一行「本司团队面/部门面决策声明」（实例对应 §8 表）——进化台账 P-35 转办；司内已有完整部门体系者（MiniGame 十一部门+专家池）引用即收口，无部门面者声明「L0 直报 L2」即可，不强造部门。
