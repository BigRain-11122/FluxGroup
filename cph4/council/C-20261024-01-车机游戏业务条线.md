# 决策记录 C-20261024-01：车机游戏业务条线立项

- 议题：是否将车机游戏升级为集团战略级业务条线，并批准首个产品与渠道优先级
- 提请：CEO（2026-10-24 令）
- 依据：`cph4/fleet/car-gaming-v1/CAR-GAMING-MARKET-REPORT-20261024.md`
- 会议：委员会 2026-10-24（T1 代决，CEO 预弃翻案权；物理件保留）

## 决议

| 编号 | 决议 | 结果 |
|---|---|---|
| R1 | 批准车机游戏业务条线（Car Gaming BU），游戏公司主责，战略级 | 通过 |
| R2 | 批准首个产品：吸嘟嘟家庭版·车机版（复用现有资产） | 通过 |
| R3 | 批准渠道优先级：理想×Unity ＞ 比亚迪 OIP ＞ 鸿蒙 NEXT ＞ 小米 ＞ 其他 | 通过 |
| R4 | 批准商业模式：C 端买断/皮肤 + B 端适配/预装/联合运营；不做广告/IAA | 通过 |
| R5 | 批准 90 天 G1 门禁：可玩 demo + 3 家渠道材料 + 1 份 LOI | 通过 |
| R6 | 提请 CEO 物理件：8295/8155 样机、版号主体、OEM 引荐 | 呈报 |

## 关键判断（会议共识）

1. 车机游戏当前是车企渠道市场，不是消费者市场；只做 C 端付费养不活业务线。
2. 窗口期 2026Q4–2027Q2；入口尚未固化，先上车比先做爆款重要。
3. 家庭/亲子是供给最稀缺、与我方资产最匹配的切口。
4. 不做手机游戏移植、不做 3A、不自建分发、不做广告。
