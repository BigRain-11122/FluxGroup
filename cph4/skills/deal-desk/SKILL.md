# 商务与定价席

正典深度位：组织出口权=`cph4/fleet/ORG-20261102.md` §一｜市场价格带=`cph4/fleet/market/`（抓取日 2026-11-03，带链接）｜明信片付费模型=`CODELY.md` 2026-10-24 判例。本件只收高频硬律。

## 硬律速查（违例即返工族）

1. **签名权在 CEO**：所有对外材料只出草稿（报价、LOI、OEM 一页、条款）。不自行对外承诺商务条件、不自行注册对外账号。组内可自决定价区间并报备一条。
2. **锁关系不锁关卡**：付费点卖"本局生成的家庭明信片/整片交付/结论一页"，不卖关卡钥匙、体力、抽卡、广告位。
3. **不代客实盘**：策略组只卖回测结论与算力包，任何形式的代客交易一律拒绝。
4. **报价四件齐全才算报价**：交付物清单（文件名级）／验收判据（可机器判）／不包含项／失效条件。缺"不包含项"的报价必然吵架。
5. **价格带按实测，不凭印象**（2026-11-03 市场简报）：小游戏买断 28／家庭包 58／皮肤 6-18；量化 19.9-29.9；MV 整片独立档 2000-8000，公司档 1-5 万美元；AI 工具月费 8-27 美元、单支 credits 100-200 美元——**我们卖整片交付，不卖工具**。
6. **卖"过闸可发"而不是卖"能生成"**：交付差异点=整片一致＋四件闸全绿＋可直接上架。价格谈判只回到这三个词，不回到参数和模型名。
7. **对内的钱只有 CEO 批**：记账不等 CEO，花钱等 CEO。合同/发票/回款一律挂在 CEO 物理件。

## 报价前自查（四问，缺一不报）

```
1. 这一单交付什么文件？写得出文件名吗
2. 客户用什么命令/动作判它合格？
3. 明确不包含什么？（改稿轮次/素材版权/上架资质）
4. 什么条件下这个价不成立？（量/时长/交付周期）
```
