# 大片尺度验收（mv-big-picture）

## 一句话
技术闸回答「这版有没有硬伤」；这一层回答「**这支片够不够格**」。两件事，别用一把尺子。

## 三档定义（先判档，再谈改进）

| 档 | 定义 | 判据 |
|---|---|---|
| **A 可上线商业 MV** | 能作为歌手/作品的正式影像产品发布 | 副歌有主唱演唱镜 + 人物有目标与对手戏 + 镜头调度有设计 + 调性统一 |
| **B 高完成度概念短片** | 好看、有氛围、有世界观，但不是"MV" | 视觉 8 分以上，但**缺主唱或缺戏**其中之一 |
| **C 素材展示片** | 图片轮播 / 素材拼贴 | 无统一调性、无人物推动、无设计过的构图 |
| **D 不及格** | 有硬伤且无法自救 | 技术闸红项 + 无叙事 |

> 判定口径：**A 档是"能发"，不是"完美"**。B 档不是差评——它是"再补一块就能发"的状态。

## 六维打分（加权看叙事，不要只看视觉）

| 维 | 权重 | 判据 |
|---|---|---|
| 开场抓人 | 1 | 前 5 秒能否让人停下来（不靠音效/字幕） |
| 视觉完成度 | 1 | 光源动机 / 景深层次 / 构图设计 / 调性统一 / 有无 CG 感 |
| **人物与戏** | **2** | 主角有目标吗？有对手戏吗？还是游客行为？ |
| **主唱表演** | **2** | 副歌有没有对镜演唱（90s-00s KTV 铁律；也是 MV 的商业底线） |
| 镜头调度 | 1.5 | 是否有大场面运动（横移/升降/环绕），还是 90% 固定机位 |
| 情绪容器 | 1.5 | 观众能不能"把自己放进去"（不知道主角想要什么 = 放不进去） |

**叙事三项（人物/主唱/容器）权重合计 5.5**——这是大片验收与技术验收最大的区别。

## A 档四必需件（缺一不可）

1. **副歌主唱对镜演唱镜**：每段副歌 ≥1 个，≥1.5s，正脸或半身；能看到嘴或明确演唱姿态。
   （规避 H3 口型先验：用侧脸/仰头/闭眼唱 + 节奏点头，不强求真口型）
2. **对手戏**：她与他有物理/视线交集（玻璃反射里的他 / 手贴玻璃与刻痕重合 / 物件交接）。
3. **一条明确因果链**：她为什么来 → 找到什么 → 发生什么。
4. **一处大场面运动调度**：横移穿场 / 环绕主体 / 升降揭示。

> 诊断为"缺第 1 件"时，**调色和剪辑都救不了**——这是素材缺口，必须补拍。

## 与邝盛卡对照（本产线正典导演）

| 手法 | 常见误判 |
|---|---|
| 多线时空交错 | 做到"并列"不等于做到"交错产生因果" |
| 低调摄影 / 侧光切脸 | 容易变成"全片都在暗" |
| 负空间 / 人贴边缘 | 容易变成"人太小看不清" |
| **拍"动作之后"** | 容易被误读成"没拍到动作" |
| 男性视角克制 | **克制过头 = 主角缺席**（0 次正脸演唱就是典型） |

## 执行法（两把独立尺子）

1. 先用视频模型独立看一遍（不给它技术数据，只给片子 + 大片标准提问）。**两个模型结论一致才算稳**。
2. 导演席对照正典做交叉判定（`CRAFT-CEO-MV-INDUSTRY-v1` 工业三律 + 六段模板 + 情绪容器）。
3. 出档位 + 六维分 + A 档四件缺口表 + 升级路线（按投入产出排序）。
4. **路线只给"能立刻做"的**：补哪几镜、几分钟 GPU、能升到哪一档。

## 反模式

- 用"技术闸全绿"当"可上线"——闸全绿但 0 次演唱镜，仍是 B。
- 用"再调一版色"当升级手段——颜色救不了"没人"。
- 把"艺术片"当豁免理由——L1 路人看不懂就是导演失职（见 ACCESSIBILITY-LAW）。
- 只找毛病不给档位——CEO 要的是"够不够格"，不是缺陷清单。
