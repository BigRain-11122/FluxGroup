# MV 美学九席（可执行版）

## 一句话
**先机检，再人判**。能测的先测（镜长/切点/黑帧/冻结/清晰度断层/响度），测不了的才交给席位用眼睛和判断力。

## 正典四件（git 权威·本 skill 只是指针）
1. **席位登记册**：`cph4/agents/seats/mv-aesthetic-seats.json`
   —— 九席的视角、判据、检查单、辩论点、机检规则。**改判据改这里，不要改提示词。**
2. **执行器**：`Tools/selfmedia/aesthetic_panel.py`
   —— `python Tools/selfmedia/aesthetic_panel.py --film <mp4> [--edl <EDIT-PLAN.json>]`
   产物：`EVIDENCE.md`（机检数字）+ `seats/<席>.md`（逐席提示词）+ `SCORECARD.md`（待填）
3. **评审制**：`cph4/fleet/mv0001-handover/outbound/krea2/30s-reel-v1/EXPERT-PANEL-PROTOCOL.md`（十三席/五闸/认证规则）
4. **判例册**：`cph4/fleet/mv0001-handover/outbound/krea2/prompt-writing-spec-v1/EXPERIENCE-LEDGER-v1.md`

## 九席速查
| 席 | 管什么 | 一条硬判据 |
|---|---|---|
| 导演 | 每镜动机/景别呼吸/运镜在镜内 | 没有动机的镜头一律可疑 |
| 编剧 | 一句话能否说清故事/连接物是否拍到 | 说不清=结构问题，不是镜头问题 |
| 剪辑 | 密度曲线/切点在事件上/同人连镜 | 末段均长必须小于中段 |
| 摄影 | 单暖源死黑/方向光/真实视差 | 说不出光源的镜头=平光 |
| 调色 | 黑位 10-14/高光 R-B 20-35/颗粒对齐 | 死黑=数码感，抬灰=脏 |
| 表演 | 意图/时序/反应延迟/眨眼 | 3 秒脸镜零眨眼=死 |
| 美术考据 | 器物形制/文明归属/使用痕迹 | 现代钢反光、错文明=判负 |
| 受众 | 3 秒钩子/认得出/情感落点/转发欲 | 一眼假的地方会被拿出来说 |
| 文字 | 字形真伪/一致性/可读性 | 一处篆书一处楔文=世界观崩 |

## 铁序
1. 跑 `aesthetic_panel.py` 拿机检 → **机检不过先修，不浪费席位**。
2. 逐席按 `seats/<席>.md` 判读（各席独立，不许互相看结论）。
3. 冲突交**仲裁席**：按"能不能直接发布"裁，产出 P0/P1 清单。
4. 只让提出问题的席复评，逐条给"已消除/仍存在/变差了"。
5. 全 P0 清零 → 记分卡收敛 → 出片。

## 纪律（血泪）
- **多模态判读必须原生复核**：代理片会造出假缺陷（曾把暗场读成"黑帧"，机检实测 YAVG 最低 25.8、欠曝 0 帧）。
- **重演换机位**：1.15 倍推近对全景无效，必须 1.5-1.8 或换镜。
- **AI 素材 5 秒匀速**：永不放满 + 密度曲线 + 切入落在动作峰值前 0.35s。
- **送审有硬上限**：多模态一次吃不下长片。实测 234s@3fps 与 78s@2fps 都可能 336s 超时——**一段压到 ≤60s、fps 1-2、提示词精简到 5 条以内判据**；超时不算判负，减半再送。
- **机检先行不是可选项**：本 skill 首次实战就用机检抓出「全片音轨 −10.4 LUFS / 真峰 +3.1 dBTP 削波」——这类缺陷席位看不出来，只有数字能抓。
