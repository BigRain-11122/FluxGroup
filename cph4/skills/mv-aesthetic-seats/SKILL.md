# MV 美学十席（可执行版）

## 一句话
**先机检，再回归闸，最后人判**。能测的先测（镜长/切点/黑帧/冻结/清晰度/响度/边界跳变），测不了的才交给席位用眼睛和判断力。

## 正典五件（git 权威·本 skill 只是指针）
1. **席位登记册**：`cph4/agents/seats/mv-aesthetic-seats.json`
   —— 十席的视角、判据、检查单、辩论点、机检规则。**改判据改这里，不要改提示词。**
2. **执行器**：`Tools/selfmedia/aesthetic_panel.py`
   —— `python Tools/selfmedia/aesthetic_panel.py --film <mp4> [--edl <EDIT-PLAN.json>]`
   产物：`EVIDENCE.md` + `seats/<席>.md` + `SCORECARD.md`
3. **块面/组装闸**：`Tools/selfmedia/shot_qc.py`（跑法见同目录 `README-QC.md`）
   逐块面：时长/欠曝/过曝/冻结/重复帧/清晰度/色温/重心/黑边；
   组装：相邻块 ΔY·Δ(R−B)·Δ重心、越轴嫌疑、总账、响度真峰、字卡。
4. **回归闸**：`Tools/mv_regression_gate.py` + `cph4/fleet/mv-album-001-jay/REGRESSION-LEDGER.json`
   —— **审片前必跑**。它回答的不是"这版好不好"，而是"这版有没有把上一版修好的东西弄丢"。
5. **判例册**：`cph4/fleet/mv0001-handover/outbound/krea2/prompt-writing-spec-v1/EXPERIENCE-LEDGER-v1.md`

## 十席速查
| 席 | 管什么 | 一条硬判据 |
|---|---|---|
| 导演 | 每镜动机/景别呼吸/运镜在镜内 | 没有动机的镜头一律可疑 |
| 编剧 | 一句话能否说清故事/两线的连接物是否被拍到 | 说不清=结构问题；连接物没拍到=剧本缺件 |
| **分镜逻辑** | 空间建立/视线匹配/银幕方向/动作连接/道具连续 | **同一件物跨镜必须真的是同一件**；新场景先给建立镜 |
| 剪辑 | 密度曲线/切点在事件上/同人连镜 | 末段均长必须小于中段 |
| 摄影 | 单暖源死黑/方向光/真实视差 | 说不出光源的镜头=平光 |
| 调色 | 黑位 10-14/高光 R-B 20-35/颗粒对齐 | 死黑=数码感，抬灰=脏 |
| 表演 | 意图/时序/反应延迟/眨眼 | 3 秒脸镜零眨眼=死 |
| 美术考据 | 器物形制/文明归属/使用痕迹 | 现代钢反光、错文明=判负 |
| 受众 | 3 秒钩子/认得出/情感落点/转发欲 | 一眼假的地方会被拿出来说 |
| 文字 | 字形真伪/一致性/可读性 | 一处篆书一处楔文=世界观崩 |

## 铁序（六步，不许跳）
1. 跑 `mv_regression_gate.py`：**看有没有复发**（音轨削波、帧数、切点对账、素材准入）。红项先修。
2. 跑 `shot_qc.py --mode all --edl`：拿块面与组装数字。**块面不达标先修，不浪费席位**。
3. 跑 `aesthetic_panel.py`：出证据包与逐席提示词。
4. 逐席独立判读（不许互相看结论），每条判据必须带时间码。
5. 冲突交**仲裁席**：按"能不能直接发布"裁，产出 P0/P1 清单；只让提出问题的席复评。
6. 全 P0 清零 → 记分卡收敛 → 出片。

## 纪律（血泪，都是实弹）
- **多模态判读必须原生复核**：代理片会造出假缺陷（曾把暗场读成"黑帧"，机检实测欠曝 0；曾把楔文暗墙读成"欧式城堡"）。
- **清晰度不能跨亮度档比**：Laplacian 是绝对能量，暗镜头天然低。必须按 YAVG 分档取中位，否则整个死黑体系全被判"糊"。
- **黑边必须"对侧对称 + 99 分位"**：单侧大片纯黑是构图（火光只照一侧），不是缺陷。
- **重演换机位**：1.15 倍推近对全景无效，必须 1.5-1.8 或换镜。
- **AI 素材 5 秒匀速**：永不放满 + 密度曲线 + 切入落在动作峰值前 0.35s。
- **送审有硬上限**：一段压到 ≤60s、fps 1-2、判据 ≤5 条；超时不算判负，减半再送。
- **机检先行不是可选项**：首次实战就抓出「全片音轨 −10.4 LUFS / 真峰 +3.1 dBTP 削波」与「全片 32/71 切点有可测断崖」——这类缺陷席位看不出来。

## 反模式（2026-11-25 复盘，必读）
| 反模式 | 症状 | 机械识别 |
|---|---|---|
| **假完成** | 目录里有三个"新版"，切点全是旧版的 | `shot_qc` 反测切点 vs EDL 对账（R-07） |
| **修复回归** | 上一版修好的音频/调色，新版又坏了 | `mv_regression_gate`（R-01 真峰） |
| **失败件入剪** | `*.fail1.mp4`、864×480 低清件被当正常素材 | `asset_pool`（R-08 名字+分辨率闸） |
| **一件污染两处** | 同一素材在两个时间点都出同一个缺陷 | 块面表里 `src` 相同的行一起看 |
| **末段变松** | 结尾镜长反而比中段长 | `lb_density`（R-09） |
| **判据误报** | 闸天天报警，人天天豁免，最后没人看 | 误报必须改判据，禁长期豁免 |
