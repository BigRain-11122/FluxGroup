# 审美批判席（Art Critique）

## 什么时候用
- 成片/关键帧/界面/海报在"机器全绿但人一眼看出问题"的时候。
- 需要把"不好看"翻译成可执行的修改指令（改什么、改成什么、怎么验）。

## 六面审查（逐面独立打分，禁合并成一个总分）
1. **构图 Composition**：主体位置、视觉重量、留白、前景/中景/背景层次、边缘裁切（人脸/手/物件被切=缺陷）、视线引导。
2. **光 Light**：主光方向是否成立、明暗比、是否有一处可读的高光、暗部是否有细节（均值 <35/255 视为不可辨）。
3. **色 Color**：色温是否统一、肤色是否成立、是否全片一套色（相邻镜头色温差 <150K 且饱和度差 <10 时判"同色塌方"）。
4. **材质 Material**：石/木/布/金属是否有真实的反射与纹理；AI 常见的"塑料感/糊面"判负。
5. **表演 Performance**：眼神是否有目标、动作是否有起止、是否有"演给镜头看"的痕迹。
6. **叙事 Narrative**：这一镜在讲什么、和上一镜/下一镜靠什么接上（动作/视线/图形/物质）。

## 判据（必须落到数字或可指认的画面对应）
- 曝光：均值 35–190/255；暗场镜允许低但主体轮廓必须可辨。
- 色温：同段落内相邻镜 ΔK ≤ 400；古今/场景切换允许跳变，但必须有叙事理由。
- 裁切：人脸不得被画框切在眉眼/嘴部；手部动作不得切在关节。
- 运动：每镜至少一个明确的运动意图（推/拉/摇/移/静），静镜必须"静得有理由"。
- 转场：每个切点能一句话说出"接的是什么"；说不出=不过。

## 输出格式（缺一不交付）
```
镜号 / 时间 / 六面分（0-5）/ 缺陷一句 / 修改指令（改什么→改成什么→怎么验）
```
修改指令必须可执行：改曝光给倍率，改色给色温方向，改构图给裁切/机位，重烧给新提示词要点。

## 红线
- 不用"加点氛围/更高级"这类不可执行的词。
- 不用抽帧代替逐帧；不用联系表代替看片。
- 审美判负不得被技术闸的 PASS 覆盖（技术过闸 ≠ 好看）。
