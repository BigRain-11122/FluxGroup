# 内容拆解技能（CONTENT-RECON）

## 何时用
- CEO/产线要求"拆解某部爆款短剧/漫剧"。
- 自家短剧/漫剧被判"节奏不对/不抓人"，需要外部基准。
- 立项前要看同赛道头部怎么开场、怎么收尾。

## 边界（硬）
- 只拆**公开可访问**内容；不碰付费墙、不绕登录、不用主号 cookie。
- 只提炼结构与参数，**不复制**剧本原文/美术/音乐/字体；引用原台词 ≤20 字且仅作分析。
- 原始样本只落 `media/recon/`（gitignored），禁进 git、禁外发。
- 真人脸/明星脸只作分析，禁进入我方生成资产。

## 执行五步
1. **取源**：`yt-dlp -f "bv*[height<=480]+ba/b[height<=480]" --write-info-json -o "media/recon/raw/%(id)s_%(title).60s.%(ext)s" <url>`
2. **量化**：`python Tools/recon/drama_recon.py <file> --frames 12`（产出镜头切点/中位时长/P90/响度/抽帧）
3. **拉片**：看抽帧 + 全片，按九面标注（C1 题材人设 / C2 钩子 / C3 集结构 / C4 节奏 / C5 反转 / C6 台词 / C7 镜头 / C8 包装 / C9 声音）
4. **AI 专项**（若是 AI 漫剧）：一致性/口型/手部/背景文字/匀速漂移/配音六查，各记失败率
5. **成卡**：按 `cph4/fleet/recon-dept-v1/METHOD-v1.md §1.3` 输出，必含"可抄 3 条 + 不可抄 1 条"

## 判读口径（防主观）
- 镜头中位 <1.5s 且 P90 <3s = 快切型；中位 >3s = 长镜叙事型。
- 首个强切点与首句台词间隔 ≤3s = 开场即冲突。
- 反转间隔 <90s = 高密度爽剧；>3min = 慢热铺垫型。
- 字幕：抽帧量字号占画面高度比例；描边/阴影/底衬三选一必须记录。

## 产出物
- `cards/CONTENT-<编号>-<剧名>.md`
- 可执行结论必须写"用在哪条产线 + 怎么验收"，禁止"节奏很好"这类空话。

## 反模式
- 只看前 3 分钟就下结论（必须全片）。
- 把"我觉得好看"写成结论。
- 把竞品台词/画面直接放进我方脚本或分镜。
