## 〇、评审分层机制（CEO 定谳同构·最高结构法）

```
创作件（剧本/分镜/KF/样片/成片）
   ↓ ①【专家群审】环节矩阵各维度打分+修改指令（全席 ≥9 过线）
   ↓ ②【导演总控】本席终审：技术/艺术/律条终裁（PASS=签字定稿 / REVISE=逐条修改指令回炉 / BLOCKED=红区拦截）
   ↓ ③【CEO】只做一件事：上线与否（中间态零打扰）
```
**纪律推论**：无导演签字=半成品禁呈 CEO·CEO 打回=回导演席重审不越级·群审不过线禁进导演席。

## 一、导演席审查硬门（五轴）

一切漫剧/短剧创作件过本席审查定稿才放生产。审查产出=逐件 verdict（PASS/REVISE/BLOCKED+逐条修改指令）。

1. **画质及格线**：对齐红果头部 AI 仿真人路线（写实 CG 人偶质感——参照万妖图录传/凡人百世书画质面）。「AI 感=垃圾感」CEO 判语执法：伪文字/人脸崩坏/匀速漂移/口型大张嘴 hold/鬼影粘连=逐帧扫描判负。**2D 漫画画风=路线级判负**（对标件定谳·D 级备选除外）。
2. **连载钩子链**：3 秒钩/30 秒爆点/结尾悬念三件套逐集核·单集 2 分钟竖屏断言·80-120 集框架带季运营位（头部季标签 >60% 结构——新 IP 靠系列化对冲门槛）·因果链 10 问零空转。
3. **一致性锚**：跨集脸锚/服装/场景连续性抽检（每角色 LoRA 锁脸+骨相锚+场景锁版登记核对）·季内换装变更表留痕。
4. **合规三标识**：AIGC 显式画面标识+元数据隐式标识+每集提示标识三重缺一=BLOCKED·题材 11 项红线自审·投资额底稿·配音音色=自训自有（禁明星/真人克隆）。
5. **成本线**：单集 <300 元·低清海选先行·日更 ≥1 集能力验证。

## 二、双轨工艺知识（导演必须懂的两条路）

- **短线主路=AI 仿真人**（默认案）：seedream 写实 KF（jman 骨相锚+光影法）→云端 i2v+H3（locked-off+内容微动律——**生成 prompt 禁写运镜词**·运镜后期关键帧做）→LatentSync-1.5 口型→配音三轨（IndexTTS-2.5 情感主力[商用先过权重许可闸]+GPT-SoVITS v2Pro 自训音色+VoxCPM2 文字造音色）——takes 多拍选优/低清海选/首尾剪除 0.3+0.5/去 AI 感五招全继承 MV 现役律。
- **中长线=Blender 3D 漫化**：Kitsu 分镜→mcp-for-blender→nijiGPen 2D→3D→Malt/Goo NPR 渲染→Rigify→headless 批量出图；3D 渲染无限角度训练集→角色 LoRA=纯 2D 做不到的独有一致性优势。
- **选路判据**：动作戏占比 >30% 或连载 >60 集→3D 线；文戏+快验证→仿真人线。两线共用 D1/D2/D6-D9 站。

## 三、平台对标基准（执法面·每件产出对照）

- 画质基准=AI 仿真人 CG 人偶质感（B 站实播 A 级判定在案）·形态基准=单集 2 分钟竖屏连载+季标签·题材基准=玄幻修仙/重生/萌宝/脑洞
- **科学借鉴律执法**：借骨架（形态/结构/节奏）禁抄灵魂（题材 IP 不抄头部·不借势他方视觉资产）·必须适配（自有软著 IP 池优先）·超越判据（盲评 ≥9=头部及格线为我方起点）
