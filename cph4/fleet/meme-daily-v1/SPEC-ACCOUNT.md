# SPEC-ACCOUNT —— 热点梗短视频账号规格（v1）

## 账号定位（账号名待 CEO 定，命名=CEO 面）
- 主推 **「梗闻联播」**：全网热点连续剧化，AI 演给你看（谐音新闻联播，一听就懂，覆盖面=全网不限车圈）。
- 备选 **「热点梗车间」**：制造感人设，"梗是我们车间生产的"。
- 一句话简介：热搜上什么，AI 就把什么演成 15 秒小剧场。
- 形态：竖屏 9:16，12-19 秒，AI 小剧场 + 大字幕 + 快嘴吐槽旁白 + 玩梗卡点。
- 发布节奏：12:00 / 18:00 / 21:00 黄金档（日更 3 条）。

## 爆款公式（深研结论·2026-10-10，落参数执行）
1. **黄金 3 秒钩子**：用户 1.2 秒定划走；开场=悬念/反差/数字三选一；禁"大家好我是XX"式自我介绍开场。
2. **情绪密度**：每 2-3 秒一个信息点或梗点；三幕式=钩子→爆点→反转金句。
3. **嘴替感**："网友翻译体"——把官方回应翻译成人话（车圈吐槽杀手锏，V1 实装："网友翻译：测试里断的，不算用户"）。
4. **大字幕即主角**：竖屏小屏，字幕>画面细节；关键词黄色高亮；每 2 秒必换卡。
5. **结尾互动钩**：提问/投票/下集预告（"下集：什么是速成车？"）——拉评论与追更。
6. **完播率>一切**：12-19s，禁拖；剪辑逐句卡点。
7. **系列化连载**：尊界刹车断→速成车→一年三款→智己加班图鉴→车圈加班图鉴系列→月经车（2026 新梗备选）——连续剧粘性=涨粉核心。
8. **评论区运营**：结尾埋"有争议但属实"的点（事实梗），置顶引导站队。

## 选题 SOP（每日 3 条）
- 配额：1 条车圈连载 + 2 条全网泛热点。
- 扫描源：微博热搜 / 抖音热榜 / 百度热榜 + 汽车圈垂直热闻（懂车帝/汽车之家）。
- 选题评分（过两问才立项）：①有无反差/数字/名场面可视觉化？②有无"嘴替空间"（官方话术 vs 网友翻译）？③是否 24-72h 内热度上升期（蹭新不蹭旧）？
- 每日执行窗：上午窗出车圈连载·午后窗出热点①·晚间窗出热点②（与机队 TJGenerators 配额错峰）。

## 合规红线（硬法·每片过门）
- **AIGC 标识**：每片左下角烧"AI 生成｜本片为AI创作演绎"水印 + 平台上传勾选 AIGC 声明（《人工智能生成合成内容标识办法》硬法）。
- **只玩事实梗**：引用公开报道事实；禁编造/断章取义；官方回应引用原话；争议未定处标"据公开报道"（V1 断裂测试=测试方单方信息，片中归因"懂车帝实测"，不替官方定性）。
- **禁生成真人脸**：人物一律剪影/背影/手部/远景（肖像权红线，承 ai-star-research 结论）。
- **禁碰**：时政/领导人/灾难伤亡/民族宗教。
- **商标泛化**：车画面用无标造型（unbranded），品牌名只出现在字幕/口播的新闻评论面。
- 企业吐槽=吐槽现象与文化，不断章诽谤；诙谐基调，不下攻击性结论。
