# 立项边界与规则 v1（2026-11-20）

> 一句话：**一个项目 = 一个新核心动词。** 换皮、换壳、加关卡、做 DLC，都不是新项目。

## 一、六个定义（先把词分清）

| 词 | 定义 | 要不要新契约 | 占不占生产槽 | 算不算 9 款/年 |
|---|---|---|---|---|
| **项目 Project** | 新核心动词，或实质不同的循环 | 要 | 要 | 算 |
| **变体 Variant** | 同一动词，换题材/美术/关卡包 | 不要（父契约下） | 不占 | 不算 |
| **壳 Shell** | 同一核心移植到另一平台（小游戏/车机） | 要（独立契约） | 派生，不占新槽 | 不算 |
| **实验 Experiment** | 3 天原型，验证新动词/新体裁 | 不要（实验卡） | 不占 | 不算 |
| **放大 Amplification** | 毕业款的 DLC/续作/大内容 | 要（放大契约） | 占（临时） | 不算 |
| **任务 Task** | 项目内的一张卡/一个功能 | 不要 | 不占 | 不算 |

## 二、四道门

### G-A 入池（便宜）
- 机会卡：情绪、动词、母体、新机制、三端、证据。
- 信号：至少 1 个主源（榜单）+ 1 个任意；持续 7 天。
- 非换皮初判：写得出"母体没有的那个机制"。
- **卡有效期 30 天**；到期没进原型 → 自动出池。

### G-B 原型（证伪）
- **3 天、≤¥2,000**，最轻载体（HTML/纸面/单场景）。
- 四问：新动词？10 秒可辨？3 天可做？去掉会不会退回母体？
- 不进生产槽；结果 7 天内必须决策。

### G-C 开工（承诺）
- 评分卡 + 原创五条 + 队列位 + 契约哈希。
- **评分卡必须过 `Tools/gds/panel_lint.py`**：七席齐、权重预注册、覆盖率 ≥0.85、无否决项；卡在 `panels/<PROJECT>.yaml`（机制见 `GREENLIGHT-PANEL-v1.md`）。
- 通过才占生产槽；未过门不得按量产排期。

### G-D 变更/砍/毕业
- 范围变更 → 改契约（升版）；不追认。
- 砍：3 天/10 天/6 周/首月 <300/退款 >20%。
- 毕业：>2× 中位 / 愿望单转化 >15% / 好评 ≥90% 且有量 → 放大轨。

## 三、12 个边界判例

| # | 情形 | 判定 |
|---|---|---|
| 1 | 同一动词，换美术/题材 | **变体**，不是新项目 |
| 2 | 同一动词，加 30 关 | **内容更新**，不是新项目 |
| 3 | 同一动词，加一个新机制且改变循环 | 可算**项目**（需 G-B 反向测试） |
| 4 | 新动词、同技术栈 | **项目** |
| 5 | 新体裁、新技术栈 | 先做 **D 实验**；过门才算项目 |
| 6 | Steam 版移植到微信/车机 | **壳**，不算新项目 |
| 7 | 毕业款的续作/DLC | **放大**，不是新项目 |
| 8 | 未毕业款的续作 | 先按**新项目**评估（不继承父款资格） |
| 9 | 外部 IP/授权题材 | **项目**，加法务门 + CEO 批 |
| 10 | 服务器/多人/联网 | **不做**（边界外） |
| 11 | 3D/重资产 | **不做**，除非 CEO 批的 D 实验 |
| 12 | 单个功能/UI 屏/数值调整 | **任务**，不是项目 |

## 四、权限

| 动作 | 谁 | 条件 |
|---|---|---|
| 建机会卡 | 制作人/代审 | 1 主源 + 1 任意信号 |
| 跑 3 天原型 | 制作人 | ≤¥2,000；不占生产槽 |
| 批开工 | 代审 | 评分 + 原创五条 + 队列 |
| 插队 | CEO 或代审 | 四条件 + 每月 ≤1 次 |
| 改价格/平台/方向 | **CEO** | 一句话 |
| 砍/日落 | 代审 | 报备；CEO 可推翻 |
| 新平台/新体裁/3D/服务器 | **CEO** | 边界外，需明确令 |

## 五、数值上限

- 生产槽 **1**；候补 **≤5**；实验槽 **1**。
- 机会卡有效期 **30 天**；原型 **3 天**；结果 **7 天内决**。
- 原型预算 **≤¥2,000**；单款总成本 **≤¥11,000**。
- 默认 **9 款/年**（8–10）；实验 **4–6 个/季**。
- 插队 **≤1 次/月**。

## 六、防"立项通胀"

| 反模式 | 判据 | 处置 |
|---|---|---|
| 换皮包装成项目 | 只有美术/题材变化 | 降为变体 |
| 队列蹲位 | 卡 30 天没原型 | 自动出池 |
| 原型膨胀 | >3 天或 >¥2,000 | 停，回池 |
| 开工后加范围 | 超出契约 | 改契约或拒绝 |
| 壳当项目 | B/C 计入 9 款 | 不计；壳是派生 |
| 实验当生产 | 占生产槽 | 停；实验不占槽 |
| 方向天天变 | 无数据支撑 | 停，先取证 |

## 七、证据

- 机会卡（1 页）
- 10 秒原型片段
- 反向测试结论
- 评分卡 + 原创五条
- 契约哈希 + 回执

缺任一项 → 不算立项。

## 八、与双轨的关系

- 守成：G-A → G-B → G-C → 生产。
- 创新：G-A → G-B；过了才转守成 G-C。
- 放大：G-D；不重新走 G-A。
