# PROTO-NOTES · Fold It 手感原型 v0.1

> FOLD-001 / E02-T1 / 3 天 spike 最小件。单文件 `proto/index.html`，纯 HTML/CSS/JS，无依赖、无外部图片/音频、0 出站请求。
> **已自测：打开无报错、能完成 3 关**（Chrome 133 headless 截图 + Node 逻辑回归 14 条断言全过）。

## 怎么打开 / 怎么操作

1. 双击 `proto/index.html`（或拖进浏览器）。双击即可，不需要服务器。
2. **折**：按住衣服 → 沿**亮起的红色虚线**（法线方向）拖 → 松手。拖过 25° 会自动走完剩下的角度并落位；不到 25° 弹回，不算错。
   虚线是绕轴镜像是 `cos θ` 的正交投影预览，所以拖到一半能看到背面（更深的那一片）翻过来。
3. 折满步数后，把衣服**拖进右边抽屉格位**（第 1 格会呼吸）；落下 150ms 缩进格位，占位点 +1。
4. **撤销**：右上「↶ 撤销」或 Ctrl+Z（单件无限次）。**拿起重放**：直接点格位里的衣服。
5. **演示**：右上「▶ 演示」→ 自动跑完本轮（折 + 入格），约 8–10s，用来录 10 秒盲看素材。
6. **重置**：清空抽屉从头来。收完三件后点卡片 = 再来一轮但**保留抽屉**（这时第 1 格已满，可以试「放不进」）。
7. 左上角是 debug 计时（t0 / first_fold / first_slot / level），正常玩可以无视。

## 原型验证了什么

- **折的手感链**：拖动 → 实时翻折预览 → 松手自动走完 → 落定「咔」（WebAudio 合成的低频撞击 + 纤维颗粒）→ 折痕永久留在布上（暗 26% + 折脊亮 62%）。
- **折痕是记忆**：折痕随后续折一起镜像移动，不会被"重画"覆盖。
- **空间约束**：6 格位、一格 3 件（规格 4–6 的简化）、占位点与「满」标；满了就放不进、弹回桌面、可以拿起重放。
- **无失败态**：折错线照样折下去（物理一致），只有「撤销」；不出现 Fail / GameOver / 倒计时 / 评级 / 惩罚音。
- **10 秒钩子**：冷启 0.9s 起有提示，第一条折线一直呼吸；实测首折可在 0.2–2s 内完成（automated 167ms）。
- **三关走通**：T 恤对折（2 折）/ 裤三折（2 折 3 层）/ 毛巾卷（3 折，卷的简化）。

## 没验证什么

- 真实布料（软弯、自重、褶皱、厚度排气）：这里是刚体网格 + 正交投影折叠，**不是布料解算**。
- 92% / 80% 成型覆盖率判定、层序遮挡正确性、塞角/内翻、金痕（落点 ≤1.5px 且 ≤2°）。
- 性能预算（DC / fps / 内存）、触控精度（真机 ±12px 吸附）、车机 4K、微信包体。
- 3 秒识别与 10 秒首爽的**人**学结论——原型只提供素材，判据要 5 人盲看才算。

## 已知简化（不是最终布料模拟）

- 网格 20×20 单元（规格 16×16 为下限，取 20 只为剪影好认）；折叠数学与 16 完全同构。
- 折线全部吸附到**网格线**，所以折位只能落在 1/20 的整数倍上；真版要支持任意折线 + 2% 垂距容差。
- 层用 `z += 10` 排序 + 前后片明度差代替真实层偏移与穿模检测；叠 3 层以上会看到"条纹叠片"。
- 只按"折线是否匹配解"判定对错，**不区分折的是哪一侧**（真版层序会因此不同）。
- 一格 3 件是为了 3 关能演示满格（规格 4–6 件）；不放 Blu-ray 级收纳算法，只做整数占位。
- 没有存档、没有图鉴、没有每日、没有音乐——按 D-009 / §9 不做。
