# Fold It（折一折）产品需求文档 v1

> 项目 FOLD-001 · 类别 A（Steam 买断）· 契约 `contracts/fold-001.yaml`（只读；本文不改契约，冲突走 G-D 变更门）
> 核心动词「折」——与吸嘟嘟的「吸」不共享动词与循环，只共享管线与模板，不构成换皮；纯换皮一票否决。
> 一局 = 一桌 4 件，68–82s（验收带 60–90s）· 100 件 / 25 桌 · 内容 3h（验收带 2–4h）· 4.3 周（试验期上限 6 周）· $14.99 · 复用 ≥80%
> 口径：3h 按"100 件 × 3 次接触 ≈2.1h + 全金追折 + 图鉴回看"估算；设计案的"每日一件"不在本需求内（见 §9），S3 实测不足按 G-D 提范围变更。
> 微信 3 件、车机 5 件是独立契约壳（FOLD-001-MINI / -CAR，判例 6），不写进 A 的 shells，不计本 RC 验收。

## 1 目标与非目标

| # | 类型 | 内容 | 可判定标准 |
|---|---|---|---|
| O1 | 目标 | 一个动词讲清：单指沿折线把纸折过去，目标剪影当场变实 | 3s 静帧盲测 5 人（无文字无 UI），≥4 人答"折东西/折纸" |
| O2 | 目标 | 一桌 4 件落在 68–82s；100 件撑起 2–4h | bot 20 局 p50 ∈[68,82]s 且无 <55s、无 >100s（G5）；3 人完整体验中位 ∈[2.0,4.0]h，首通单独记录 |
| O3 | 目标 | 4.3 周出 RC，复用 ≥80%，单款成本 ≤¥11,000 | RC 包 + 8 闸回执；复用统计 ≥80%；实际支出 ≤11,000 |
| N1 | 非目标 | 不做成长/数值/经济 | 全包无货币、无等级、无星级、无评级；静态扫描 0 命中 |
| N2 | 非目标 | 不做长线运营 | 无每日任务、无签到、无排行、无好友 |
| N3 | 非目标 | 不做 3D/多人/联网 | 2D 纸面渲染；抓包 0 出站请求 |

## 2 用户故事

| # | 场景 | 故事 | 可判定验收 |
|---|---|---|---|
| U1 | 进入 | 双击图标后 5 秒内看到"继续/开始"，不用登录 | 冷启 ≤5s 到可操作；账号步骤 0 次 |
| U2 | 教学 | 第 1 件用一句话教我"按住纸角，沿虚线拖过去" | 单条 ≤12 字；不点跳过也能过第 1 件；3 人中 ≥2 人 60s 内完成 |
| U3 | 折 | 我拖过折线，纸自己走完剩下的角度落位，有"咔"一声 | 松手 ≥25° 自动走完；≤200ms 吸附（±8° / ±2px） |
| U4 | 完美折 | 折得够准，折痕变金色纤维线；一件全金，图鉴格加金框 | 落点 ≤1.5px 且折角 ≤2° → 金痕；HUD 计数与日志一致 |
| U5 | 折歪 | 折错不怕：纸照样折下去，长按 0.4s 撤销，不会被判失败 | 无红、无惩罚音；撤销 0.25s 展平；单件无限次；无失败页 |
| U6 | 图鉴 | 我想看折过的东西，断网也能翻，空格一眼可见 | 100 格三态（未折/已折/全金）；无网可开；打开 ≤300ms |
| U7 | 设置 | 调音量、灵敏度、左右手、色弱配色，改完立刻生效 | 7 组控件；改动 ≤1 帧生效并落盘；重启保留 |
| U8 | 存档 | 关掉游戏，下次点"继续"回到上次那桌 | 写盘 ≤50ms；重进落点一致；断电最多丢 1 件 |
| U9 | 退出 | 我按 Alt+F4 或点退出，进度不丢 | 退前写盘；日志必有 quit(reason) 一条 |

## 3 页面与流程

```text
[启动 t0] → [主菜单] ─继续/开始→ [游戏内一桌 4 件] ─4 件完成→ [结算] ─再来一桌→ [游戏内]
[主菜单] ├→ [选桌] ─选桌→ [游戏内]   ├→ [图鉴] ─返回→ [主菜单]   └→ [设置] ─返回→ [主菜单]
[游戏内] ─ESC/暂停→ [暂停层]：继续 / 撤销上一折 / 回主菜单
```

| 页面 | 必需元素 | 交互约束 | 验收 |
|---|---|---|---|
| 主菜单 | 标题、继续（显示"桌 n/25"）、选桌、图鉴、设置、退出 | 继续为默认焦点；无账号 | ≤2 次输入进局；无存档时"继续"禁用而非报错 |
| 选桌（关卡选择） | 25 张桌卡（主题名 + 4 件缩略 + 金痕数） | 按段解锁，未解锁显锁不可点 | 25 卡滚动 p50 ≥60fps；状态与存档逐卡一致 |
| 游戏内 HUD | 右上目标剪影、4 件进度点、金痕计数；底部撤销提示与暂停 | 不遮挡折线操作区；无固定遮挡层 | 1080p 占屏 ≤12%；全界面无倒计时数字 |
| 结算（一桌结束） | 本桌 4 件成品、金痕 n/N、再来一桌/回菜单 | ≤400ms 出现；无分数、无评级、无"重来" | 3 秒可读完；点"再来一桌"直接开局 |
| 图鉴 | 100 格架子、三态、按件详情（可端详折痕） | 断网可用；按住看折痕 | 打开 ≤300ms；未折格内容不可见 |
| 设置 | 母带/音乐/音效、灵敏度、左右手、减少动效、色弱、语言、窗口 | 即改即生效，返回不丢 | 7 组控件；重启后值与落盘一致 |

## 6 埋点事件

> 无服务器：只写本地 `logs/telemetry.jsonl`，≤2MB/7 天/滚动 3 份，0 出站请求。公共字段 `event,ts_utc,session_id,platform,app_version,build_id`

| 事件 | 触发点 | 专有字段 | 用途 |
|---|---|---|---|
| t0 | 进程启动、主菜单首帧 | first_run, save_exists, locale, boot_ms | 首启时长基线、漏斗分母 |
| first_fold | 首次完成吸附 | t_since_t0_ms, level_id, fold_index, angle_err_deg, snap_ok | 教学有效性；目标 ≤10s |
| first_reward | 首次获得图鉴条目 | t_since_t0_ms, level_id, collection_id | 首奖励到达；目标 ≤150s |
| level_complete | 一桌结算页展示 | table_id, items_done, gold_n, gold_total, duration_ms, undo_count, cover_avg | 单局时长分布、难度曲线、金痕率 |
| quit | 退出且写盘完成 | page, session_ms, reason(menu/altf4/unclean), progress_written | 流失页定位、写盘可靠性 |
| settings | 任一设置项变更 | key, old, new, page | 默认值是否合理、色弱/灵敏度真实使用 |

## 7 三端差异

| 项 | Steam（Win64，主） | 微信（3 件壳） | 车机（5 件壳） |
|---|---|---|---|
| 输入 | 鼠标按住拖动；触控板/触屏单指 | 单指，9:16 竖屏，剪影在顶手指在下 | 单指大触控，命中 ≥24mm，两段式（先选中折线再拖） |
| 分辨率 | 1080p 起；16:9/16:10/21:9；窗口/无边框 | 750×1334 逻辑，适配安全区 | 3840×2160 横屏，控件贴边 |
| 包体 | ≤300MB（装后 ≤600MB） | 主包 ≤4MB，分包 ≤30MB | ≤200MB（5 件 demo） |
| 存档 | 本地 JSON；Steam Cloud 可选（取较新，失败不阻断） | wx.setStorage 本地；清除即重置 | 本地，按车机账户隔离 |
| 内容范围 | 100 件 / 25 桌 + 图鉴 + 成就 | 3 件，无图鉴无每日，结束一张静态卡 | 5 件 2 分钟循环，无文字 |
| 广告/联网 | 无；0 请求 | 无 IAA；仅授权必需，游戏内 0 请求 | 无；0 请求 |
| 附加门 | G1–G8 | package_4mb_30mb + mini_game_review | car_4k60 + oem_spec + signing |

## 9 明确不做

| 不做 | 拒收判据 |
|---|---|
| 广告/IAA | 包内广告 SDK 引用 0；G6 静态扫描 0 命中 |

| 排行/社交 | 无榜单、无好友、无分享得奖励 |
