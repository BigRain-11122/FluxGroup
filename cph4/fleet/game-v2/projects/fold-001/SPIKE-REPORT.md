## 二、没测到什么（不许外推）

| 项 | 原因 |
|---|---|
| 层遮挡 / 穿模 | 原型用 `z+=10` + 明度差代替，3 层以上会看到"条纹叠片" |
| 92%/80% 覆盖率、IoU 判定 | 原型只判"折线是否匹配解"，没有轮廓判定 |
| 6 件一格 | 原型一格 3 件；第 6 件滑进缝的空间爽点未验 |
| 首通时长 127min | 原型只有 3 关；不能外推 |
| 1080p/4K 性能 | Canvas 2D ≠ Unity；必须进引擎重测 |
| 5 人盲看 | 需要真人；目前只有素材 |

## 三、测试中修掉的 6 个真 bug

1. 交叉折线等距时干扰线抢解 → 加解优先权重。
2. 桌上有件时格位里的衣服点不起来 → 允许未开始折时拿起。
3. rAF 时间戳不推进导致 dt=0 卡死 → 改 performance.now()。
4. toast 压住抽屉第三行 → 移到底部居中。
5. 演示模式对满格无限重试 → 顺延到空位，无空则停。
6. 格位缩略图溢出色块 → 收紧边距。
