## 二、证据四级（判据只用 E1/E2 才能给 4–5 分）

| 级 | 定义 | 例子 | 能支撑 |
|---|---|---|---|
| **E1 实测** | 脚本/引擎/人测记录，带路径与时间 | `replay_result.json`、录屏计时、8 闸回执 | GO |
| **E2 硬数据** | 外部 API / 平台数据实拉，带参数与日期 | SteamSpy 2026-11-20 拉取、Steam 商店 API | GO |
| **E3 文档推断** | 设计案、估算、内部推演 | 首通 127min 的算术外推 | 只能到 PIVOT/条件 |
| **E4 假设** | 未验证的判断（原【设】） | "半折静帧可能被读成几何拼图" | **不得单独支撑任何 GO** |

三条机械化规则（`panel_lint.py` 强制）：
1. 给 4–5 分的判据，必须挂至少一条 E1/E2 证据，且文件真实存在。
2. E4 在「支撑 GO 的判据」里出现一次即判 FAIL。
3. 证据日期早于契约日期 = 过期证据（承接「证据必须新于代码」C-02）。

## 三、判分与门槛

- 单条判据 0–5 分；`null` = 未评估（NOT_ASSESSED），**不算 0 分也不算满分**。
- 加权均分只按**已评估权重**归一；覆盖率 = 已评估权重占比。
- 决策：

| 决策 | 条件 |
|---|---|
| **GO** | 覆盖率 ≥0.85 且加权均分 ≥4.0 且无否决 且 GO 判据中 E4=0 |
| **CONDITIONAL** | 覆盖率 ≥0.60 且加权均分 ≥3.0，且缺项全部写明「补测动作 + 截止」 |
| **NO-GO** | 其余；或任一否决项触发 |

覆盖率单列的意义：**"没测"不能靠打分洗成"差不多"**。一项没测就是覆盖率掉一格，掉到 0.85 以下不能 GO。

## 四、一票否决（任一触发即 NO-GO，不参与加权）

| # | 项 | 判据 | 法条 |
|---|---|---|---|
| V1 | 侵权/可识别真人 | 明星脸、原作素材直用 | 判例 9；compliance |
| V2 | 服务器/多人/联网 | 有联网依赖即否决 | C-09；判例 10 |
| V3 | 纯换皮 | 只改美术/题材/关卡数 | 判例 1/2；§六 反模式 |
| V4 | 证据造假 | E4 冒充 E1、0 用例报 Passed、包比代码旧 | C-05；RPB §四「瞎转」 |

V4 的处置不是"改分"，而是**本次评审作废**，重跑。

## 五、独立性（照着 `agents.registry.json` 的 doer≠checker≠auditor）

- S7 审计席的作者不得是本卡任何判据的作者，也不得是签字人。
- 同一张卡里，S1–S6 可以同一位制作人署名，但**S3/S5 的 4–5 分必须有第三方证据**（人测记录、引擎日志），不能是设计者自述。
- 签字人 = 制作人（G0–G3）；G4 只有 CEO。

## 七、产出物（缺一不算立项）

1. `panels/<PROJECT>.yaml` — 机器可读评分卡（席位、判据、分数、证据、否决）。
2. `panels/<PROJECT>.md` — `panel_lint.py --render` 生成的一页纸。
3. `panel_lint.py` 结论：`GO` / `CONDITIONAL` / `NO-GO` + 覆盖率 + 否决命中。
4. 缺项清单：每条 `null` 判据写明「补测动作 / 谁做 / 截止」。

## 九、一次评审怎么跑（4 条命令）

```bash
# 1) 写卡：复制上一张，只改判据/证据/分数（权重不许动）
cp cph4/fleet/game-v2/panels/FOLD-001.yaml cph4/fleet/game-v2/panels/<ID>.yaml

# 2) 独立席旁证（可选但建议）：9b 顺序跑 S1 市场 + S7 审计，落 local/
python Tools/gds/panel_review_local.py

# 3) 校验：先负控，再验卡
python Tools/gds/panel_lint.py --self-test
python Tools/gds/panel_lint.py

# 4) 出人读页
python Tools/gds/panel_lint.py --render cph4/fleet/game-v2/panels/<ID>.yaml
```

`panel_lint` 返回非零 = 卡不合法，不得进 G-C。模型旁证只进 `note`，**不进 evidence**。
