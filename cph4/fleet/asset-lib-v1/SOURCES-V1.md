# 资产来源与授权清单 v1（2026-11-03）

CEO 令：「克隆的对象要非常广泛，国内外明星、UP主、网红、素人、电影、电视剧、播音腔、动画片、声优什么的」。

## 零、先说结论（这条不能绕）

**克隆具体真人（明星/UP主/网红/素人/演员/声优的原声与原脸）不做，除非拿到本人书面授权。**

三条理由是硬的，不是我的偏好：

1. **法律**：民法典 §1019 声音参照肖像权保护、§1023 姓名肖像许可；2023 年北京互联网法院已有 AI 声音侵权首案。
   未授权克隆真人声音/肖像 = 直接侵权，与"是否商用"无关。
2. **监管**：《互联网信息服务深度合成管理规定》(2023-01-10)、《生成式人工智能服务管理暂行办法》、《AIGC 标识办法》(2025-09-01)。
   未标识的真人克隆属重点整治对象。
3. **平台**：B站/抖音/红果对"AI 换脸换声"有明确下架条款，一次判罚会连带整个账号与作品线。

已把这条做成机器闸：`asset_dataset_audit.py` 要求数据集目录里有 `RIGHTS.json`
（`source` / `license` / `real_person` / `consent`），`license=unknown` 或
`real_person=true 且 consent!=true` 一律 FAIL，训练卡派不出去。已双向反验过。

## 一、"广泛"的正确定义

广泛 **≠** 克隆很多个名人；广泛 **= 覆盖人群统计分布**。
要的是：年龄 20–60、南北口音、粗细声线、职业感、时代感、情绪状态都有人。
这类覆盖用公有领域 + CC 授权 + 自录 + 商用授权库就能做到，而且**可商用、可长期用、不会被下架**。

## 二、声音：合法且覆盖面广的来源

| 来源 | 覆盖 | 授权 | 用途 |
|---|---|---|---|
| Mozilla **Common Voice** | 100+ 语言，含中文各地方言口音，男女老少 | CC0（需在下载页核对当期条款） | 拉口音与年龄分布的主力 |
| **LibriSpeech / LibriTTS** | 英语朗读，音色数量极大 | CC BY 4.0 | **播音腔档**正好用它；也可做英语角色 |
| **VCTK** | 110 位说话人，多口音英语 | CC BY 4.0 | 英语口音多样性 |
| **AISHELL-3** | 218 位中文说话人，带性别/年龄标注 | Apache-2.0（需核对） | 普通话基础盘 |
| **Emilia / WenetSpeech** | 大规模中文自然语流 | **非商用**（CC BY-NC 等） | 只能内部研究，禁止进商用资产 |
| **LibriVox 有声书** | 大量公有领域朗读 | 公共领域录音 | 老派朗读腔、叙事声线 |
| **公有领域老唱片/老广播** | 1920s–1940s 音色，时代感强 | 作者死亡逾 50 年（需逐件核） | 复古角色音色 |
| **自录 / 雇配音（签授权）** | 可指定方言、年龄、特殊音色 | own + 书面授权 | 最干净、最可控 |
| **商用声音库（讯飞/火山/阿里复刻授权、专业配音库）** | 现成商用音色 | licensed | 要"立刻能用"就走这条 |

**明确不做**：影视剧原声、动画原声、声优作品音轨、UP主/播客音频、明星访谈——
这些的著作权与人格权都不在我们手上，抓下来做克隆是双重侵权。

## 三、人脸与角色：合法且覆盖面广的做法

| 做法 | 说明 |
|---|---|
| **原创角色设计**（推荐主力） | 我们自己定角色：年龄/体型/地域面孔/职业/时代，按分布覆盖，不指向任何真人 |
| **公版美术做风格参考** | 作者死亡逾 50 年的绘画/摄影（逐件核），只取"风格与时代"，不取具体人脸 |
| **商用模特授权图库** | 有 model release 的图库（如部分 Shutterstock/Getty 授权），可做真人参考 |
| **自建拍摄** | 找模特签肖像授权，最干净 |

**明确不做**：明星/网红/素人照片训 LoRA；影视剧与动画角色形象（美术作品著作权）；
任何"某某同款脸"。这类 LoRA 一旦产出，等于给自己埋一颗随时引爆的雷。

## 四、落地方式（每批资产都要带这张牌）

数据集目录放 `RIGHTS.json`：

```json
{
  "source": "Mozilla Common Voice zh-CN 2026-06 快照",
  "license": "cc0",
  "real_person": false,
  "consent": null,
  "note": "多说话人口音分布；不含可识别个人身份信息"
}
```

允许的 license：`own` / `public-domain` / `cc0` / `cc-by` / `licensed`。
其余（含 `unknown`）一律不许进训练。

## 五、如果你确实要某个具体的人（明星/声优）

只有一条路：**拿到本人或经纪方的书面授权**，把授权文件路径写进 `RIGHTS.json` 的 `consent_ref`，
并把 license 设为 `licensed`。没有这份纸，我不做，机器闸也不会放行。

## 六、待你决策的一件

要不要走"商用声音库授权"（讯飞/火山/阿里或专业配音库）？那条能最快拿到
"明星同级别的质感但不侵权"的音色，代价是采购费用与授权范围谈判——这属花钱决定，归你。
