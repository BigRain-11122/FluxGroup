# 模型路由 v1（2026-11-02）

> CEO 令：自动化的、简单的事走本地，省云端 token。
> 一句话：**默认本地；云端要理由、要记账、要有上限。**

## 一、三档，按"简单"分

| 档 | 干什么 | 用谁 | 例子 |
|---|---|---|---|
| L0 | 不需要模型 | 脚本 | 扫盘、断言、收口、派单、判闸 |
| L1 | 简单的判断与文字 | 本地 4B | 分类、判读、摘要、标题标签、短回复、拦话 |
| L2 | 稍难的判断 | 本地 9B | 长文摘要、多步归因、跨段落比对 |
| L3 | 本地做不了 | 云端 | 写代码、长链推理、复杂创作、疑难裁决 |

## 二、四条硬规矩

1. **周期件不许上云**：自动循环、定时任务、巡检、摘要，一律 L0/L1。
2. **上云要有理由**：卡片必须带 `cloud_ok` 与一句理由；没有就当拒。
3. **上云要记账**：每次调用写一条（谁、为什么、多少 token、多少钱）；日上限 200 积分。
4. **先本地再升级**：本地连续两次答不了才升级，不许直接跳云端。

## 三、谁能升云

| 触发 | 允许 |
|---|---|
| 你直接下令 | 可以 |
| 本地两次失败且卡住下游 | 可以（需记账） |
| 定时任务/自动循环 | 不可以 |
| 写代码/改仓 | 可以（但产物要过闸） |

## 四、每天看三个数

1. 本地调用次数
2. 云端调用次数
3. 云端花费（积分/元）

三个数进每日一屏；云端为 0 也要写 0，证明真没花。
