# 大脑工位 · 岗位书（算力大脑 / 3×V100）

> 你现在还没入网。这份岗位书是**入网后的合同**：先按它验收，合格才进排产。
> 上位法：`cph4/registry/CANON-V2-20261111.md`；配额见 `STATIONS.json` 的 brain 段。

## 一、你的领域（只做这些）

1. 量化：数据整理、回测、报告、信号导出（`PROD-QUANT-REPORT`）。
2. 深度判断：跨域根因、方案取舍、代码评审（只出结论与理由，不代执行）。
3. 大脑服务：按需提供大模型推理（入网后由主控网关统一入口）。
4. 重批：媒体批量转码、批量校验这类吃 CPU/RAM 的活。

## 二、你不做的事

1. 不做内容创作与美术生成（那是视觉与声音工位）。
2. 不直接改队列、不改卡状态（模型只做参谋，不做法官）。
3. 不对 CEO 对外发言，不代发任何平台内容。
4. 未入网前不接任何活。

## 三、入网前置（缺一条就不算上岗）

1. 系统装好、驱动正常、`nvidia-smi` 能看到全部卡。
2. 磁盘余量达线（现有 512G 盘被记录为不够，需加盘）。
3. 并入内网（tailnet），端点写进 `STATIONS.json` 与节点名册。
4. 能读到 origin 上的分片（`git show origin/main:cph4/fleet/rt/*/queue.jsonl`）。

## 四、量化判据（做完要能被复现）

1. 同一命令、同一数据窗口，结果可复现；随机种子固定。
2. 报告必须带：收益、最大回撤、夏普、样本外区间、交易成本假设。
3. 信号导出为 CSV，字段与口径写清楚，能被别的线直接消费。
4. 不许只报好看的窗口；样本外表现必须单列。

## 五、判断类活的判据

1. 结论必须带证据指针（文件、行号、数据）。
2. 不确定就写“证据不足”，不许编。
3. 评审输出格式：问题 → 证据 → 影响 → 建议动作。

## 六、你那台机的特殊约束

1. CPU 无 AVX2，本地大模型的 CPU 卸载路线不可用，只能全驻留。
2. 六卡供电分线与功率墙要守住；温度到上限就降并发。
3. 显存 48G 池是给大脑服务的，不要把显存全吃在一件事上。

## 七、上岗验收（三条全过才进排产）

1. 跑一份最小回测，同命令两次结果一致，报告三项指标齐。
2. 起一次大脑服务，主控网关能调通。
3. 完成一次代码评审样例，输出四段式结论。

## 八、领回去时对你说的一句话

> 你是大脑工位：量化、深判、重批；先入网再加盘；结论必带证据；只做参谋不做裁决。

## 十、你的智能体

1. 运行时：`python3 Tools/fleet/station_agent.py --station brain --loop 300`（Windows 用计划任务每次 `--once`）。
2. 它只巡你自己的队列、回执与产物，发现写进 `rt/brain/`；需要判断时调用主控 8792 网关。
3. 它的结论是初审，不是最终验收——你不能拿它给自己作证。
4. 规格见 `cph4/fleet/stations/AGENT-SPEC.md`。
