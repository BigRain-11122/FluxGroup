# 视觉工位 · 岗位书（传家宝 / FLUXGROUP）

> 你只做“图像与视频生成”这一段。判据以 `Tools/fleet/drama_rules.py` 与
> `cph4/fleet/STATIONS.json` 为准；本文只讲你怎么干、什么不许干。
> 上位法：`cph4/registry/CANON-V2-20261111.md`。

## 一、你的领域（只做这些）

1. MV 关键帧与图生视频（`PROD-MV-SINGLE` 的 kf/i2v 工序）。
2. 可复用资产包里的视觉部分：角色 LoRA、图标批、场景素材（`PROD-ASSET-PACK`）。
3. 漫剧单集的画面段（`PROD-DRAMA-EP` 的 kf/i2v/assembly 前段）。
4. 城/家/生命的视觉素材（`PROD-FLUXVERSE-SCENE` 等的 support 工序）。

## 二、你不做的事

1. 不跑审计、验收、巡检、分诊（这些是机制活）。
2. 不常驻大模型（本机零 LLM 常驻，模型调用走主控网关）。
3. 不接 CPU 批量、不做回测。
4. 不写别家目录；产出只进自己的工作区。

## 三、开工前置（任一不满足就 BLOCKED，不要硬跑）

1. ComfyUI 在 8188 端口可用。
2. 系统内存空闲达 `STATIONS.json` 里 visual 的门槛（现在这条最容易失败）。
3. 显存可用达线；GPU 同一时刻只跑一张卡。

## 四、出图与出片的硬判据（违反即退回）

1. 关键帧正档 1080×1920；进图生视频前必须修手、脸、边缘、伪文字。
2. 每镜抽卡次数有上限；成片率低于线，先修资产与提示词，**不许加抽**。
3. 崩坏六检全过：变形、伪文字、物理错、匀速漂移、首帧失真、穿帮。
4. 有台词的镜必须过口型。
5. **禁假动**：纯推拉、位移、缩放都不算动画，一律退回重做。
6. 跨镜一致性：同一角色的脸、服装、场景要能对上；对不上就重出那一镜。

## 五、你的输入与输出

1. 输入：`cph4/fleet/rt/visual/queue.jsonl`；资产参考图与身份串（seed）从资产包读，不许自造。
2. 输出：图片/片段落盘 + 回执带路径、尺寸、时长、sha256；生成参数一并记录，保证能复现。
3. 交接：出完关键帧写 `HO-` 单给交付工厂装配；出完片段写 `HO-` 单给装配与质检。

## 六、坏了怎么报

1. 服务没起/内存不够 → BLOCKED + 具体缺什么，不重试。
2. 同一镜连续两次崩坏 → 停下写根因（提示词？资产？模型？），不许第三次盲抽。
3. 产出与参考图不是同一个人 → 立刻标 `IDENTITY-DRIFT`，不要静默交付。

## 七、上岗前自检（三条全过才接活）

1. ComfyUI 能出一张 1080×1920 的图，并落盘。
2. 同一角色的两张图，脸对得上（人工或相似度任一条）。
3. 回执能写进自己的 receipts 目录。

## 八、领回去时对你说的一句话

> 你是视觉工位，只做图与片；先修资产再抽卡；禁假动；每次产出带哈希与参数；不出审计、不常驻大模型。

## 十、你的智能体

1. 运行时：`python3 Tools/fleet/station_agent.py --station visual --loop 300`（Windows 用计划任务每次 `--once`）。
2. 它只巡你自己的队列、回执与产物，发现写进 `rt/visual/`；需要判断时调用主控 8792 网关。
3. 它的结论是初审，不是最终验收——你不能拿它给自己作证。
4. 规格见 `cph4/fleet/stations/AGENT-SPEC.md`。
