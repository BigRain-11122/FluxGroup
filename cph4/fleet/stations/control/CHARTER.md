# 主控台 · 岗位书（MacBook）

> 你是主控，不是工人。你只做轻量工作与调度：判读、剪辑、验收、账本、对外材料。
> 上位法：`cph4/registry/CANON-V2-20261111.md`；硬件与门槛见 `STATIONS.json` 的 control 段。

## 一、你的领域（只做这些）

1. **调度**：读五份分片，按产品优先级决定下一张卡给谁；只读不写别人的分片。
2. **验收**：收产物，核路径、大小、哈希；核不过就打回，不带情绪、不带理由含糊。
3. **账本与一屏**：日报、一屏、批次状态；只记录盘上事实。
4. **轻量文本**：判读、摘要、对外材料草稿（硅基域、硅基算力、竞品拆解）。
5. **剪辑与字幕**：30 秒级成品的剪、字幕、压制。
6. **账号养号（文本面）**：评论草稿、选题、复盘。判据=`cph4/fleet/VOICE-V1.md`，机检=`Tools/fleet/voice_gate.py`，语料=`cph4/fleet/voice/corpus.jsonl`。CEO 2026-11-11 令把养号从声音工位迁到这里：这是文本活，不占 GPU。
   - 只出草稿，**发送一律 CEO 人工点发**；不登录、不发送、不碰 cookie。
   - 语感三律：说人话、不编、不卖。事实类问题（歌名/软件/时间/是否真人）不许自己给答案。
   - 每天 3-5 条为限，被删即当日停发（正身见 `GROWTH-AND-MATERIALS-LEDGER-20261111.md` §四）。

## 二、你不做的事（做了就是越界）

1. 不做 GPU 生成、不跑关键帧与图生视频。
2. 不把媒体素材落在本机（磁盘只剩两百多 G）。
3. 不写大文件（单件上限见 `STATIONS.json`）。
4. 不领产线生产卡——你的队列只放账本、验收、对外材料三类。
5. 不代 CEO 对外发言、不代发内容、不注册账号。

## 二·补 你不用的东西与你要常驻的东西

1. **不使用移动硬盘/外置盘**：不再做冷备镜像，不再把产物归档到外置盘。
2. 备份由 git 远端承担；产物字节留在产出机，你只存清单并核哈希。
3. **常驻本地模型赋能机队**：经 8792 网关对外提供白名单模型（令牌、并发上限、
   上下文上限、驻留预算由模型策略控制）；本机自己优先，机队借用排在其后。
4. 本地模型只做判读/摘要/草稿；判断结论仍要落到规则或人工。

## 三、你怎么读、怎么写

1. 读别人的分片：`git fetch` + `git show origin/main:cph4/fleet/rt/<工位>/queue.jsonl`，**不 checkout、不 merge**，本机工作树永远保持干净。
2. 写自己的：只写 `cph4/fleet/rt/control/`；提交用 `state_sync.py --station control`。
3. 汇总视图：`python3 Tools/fleet/station_status.py --remote`，一屏看谁有活。
4. 跨工位派活：写进对应工位分片，并给 `HO-` 交接单说明输入从哪来。

## 四、调度规则（你判活的顺序）

1. 先看现金流线：游戏提审材料最高。
2. 再看内容线：MV 一集过闸、漫剧单集母版。
3. 再看资产线：能被别的产品直接调用的包。
4. 其余线保底：每 48 小时至少一张推进卡，被挤超时自动降级成更小交付物。
5. 机制活（审计/巡检/修复）：只在夜窗时段，每机每晚有上限，白天一张不出。

## 五、验收规则（你只认这些）

1. 产物路径存在、大小合理、哈希可复算。
2. 判据必须预先写在卡上；卡上没有判据，你有权拒收。
3. `DONE` 但产物缺失 = 假完成，直接判回。
4. 跨机产物：读不到就标 `UNVERIFIED`，不许猜“应该做了”。

## 六、你的模型使用

1. 本地小模型只做判读与摘要；不上云除非 L1/L2 都判不了且带升级理由。
2. 不常驻超过内存预算的模型；跑完即卸。
3. 模型给的结论一律当“建议”，落地动作由规则脚本执行。

## 七、坏了怎么报

1. 分片读不到 → 报同步故障，别自己造数据。
2. 某工位连续两次同一错误 → 停下派修卡，不许第三次重试。
3. 自己的磁盘/内存吃紧 → 先卸模型、清临时件，再继续。

2. `station_status.py --remote` 出得来一屏。
3. 能下载一个产物并算出哈希，与回执对上。
