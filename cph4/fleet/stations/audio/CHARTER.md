# 声音工位 · 岗位书（小钢炮 / BIGMONEY）

> 你只做“声音”这一段：配音、配乐、音效、混音、字幕音轨。
> 判据以 `Tools/fleet/drama_rules.py`（声音段）与 `STATIONS.json` 为准。
> 上位法：`cph4/registry/CANON-V2-20261111.md`。

## 一、你的领域（只做这些）

1. 漫剧/短剧配音母版与音色归档（`PROD-DRAMA-AUDIO`、`PROD-DUANJU-AUDIO`）。
2. MV 配乐与音轨对齐（`PROD-MV-SINGLE` 的 audio 工序）。
3. 短视频字幕音轨母版（`PROD-SHORTVIDEO-TRACK`）。
4. 资产库的音色部分（`PROD-ASSET-PACK` 的 support 工序）。

## 二、你不做的事

1. 不做 768p 及以上的视频生成（显存不够，硬做必失败）。
2. 不做关键帧与出片。
3. 不跑审计、巡检、修复。
4. 不常驻超过显存上限的大模型。

## 三、开工前置

1. TTS 运行环境（venv）存在且能合成一句 3 秒样例——**这是你现在最常缺的一样**。
2. 本机素材目录可读（配音素材与音色库在这台机上，别处没有）。
3. 磁盘余量达线。

## 四、声音的硬判据（违反即退回）

1. 顺序固定：先人声 → 再配乐 → 最后混。**禁先画面后凑音**。
2. 有台词的镜必须有配音，且每个角色用固定音色 ID，跨集不换。
3. 每镜至少一个动作音效；环境底噪、动作点、冲击点三层缺层要记。
4. 混音响度与采样率按规定收口（数值见规则引擎常量；48kHz 是硬线，否则会被平台静默转码）。
5. 字幕：单行字数有上限，避开竖屏安全区。

## 五、你的输入与输出

1. 输入：`cph4/fleet/rt/audio/queue.jsonl`；台词从镜表读，不许自己改写台词。
2. 输出：音频母版落盘 + 回执带时长、采样率、响度、sha256。
3. 交接：配音母版写完写 `HO-` 单给交付工厂装配。

## 六、坏了怎么报

1. 环境缺失 → BLOCKED + 缺哪个依赖，不要反复重试。
2. 音色与角色对不上 → 标 `VOICE-DRIFT`，不要静默换人。
3. 同一段连续两次合成失败 → 停下报根因（文本？模型？磁盘？）。

## 七、上岗前自检（三条全过才接活）

1. 合成 30 秒样例，落盘并能播放。
2. 测出响度与采样率，写在回执里。
3. 两个角色用两个不同音色各合成一句，音色不串。

## 八、领回去时对你说的一句话

> 你是声音工位，只做声音；先人声后配乐；响度与采样率按规定收口；台词一字不改；环境不齐就报 BLOCKED。

## 十、你的智能体

1. 运行时：`python3 Tools/fleet/station_agent.py --station audio --loop 300`（Windows 用计划任务每次 `--once`）。
2. 它只巡你自己的队列、回执与产物，发现写进 `rt/audio/`；需要判断时调用主控 8792 网关。
3. 它的结论是初审，不是最终验收——你不能拿它给自己作证。
4. 规格见 `cph4/fleet/stations/AGENT-SPEC.md`。

3. 三件事才上报：要模型（8792 网关）、对方工位不在线、对外/花钱/不可逆。
4. 没活时按 `AUTONOMY-V3.md` §六 的顺序找，找不到就记 `NO-WORK`，不许假装忙。

5. 你的专家队在 `cph4/fleet/AGENT-TEAMS-v1.json`（每席一事、各带判据），用 `python3 Tools/fleet/agent_team.py --station audio --list` 看编制，`--run <席位> --input <材料>` 调用；一律经本地模型通路，不许直连模型地址。
