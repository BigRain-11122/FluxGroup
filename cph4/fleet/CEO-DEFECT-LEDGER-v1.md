# CEO 挑错复盘台账 v1（CEO-DEFECT-LEDGER）

> 立账：2026-10-24｜CEO 令：「我挑的毛病都要复盘记录，下次自己查」
> 适用范围：MV / 短视频 / 车机 UI / 游戏，全部产线
> 铁律：**每一条 CEO 挑出的毛病 = 一条台账 + 一个可执行自检 + 一道闸**。只记账不落闸 = 没修（承 QC-MASTER-CHECKLIST 执法契约）。

---

## 使用规则

1. **24 小时内入账**：CEO 指出问题后，当窗建条目，缺一不可（现象/根因/自检/闸）。
2. **下片开机必跑**：任何新片开工/出片前，把台账里「自检」列的命令跑一遍；未跑不许出片。
3. **复发即升格**：同一问题第二次出现，自检从「人工看」升格为「脚本断言」，并记录升格日期。
4. **不许只写感受**：每条必须有数字或命令；没有就写「待量化」并给出量化方法。
5. **CEO 只做终点终审**：CEO 看片还能挑出问题 = 本条台账的闸失效，按复发处理。

### D-20261024-01 镜头跳动（成片整体位移）

| 项 | 内容 |
|---|---|
| 发现 | 2026-10-24 CEO：「镜头还是有跳动，这是AI通病，好好解决」 |
| 现象 | 成片 v707 多处镜内画面整体位移：84.375s(6.6px)、92.208s(36.9px)、109.375s(6.2px)、135.167s(26.8px) |
| 根因 | 至少 R06 源片静止（0.02px/帧），成片却横移 26.8px → **装配/变速引入**，非 i2v 生成；旧修法「用前一帧顶替」只能治单帧，且会造冻结；帧间混合会双重曝光 |
| 自检 | `python Tools/mv_seam_scan.py <成片>` → 镜内整幅位移跳必须为 0；`python Tools/release_gate.py --plan-cuts <同源切点表>` → 非计划硬跳 0 |
| 落闸 | `Tools/mv_stability_gate.py`（出片前强制）；锁定机位镜头用 `Tools/mv_stabilize_locked.py`；QC §25 |
| 复发判定 | 任意一镜镜内位移 > 6px 且非切点/非叠化 = 复发 |
| 备注 | 字幕已烧时不可整幅修；正法=无字幕母版→稳定化→重烧字幕 |

### D-20261024-05 剪辑把带病成片放行（职责事故）

| 项 | 内容 |
|---|---|
| 发现 | 2026-10-24 CEO：「剪辑干什么吃的 把成片剪出来这么多问题」 |
| 现象 | v707 出片仍含 4 处镜内整幅跳（84.375/92.208/109.375/135.167）、2 处冻结（43.917/189.917），且修片方式本身制造新问题 |
| 根因 | ①剪辑验收只核帧数/时长/字幕，**不核时间轴稳定性**；②用「前一帧顶替」补丁式修片，不做归因（装配 vs 源片 vs 生成）；③切点表与成片不同源，导致「非计划硬跳」误判；④曾用抽帧/联系表判 PASS（已被 CEO 推翻）；⑤剪辑无独立签核，问题漏到成片闸才暴露；⑥导演席只看构图/表演，不逐帧看位移 |
| 自检 | 出片必跑 `Tools/mv_stability_gate.py`（seam=0、freeze=0）+ `Tools/release_gate.py --plan-cuts`（非计划硬跳=0）；切点表必须由成片 scene detect 生成并与 EDL 对账；逐镜位移/冻结表随片留档 |
| 落闸 | 剪辑交付三表：**切点表（同源）+ 变速表 + 稳定性报告**；剪辑+导演双签才可进成片闸；缺一表=退回。装配脚本禁「帧间混合」与「无动机推近」 |
| 复发判定 | 任一跳动/冻结在成片闸之后才被发现 = 剪辑闸失效，按事故复盘 |

### 剪辑岗职责（D-05 附带定责）

1. **时间轴正确性**：切点同源、帧数/时长一致、变速逐镜有记录。
2. **时间轴稳定性**：镜内位移、冻结、单帧闪、字幕位置，全片负责；不是「导演看出来的才算」。
3. **归因**：任何异常先判「源片/装配/变速/字幕」，再选修法；禁补丁式掩盖。
4. **交付物**：成片 + 三表 + 稳定性报告 + 已知问题清单（零隐瞒）。
5. **签字**：剪辑签「三表齐、闸已过」；导演签「画面与节奏」；缺签不交片。
