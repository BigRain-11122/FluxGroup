## 一、思维导图（文字版）

### 1. 路线（先定赛道，再定工具）
- **三种形态**（平台给的系数不一样，选错等于白干）
  - 2D 漫剧：i2v 抽卡，成本最低，一致性靠档案 → 红果系数 40×
  - 3D 漫剧：资产一次做、百集复用，最稳，也最缺 → 红果 50×；占热播 TOP5 四席，上新不足 5% 却贡献 69.5% 新增播放
  - AI 仿真人：观众盘子最大、红线最紧 → 红果 60×；2026-04-27 起取消普惠保底
- **三层技术栈（不是三选一，是分工）**
  - 一站式 Agent：小云雀 / 巨日禄 / 万兴剧厂 / 天工短剧工作台 → 出骨架最快（《万兽独尊》5 人 8 天 60 集，客户口径）
  - 云端顶模：Seedance 2.5（单镜 30 秒直出、50+ 多模态参考、帧级编辑）+ Seedream 5.0 Pro + 可灵 / Vidu / 海螺 → 打英雄镜、定画风
  - 本地 ComfyUI：Wan2.2（首尾帧 Fun InP）/ LTX-2.x（"一图漫剧"）/ Qwen-Image / z-image-turbo → 跑量产，8G 显卡可开工
- **选路判据**
  - 动作戏 >30% 或连载 >60 集 → 3D/资产复用线
  - 文戏为主 + 要快速验证 → i2v 线
  - 要出海多语 → 先出 1080p 无字幕母版，再译制
- **成本锚（2026 工业化口径）**：800–1000 元/分钟；单集 1200–1800 元；100 分钟 8–12 万；7–14 天；1–3 人
- **算成本只能用"单段价 ÷ 成片率"**，不能用单段价，更不能看模型跑分
- **残酷分母**：抖音端 22.19 万部新上线，1055 部破亿 = 0.47%；约 90% 公司在亏 → 靠量无效

### 2. 剧本（决定天花板，画质补得回来，故事补不回来）
- **单集公式**：3 秒钩 → 10 秒立冲突 → 中段 1–2 次反转 → 结尾强钩
- **开场三类钩**：直接冲突 / 强悬念 / 极致反差。**禁铺垫超过 10 秒**
- **结尾三类钩**：悬念钩 / 危机钩 / 反转钩；卡在情绪最高点黑屏，钩子强度必须大于本集所有冲突
- **节拍密度**：每集 ≥3 个"动作→反应"节拍；无冲突闲谈 ≤20 秒；台词短、碎、锋利
- **长线结构**：1–5 集立人设抛主线；每 3 集小高潮、每 5 集大高潮；12–15 集中点大反转；结局留续集钩
- **人设反差锚**：一个与标签冲突的细节（女战神偷偷喂流浪猫），第 1 集就放
- **剧本→镜语**：把文学句翻成"主体 + 动作 + 景别 + 光线 + 固定/运动"，生成层只认这个
- **单集必须闭环**（开场冲突→升级→钩子），不是连续剧切片

### 3. 资产（一致性 = 命门；观众记不住名字，但会记住脸）
- **角色档案**：定妆 + 三视图 + 3–5 张多角度/多表情，中性灰底
- **身份锁三件套**：脸部参考图 + 固定身份串 + seed；参考强度 70–85%
- **多模态参考**：Seedance 2.5 单次可吃 30 图 / 10 视频 / 10 音频（厂商口径）
- **场景锁版**：主场景多角度 + 720° 全景；复杂场景给多张
- **道具资产**：从剧本提炼（武器/信物/手机），跨集复用
- **音色库**：每角色 1–2 个固定音色 ID，跨集不换
- **复用率 = 产能**：第 2 集起只补新镜

### 4. 分镜 → 关键帧 → 图生视频（决定它像不像"剧"）
- **镜表字段**：镜号 / 景别 / 运镜 / 时长 / 角色 / 场景 / 动作 / 情绪 / 台词 / 首尾帧
- **镜长**：每镜 2–3 秒；单镜 ≤5 秒；30 秒直出只留给重点镜
- **一镜一意图**：一个动作、一个情绪，不塞两件事
- **KF 海选**：低清 512–672 宽出 16–32 张 → 取 2 → 正档 1080×1920
- **KF 精修**：进 i2v 前把手/脸/边缘/伪文字修干净（首帧烂，视频只会把烂放大）
- **提示词结构**：主体 + 表情 + 动作 + 服装 + 环境 + 光 + 机位 + 画风；运镜单列
- **白模预演**：3D 导演台定走位与运镜，减少盲抽
- **真动 vs 假动**：禁 Ken Burns / 推拉 / 纯位移；真动=生成的表情、布料、粒子、口型
- **i2v 控制手段**：首尾帧补间 / 参考锁定 / 片段重拍（只重做坏的那段）/ 30 秒直出
- **抽卡预算**：每镜 ≤3 抽、成片率 ≥50%；低于 50% 先修资产与提示词，不是加大抽卡
- **崩坏六检**：morph / 伪文字 / 物理错 / 匀速漂移 / 首帧失真 / 穿帮
- **口型**：说话镜必须过（LatentSync 级，约 6.5G 显存）

### 5. 声音 → 装配（没声音 = 没人看）
- **顺序**：先出人声 → 再配乐 → 最后混。禁"先画面后凑音"
- **配音**：多角色音色 + 情感向量（IndexTTS / GPT-SoVITS 自训 / VoxCPM / SeedAudio 19 语）
- **音效三层**：环境底噪 / 动作点 / 冲击点；每镜至少一个动作音
- **BGM**：正版池或自制，情绪跟集内曲线走
- **混音**：整体 −14 LUFS ±2；处理完必须收口 48kHz（否则成片静默变 96k）
- **剪辑**：剪在词上、剪在节拍上；转场只用电影语法（禁白闪/抖动/放大/贴纸花字）
- **前 3 秒**：帧差必须动（>0.02），静图开场一律不过
- **字幕**：ASR 自动出 + 人工校；单行 ≤17 字；避开竖屏安全区
- **变速**：必须插值，禁直接改帧率
- **规格**：1080×1920 / ≥30fps；短剧 90–120 秒，漫剧 60–90 秒

### 6. 质检 → 发布（机器能测的先测，测不了的才给人看）
- **七条硬指标**：分辨率 / 帧率 / 音轨 / 响度 / 镜长 / 前 3 秒 / 字幕
- **一致性机检**：跨镜 frame_diff + 脸锚相似度 + 服装场景连续性表
- **缺陷字典**：崩脸 / 伪文字 / 多手 / 穿模 / 匀速 / 首帧失真 / 速度线穿帮
- **盲评 ≥9**（把头部及格线当我们起点）；版本数 ≤3，超线先修闸不烧轮
- **备案**：存量 2026-03-31 前补审，4-01 起未备案全网下架；投资 <100 万=平台自审后报省备案
- **AIGC 三标识**：画面显式 + 元数据隐式 + 每集提示，缺一即 BLOCKED
- **分账系数**：红果 仿真人 60× / 3D 50× / 2D 40× / 解说 5×；2026-04-27 起 AI 仿真人普惠保底取消
- **出海**：去字幕 → ASR → 翻译 → OCR 画面字 → 配音 → 压制 → 分区审核（100 集×9 语≈48h，云厂商口径）
- **数据回流**：看完播、追更、前 3 秒留存，不看播放量；回流到下一集剧本与钩子

### 7. 产能 → 十个坑
- **团队**：1–3 人可跑；单集约 3 小时工（剧本 20 / 分镜 30 / 素材 60 / 视频 60 / 剪辑 40 分钟）
- **产能**：熟练 5–10 集/天；日更 1–2 集；先囤 10–20 集再上
- **纪律**：一批只改一个变量（同批同画风同参数）
- **坑 1** 先做画面后写剧本
- **坑 2** 一镜塞多动作（必崩）
- **坑 3** 追求 100% 一致性反复抽卡（该用背影/侧脸/剪影换效率）
- **坑 4** 静态图推拉冒充动画
- **坑 5** 无声量产
- **坑 6** 480p 上采样冒充 1080p
- **坑 7** 一集一个画风
- **坑 8** 把 AI 感当风格
- **坑 9** 一次生成十集再检查
- **坑 10** 只看模型跑分，不看成品率

## 六、待决三件（其余按既有规则自决推进）

1. **主路选哪条**：2D 漫剧（最快出片）／3D 漫剧（系数高、最缺、最慢）／仿真人（盘子大、保底已取消）——建议先 2D i2v 打样验证追更，同期用 3D 资产库做第二季。
2. **资产层谁来做**：三视图+720° 锁版+音色库是后续所有集的复用底座，建议单独立卡、一次做完（现在是每集现攒）。
3. **闸门落到代码**：一致性（frame_diff/脸锚）与口型两项目前只有纪律没有脚本，建议本周内落 `drama_quality_gate.py` 新检项。
