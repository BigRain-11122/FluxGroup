# 漫剧/短剧 认知基座 CANON-v1（2026-11-03）

> 这份文件是这条业务线的**唯一认知入口**：新会话先读这里，再读工序与闸。
> 只写结论与判据，不复制别处正文（数字与来源指针见文末）。

## 一、这是什么（定义，先把错的理解划掉）

- 漫剧/短剧 = **关键帧 → 图生视频(i2v) → 剪辑 → 配音配乐 → 字幕 → 闸**。跟 MV 是同一条链。
- **不是**：会动的 PPT（推拉/缩放/纯位移）、引擎建模渲染的 3D 动画、图文+旁白的解说视频。
- 品类优势只有一个：**用 i2v 把"每分钟成本"拉到传统动画的百分之一**。任何改道都会把这个优势丢掉。

## 二、市场事实（三条，决定我们卖什么）

1. 大盘大、增长快，但钱被流量税吃掉：2026Q1 全球短剧下载 8.5 亿次(+140%)、内购 7.5 亿美元；投流约占出海成本 50%，北美单用户获客 5.28 美元。
2. 3D 漫剧在榜单占位很猛（红果热播 TOP5 占 4 席），但那是另一条赛道，不是我们的做法。
3. 爆款率极低（0.5% 量级），90% 团队亏损 → **靠量没用，靠"能不能打"**。

**结论：卖成片给平台方/自营分账，不自己买量。**

## 三、头部在做什么（我们要对齐的四件事）

1. **节奏**：3 秒爆点 → 10 秒立角色 → 中段刺激 → 结尾反转；每镜 2–3 秒。
2. **一致性**：角色档案 3–5 张多角度 + 参考强度 70–85% + 固定 seed；跨镜不换脸是死线。
3. **口型**：说话镜必须有口型（LatentSync 类，Apache-2.0，约 6.5GB 显存）。
4. **产能口径**：每镜 ≤3 抽、成片率 ≥50%；用"成片率"算真实成本，不看模型跑分。

## 四、我们曾经错在哪（对照数字，留作教训）

旧 60 集成片实测：**540×960 / 25fps / 无音轨 / 静图推拉**。
→ 这不是"画得不够好"，是**品类错位**。修一版就要把三项一起补：分辨率、帧率、音轨。

## 五、交付判据（全部机器可测，缺一即 FAIL）

| # | 判据 | 阈值 | 判在哪 |
|---|---|---|---|
| 1 | 竖屏分辨率 | ≥720×1280（正档 1080×1920） | drama_quality_gate |
| 2 | 帧率 | ≥30 | 同上 |
| 3 | 音轨 | 人声+音效+BGM，-14 LUFS ±2 | 同上（用 loudnorm 的 input_i，不用 mean_volume） |
| 4 | 时长 | 10–90 秒（单集/样片） | 同上 |
| 5 | 前 3 秒运动 | 帧差均方 > 0.02 | 同上 |
| 6 | 平均镜长 | ≤4.0 秒 | 同上 |
| 7 | 字幕 | 烧制或外挂，单行 ≤17 字 | 同上 + 折行律 |
| 8 | 跨镜一致性 | 角色区域像素差 ≤阈值 | frame_diff（待接） |
| 9 | 口型 | 说话镜音画同步置信度达标 | LatentSync（待接） |

## 六、工序（机器可派的段，id 与工序表一字不差）

创意段（立项/剧本/分镜提示词）是判断活，由导演席出稿；**下面这些 id 是工序表里的真段**，
两处不一致 `line_canon.py` 直接判 FAIL。全表在 `cph4/fleet/ri/content/lines/{duanju,drama}.json`。

**漫剧（bigstream-drama）**
```
src-scan   素材盘点：关键帧/片段/配音/配乐的真目录（drama_inventory.py）
manifest   装配清单：把盘上片段按镜号排序、认人声/配乐、可选读 srt → manifest（drama_manifest.py）
assemble   装配：片段+人声+配乐+烧字幕 → 1080×1920@30（drama_assemble.py）
gate       交付闸：独立复跑，不采信装配器自报（drama_quality_gate.py）
accept     质量验收：缺一份闸回执就不算交付（quality_gate.py）
```

**短剧（bigstream-duanju）**
```
inventory     素材盘点（先找到这台机上的真目录）
tts-qc        配音质检：逐集缺句/静音/削波（tts_batch_check.py）
manifest      装配清单：片段+人声+配乐 → manifest（drama_manifest.py）
remux         带声合流：按 manifest 出成片，loudnorm -14（drama_assemble.py）
episode-list  可发集数清单：集号+时长+体积+闸结论
accept        质量验收：缺一份闸回执就不算交付
```

**两类段都必须留证据**：缺素材时回执写 `verdict=BLOCKED` 并写明缺哪一段（rc=3 属正常等上游），
禁止零产物退出——零产物会让下游分不清「没干」和「干不了」，线就静默停摆了。

人工侧的创作段（对应下面这条链，供人读）：
```
选题/市场门 → 剧本（3 秒钩/30 秒爆点/结尾悬念）→ 分镜+角色档案(3–5 张+身份串+seed)
→ 关键帧(正档 720p/1080p) → i2v 逐镜(2–3 秒/镜，≤3 抽) → 口型+配音 → 上面四段机器工序
```

## 七、成本与产能（用来判断"这单能不能接"）

- 单分钟 800–1000 元；单集（1.5–2 分钟）1200–1800 元；单集约 3 小时工。
- 单集报价低于 1200 元 = 亏；高于 3000 元/分钟 = 客户会转投传统档。
- 一人一天 1–2 集为健康线；低于 1 集/天说明工序有堵点，先修堵点再加量。

## 八、失效条件（到了就停，不硬撑）

1. 连续 4 周没有任何一集过九项闸 → 停线修工序，不再排新活。
2. 同一类缺陷（崩脸/换装/口型/音轨）连续 3 集复发 → 停线，先修闸。
3. 单集真实成本连续 2 个月高于报价 → 停售该档，重定工序。
4. 平台方连续 2 次退回同一问题 → 按退回项改判据，不解释。
