# 漫剧/短剧质量规格 v2（2026-11-03 整改）

> 起因：CEO「漫剧短剧的产出非常糟糕，完全赶不上现在头部的质量和生产」。
> 本件只写**能机器测**的差异，不写审美口号。测法=Tools/fleet/drama_quality_gate.py。

## 一、我们和头部的实测差距（这不是判断，是数字）

| 项 | 我们 60 集成片（2026-10-26 全量） | 头部做法 | 结论 |
|---|---|---|---|
| 分辨率 | **540×960** | 1080×1920 | 差一档，平台压缩后更糊 |
| 帧率 | **25fps** | 30fps 起 | 一镜一推拉时明显顿 |
| 音轨 | **无音轨**（"画面+字幕"口径） | 人声+音效+BGM，混到 -14 LUFS | **最致命**：静音漫剧在今天等于没人看 |
| 平均镜长 | 未管控 | 2–3 秒一切 | 节奏慢，前 3 秒留不住 |
| 前 3 秒 | 未测钩子 | 3 秒内必须有冲突/悬念 | 完播率的第一道门 |

结论一句话：**先补音轨，再提分辨率与帧率，同时把镜长压到 4 秒内**。画风不是当前瓶颈。

## 二、v2 交付判据（全部机器可测）

1. 竖屏，正档 1080×1920；降档不得低于 720×1280。
2. 帧率 ≥ 30。
3. 必须有音轨：人声 + 音效 + BGM；整体响度 -14 LUFS ±2。
4. 单集/样片时长 10–90 秒。
5. 前 3 秒画面必须有变化（帧差均方 > 0.02）——静止图开场一律不过。
6. 平均镜长 ≤ 4.0 秒（用 scene>0.30 检测切点算）。
7. 字幕：烧字幕或外挂字幕文件，二者必有其一；单行 ≤ 17 字（沿用 GUARDED_V4 折行律）。
8. 音轨采样率 48000 或 44100 Hz。2026-11-03 补：`loudnorm` 内部工作在 192k，AAC 上限截到 96k，装配链若不在响度处理后收敛回 48k，成片会静默变成 96kHz（平台一律按 48k/44.1k 收）。

## 三、工序改动（对应 D3–D8）

- D3 关键帧：正档直接出 1080×1920（不再用 540p 出正片；低清只作海选）。
- D4 动效：**每镜必须真动**（i2v 出的运动、表情、口型、布料/发丝/粒子），
  **禁 Ken Burns / 推拉图片 / 纯位移**——静态图推拉是 2019 年的做法，现在等于没做。
  判定：镜头内的主体像素位移必须来自生成（i2v），不是后期缩放；闸用"主运动方向一致性 +
  光流幅值"区分，推拉件的位移是全局同向，生成件有局部运动。
- D6 配音：必须先出人声，再配乐；不许"先画面后凑音"。
- D7 装配：混音链固定 `loudnorm=I=-14:TP=-1.5:LRA=11`；字幕烧制。
- D8 成片闸：`drama_quality_gate.py` 必须 PASS，否则不算交付（QUALITY-GATES 已把该闸列入）。

## 四、验收口径（CEO 一眼判断用）

- 看三件事：**有没有声音 / 前 3 秒动不动 / 一镜是不是拖太久**。
- 三条全过，才谈画风与剧情；任何一条不过，先返工这一条，不做第二条样片。
