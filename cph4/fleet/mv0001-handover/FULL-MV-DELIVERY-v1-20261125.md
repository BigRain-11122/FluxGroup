## 三、剪辑怎么解决"AI 素材都是 5 秒、匀速"

| 手法 | 做法 | 依据 |
|---|---|---|
| **永不放满** | 除前奏/尾奏外每镜只取 2.4–4.5s（源 5.17s 有余量） | 整段播 = 5 秒一个节拍，必然发木 |
| **密度曲线** | 前奏 4.3s/镜 → 主歌 3.95 → 副歌 2.81 → 主歌2 3.50 → 副歌2 2.79 → 桥段 4.85 → 末副歌 2.83 → 尾奏 3.31 | 90s 港台 MV 语法：慢起、副歌收紧、桥段呼吸、末段最密 |
| **切入落在动作峰值前 0.35s** | 逐帧量出每个镜头的运动峰值（`pool/SHOT-MOTION.json`），刀落在"动"上 | 同 auto-editor 的 motion 模式原理（自实现） |
| **重演换机位** | 同镜第 2/3/4 次出现时换切入（+1.2s）+ 推近 1.15/1.30 | 让重演看起来像新镜头 |
| **断开同人四连** | 103–114s 原为连四个"他"，已插成 他—她—她—他 | 剪辑席点名"11 秒断点" |

## 四、90 年代胶片调色（承 v14 链）

黑位抬到胶片密度 → 高温端只动 >0.70 压红提蓝 → halation（阈值 0.82 / 不透明度 0.20）→ 统一颗粒 → 暗角 0.28 → 片门微抖 ±0.5px。

## 七、还差什么（如实记）

1. **拓片与碑的同一性**：需要一镜"拓片缺口 = 碑身破损"的匹配剪辑（或重烧那张拓片为楔文）。本机无人像/道具补拍条件，属重烧级。
2. **480P 段画质断档**：那几镜是早期 864×480 素材，上采样后颗粒与 768P 不同档。可做"480P 段统一降噪+补颗粒"匹配，但会牺牲一点锐度。
3. **大景别重演**：神庙/石碑全景 4 次出现，1.15 推近在广角上无效，需要更激进的推近（1.5-1.8）或换镜。
4. **素材只有 36 个不同镜头**：撑 234 秒必然复读，这是素材量问题，不是剪辑问题。
