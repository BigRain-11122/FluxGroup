## 〇 实锤 bug（本窗拉片发现·先治）

**金句字层（M1 记忆点「我却在旁静静欣赏你」）在全系成片中从未渲染**——44.8s 满窗帧零文字（多模态逐区扫描实证）+42/43.5s 同证。根因=**单帧 PNG 输入的 fade PTS 陷阱**：`-i s9_lyric.png` 产出单帧流（pts=0），`fade=t=in:st=42.78:alpha=1` 对 pts=0 帧算出 alpha=0 → overlay eof_action=repeat 重复的全透明帧 → 永不可见。**修复=输入加 `-loop 1 -t <窗长>` 使字层流铺满时间轴**（fade 按真实 PTS 工作）；V5 装配器焊断言：字层窗内必抽 1 帧多模态验字（无字=装配失败）。

## 二 金句层 M1 修复+升格（42.78-45.07·「我却在旁静静欣赏你」）

- 渲染修复见 §〇（-loop 1 化）
- 动画升格：fade-in 0.5s→**0.8s**·fade-out 0.45s→**0.6s**（呼吸感与 case 光呼吸同频）
- 位置实帧重定：44.8s 帧多模态判读=**左侧暗带中央偏下（x≈8-30%·y≈40-55%）最优**（近全黑底·金字悬浮感最强·不遮三焦点）——V5 KF 到货后按新帧复核
- 选位后必过可读性三查：对比度（金字 vs 底 ≥4:1）/不遮脸/不压玻璃高光带

## 三 歌词字幕版规范（sub 发行版/审看版）

| 项 | 设计 |
|---|---|
| 字体 | 思源宋体 Medium（比歌名轻一档·阅读层不抢画面） |
| 字号 | 42-46px（1344 宽·可读不主导） |
| 位置 | 底部居中·基线距底 ≥8%（安全边） |
| 阴影 | 2px 软投影 @50%·无硬描边；亮底帧允许 1px 暗细缘作可读下限 |
| 出现/消失 | **词级**：词起 fade-in 0.3s→行尾 fade-out 0.25s（whisper 词锚驱动·卡拉OK 逐字染色禁用=现代流媒体风判负） |
| 行规则 | 单行 ≤14 字·超行折行安全带（drama 判例承袭） |
| 卡点 | 词首帧对 whisper 锚 ±0.1s（CHK-E4 联合执法） |

## 四 片头/片尾/AIGC 标识

- **AIGC 开门帧标识**（法定·AIGC 标识办法）：首帧右下角「AI 生成内容」28px·白 40%·随首场景 fade-in 同步入·驻 3s；+平台端勾选双轨（PLAYBOOK S8 已有·本件给字体参数）
- **片尾字卡**（发布版）：Z04 淡出后 1.5s 黑场→作品字卡 2.5s（歌名/原唱署名/改编声明·讹传勘误表正身/制作署名）——同金体系·中央排·极简·fade 0.5s in/out
- **封面/缩略图**：**封面帧=记忆点帧律**——候选=M1 金字侧影（42.78 修复后）/M4 隔世对视（197s）/M6 字存（229s）·16:9 主图+竖版 crop-safe 构图（关键元素居中 60% 安全区）
