## 一、满意锚点：v7 到底做对了什么

`DIRECTOR-REVIEW-V7-30s-20261123.md` 的 verdict 是 **PASS（可交付）**。原始记录：

```
帧数 720 / 时长 30.000s（音视频同长）
精确重复帧 0    冻结段 0    人脸跳变 0
欠曝帧 15（片头 6 + 片尾 8 + 切点 1）
硬切 9 处：4.42 8.42 11.92 13.67 17.29 19.50 22.75 24.75 27.75
音频 −14.9 LUFS / −1.1 dBTP
暗水印 解码 bit-acc 100%
```

它做对的是**四件事**，每件都是可复制的：

| # | 做法 | 为什么有效 |
|---|---|---|
| 1 | **只改可量化缺陷**：13.67–17.29 全片最暗镜（YAVG 6.5–8.5）做时间变伽马提亮 | 缺陷有数字就能验；其余 28 秒**一帧未改**，没有引入新风险 |
| 2 | **音频单独过链**：两遍 loudnorm + alimiter(−2.5dB) + −1.2dB，**视频直拷** | 音频病用音频手段治，不碰画面 |
| 3 | **整片 720 帧逐帧计算，不抽样** | "精确重复帧 0 / 冻结 0" 是算出来的，不是看出来的 |
| 4 | **不改结构**：只做镜头级替换（v5→v6→v7 都是同一套切点） | 结构不动 = 不会把装配层的错误带进来 |

**v7 的成功公式 = 小改动 + 全帧验 + 结构冻结。**

### 2.1 最硬的一条：音频削波回归

- v7 用**两遍 loudnorm + alimiter** 把原片自带的 **+2.1 dBTP** 削波修到 **−1.1 dBTP**，写进了交付档。
- v13 的装配脚本用 `-c:a copy`（直接复制源音轨），把同一个 +2.1 dBTP 又带回来了。
- 实测：`爱在西元前-30s-v13-final.mp4` → **+2.1 dBTP**（今天用 shot_qc 复测确认）。

**这不是"新问题"，是"旧修复丢失"。**

### 2.2 第二硬：重排脚本从未跑通，但交付了三个"新版"

- `EDIT-AUDIT-30s-20261124.md` 诊断出病根：前 9 镜有 8 个是"石头+文字"，缺人物交替。
- 方案明确：补烧人物镜 + 按"人—物—人—物"重排 + 切点吸乐句。
- `build_v13.py` 就是执行方案的重排脚本 → **`setpts` 系数写反**（`(b−a)/target`），首跑 720→536 帧 / 30s→22.33s。
- 实际交付的 v13 三版来自 `build_v13c.py`（从 **v10** 改的，只换尾段）→ 结构原样保留 v5 的 11 镜。
- 实测三版切点全部相同：`3.42 4.42 8.42 11.92 13.50 17.33 19.50 21.42 22.67 24.75 27.75`。

**没有人发现，因为没有人把成片切点和剪辑表对账。**

## 三、六条根因

| # | 根因 | 证据 | 为什么长期没被发现 |
|---|---|---|---|
| 1 | **版本之间没有契约** | v7 修好的音轨能力，v13 换脚本就丢 | 每版脚本独立写，没人把"已修项"写成断言 |
| 2 | **诊断与执行脱节** | `EDIT-AUDIT` 写了方案，`build_v13.py` 写了但没跑通 | 交付按"文件名有 v13"算完成，不按"切点吻合"算 |
| 3 | **检查粒度只有整片** | v7 的全片统计能抓重复帧，抓不到"这块糊" | 块面级指标（清晰度/黑边/时长偏差）此前不存在 |
| 4 | **素材层没有闸** | fail1 / 864×480 / 糊件 / 带黑边件全部入剪 | 池子只做"去重成镜头池"，不做"准入" |
| 5 | **闸会误报就被人豁免** | 死黑体系被误判"黑边"、暗镜被误判"糊" | 误报 → 人工豁免 → 豁免多了闸就没人看（既有判例） |
| 6 | **台账要求写了没建** | `MV-DEFINITION-OF-DONE-v1 §八`（11-05）要求 `REGRESSION-LEDGER` | 20 天没人建；`D-05` 要求切点同源，也没执行 |

> 第 6 条是元根因：**前面五条都被诊断过，药方也写过，只是没人执行。**
> 这正是 `MV-LESSONS-LEARNED-v1` 第八节那句话：「九成不是模型不行，是该在出生地拦的没拦」。

## 六、一句话总结

> 之前满意的 v7，靠的是**小改动 + 全帧验 + 结构冻结**。
> 后来变差，不是因为不会做，而是因为**每次重建都从零开始写脚本，把上一版修好的东西留在上一版**。
> 正解不是"更努力地改"，是**把已修项变成断言，重建前先跑一遍**。
> 台账今天建了，闸今天通了，技能今天改了 —— 剩下的就是执行。
