## 三、执行手法（只用现有素材）

1. **边界交易**：相邻两镜之间移动切点，从长镜"借"时间给短镜 → 总长不变、歌词锚不动（±0.1s）。
2. **只取一段**：素材 5s，成片只用 1.0–1.5s（挑动作峰值段），其余丢弃 → 快剪来源。
3. **慢放拉长**：桥段把 2.6s 素材用 0.55–0.7x 拉到 4–6s（必须 RIFE/minterpolate 插值，禁顿挫）。
4. **转场分级**：快段用**干净硬切**（不叠化，避免"两个她"的重影）；慢段用 0.4–0.8s 叠化；段落交界（非副歌内）用 1.0–1.4s 长叠化。
5. **禁**：所有切点统一 0.4s 叠化（那是"平"的元凶之一）。

## 五、验收

- 全片镜长标准差 ≥ **1.8s**（现状 1.39，太平均）
- 副歌 A/B 段平均镜长 ≤ **1.5s**，桥段平均 ≥ **4.5s**
- 快段内**零叠化**（防重影），慢段叠化 0.4–0.8s
- 微叠化孤岛 = 0；帧间突跳只在设计切点上
- 歌词锚偏差 ≤ 0.1s
