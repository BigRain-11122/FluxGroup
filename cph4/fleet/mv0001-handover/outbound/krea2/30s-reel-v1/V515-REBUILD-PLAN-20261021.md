## 二、纪律（这次不打折）

1. **烧前必过 `Tools/preflight_gate.py`**：首帧 sign-off + 词表 token + 零否定句 + 场景锚。任一不过 → 不提交。
2. **同一镜同一缺陷连烧 2 条仍复现 → 停，转方案**，不许换种子硬赌。
3. **480P 验证 → 过闸 → 才出 768P**，禁止直接烧高清。
4. **每轮必须出密集帧板**（0.2–0.33s 间隔）做逐帧判读，不许看联系表定罪。
5. **成片只做一次编码**：所有替换件先在源分辨率对齐，最后一次性装配，不在成片上反复叠加编码。
6. 每镜替换后总时长必须保持 234.25s（±1 帧），音频不动。

## 三、顺序

R1 → R2 → R4 → R3（R3 需先确认角色设定：书吏是否就是男主）。R5 与重拍并行做，最后统一装配。

## 四、装配与验收

1. 各替换件按原窗口时长对齐（速度/裁切按原表）。
2. 一次性装配 → **只编码一次**（crf 17–18，保画质）。
3. 全项验收：帧数/时长、响度、零定格、**微叠化孤岛=0**、逐帧突跳复查、抽帧人脸一致性比对。
4. 导演席 + 制监席双签后呈 CEO。
