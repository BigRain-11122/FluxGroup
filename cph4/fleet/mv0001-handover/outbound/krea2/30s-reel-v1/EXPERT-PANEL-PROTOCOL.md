## 二、评审闸位（四段流水·每段过闸才进下一段）

1. **设计闸**：立意案+镜头表+提示词清单 → 六席评审 → 修复闭环 → 认证
2. **关键帧闸**：frames/ 全帧 → 帧级多模态锐评+六席抽审 → <8.5 帧换种子重摇 → 认证
3. **视频闸**：逐镜头 i2v 产物 → 六席抽审（画质/运镜执行/AI 动作崩坏）→ 认证
4. **成片闸**：剪辑成片 → 六席全审（节奏/调色统一/歌词卡点/三律/盲评≥9）→ **呈 CEO**

**认证规则**：全员各维 ≥7.5 且无 FAIL 判定 + 每席 TOP3 修复项全部闭环 → CERTIFIED。任一席 FAIL → 打回该段修复重审。
**CEO 呈审面**：仅第四闸 CERTIFIED 终件（+一段大白话评审团结论摘要）。CEO 主动要看中间态=例外放行。
