# MiniMax H3 视频引擎测试报告（h3-video-test-v1）

- **测试设计**: 用我们已过门的 Krea 2 首帧做图生视频（first_frame 锚定·分镜表运镜令直用）——测它接不接得住我们的图
- **T1 刻字特写（微距·静机位·小动作）**: **8.5/10 过线**——首帧零漂移·手部按压动作自然无融化·火光/浮尘物理稳·暖橙纪律满分·已压楔痕纹丝不动（AI 视频最易崩处没崩）；唯逆光指缘极轻微蠕动+无原生音轨（成片需铺拟音）
- **T2 女神显影（人物·复杂光效·粒子）**: **4/10 不通过**——裙摆几何崩塌（凭空长出僵硬「翅膀」）·「火光减弱女神渐亮」反向光平衡未执行（火灭了人更黑）·余烬违反物理向下坠·褶皱纹理逐帧游动
- **引擎判定**: H3 安全区=静态/微动/特写/道具/静场镜头；崩区=人物动态+复杂光效+粒子物理
- **用法建议**: 按镜头类型分配——刻字/出土/地层/灯暗等静场特写交给 H3（8.5 水平）；女神显影等人物情感峰值镜头：①简化运镜（女神静立只留光烟微动=落回 H3 安全区）或 ②后续测试更强引擎
- 两个测试视频（5 秒·768P）随夹：h3_carve_test.mp4 / h3_goddess_test.mp4
