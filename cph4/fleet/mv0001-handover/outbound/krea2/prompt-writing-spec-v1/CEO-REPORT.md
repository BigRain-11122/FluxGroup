## 一、问题出在哪（大白话）

1. **越写「不要」越出什么**：我们的图管线没有"负面通道"（负面条件是关死的零），所以「NOT Korean idol / no K-pop / no makeup / no watermark」这些句子全部被当成**要画的内容**喂给了模型。您反复纠正的"太韩化"，根源就是我们每张图都在提示词里亲手写了 Korean idol、K-pop、makeup 这些词。
   **官方实锤**：Qwen 官方自己的提示词改写工具第 8 条规则原话——「改写之后的prompt中不应该出现任何否定词」。（来源：github.com/QwenLM/Qwen-Image 官方代码）
2. **用词太虚**：以前写 "beautiful / cinematic / nostalgic feel" 这类模糊词——专业社区的定谳：「一个词如果不能被摄影机、测光表或秒表检测到，就改写它」。模型听到「电影感」会给什么全看心情，听到「钨丝灯 3200K 从左侧打光、柯达 5279 胶片、telecine 暖调」才知道具体画什么。
3. **年代穿帮**：专家审查查出我们用的胶片型号「Vision3 5219/5207」是 2007/2009 年才有的——难怪画面偏「干净现代」。2001 年当班的是 **5279（夜）/5246（日）**；青色阴影、变形宽银幕耀斑这些是 2010 年代好莱坞审美，全换成 2001 台湾 MV 的真实拍法（telecine 暖调+奶黑+钠灯/荧光管/穿烟逆光）。
