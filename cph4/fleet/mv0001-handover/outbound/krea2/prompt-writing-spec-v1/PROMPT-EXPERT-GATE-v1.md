# PROMPT-EXPERT-GATE v1 — 提示词专家审闸（CEO 令 O-20261015·铁闸）

> 溯源：CEO 原话 2026-10-15「好好去调研，提示词的各种技巧和规则，你现在写的提示词，还是容易误导AI。好好看官方文档。摸清规则，**每次提示词都要过1遍提示词专家审才能开始生产**。」
> 定位：**一切进生产的生成提示词（t2i/编辑/i2v/云端视频/音频TTS）过本闸后才准烧**——lint 机核拦机械违例、专家审拦语义误导、导演席签发后才点火。本闸=EXPERT-PANEL-PROTOCOL 四闸流水的常设前置闸（设计/修复/重摇/云端批每包都过·不设豁免）。
> 规则正典：PROMPT-SPEC.md（词表/组装/lint）+ EXPERIENCE-LEDGER（判例 18+技巧 13）+ R-20261015-prompt-rules-official（官方规则全典·本闸检查单的官方背书面）。

## 一、闸位与流程（谁审·何时审·怎么过）

```
词表组装器产出 prompt 包 → 第1层·lint 机核（三名单/FLAT门/长度/ID逐字·脚本断言）
  → 违例=自动改写复检·复检不过=打回作者（零专家调用）
  → 机核全过 → 第2层·提示词专家审（语义面·云端 LLM 席位·批级审查）
  → 逐条 verdict（PASS/FIX+改写稿/REJECT）→ FIX 项改写稿直接回填包内
  → 第3层·导演席签发（核设计意图类裁定权）→ 才准烧
```

- **审谁**：提示词专家席=独立于作者视角的专职审查代理（禁自审自签——作者不得兼审）。
- **审什么**：每包逐条（KF 包=逐镜 prompt+i2v 六段式；修复包=逐修项；云端批=逐镜）。
- **verdict 留档**：`PROMPT-GATE-<包名>-v<N>.md` 随包上链（逐条分+病灶行+改写稿·违例引用检查单条号）；无 verdict 的包=未过闸，烧制侧拒收（脚本断言位：派单含 verdict 文件名）。
- **效率律**：批级一次过全包（禁逐条开会）；专家审在烧制**前**（烧后返工=10 倍成本·CEO 效率令）；低清试构图位照旧（试构图=构图面·本闸=语义面·两闸各拦各的）。
- **复发升格**：同病灶复发=闸失效→当窗升格（检查单条目→lint 正则→脚本断言·能机核不靠人记·EXPERIENCE-LEDGER §四律）。

## 二、专家审检查单 v1（十一面·逐条判 PASS/FIX）

> **官方背书层**（R-20261015-prompt-rules-official·防线二直验过）：B1 色相/否定=BFL docs.bfl.ml「no negative prompt field」官方替换表+Qwen 改写器第 8 条+arxiv 2406.02965（否定=迟效中和·概念仍注入）｜C1-C4=BFL「put first whatever matters most」+trailing clause 禁令+Krea「Group subjects with their own attributes」+BFL「visible details that distinguish」｜D1=五源定谳（ConsistI2V/HPSD/I2VEdit 三论文+Seedance 2.5「The model must adapt to that asset」+H3「fully referenced」）｜G1=Krea 第 9 条「Preserve User Medium…honor it. Do not pivot」｜E 面=Seedance 密度双向律（too little→improvise/too much→omitted）+一镜一运镜+缓慢细微动作优先+多人 ≤2-4 上限｜H1=Seedance 防崩尾句官方原文｜J4=Anthropic 黄金法则（给无背景同事看）。**多属性冲突内部取舍机制=官方无明文（⚠️经验律·C1/I1 消解法为我方补位）**。四路波文件=cph4/research/waves/2026-10-15-prompt-rules/（75+25+10 条编号规则+URL 全档）。

### A 结构合规（机核为主·专家复核）
- A1 模型官方组装序正确（Krea2 八块序/Seedance 八要素/H3 三字段/Edit 三段式）·单段散文·长度 40-200 词
- A2 ID 块逐字复用（同一人零改写）·单人物镜挂 exactly one figure
- A3 每模型特有约束位正确（Seedance 防崩尾句位/Qwen-Edit 官方后缀位/H3 时间戳切镜制——**Seedance 禁精确秒数 vs H3 需时间戳·跨模型禁套用**）

### B 语义清晰（误导主病灶面）
- B1 零否定（NEG 名单）·零模糊词（VAGUE 名单）·零概念注入（CONCEPT 名单：反韩化=词全消失不是否定它）
- B2 可检测性原则：每词能被摄影机/测光表/秒表检测；情绪标签词（电影感/史诗感/氛围感）全禁
- B3 概念滑动词改直给词（P-05 律：wedge-cut grooves 式直锚）·抽象名词落到可检特征
- B4 编辑指令一句直接具体改动+保持项（不重述整幅画面·不写过程）

### C 属性一致（色相渗漏面·V3 SIL1 判例族）
- C1 **材质色×调色冲突扫描**：主体材质色（black basalt）与调色段色词（amber monochrome）同包时必须显式消解——改调色词为「光色不改物色」写法（`torch light gilds the surface amber while the stone itself stays near-black`）或删其一；**两个真值源竞争同一属性槽=模型掷骰子**
- C2 每个形容词绑定唯一主体（禁悬空修饰：性/数/归属不清的描述词）
- C3 服装三要素齐全（材质+版型+色名·J-01）·品类词禁裸奔
- C4 器物形制锚：构造名词具体到部件（`forged-iron cylindrical wall sconce bowl` 级·SIL1 tiki 火把判例）·禁只写品类名让 AI 补形制

### D 起帧与事实一致（i2v 铁律）
- D1 **起帧主导律**：i2v 动作必须是首帧状态的自然延伸；**与首帧对抗的动作（闭嘴帧要求张嘴/坐姿帧要求站起）=模型拒执行**——要改先改帧，不改帧就不写对抗动作
- D2 帧内锚点律：事件类动作（打击/爆发）由起点帧承载道具与姿态，提示词只写余震衰减态（P-01/J-02）
- D3 画内光律：光效须有帧内光锚或改画外 implied 写法（P-03/J-03）·光事件 ≤2 个/镜（J-06）
- D4 叙事接链：提示词描述的事件链必须能从首帧读出（素板断链判例 SIL2）

### E 动作可执行性
- E1 运镜五槽齐全（MOVE/CURVE/MOTIVE/TEXTURE/ALIVE）·单镜单运镜·平速语全禁·orbit ≤20°
- E2 幅度配档（P-12）：大运动=降级预案；静态微动=安全区主力
- E3 词级动作绑定（P-13）：画面动效绑到可见动因·编舞式描述（逐个点亮）禁
- E4 异步正锚（P-09）：异步=各 at its own pace 正写法
- E5 生命脉冲律：静止主体必须留一处微动源（眨眼/呼吸/发丝）且锁死其余（P-10）

### F 身份一致性
- F1 帧间守恒：服装/发型/道具链逐镜核对·morph 风险帧链 last→first
- F2 参照图点名（picture 1/2/3·≤3 张）·构图跟随 image1
- F3 防克隆人（exactly one figure）·双胞胎防分身

### G 媒介与年代锚
- G1 **媒介漂移防护（SIL4 判例）**：真人实拍锚显式声明（`live-action 35mm film frame`）·动画平涂歧义词（illustration 系/style 泛词）零容忍；LoRA/检查点污染面归 VFX 席（档位验·非提示词面）但提示词媒介锚必须独立成立
- G2 年代词表合规：胶片型号年代正确（5279 夜/5246 日）·年代签名光色词（sodium/fluoro/halo/telecine）
- G3 现代穿帮词扫描（AI 禁品清单 §9 联动）

### H 约束位合规
- H1 模型原生约束句逐字用官方口径（Seedance 防崩尾句原文·不自行改写）
- H2 权重条 3-5 条·负权重反转写法（K-pop:-3 式·仅限支持权重的管线）
- H3 音轨律：提示词零环境音/氛围声描述段（成片=画面+歌）

### I 冲突总扫描（专家审核心价值面）
- I1 **双真值源冲突**：同一属性两个来源给不同值（材质色 vs 调色/服装 ID 块 vs 服装描述/年代锚 vs 现代词）=逐对消解
- I2 不可能同时性：物理冲突（光同时冷又暖照同一面/身体同时静止又运动）逐项排
- I3 过约束扫描：同镜约束 >5 条硬冲突时按主体块优先级削减（主体>光>镜头>风格）

### J 产出前四答（自检·逐镜必答）
- J1 这段话里每个名词 AI 能画出什么？（画不出的=删或换）
- J2 首帧里有什么、提示词要它变成什么？（i2v）
- J3 哪两个词在打架？（冲突面）
- J4 换一个不懂上下文的模型读这段话，会读出什么歧义？（跨模型歧义）

### K 表演律（2026-10-15 增面·CEO 令「人物的表演也是硬伤，非常生硬」O-20261015-1655·正身=R-20261015-mv-performance-stack）
- K1 **情绪禁标签词**：sad/joyful/angry 等情绪词全禁出提示词——一律展开为可检测微行为链（悲伤=低头+肩膀微颤+攥紧衣角式·官方情绪外化法；可检测性原则向表演面延伸）
- K2 **表演弧线镜间连续**：人物的情绪-行为状态跨镜必须有承接链（前一镜的落点=后一镜的起点·断链=「素板叙事断链」表演版）；思考位先行（先思后唱律 O-20261014-1050）+酝酿态外化
- K3 **参考片驱动镜=提示词只写增量**：走 S5 表演增强站（口型/表情迁移/舞段）的镜——prompt 不重复描述参考片已有的表演内容，只写该镜独有增量；表演参考片库位在册（工具之外真瓶颈）
- K4 **生命脉冲多源不同律**：静止主体 ≥2 处微动源且节奏互异（呼吸+眨眼+发丝不同步——单源=死板感来源之一）；幅度配引擎档（E2 律联动）

## 三、判定与验收线

- **PASS**：十一面零 FIX·verdict 落档 → 导演席签发 → 烧
- **FIX**：逐条给改写稿（不是给意见——直接给可烧文本）·作者合并复检·复检再过闸
- **REJECT**：结构性误导（起帧对抗/属性双真值源/整包概念注入）=打回重写·不修字
- **量化验收**：过闸包烧制后 QC 回看——verdict 里 FIX 过的病灶面复发=闸失效复盘（QC-MASTER-CHECKLIST §24 回流）

## 四、派单纪律（提示词专家席 brief 模板）

席位 brief 必含：①本检查单全量内联 ②被审包原文（含每镜模型名/用途/首帧描述[i2v 须帧内容简述]）③只读文件上限（≤3·规则正典按需内联省读）④终稿=verdict 文件（逐条分+改写稿·≤检查单条数×包镜数行）⑤禁复述规则原文·直接给判定与改写。云端 LLM 档（CEO 直令快车道+终稿质量闸免试档·token-economy §十）。

## 五、与现行四闸的关系（零重复分工）

| 闸 | 拦什么 | 本闸关系 |
|---|---|---|
| 设计闸（十三席） | 立意/剧本/镜头表整体 | 本闸管设计闸产出的**提示词文本本身**逐镜审 |
| 关键帧闸（十席两波） | 帧画面质量 | 帧烧前本闸先过（prompt→帧）·帧闸照旧 |
| 视频闸 | i2v 产物质量 | i2v 烧前本闸先过（prompt→视频）·视频闸照旧 |
| 成片闸 | 成片整体 | 无交集 |

**铁律**：任何修复批/重摇批/新增镜批/云端批=新包=重新过闸（零豁免·「小改动」例外口不存在——V3 修复批四连判负的教训：改一处漏审全包）。
