## 一、交付：`Tools/mv_release.py`（一条命令出发布件）

把今天手工跑的六步串成一次调用：
1. 规格核验（帧数/帧率/时长/音轨）
2. 黑帧 + 定格检测（ffmpeg 双路）
3. 剪辑索引（PySceneDetect → CSV）
4. 响度与真峰值；超线自动出 `_pub`（视频流 copy，只处理音频）
5. 交付闸（带重演白名单与设计静止窗）
6. 汇总 `-qa.json`，PASS 才给发布路径

用法：
```
python Tools/mv_release.py <video> --whitelist cph4/fleet/mv0001-handover/MV0001-REPRISE-WHITELIST.json \
  --card 0:3.5 --card 38.79:40.21 ... --poster 52
```
价值：41 曲计划每首都要走一遍，以后一条命令，不再手工六步。

## 三、发现二：闸的静止判据与定格判据不是一回事

两者互不覆盖：v724 的 D2 判 10 处、freezedetect 判 5 处，**交集很小**。
