## 四、本轮体检改掉的两处（v6 → v7）

1. **13.67–17.29s 暗镜**：全片最暗一镜，前 1.25s 均值仅 6.5–8.5（手机端读作黑场）。
   修法＝只对这一镜做**时间变伽马**（t<0.25s 固定 1.10，0.25–1.90s 线性回落 1.00），
   其余 28 秒一帧未动。实测 13.7s：6.4 → 9.0；14.2s：7.2 → 9.6；18s 后保持原光弧。
   欠曝帧数 44 → **15**（剩下的全是片头片尾设计黑场）。
2. **音轨真峰削波**：全片实测 −13.0 LUFS / **True peak +2.1 dBFS**（原片就是削的）。
   修法＝两遍 loudnorm（−12.8 目标）+ alimiter(−2.5dB) + 音量 −1.2dB，再复测：
   **−14.9 LUFS / −1.1 dBTP / LRA 2.3**，视频流 `-c:v copy` 保住暗水印。

## 五、查了但**判定不改**的三项（附理由）

1. **19.5–22.75s 清晰度 31**：原生帧复核＝神殿光柱 + 尘埃 + 大虚焦，属设计；改锐会毁氛围。
2. **多镜"近静止"**（凿石 diff 2.0、女主近景 1.3）：全片是静帧+微动语法，火焰/尘埃/眼神在动，非卡死。
3. **12.3–13.3s 检出"两张脸"**：是**石雕浮雕**上的两张脸（汉谟拉比式王与神），不是真人，不算换脸。
