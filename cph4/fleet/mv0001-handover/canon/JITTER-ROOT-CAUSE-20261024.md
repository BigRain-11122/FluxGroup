# mv0001 成片「跳动」归因与修复方案（2026-10-24）

> 触发：CEO「镜头还是有跳动，这是AI通病，好好解决，可以剪裁，可以重烧，可以别的，好好研究」
> 对象：`full_mv_v707.mp4`（5623 帧 / 234.25s / 24fps / 1344×768）

---

## 1. 结论（先给判断）

1. **至少有一处跳动不是 AI 生成造成的，是装配/变速阶段引入的。**
   铁证：R06（131.72–138.56s）的源片 `R06_museum_verse_v5.mp4` 全程静止（逐帧位移 0.02px），但成片在 **135.167s** 整幅横移 **26.8px** 后又缓慢回漂。源片干净、成片位移 → 问题在装配链。
2. **这类问题不能靠「平滑 / 补帧」在成片上修**：字幕已经烧进画面，整幅平移会把字幕一起带走。必须回到烧字幕之前的母版处理。
3. **已确认的镜内整幅跳动只有 4 处**（其余大位移是切点或叠化，不是缺陷）：

| 时间 | 帧 | 位移 | 镜 | 判定 |
|---|---:|---:|---|---|
| 84.375 | 2025 | 6.6px | C03_dig_reveal（锁定机位） | 镜内跳 |
| 92.208 | 2213 | 36.9px | C05_flame_gap（锁定机位） | 镜内跳 |
| 109.375 | 2625 | 6.2px | C09b_flame（复用 C05） | 镜内跳 |
| 135.167 | 3244 | 26.8px | R06_museum_verse（锁定机位） | 镜内跳（源片干净，装配引入） |

4. 26.0 / 38.9 / 40.2 / 42.2 / 44.1 / 77.5 / 224.1 等大位移经抽帧核对，分别是**暗场硬切**与 **T 桥叠化**，不是缺陷；切点检测阈值偏高（27）导致它们被误报。
5. 火焰镜（C05/C09b/R07）的高 MAD 是火焰本身的运动，不等于跳动；需要按「整幅位移」判定，不能按帧差。

## 3. 为什么在成片上补帧不行

- v700–v707 的做法是「把跳变帧替换成前一帧」。这会制造 1 帧冻结，长镜里能看出来；对多帧跳还会在尾部制造新跳（v701 实测 14 处）。
- 帧间混合会出双重曝光（火焰/金线镜已实锚）。
- 整幅位移修正会连带移动已烧字幕，不能直接做。

**正法：在烧字幕之前修画面，再统一烧字幕。**

---

## 4. 修复方案（按成本从低到高）

### A. 装配层（首选，不重烧 AI）
1. 用 `build_full_mv_v5.py` 生成**无字幕母版**（跳过 overlay 段，输出 base）。
2. 对全部「锁定机位」镜头做逐镜稳定化：以镜首为参考，抵消整幅位移；**有意运镜的镜头不动**。
3. 复核：`mv_seam_scan.py` 目标 = 镜内整幅位移跳 0；`release_gate.py` 非计划硬跳 0。
4. 重新烧 ASS 字幕 + 片名卡 + AIGC 标识，得到 v708。
5. 逐帧复核四处已知点（84.375 / 92.208 / 109.375 / 135.167）。

### B. 单镜重渲染（不动生成模型）
- 若某镜源片本身带跳，用源片按原速度重渲染该镜，替换母版中的同窗段（帧数必须一致）。
- R06 已验证：从源片重渲染后逐帧最大位移 0.2px，无跳。

### C. 重烧（最后手段）
- 仅当源片本身有 i2v 接缝（多帧跳）时使用；按现行闸链重烧：preflight 四查 → 480P → 768P → 首尾帧闸。
- 本片目前**没有证据**需要重烧；先做 A/B。
