# 导演决策：生成方式与叙事方式（2026-10-24）

> 触发：CEO「只用首图叙事会不会好点不抽风，去调研」+「叙事可以直白表达歌词，也可以空镜/慢镜，导演好好想」+「刻玄武岩连续两次很诡异，镜头不错可以剪掉」
> 结论先行：**不是“首图一定更好”，而是要按镜头类型选约束方式；叙事也不是二选一，按段落分配。**

---

## 一、首图 vs 首尾帧：调研结论

### 1.1 两种模式的本质

| 模式 | 机制 | 优点 | 已知问题 |
|---|---|---|---|
| 只用首图 | 模型从首帧向前“外推”，首帧影响力随帧数衰减 | 运动自然、没有强制终点 | 长镜会漂移；模型不知道要动到哪，常见**原地轻微抖动**；终点不可控 |
| 首+尾帧 | 给两端锚点，中间做过渡 | 终点可控、转场可设计、角色不易跑 | **两端差距过大时中间会变形/穿模**；模型为了“到达”会强行扭画面 |
| 中间关键帧/分段 | 把长动作拆成 2–3 段，每段首尾相近 | 约束最强、最稳 | 生成次数增加；段间要接得上 |

### 1.2 对“抽风”的判定

- **原地抖/画面飘** → 首图模式的典型病，因为运动目标未定义。
- **中段扭曲/人脸变形** → 首尾帧模式的典型病，因为首尾差太大。
- **整幅位移步进** → 我们的实测是装配/变速引入，不是生成模式问题（见 JITTER-ROOT-CAUSE）。

### 1.3 决策表（按镜头类型选）

| 镜头类型 | 用哪种 | 理由 |
|---|---|---|
| 空镜、环境、火光、尘埃（无人物动作目标） | **只用首图 + 明确运动提示 + 4–6s** | 不需要终点；短时长可避免漂移 |
| 人物小动作（抬头、转身、抬手） | **首尾帧**，两端构图差 ≤20% | 有明确终点，变形风险低 |
| 人物大动作（坐下→站起、走近→停住） | **拆两段**，每段首尾相近 | 单段首尾差太大必变形 |
| 需要精确接下一镜的转场 | **首尾帧**（尾帧=下一镜首帧） | 保证剪辑点对得上 |
| 长镜（>6s） | **不用单段生成**，拆段或剪短 | 任何模式长镜都会漂 |

### 1.4 立刻执行的管线调整

1. **默认时长压到 5s**（现有多条 8–10s take 是漂移温床）。
2. **首尾帧只用于“有明确终点”的镜头**；空镜/氛围镜改首图。
3. **首尾帧差值闸**：两端画面结构差（SSIM/边缘重合）低于阈值才允许首尾帧，否则拆段。
4. **生成后先跑稳定性扫描**（`mv_stability_gate` 的逐帧位移部分）再进剪辑，坏的直接弃，不带到剪辑。

## 二、叙事方式：直白歌词 vs 空镜/慢镜

### 2.1 原则

- **直白表达歌词**用于“信息必须被听懂”的位置：情节转折、关键道具、歌名句。
- **空镜/慢镜**用于“情绪需要停留”的位置：主歌铺陈、间奏、尾奏、段落转换。
- 周格泰的做法是固定机位+平衡构图+电影化叙事；空镜的本质是“景语皆情语”，不是填充。
- 两者比例建议：**直白 40% / 空镜与氛围 35% / 人物表演 25%**（按本片当前素材测算，直白偏多，空镜偏少）。

### 2.2 本片分段方案

| 段落 | 时间 | 叙事任务 | 用法 |
|---|---|---|---|
| 前奏 | 0–17.5 | 建立“博物馆/黑场”世界 | 空镜为主：展厅、灯、玻璃反光、尘埃 |
| 主歌1 | 17.5–47.5 | 她被一块石板吸引 | 人物状态 + 空镜交替；不解释 |
| 主歌2 | 47.5–77.3 | 巴比伦世界展开 | 直白：战争浮雕、河流、火把（歌词对应的物） |
| 副歌1 | 77.3–108.2 | 刻字=爱的证据 | 直白为主：凿、楔形、沙埋、火 |
| 主歌2 重演 | 110.5–138.6 | 千年后同一块石头 | 空镜+她的反应；避免与前面同构图 |
| 副歌2 | 141.8–172.5 | 古今叠印、注视链 | 人物表演 + 匹配切（眼→眼） |
| 桥段 | 172.5–197.5 | 疲惫、远家、余烬 | 慢镜/空镜为主，允许留白 |
| 尾段 | 197.5–234.3 | 她与石板、灯灭字存 | 直白收束（歌名句）+ 空镜收尾 |

### 2.3 具体改动

1. **前奏加 1–2 个空镜**（展厅长廊、灯逐个亮起），现在前奏信息太满。
2. **桥段（172.5–197.5）放慢**：保留 1–2 个 3–4s 的慢镜空镜（余烬、尘、空展柜），不要每个切点都换信息。
3. **尾奏留白**：Z03 灯灭后多留 1.5–2s 黑场/余晖，不要立刻结束。
4. **歌名句“爱在西元前”** 保留直白画面（Z01），这是必须被听懂的锚点。

## 三、“刻玄武岩连续两次”的处理

### 3.1 判定

- 位置：C06（92.62–95.22，凿子落定/第一次敲击）与 C08（100.14–102.88，锤击崩屑）动作同质；E06（208.08–212.66）复用 C08。
- 观众感知为“同一个动作放了两遍”，属于**动作重复**，不是画面缺陷。

### 3.2 决策（导演）

1. **保留一次完整动作**：C08（锤落+石屑）是信息最完整的一次，保留。
2. **C06 改为“落定前的静止”**：只保留凿子对准楔口、手部静止的 1.2–1.5s，剪掉落锤瞬间；这样与 C08 形成“预备→击发”，不是重复。
3. **E06（208s）不再复用完整锤击**：只保留石屑落下的尾部 0.8s，或替换为“刻痕特写”，避免第三次同动作。
4. 如果 C06 的画面质感足够好，也可以整段删掉，用 C05 火苗多留 0.5s 过渡。

### 3.3 验收

- 全片“同一敲击动作”出现次数 ≤2（预备一次、击发一次），且不连续。

## 四、转场升级（配合博物馆审查）

- **眼→眼匹配**：R06 她的侧脸/视线 → D01 他抬眼的同屏幕位置。
- **凿痕→发丝**：楔形斜线 → 她发丝的斜线（图形匹配）。
- **火→火**：D03 展柜火光 → C05 火把。
- **玻璃→石面**：她的倒影边缘 → 石碑表面（物质过场）。
- 以上四处替换现有硬切；其余硬切保留（MV 正常语法）。

## 五、验收判据

1. 首尾帧镜头：两端结构差在阈值内；生成后位移扫描无 >6px 步进。
2. 叙事：静音看片能说出“她在博物馆看石板，想象西元前的刻字人”。
3. 动作重复：同一敲击动作 ≤2 次且不连续。
4. 空镜/慢镜占比达到 30–35%，桥段至少有 1 处 3s 以上停留。
5. 转场：OPPOSE=0；同构图相邻切点=0。
