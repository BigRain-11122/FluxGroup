## 一、版式决策

| 决策 | 取值 | 理由 |
|---|---|---|
| 走向 | **竖排** | 开头镜头人物占左侧、台灯占右上，右边缘是唯一干净竖列；横排（v2 已试）会压到肩膀 |
| 字体 | 宋体（SimSun） | 2000 年代华语 MV 的默认语感；雅黑太"现代产品" |
| 字号 / 字距 | 112px / 字间 10px | 5 个字占满第一镜高度，不抢画面 |
| 颜色 | 暖纸白 #F3EEE5 | 纯白在钨丝灯下会发青、显假 |
| 阴影 | 双层偏移（+2/+3、+1/+1）低透明 | 模拟胶片柔投影，不用硬描边（合 TYPOGRAPHY-SPEC） |
| 位置 | 右边距 206px，起于 y=252 | 避台灯下沿，整列落在暗部 |
| 分隔 | 竖细线（宽 1px，透明度 85/255） | 把片名与词曲分开，不加框不加底色 |
| 词曲 | 右对齐贴线：作詞 方文山 / 作曲 周杰倫 / 編曲 林邁可 / 演唱 周杰倫 | 字号 26/31，行距 52，垂直居中对齐片名 |
| 时长 | 0.45s 淡入 → 2.62s 起淡出 → 3.37s 结束 | **只活在第一个镜头内**，不跨越切割（v1 曾跨镜压到女主，已改） |

## 二、试过的两版（留档，说明为什么是现在这个）

- **v2 横排**：字号 118 右对齐，压到人物肩膀与手臂，作废。
- **v3 竖排首版**：右边距 168，最上「愛」顶到台灯强光区，对比不足；改为 206 / 下移 20px 定稿。
