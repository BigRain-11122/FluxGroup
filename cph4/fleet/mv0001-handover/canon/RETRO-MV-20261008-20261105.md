## 二、七类反复出现的问题（每类：首次→复发→为什么没根治）

1. **修片打补丁 → 制造新接缝**（10-23）
   首次：碎片重播 20 处。修法：换帧/顶帧/调色。结果：每补一次多一道接缝。
   未根治因：**没有"重建优于补丁"的硬规则**，谁方便谁补。

2. **同病三犯（转场跳帧）**（10-13 → 10-19 → 10-24）
   每次都是"这一条我改了"，但没有把"转场必须动作/视线/物质接得上，禁白闪放大抖动"写成机器断言。
   未根治因：**批评只进文档，不进闸**。

3. **闸假绿 / 假红**（10-24 模板与搜索区同尺寸→恒 0 位移；11-04 D2 帧率未归一、D3 帧当秒）
   未根治因：**闸本身没有正反样例验证**（新判据从不用"应拒绝"样例验），也没有版本化基线。

4. **能力回归：分色丢了**（10-24 v712 有古今分色 → 11-02 v721 现代段调色链是 `eq=saturation=1.0` 空操作）
   未根治因：**没有回归断言**。重建脚本换一版，上一版做对的事没人守。

5. **最后一公里无人签**（11-02 → 11-05，三天）
   V7.19/20/21 出了片、过了闸，卡在"没人签"。版本号一路涨，交付面一步没进。
   未根治因：**没有单一责任人 + 没有超时升级**。

6. **反馈未断言化**（40 条批评里能机器检的不到 1/5）
   未根治因：**没有"24 小时内批评→断言"的转化规则**。

7. **感知误判白烧**（10-24「女主一致性崩了」实为背身极暗不可辨 → 正解是提亮不是重拍）
   未根治因：**先归因后动手没有变成流程强制项**。

## 三、根因归类（机制层的六个洞）

| 洞 | 后果 |
|---|---|
| 无定版定义 | 每轮"再改一点"，15 版不定 |
| 闸只查技术不查创作契约 | 机器全绿而全片一个调子 |
| 无回归守护 | 做对的能力会被下一次重构丢掉 |
| 改片与签片同席 | 自审自签，问题反复 |
| 批评不进断言 | 同一个错可以犯三次 |
| 最后一步无责任人 | 出片≠交付，卡三天 |

## 四、做对了什么（要保留的）

1. 归因先于动手（R06 静止 vs 成片位移 → 避免白重烧）。
2. 从 EDL 重建而非打补丁（碎片重播 20→1）。
3. 云端出片 + 本地闸的组合（成本与判据分离）。
4. 逐件闸留回执（可复核，不靠自述）。
5. 快样先行（几十秒片段先给方向）。

## 五、机制（正身 = mv-album-001-jay/MV-DEFINITION-OF-DONE-v1.md）

复盘结论已并入该件，本件只列要点，**阈值与判据只在那一处立，本件不另立**：

1. **六门定版**（G1 结构 / G2 重复静止 / G3 转场 / G4 创作契约 / G5 盲审 / G6 交付就绪），全绿才叫定版。
2. **版本收敛**：未过 G1-G4 叫修复轮，不升版本号；定版后只改被点名项。
3. **回归守护**：每门断言配一条"历史已修能力"守护样例，任何重建先跑回归。
4. **分权**：改片席 ≠ 签片席；主控只发卡与裁决。
5. **批评转化**：CEO 批评 24h 内必须变成一条可执行断言（带正反样例），否则算未闭环。
6. **二犯停机**：同一缺陷二犯即停线复盘，记过失。
7. **最后一公里**：出片后 6 小时内必须有人签或升级，不许"出了片没人管"。
