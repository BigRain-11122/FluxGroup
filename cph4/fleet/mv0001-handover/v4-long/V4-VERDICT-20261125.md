## 一、L01_ENTRY_DOLLY —— ✅ 成功，且是本批次最高价值镜头

六帧轨迹（0.1 / 1.6 / 3.2 / 4.8 / 6.4 / 7.8s）：

```
0.1s  她在展厅远端，两侧展柜，背对镜头
1.6s  走近，中景
3.2s  继续走，展柜在左
4.8s  左侧玻璃上浮出楔文碑面，她转向它
6.4s  她站在碑前，玻璃里是楔文
7.8s  她抬手，指尖朝玻璃上的楔文
```

**一条镜头同时解决三件事**：

| 解决什么 | 怎么解决的 |
|---|---|
| 镜头调度单调 | 真实推轨运动 + 视差，8 秒一个完整运动 |
| 因果链缺失 | **"她走进 → 找到碑 → 伸手"** 本身就是完整因果单元 |
| 对手戏缺失 | 她与碑的物理互动（伸手）在同一个镜头内完成 |

而且它替代了原本"远景+中景+近景"三个拼接镜，**拼接感直接消失**。

## 二、L03_TIMEBRIDGE —— ❌ 失败，不采用

六帧轨迹：

```
0.1s  台灯下他写字
1.6s  继续写
3.2s  火焰从纸面升起
4.8s  大幅火焰 + 碑面（火焰像贴纸特效）
6.4s  火焰褪去，碑面
7.8s  碑面 + 尾巴
```

三条硬伤：

1. **火焰形态廉价**：橙黄色卡通状火舌，是典型的"AI 特效贴纸"，直接踩「去 AI 感」红线
2. **过渡不连续**：是"烧穿"而不是"光影渐变"，中间有跳变
3. **末段 DUP 8%**：4.83–8.00s 近静止

**判定：判负，不重烧。** 理由：这条的失败是"模型对该转换的理解是烧穿"，换参数只会得到另一种廉价火焰；继续烧是空烧。
若仍需要古今连接，走已验证的 L01 路线（同空间位移），或用 `HANDGLASS`（手贴玻璃+倒影）做连接。

## 五、技术判例（新增）

- **首尾帧在 H3 fl2va 上可用**：`last_frame` 接线后 192 帧 @ 8s 稳定，末帧真的落到目标构图。
- **首尾帧能解决"运动方向"但不能解决"跨语义跳跃"**：同空间位移（走进展厅）完美；跨时空材质转换（纸→碑）会退化成廉价特效。
- **判据**：首尾帧两种用法 —— ①同场景位移 = 高成功率；②跨语义转场 = 高风险，失败应直接弃而非重烧。
