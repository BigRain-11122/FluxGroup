## 二、内容侧实测（2 部竖屏正片，全片量化）

| 指标 | 真人短剧（51:10） | 另一部（42:04，标签含 ai） |
|---|---|---|
| 切点（自动标定阈值） | 1,257（0.30） | 665（0.20） |
| 镜头中位 | **2.23s** | **2.50s** |
| 镜头 P90 | 3.83s | 9.44s |
| <1s 短镜占比 | 8.1% | **22.7%** |
| 切点/分钟 | **24.6** | 15.8 |
| 整体响度 | **-10.24 LUFS / TP +0.57 dBTP** | -13.53 LUFS / TP -0.47 dBTP |
| 画面 | 240x426 竖屏（下载代理档，非源分辨率） | 同 |

### 可直接用的结论
1. **镜头中位 2.2-2.5 秒**是这类竖屏爽剧的稳定基线；P90 3.8s（真人）说明"绝大多数镜头不超过 4 秒"，长镜只作为偶尔的情绪停顿。
2. **短镜（<1s）用量是风格分水岭**：真人版 8%，另一部 23% —— 高短镜占比对应"闪回/打脸/信息轰炸"剪法，是节奏更"抓"的形态。
3. **响度差 3.3 LU**：真人版 -10.2 LUFS 明显更"响"，且 TP +0.57 dBTP **已过 0 dBTP 削波线**（平台投放常见做法，但音质有损）。我方交付建议 -14 LUFS / TP ≤ -1 dBTP，平台 loudnorm 后仍统一。
4. 交付形态基线：竖屏 9:16 + 底部内嵌白字幕（抽帧确认），字幕无重描边、带轻阴影。

## 三、游戏侧实测

### G-01《向僵尸开炮》包体（335 MB APK）
- Unity + **IL2CPP**；解压 455.8 MB；assets 62.3% / lib 31.2% / dex 4.7%。
- **双 ABI 同发**：arm64 74.8 MB + armeabi-v7a 67.6 MB；两份 `libil2cpp.so`（42.98 + 39.64 MB）高度重复。
- 单个繁体字体 AB **11.96 MB**（整字库）。
- 广告 SDK：穿山甲（4 dex）+ 抖音（3）+ 微信（2）+ 优量汇（2）+ UnityAds（1）→ 标准多聚合 IAA。
- 结论 3 条见卡片；核心是「只发 arm64 + 字体子集化」可直接省 ~77 MB 量级。
