# 小游戏认知基座 CANON-v1（2026-11-03）

> 这条线（biggame）的唯一认知入口：新会话先读这里，再读工序与闸。
> 只写结论与判据，数字与来源见文末指针。

## 一、这是什么

- 我们做**轻量 2D 小游戏**，单局 60–90 秒，随时可停；一次做一款，首发只上 1 款。
- **不是**：买量型 IAA 产品、重度经营、3D、数值成长型养成。CEO 全 2D 令是硬约束。
- 商业模式差异：**锁关系不锁关卡**——付费点是"本局生成的家庭明信片"，不是第 N 关钥匙。

## 二、市场事实

1. 2025 国内小游戏收入 535.35 亿元（+34.39%）；IAP 364.64 亿（68.11%）、IAA 170.71 亿（31.89%）。
2. 67% 新增用户来自付费投放，腾讯广告+巨量合计占 98.3% —— **我们不走买量**。
3. 头部 IAA 靠广告变现，对亲子场景不友好（广告打断孩子）；这正是我们的空档。

（来源与链接：`cph4/fleet/market/biggame.md`，抓取 2026-11-03）

## 三、三条设计铁律（可机器判）

1. **不做失败**——孩子在车里哭=产品死；没有失败态、没有体力、没有倒计时惩罚。
2. **单局 60–90 秒**——超过就打断带娃场景。
3. **不做数值成长，只做收藏**——成长靠"明信片册"的记录量，不靠数值变强。

## 四、我们曾经错在哪

- 39 款在册、约 9 款有真包、**0 款上线**——唯一战略卡点是账号资质链（AppID→ICP→软著→提审），属 CEO 物理件，不是研发能推的。
- 队列长期无"前三关重做"任务，需求件停在原型没接引擎 → 现在按工序表出卡，避免"设计档最厚、包里最空"。
- 单独生成按钮/面板而不是整屏再拆层 → 已改：整屏 mockup → 原位拆层 → 透明 PNG → 引擎。

选款、提审、账号资质是判断活与 CEO 物理件，不写成机器工序卡——写成卡只会每天派一张干不了的卡。

## 七、成本与定价

- 定价：买断 28 元 / 家庭包 58 元 / 皮肤 6–18 元。**不卖**关卡钥匙、体力、抽卡、广告。
- 成本结构允许零买量：不做投放，增长靠内容分发与家长口碑；这决定了单款必须小而快。
- 付费意愿来自"记录"而非"解锁"——家长为回忆付费的意愿高于为关卡付费。

## 八、失效条件

1. 某一款 30 天做不出可玩包 → 换题，不延长。
2. 单款买量成本出现（即我们开始投流）→ 立即停，说明模式已跑偏。
3. 出现失败态或广告打断 → 判定返工，不谈判。
4. 连续 7 天无线产物 → 该线自动挂起。
