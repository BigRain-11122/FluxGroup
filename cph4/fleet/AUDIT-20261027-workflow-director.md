## 二、七处失衡（每处带证据与代价）

### I-1 文档/门 与 成片 失衡
12 版剧本、7 份 PROMPT-GATE、25 节 QC，而成片只有 1 支且未过审。**门在增加，产出没跟上**——门变成了自证勤奋的载体。
代价：CEO 看到的仍是"没片"。

### I-2 研究 与 开烧 双向失衡
- 往"过度"偏：7 曲无 audience-voice 研究件 → 一律禁开工（研究债阻塞产能，而 GPU 现在空着）。
- 往"不足"偏：10-25 W2 i2v 用废稿开烧 25 镜被 kill（无门盲烧，浪费 16h 窗口）。
**两种失败同时存在，说明缺的是「配比」不是「更多门」。**

### I-3 出生地拦截未落地（漫剧最贵教训）
KF 全池重烧两次（178 张 + 368 张备份），根因（CLIP 77 截断 / 锚三形态漏匹配）都是**烧前可检**的，却在出图后才发现。
代价：整池重烧 + 11 小时卡死一次。

### I-4 产线间产能失衡
声音线 10-18 完成样带后 9 天零动用（有产能无排产），同一时间 GPU 4% 空转、繁剧已收口等下游。
代价：三面（GPU/CPU/声音）没有统一队列，各自等各自的活。

### I-5 同步面失衡
两仓落后 390/410 且在扩大；本窗我本人两次以落后工作树覆盖远端（已补正）。**"外科推送"已成常态手段 = 工作树长期不收敛的症状**，事故率只会继续升。

### I-6 门位失衡（一线一标被破坏）
MV 有 D1→D7 七站 + QC 25 节；漫剧只有事后 QC（片长/字幕/帧），**没有剧本门与开烧门**。同公司两套标准，漫剧的便宜是靠"事后返工"换来的。

### I-7 判例 与 机械断言 失衡
判例库已厚（P-01..P-12、QC CHK 系列），但"入册≠生效"：77-token 事故早入册，预算器今天才造出来；锚三形态事故入册后又出现席间新方言。
**没有断言/工具的判例=散文，不是机制。**

## 三、均衡七律（导演席主张·供委员会裁定）

- **R1 门的经济学**：每道门必须能举出「它拦下过什么」。举不出的门=空门，下线。加门必须同批减门或合并。
- **R2 生产-研究配比**：任一时刻**至少一条线在产**；研究债 >30% 曲目即触发研究冲刺班。禁「研究全归才动工」，也禁「无研究盲烧」。
- **R3 出生地拦截**：缺陷在哪一站最早可检就装断言；**烧前必过三验**（token 预算 / 锚命中全量模拟 / 记忆点挂镜）。
- **R4 产能配平**：GPU / CPU / 声音 三面各有队列与心跳；任一面空闲 >2h 且池有活 = 调度缺陷，入台账。
- **R5 同步窗口**：每日一个收敛窗（无在飞时）；工作树落后 >50 提交视为事故，必须收敛或重 clone，禁用"永久外科推送"掩盖。
- **R6 一线一标**：每条线同构五站（研究 → 剧本/台本 → 开烧三验 → 装配 QC → 复盘回灌）。允许各站轻重不同，不允许缺站。
- **R7 判例机械化**：一条判例入库必须同时产出**断言/工具/清单**三选一；否则标"散文态"并计入技术债，月度清账。
