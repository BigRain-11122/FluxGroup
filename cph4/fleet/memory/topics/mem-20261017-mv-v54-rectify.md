## 1. E04 慢放三重放大判例（女主镜 AI morph 修复正法）

- **病机**：minterpolate=mi_mode=mci 光流插值（v<0.96 自动启用）在慢放镜里**合成中间帧=鬼脸本体**——源帧干净（密集板静帧 13/13 对零漂移）但成片鬼影鬼畜。慢放三重放大：①插值中间帧密度随慢放比增大 ②罪段屏占拉长 1.39 倍 ③慢动作把注意力钉死在面部走廊。
- **修复正法（素材级·零重生成）**：提速降插值密度。E04 案例：0.72→0.85（插值帧减 39%），数学精确解=素材全长/新速 + tpad 定格 = 窗长（5.17/0.85=6.08+1.10=7.18 恰满窗）；定格帧必须落在设计终态（两脸清晰贴面）+罪窗压一发低 alpha 金光 bloom 保险（215.30·0.16s·α0.45）。
- **判读纪律**：素材密集板须按正确仿射换算片上↔素材时刻（speed 乘非除）；标签错位会让判读员误锚罪窗——板标签换算公式写进脚本注释并在 prompt 里直接给正确表。

## 3. v54 XFS 内点扩法（装配器工程正法）

- 块尾延律通用化：**块 i 尾行尾延 = XFS[i] 的 D**——A1/A2/T/G 特判全部对齐此律（T 特例发射窗 1.40+XFS[2]D=1.80 正典兼容）。加内点 XF 只需 `sorted([(21.90,fade,0.36)]+v5.XFS+XF_EXTRA)`，分块 G 按 XFS[3:] 界拆，块数=len(XFS)+1。
- **预删段件缓存清单（REEMIT 模式）**：新 XF 点的前块段件/换源段件在 D51 缓存里是旧版（无尾延/旧源）——REUSE 会吃掉修复。装配器头部 V54_REEMIT 列表 os.remove 强制重发射（v54.py L87-97 实例：D08 换源+S9/R04/D03b/E01b/E04 尾延共 7 件）。
- 块缓存命名隔离：新块划分换前缀名（v54_blockG%d）防踩 v53 缓存；pin 后缀件（_fx.mp4）按帧目标自动失效。
- 数学自检链全承 v53：block_frame_targets（partial-sum pinning）/XF offsets 对锚 ±0.05/final_len ±0.5/J-32 源计数断言——14 点链一次通过。

## 4. N03/R03「morph」定罪推翻判例（QC 判读纪律）

V53 判读定罪「雕像五官帧间 morph=明显」被 V5.4 复现检验**推翻**（28 帧 Δ0.30s 镜内对照：N03 13/13 对零漂移、R03 13/13 对零几何漂移，双双 C 级）。误判三机制：
- **跨切对比污染**：两镜是不同雕像设定（博物馆米色 3/4 侧 vs 巴比伦深色正脸），板上网格并列时「全变」被误记为 morph——判读板跨镜并列必须镜内对照帧对帧核。
- 火光闪烁误读：面部亮度逐帧波动（火光相位）在暗部轮廓产生「位移观感」。
- FX 伪影错误归属：烟雾高纹理区插值伪影被记账到脸上。
教训：**定罪前先复现**——重抽帧按镜内相邻对照验证，勿信前轮稀疏抽帧判读。
