## 二、工单状态机（产线骨架）

```
NEW → READY → IN_PROGRESS → QA → PASS → BURNED
                    ↘ FAIL → READY（带原因+打回站）
任意 → HOLD（导演）→ READY
```
- 工具 `Tools/woticket.py`（JSONL 台账 `WORK-ORDERS.jsonl`）。
- **WIP 上限：IN_PROGRESS ≤2、QA ≤6**；**同一时间只允许 1 个在制版本**。
- 实测拦截：NEW 跳 IN_PROGRESS 被拒；第 3 张进 IN_PROGRESS 被 WIP 拦。

## 三、导演介入四权（艺术化，不影响安全闸）

| 权 | 命令 | 说明 |
|---|---|---|
| 停 | `director.py hold` | 任意状态 → HOLD |
| 放 | `director.py release` | HOLD → READY |
| 改判 | `director.py art --tier C --veto` | **C 档可把 PASS 打回**（技术过但难看） |
| 留话 | `director.py note` | 只记录 |

艺术四档：S（可当封面）/ A（正常入片）/ B（排后段）/ C（否决）。技术闸管"有没有硬伤"，艺术档管"值不值得存在"，**两者都过才算过**。
三条边界：不改硬指标、不自签复核、必须留理由（进 `DIRECTOR-LOG.jsonl`）。

## 四、流程自审 12 项（核心结论）

**"流程不缺条款，缺条款被执行的证据链。"** 闸、签核、预算、台账都写了，但没机制强制调用 → 出现闸空转、台账空、预算无计时。
12 项改进已列（M1 闸双向验证、M2 基准表、M3 变更假设卡、M4 签核纳入执行、M5 闸覆盖率、M6 素材索引、M7 偏差到期、M8 判读≤12格、M9 计时、M10 自动化健康、M11 汇合仲裁、M12 替换必附对比）。
