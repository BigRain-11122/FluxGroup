## 一、任务

修 V5.11 唯一残留缺陷：40.2–44.0s（S8_case + S9_profile）玻璃上出现倒影人脸，违反 2026-10-12「倒影脸清除令」。

## 二、三轮废片各自违反了哪条既有规则（核心教训）

| 轮次 | 做法 | 违反的规则 | 后果 |
|---|---|---|---|
| 1 | 直接拿原首帧 i2v，2 seeds | **缺陷出生地拦截律**（每类缺陷在最早可检站拦） | 首帧自带倒影 → 2 条 take 全部继承，白烧 |
| 2 | 用 Qwen-Edit 改首帧，提示词写 `no reflected face` 且提到 `her hand` | **闸 H 零否定句**（prompt-spec v2：零否定，否定词会把目标"叫出来"） | 倒影去了，但**凭空多画一只抬起的手**，刻纹也被改亮 |
| 3 | `scene="hall"` + `light="godray"` 描述博物馆展柜 | **闸 D 起帧一致 / 闸 G 场景锚**（提示词 token 必须与首帧事实一致） | 背景被换成巴比伦火盆石厅，等于换场景 |

结论：规则在库里，**动手前没有逐条过闸**才是废片根因，不是经验不足。

## 三、词表 token 事实（防再猜）

`prompt_lexicon.py` 合法键（本次实测）：

- **SHOT_SIZE**：ecu / cu / hs / med / mw / wide / ext（**无 mcu**）
- **SCENE**：corridor / classroom / library / rooftop / street / court / desk / tablet / **hall=巴比伦火厅** / temple_corridor / **museum=夜间博物馆展柜通道** / gate / shopfront / street2001
- **LIGHT**：tung_left / tung_right / window / golden / dusk / lamp_desk / flame / halo / **godray=神殿硬顶光柱** / sodium / fluor / **onelamp=低照度单光源** / butterfly / rim / split
- **GRADE**：tw2001 / mono / bluefire / nost
- **TEXTURE**：film_night（Kodak Vision 500T）/ film_day（250D）/ mist / soft

博物馆镜头必须用 `scene="museum"`、`light` 用 `onelamp` 一类，禁用 hall / godray / temple_corridor。

## 四、S9 这一镜的固有矛盾

- 该镜构图本身＝「人物侧脸 + 玻璃里的一张脸」。H3 把"玻璃=反射人脸"当场景语义的一部分，**换了 3 个种子仍然复现**。
- 首帧清洗后（2 倍放大核过：玻璃区无五官轮廓、无修补痕），模型仍会自行补出镜像脸 → 继续换种子/换提示词＝继续赌概率。
- 三条合规路线：**A 换构图重拍**（新首帧，成本高）｜**B 换镜**（用同场景已过闸的干净镜头替换这 1.78s，成本最低、不动结构）｜**C 逐帧局部修补 43 帧**（＝后处理遮症状，CEO 已定谳不做）。
- 判定：**走 B**；同一构图不再重烧。
