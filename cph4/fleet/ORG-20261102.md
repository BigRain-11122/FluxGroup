# 组织定案 2026-11-02（最终版）

> CEO 定案三条：①所有子公司都保留，只分优先级；②Biggame 与内容同为 P0；③组织要能一眼看清，包括委员会。
> 本件是组织正身。看完这一页，就知道谁存在、谁先干、谁判、谁签字。

## 一、五层总图

1. **决策层**：CEO、决策委员会、中枢。
2. **业务层**：内容组、游戏组、策略组、城市组。
3. **职能部门**：产线、质检、资产、拆解、财务账、合规。
4. **执行层**：机队（五台机器）。
5. **优先级**：P0 到 P3，决定谁先排队，不决定谁被关掉。

## 二、决策层

1. **CEO**：定方向、定红线、签对外、批花钱。四件事，别的不管。
2. **决策委员会**：三个人，来自三个不同岗位——风控、质检、产线各出一人。
   - 只裁"机器判不了、又不到 CEO"的事。
   - 48 小时内必须给结论，给不出就升级给 CEO。
   - 每周一次短会，只审三件：本周停什么、开什么、哪条线要降级。
   - 不做名义投票：结论只写"谁判的、依据是什么、谁复核"。
3. **中枢**：一个人加几个 AI 席位，干四件——派活、盯产物、盯阻塞、写一屏。

## 三、业务层（四个组，对应全部子公司）

1. **内容组（P0）**：BigStream。
   - 做 MV、短剧、漫剧，卖到海外。
   - 负责人：导演席。验收：质检席。出口：CEO 签名发布。
2. **游戏组（P0）**：Biggame。
   - 做轻量 2D 小游戏，微信小游戏、海外超休闲、车机适配。
   - 负责人：游戏席。验收：质检席。出口：CEO 签名上架。
   - 铁规矩：只做 2D、单局 60–90 秒、儿童场景不做失败。
3. **策略组（P1）**：BigMoney（引擎）+ BigDomain（前台与收钱）。
   - 做 19.9 策略算力包。
   - 负责人：量化席。验收：风控席。出口：CEO 定价与报价。
4. **城市组（P2）**：BigLife（人口）、BigHouse（安家）、FluxVerse（城）。
   - 做硅基城市的人、房子、界面；城只当看板，不当产品卖。
   - 负责人：城市线席。验收：质检席。出口：内部使用，不对外发布。

## 四、职能部门（不属于任何组，服务所有组）

1. **产线**：五台机器、模型、渲染、配音、装配。负责人：产线席。
2. **质检**：所有闸、观众三层、发布前检查。负责人：质检席。
3. **资产**：素材、模型、音色、字体、提示词、居民档案。负责人：资产席。
4. **拆解**：扒榜、拆包、竞品配方。负责人：拆解席（服务 P0/P1）。
5. **财务账**：算力成本、云花费、收入回执。归中枢，只有 CEO 能批钱。
6. **合规**：标识、备案、授权、儿童场景四条红线。归中枢，一票否决。

## 五、执行层（机队五台）

1. **公司生产力**（bm-a）：构建、装配、转码、夜窗重活。
2. **传家宝**（bm-b）：配音、回测、音频。
3. **小钢炮**（bm-c）：出图出片，内存不足就不派。
4. **算力大脑**（bm-d）：未入网；入网后接重 GPU 与回测。
5. **MacBook Pro**（bm-m）：中枢驻地，只做调度、判定、观测、出包。

## 六、优先级（只影响排队顺序）

| 级别 | 谁 | 什么时候用机器 |
|---|---|---|
| **P0** | 内容组、游戏组 | 优先占用，白天可用 |
| **P1** | 策略组 | 夜间与空档 |
| **P2** | 城市组 | 用 P0/P1 的空余 |
| **P3** | 算力、车机 BU | 用一切空余；等外部资质 |
| 支撑 | 拆解、音色库、质检、资产 | 随时，随用随停 |

**四条规则**
1. 不关停：没活只报"等供给"。
2. 只排队：P0 有活时先干 P0。
3. 空档就给低优先级：机器闲着就干 P1–P3，不许空转。
4. 连续两个季度零产物零收入，只降级，不除名。

## 七、判据

1. 7 天：队列里 P0 的卡总是先被领走。
2. 30 天：P0 出第一条能发的片、P1 出第一份回测结论、游戏组出第一个可玩包。
3. 60 天：19.9 收到第一笔钱，或写清为什么收不到。
4. 90 天：四个组各有"下个月能重复交付"的固定产物。
