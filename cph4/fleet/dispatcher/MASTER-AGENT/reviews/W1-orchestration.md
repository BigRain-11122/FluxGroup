## 问题

1. **交接协议无正身（最重）**：病灶=orders 行仅四要素（@机/lane/回执窗/验收物），spec、溯源令号、输入输出路径、依赖、回执 schema 全缺，执行机独立干活上下文不足；证据=G5 自认 bm-b/c 承接协议未成文、POOL 卡与 orders 行无 ID 关联；修法=定交接卡 schema 入 CHARTER，L2 转单双写「POOL 卡+orders 行带卡 ID」。

2. **路由律纸面化**：病灶=复杂度×质量×token 三因子无阈值无判分表，同件异班可异判→路由漂移，且 L1 路由未接线（消费率 0.2%·G3）；证据=§二仅品类枚举无量化边界；修法=品类白名单表定谳可判定面+云端调用逐行记 route 因子、周审「本可本地」误路由率（ROUND.md 是否含阈值=待证·未越读预算）。

3. **跨班接力两断点**：病灶=台账 append-only 不拆分→8 班读史成本 O(n) 膨胀；班中未决判断无「关窗前落盘」强制律，思路即丢；证据=§五台账不拆分+复窗首动作仅盘点死单；修法=班末未决件必写 NEED-JUDGMENT（带续办字段）+台账月度索引/滚动归档。

4. **对照业界缺三件、两件不该抄**（外部知识·置信=确认）：缺多步依赖图（POOL 无 depends_on）、状态合法迁移表（核销有原则无操作判据）、班次交接单固定格式——LangGraph checkpoint、MetaGPT SOP 门可借模式。不该抄=AutoGen 自由对话编排（烧 token+非确定）与动态 spawn/事件总线（schtasks 定席更稳·置信=推测），文件台账确定性正合 Windows 栈。修法=POOL 加 depends_on+五态迁移表入 CHARTER+核销双勾（验收物在+观感验证）。
