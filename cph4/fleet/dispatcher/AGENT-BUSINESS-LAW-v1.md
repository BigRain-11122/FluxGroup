# AGENT-BUSINESS-LAW — Agent 业务法 v1（发现 · 创新 · 审查）

> 溯源：CEO 令 2026-10-15 晨（问诊窗原话）：「agent最主要的业务要发现机器没干活，任务没排满，没有产出，方向不对等等，其次是创新等，还有审查，你好好想一下，给我弄全面且科学」（O-20261015-1030）。
> 定位：**Agent 系统的业务总法**——机制怎么咬合归 `cph4/registry/mechanism-map.md`（管道图），法条索引归 `law-registry.md`，节律明细归 `cadence.md`；本件回答「agent 存在来干什么、每类失败由谁发现、判据是什么、发现后怎么办」——四件互指不复制。
> 性质：**并档收编件**——本件零新法条，把散落在案的防闲置律/意义门/三态归因/完成定义/新鲜验证/自迭代/审查律收编为一张业务总图+一张缺口账+一个执行序列（法熵守恒：CEO 直令+收编不新增）。

## 〇、业务优先级法（CEO 定谳·全文最高条）

| 优先级 | 业务 | 一句话定义 | 带宽/预算规则 |
|---|---|---|---|
| **P0 发现** | 让四种浪费无处藏身 | 机器没干活·任务没排满·没产出·方向不对（+「等等」=系统级病） | 一切让位 P0：红旗/死线在场时创新与审查让路；探测栈 24/7 零 token 常开 |
| **P1 创新** | 让系统每周比上周强 | 自迭代·轮子引进·新机制提案 | 限额节奏（入队 ≤2/日·自艺 ≤1/周·收敛律）；法熵守恒+权面自扩禁 |
| **P2 审查** | 让一切宣称可信 | 产线件审·机制审·正典审+审查的审查 | 与 P0 传感复用（已测面禁重测）；批审查让位死线件 |

判读律：三业务冲突时 **P0 先行**（创新调研让位红旗处置·审查批让位死线件）；P0 自身的张力仲裁见 §五。

## 二、探测架构（成本分级·正本=mechanism-map §〇/§一·此处只列层）

L0 机级（IdleWatch PT15M/承载件 PT15M/探针 PT1H/看门狗族）+ L0' 域级（巡视席 PT30M×10=48 扫/日）**零 token** → L1 本地 35B 判读（日 digest·近零 token）→ L2 云端判断班（**旗触发才上**·token 有账）→ CEO 兜底（只拿：红旗驻留 >90min/死线风险/物理件/保留面）。

**SLA 三线**：旗响应 ≤30min（夜窗事件班 ≤15min·7min 实证）·处置后复探验证 ≤30min·连 3 次复闲才报警（防抖内置=防「狼来了」报警疲劳）。

## 三、判读四律（假信号免疫——一切传感/审计/回执的消费规则）

① **产物实证律**：done/green 必须有产物级证据（mtime/sha/字节/commit），日志级证词不采信。
② **三态语言律**：已安排/在做/已完成严格分立——发令≠开工，承诺必带验收物（完成定义先行）。
③ **多源交叉律**：单一信号不采信——心跳+实测+台账三源，repo_heads 双源互验，「verdict green≠有效工作」。
④ **新鲜度律**：报现状先实测戳；引用记忆/文件前先验其在。

（四律=在册判例收编——防的是 C2 假 done/E2 假绿/E6 传感器说谎这类「系统骗系统」。）

**P0 内部张力仲裁（科学面）**：满载线（A/B）与意义门（D）互为对冲——只压满载会逼出「为凑数而烧」（D1 复发），只讲意义会放任真闲置（A 复发）。可测定义=C1「零产出日解释率」：**允许低产出日存在，但每一天要么有产出、要么有解释**——这就是「排满且有意义」的判据化。

## 六、P1 创新业务（管道化·限额节奏）

- 管道：痛点观察/判例回灌 → 提案（成本收益判据）→ 评审（委员会/专家席）→ 执行 → 收口 → 判据回访。
- 在役载体：CEO-PROXY ROUND 步9 自迭代协议 v1（日复盘 23:43 固定片·入队 ≤2·周日 21:43 深复盘·自艺 ≤1/周·收敛律=连续 7 日零新项降快扫）。
- 约束三律：法熵守恒（新增须并档/退役 ≥1 旧法）·权面自扩禁（工艺面 only）·轮子优先（build 前先搜 GitHub 高星）。

## 七、P2 审查业务（三面+审查的审查）

- **产线件面**：十席两波群审/盲评/成片闸/导演席（BigStream）·委员会直审（BigGame/BigMoney）——正本各产线正典。

## 八、资源经济学（发现业务自身的成本账）

探测栈成本≈0（L0/L0' 全 schtasks 零 token·L1 本地近零·L2 旗触发有账）vs 闲置/错向损失（GPU·日闲置=沉没电费+机会成本·判负批续烧=真金）——**投入产出比恒成立，故 P0 探测 24/7 常开不设预算闸**（真金闸只管云端生成面·不管探测面）。监控者递归三层封顶：probe 盯班→日覆盖审计盯 probe→回访窗+CEO 抽查兜底（无限回归有限化）。

## 十、总裁定（一句话）

**Agent 的第一职责=让机队每一瓦电都变成产出、每一个令都落成事实、每一个方向都对齐目标——发现是本分，创新是进阶，审查是底座；一切机制为此三者服务，一切判据以证据说话。**
