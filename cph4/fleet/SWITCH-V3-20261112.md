## 二、visual（传家宝）切换步骤

在 `K:\` 等价工作目录下，**PowerShell** 里逐条执行（每条失败就停在那条，把输出贴回来）：

```powershell
# 1) 同步到新架构（不动本地未提交改动：--mixed 只移动 HEAD）
cd <你的 FluxGroup 工作目录>
git fetch origin
git status --short          # 有本地改动先看一遍，别直接 reset
git reset --mixed origin/main
git checkout origin/main -- Tools/fleet cph4/fleet

# 2) 确认身份与自检（四条全绿才继续）
python Tools\fleet\fleet_identity.py            # 应显示 visual（依据=identity-file 或 hostname）
python Tools\fleet\station_shards.py --list
python Tools\fleet\station_status.py --remote
python Tools\fleet\station_drive.py --station visual --dry    # 看 would_create / unknown_output

# 3) 停掉旧流程（否则新旧两套同时写分片）
#    按 R40/12:45 两条记录的退役清单：HQ-ProductionClaim、HQ-FleetDispatcher、
#    HQ-CEOProxyEventCarrier、Bigmoney-*Tick 等在跑的旧任务全部 Disable
Get-ScheduledTask | Where-Object {$_.TaskName -like "HQ-*" -or $_.TaskName -like "Bigmoney-*"} |
  ForEach-Object { Write-Host "DISABLE $($_.TaskName)"; Disable-ScheduledTask -TaskName $_.TaskName }

# 4) 注册 v3 自驱（每 5 分钟一次；S4U 被拒就用 Interactive 降级并记入 task-s4u-backlog.md）
schtasks /Create /TN "FluxGroup-StationDrive-Visual" /SC MINUTE /MO 5 /F `
  /TR "\"<python路径>\" \"<工作目录>\Tools\fleet\station_drive.py\" --station visual --once"

# 5) 首火验证（必须看到真产出，不许只看任务状态）
schtasks /Run /TN "FluxGroup-StationDrive-Visual"
Start-Sleep -Seconds 60
type cph4\fleet\rt\visual\log\<今天>.jsonl | Select-Object -Last 5
```

**验收判据（缺一不算切好）**

1. `fleet_identity.py` 输出 `visual`；
2. `station_drive --station visual --dry` 不报 blocked；
3. 分片里出现本机新写的卡（`created_by=self-drive`）；
4. 当天 log 有 `RUN` 行；
5. 旧任务全部 Disabled（用 `Get-ScheduledTask | ? {$_.State -eq "Ready" -and $_.TaskName -like "HQ-*"}` 应为空）。

## 三、切换后各工位各司其职（契约，不靠口头）

- **只写自己的分片**：`cph4/fleet/rt/<你的工位>/queue.jsonl`。写别家会被护栏直接拒（`PermissionError`）。
- **跨工位交接走 outbox**：把卡追加到自己的 `rt/<你>/outbox.jsonl`，目标机下次 SENSE 时自己入队；不要写对方分片。
- **判据**：`TAXONOMY-v1.json` 的 `judge`。人判件（`manual`/`human`）机器**不许**标 DONE。
- **失败**：`FAILED` 会自动退避重试（5/10/20 分钟，3 次后转 `BLOCKED` 并写缺什么）。
- **缺输入**：卡上带 `requires` 且路径不存在 → 直接 `BLOCKED`，不执行、不重试。
- **不要恢复** `PRODUCTION-QUEUE.jsonl` 那条旧链路；它已归档，读它的工具不许进执行面。
- **要模型**：走 `local_model.generate`（拿 keep_alive/审计/额度）；直连 8792 属于 P1。

## 四、卡住了怎么办

1. 先看 `station_drive.py --station <你> --dry` 的输出，`blocked` 字段会直接说原因。
2. `unknown_output` 里的条目是 `TOOL-PENDING`（契约有、命令没接）——**不要硬接假命令**，登记即可。
3. 三件只能上报、不许自己决定的事：要模型（网关/额度）、对方工位不在线、对外发布/花钱。
