## 一、调性一句话

**「冷蓝黑的琴房，只剩一盏还亮着的灯。」**
——全片 95% 的画面在蓝黑里，唯一不进蓝的是那盏 2200K 台灯；它在片尾还在亮着，这就是全片的落点。

## 四、参数链（ffmpeg·装配站照抄）

```bash
# 基底（全片）
eq=contrast=1.06:brightness=-0.012:saturation=0.94
curves=blue='0/0 0.35/0.40 0.70/0.76 1/1'          # 蓝通道上抬=冷
colorbalance=bs=.05:bm=.03:bh=.02                   # 阴影偏蓝青
# 暗角（邝盛语言·内景低调）
vignette=PI/4.6
# 颗粒（35mm·最后一步，禁被调色扭曲）
noise=alls=6:allf=t
```

**关键约束**：台灯区（画面左上 1/3）**不许进蓝**——用 lumakey+mask 保护暖区，否则那盏灯会变成白灯，全片立意就塌了。

## 五、校准协议（GRADE-LAW §一-3 硬序）

1. 量测先行：装配后逐段抽 3 帧，量 YAVG / 蓝通道均值 / 暖区均值 → 对表；
2. 盲评：与星晴、可爱女人同机位帧**并排盲测**，十席判「一帧认出本曲」≥8/10；
3. 调色师席签字 → 才允许 D8 成片闸。
