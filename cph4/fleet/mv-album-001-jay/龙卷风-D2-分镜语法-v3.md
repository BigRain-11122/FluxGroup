# 《龙卷风》D2 分镜语法 v3 — 取景 / 服装 / 表演 / 运镜 四条重写

> 起因：CEO「取景服装表演运镜什么的都很烂」。本件不解释，直接改规矩，并给出可执行的分镜表。
> 适用：本曲全部镜头；同族毛病在星晴/可爱女人同样存在，修法共用。

## 一、先看尸检：现在的片子烂在哪（对着 29 帧原片说的）

| 轴 | 现状 | 病根 |
|---|---|---|
| 取景 | 29 镜里 20 镜是「人站在画面中央的中景/近景」，机位高度几乎全在眼平线，焦段挤在 35–85mm | 没有焦段阶梯，没有机位高度差，没有前景层，构图靠「把人放中间」解决 |

## 二、四条硬规矩（违反即打回，不再逐条解释）

### 1. 取景
1. **焦段阶梯**：每场必须出现 ≥3 档（18/24 · 35 · 50 · 85 · 135），相邻两镜不许同焦段。
2. **机位高度**：每场至少一次低机位（≤腰高）与一次高机位（≥头高），眼平线不得超过该场 50%。
3. **前景层**：≥1/3 镜头必须有前景遮挡（门框/窗棂/纱帘/椅背/肩），禁「干净空框里放一个干净的人」。
4. **不对称构图**：主体重心放在 1/3 线上，视线方向留白 ≥40%；正面居中的「证件照构图」全片 ≤2 次，且只给主动的那一刻。
5. **景别不连用**：同景别不许连镜；大全—特写可以直接切（跳切律），中间必须跳档。
6. **一镜一信息**：每镜只承担一个叙事信息（谁/在哪/想要什么/被什么挡住），不许一镜同时交代三件事。

### 2. 服装（2000 台湾，不是现代极简）
- **男主三套，按三段换**：
  - 第一段（她来）：水洗蓝白细条纹短袖衬衫，下摆不扎，直筒深色牛仔，旧帆布鞋；手腕一根深色编织绳。
  - 第二段（风暴/失控）：同一件衬衫淋透、贴身、下摆抽出，外套一件深灰薄连帽（拉开不拉合）。
  - 第三段（后知后觉→走出）：素白圆领 T（领口洗松）、灰绿工装裤、拖鞋→换鞋出门。**同一件衣服要有穿着痕迹的递进**，不许三套都「崭新平整洁净」。
- **女主三套，只活闪回**：米白针织开衫（扣子扣错一颗）／浅蓝连衣裙+白袜帆布鞋／灰蓝薄外套（他的外套，肩宽两号）。围巾只用一次。
- **禁品**：修身潮流款、韩系街潮、极简无细节、任何 logo/印花文字、现代机能面料（防水拉链/速干）。
- **材质锚**：洗旧棉、起球针织、褪色丹宁、磨白帆布——每套写进提示词，不只写颜色。

### 3. 表演（每镜必须能写成「他想要什么／被什么挡／做了什么」）
- **禁词**：沉默、克制、压抑、落寞、若有所思、看着远方。
- **必须**：每镜一个**及物动词**（擦、塞、拽、扶、拧、找、推、数、扣、摊开），且手上有物件。
- **三段式**：起（动作开始）—承（遇到阻碍/停半拍）—转（改变了什么，哪怕只是把东西放歪）。
- **零看镜头**：全片 0 次直视镜头；需要「看她」时，视线落在**画外的一个具体点**（门缝、桌上的杯子、她刚站过的地方）。
- **呼吸与重量**：每镜至少一处「身体对抗重力」的细节（撑桌起身、弯腰时膝盖先弯、提重物时肩下沉）。

### 4. 运镜（有动机才动，没动机就锁死）
- 允许的四种动机：**跟随**（跟着他走）／**揭示**（摇出画外的东西）／**压迫**（缓慢推进逼到脸上）／**撤离**（拉开、丢下他）。
- 每镜在分镜表里写死动机名；写不出动机的，一律 `lock`（三脚架锁死），不许「轻轻推一下」凑数。
- 同一场内运镜方向不得来回摆（推一次就推到底，别推—停—再推）。
- 手持只给失控段（风暴、抓空），且抖动幅度写进提示词（微晃/明显晃）。

## 三·补、贯穿物件：那杯水（原版考据回填后改的主轴）

原版《龙卷风》真正的骨架不是「房间狼藉」，是**一杯水**：饮水机接水 → 杯子随震动在桌上走 → 震碎/静止。它同时是全片的节拍器与情绪表。本稿把所有镜头串在这一条物件链上：

| 拍 | 杯子状态 | 对应词段 |
|---|---|---|
| 冷开场 | 他接满一杯水，放在桌上，水面有一点点微颤（不是风，是楼板在颤） | 前奏（无音乐） |
| 主歌 A | 杯子在桌上被震得一点一点挪位；他伸手扶了一次，又松开 | 「没有你以后 我灵魂失控」 |
| 副歌 1（断点处） | **音乐停的三秒里，水面出现同心涟漪**——只有水在动，人不动 | 「爱情来的太快」 |
| 副歌 2 | 杯子被震到桌边，他扑过去按住，水晃出来 | 「离不开暴风圈 来不及逃」 |
| 崩塌段 | 书架倒、书飞、灯泡摆动；杯子滚落但没有碎 | 「无处可躲」 |
| 收尾 | 一切停下，**水面静止**，他捡起杯子（全片唯一主动动作） | 「后知后觉 我该好好生活」 |

**执行含义**：杯子必须在 ≥8 个镜头里出现（同款、同位置逻辑），这也是判断「取景是否成立」的硬指标——一个贯穿物件比十张漂亮空镜更能让观众相信这是一支 MV 而不是图集。
