# 第一部分：细颗粒度流程

## N0 立意

**输入**：歌曲、目标受众、发布渠道
**输出**：`IDEA.md` — 一句话立意 + 一句话"看完该有什么感受" + 三条"不做什么"

| 子步 | 做什么 | 判据 |
|---|---|---|
| N0.1 | 写一句话立意 | 不含"好看/致敬/感动"这类空词 |
| N0.2 | 写受众画像（年龄/年代记忆/平台习惯） | 能说出他们会为什么转发 |
| N0.3 | 写三条负向清单（俗套/擦边/侵权） | 每条纹具体到画面元素 |
| N0.4 | 反测：把立意讲给外行，30 秒内能复述 | 复述准确 |

**高发错误**：立意写成"氛围词"；负向清单写"不要低俗"（不可执行）。
**工具**：无（人写）。

---

## N1 文本六轴（歌词逐句）

**输出**：`LYRICS-6AXIS.md` 表：句号 / 原文 / 意象 / 时空 / 人称 / 修辞 / 情感值(0-10) / 视觉指示 / 可拍性

| 子步 | 做什么 | 判据 |
|---|---|---|
| N1.1 | 逐句拆六轴 | 每句 6 列齐全，不许留空 |
| N1.2 | 标情感值曲线 | 全曲有 ≥2 个峰、≥1 个谷 |
| N1.3 | 标"可拍/只能感受" | 只感受的句子要用物象承载（转译） |
| N1.4 | 找记忆点句（3–5 句） | 能指出是哪一句会被记住 |

**高发错误**：把歌词当旁白逐句配画面（图解化）；情感值全平。
**工具**：无。

---

## N2 叙事结构

**输出**：`STORY-STRUCTURE.md` — 四律检查表 + 叙事结构图

| 子步 | 做什么 | 判据 |
|---|---|---|
| N2.1 | 画节奏曲线（纵轴=强度） | 有峰有谷，峰在副歌、谷在桥段 |
| N2.2 | 查因果链 | 每一场"因为上一场 X，才有这一场 Y"能说通 |
| N2.3 | 查记忆点密度 | 每 40–60s 至少一个 |
| N2.4 | 查衔接三锚 | 每个转场能指出：视线/动作/物质 三者之一 |
| N2.5 | 反炫技检查 | 每个转场回答"它在讲什么故事"，答不上＝删 |

**高发错误**：为炫技而转场；双线（现在/古代）只靠字幕区分。
**工具**：无。

---

## N3 剧本（分场）

**输出**：`SCRIPT.md` — 每场：地点/时间/人物/动作/情绪/结果/是否需要台词

| 子步 | 做什么 | 判据 |
|---|---|---|
| N3.1 | 逐场写"谁·在哪·做什么·为什么·结果" | 五要素齐 |
| N3.2 | 逐场自问"删了会怎样" | 答"没影响"＝删 |
| N3.3 | 剧本四律自检 | 写好/逻辑通顺/自然/立意高，逐条打分并写理由 |
| N3.4 | 人物一致性设定 | 发型/服装/年代形制写成可执行清单（供 S2 用） |
| N3.5 | 禁忌扫描 | 镜面反脸、真人可识别、俗套桥段，逐条排除 |

**高发错误**：场次多但都不推动；人物造型只有形容词没有可执行项。
**工具**：无。

---

## N4 分镜 + 节奏

**输出**：`SHOTLIST.md`（每镜：ID/时长/景别/运镜/光位/功能一句话/情绪值）+ 节奏曲线表

| 子步 | 做什么 | 判据 |
|---|---|---|
| N4.1 | 按叙事段落分配镜数与时长 | 副歌 1.0–1.6s、桥段 4.0–6.5s、其余 2.4–3.4s |
| N4.2 | 每镜写"功能一句话" | 写不出＝删 |
| N4.3 | 算镜长标准差 | ≥1.8s（否则节奏平） |
| N4.4 | 标切点类型 | 快段硬切 / 慢段叠化 / 段落交界长叠化 |
| N4.5 | 标注每镜素材来源 | 已有 / 需重拍 / 可复用别镜 |

**高发错误**：所有镜头 3s 左右（本轮实战 73 镜均长 3.21s）。
**工具**：`RHYTHM-DESIGN-v1` 模板。

---

## S1 提示词

**输出**：每镜 `prompt.md`（I2VA 结构 + 槽位）

| 子步 | 做什么 | 判据 |
|---|---|---|
| S1.1 | 用词表拼：shot/angle/move/scene/light/grade/texture | 全部命中 lexicon 合法键 |
| S1.2 | 动作段写"可拍动作"，不写情绪形容词 | 动作能被摄像机看见 |
| S1.3 | 场景锚与首帧一致 | 博物馆不许写 hall/torchlit |
| S1.4 | 零否定句 | 无 no/not/without/avoid |
| S1.5 | 过 `preflight_gate.guard()` | 返回空列表 |

**高发错误**：写 `no reflected face` 反而召唤出倒影；scene 用错把博物馆变神殿。
**工具**：`Tools/preflight_gate.py` + `prompt_lexicon.py`。

## S2 首帧

| 子步 | 做什么 | 判据 |
|---|---|---|
| S2.1 | 首帧来源确定 | 优先"成片该镜起始帧"；次选已验 KF |
| S2.2 | 2x 放大目检 | 无倒影脸/无多手/无文字乱码/无新增元素 |
| S2.3 | 身份核对 | 与角色库 ID 锚一致（发型/脸型/胡须） |
| S2.4 | sign-off 记录 | 写进 job 记录，缺记录不许烧 |

**高发错误**：首帧自带倒影 → 5 条 take 全废（本轮实锚）。
**工具**：Qwen-Image-Edit（`krea2_qwen2511_edit.py`）。

## S3 i2v 验证

| 子步 | 做什么 | 判据 |
|---|---|---|
| S3.1 | 480P 试烧 2–3 条 | 单条 ≤2min |
| S3.2 | 看方向：动作成立/人物不崩/背景不漂 | 三个 yes 才进 S4 |
| S3.3 | 不追求完美 | 480P 只做方向判断 |

**高发错误**：直接烧 768P 高清。
**工具**：ComfyUI(141.8k) + H3 工作流。

## S4 选优

| 子步 | 做什么 | 判据 |
|---|---|---|
| S4.1 | 烧前写判据（每镜 3–5 条） | 判据可量化 |
| S4.2 | 密集帧板（0.2–0.33s） | 脸零漂移 / 嘴部 ≥2 次开合 / 刻痕稳定 / 无新增元素 |
| S4.3 | 逐条打分，不凭感觉 | 记录哪条过哪条不过、为什么 |
| S4.4 | 同镜同缺陷连烧 2 条复现 | 立即 BLOCK，转换镜/换构图 |

**高发错误**：烧完才想标准；"看起来还行"就过。
**工具**：密集帧 + 多模态判读。

## S5 剪辑

| 子步 | 做什么 | 判据 |
|---|---|---|
| S5.1 | 生成 EDL（切点/时长/转场类型） | 切点吸附词/拍 |
| S5.2 | 每切点前后留 30–200ms | 不切字头 |
| S5.3 | 分段 extract → `-c copy` concat | 全片只编码一次 |
| S5.4 | 每切点 30ms 音频淡变 | 无爆音 |
| S5.5 | 跑 `release_gate.py` | 非计划硬跳 ≤5、孤岛=0 |
| S5.6 | 成片上逐切点 ±1.5s strip+波形 | 无断裂/闪帧/字幕被遮 |

**高发错误**：删帧修孤岛（时间轴位移，越修越糟）；全片统一 0.4s 叠化（人物叠影）。
**工具**：xxffmpeg + PySceneDetect(5.3k) + `release_gate.py`。

## 工具使用纪律

1. **先搜后造**：任何新模块开工前必须有一行"寻源结论"（有轮子=名称+星数+许可；无轮子=零适配注记）。
2. **试用必须落地**：拉下来 → 跑我们自己的素材 → 写结论（能用/不能用/替代哪个环节）。
3. **不许只学习不落地**：结论要么进闸脚本，要么进流程文档，否则视为未完成。
4. **许可证检查**：MIT/Apache/BSD 可直接用；GPL 慎用（分发风险）；商用不明的不进产线。
