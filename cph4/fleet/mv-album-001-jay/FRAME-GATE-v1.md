# 首尾帧闸 v1 + 提示词根因对照（2026-10-21）

> CEO 令：「尤其审核好首尾帧，这个错了视频一定错」＋「反复强调提示词的重要性」。
> 本件＝首尾帧闸的判据与签核 + **本轮实测结果** + **缺陷→提示词根因→强制条款** 对照表。

---

## 一、为什么首尾帧是命门

- i2v 是"从首帧往后长"：首帧带什么缺陷，全片这一段都带着（本轮 5 条 take 全复现倒影就是实证）。
- 尾帧决定下一刀的观感：尾帧若停在动作中段/半叠化/低信息状态，下一镜怎么接都跳。
- 因此：**首帧闸不过 → 不许烧；尾帧闸不过 → 不许进剪辑。**

## 二、首帧闸判据（每镜逐项，缺一不过）

| # | 判据 | 数值/形式 |
|---|---|---|
| F1 | 无镜面/玻璃**人脸**倒影 | 0 处（允许反光、反物、反手影） |
| F2 | 人脸完整、无崩坏 | 五官无错位、无多眼、无融化 |
| F3 | 手部结构正常 | 可见手指数与握姿合理，无多指/粘连 |
| F4 | 文字只出现楔形刻痕**或**中文字幕，不出现拉丁字母 | 0 处拉丁 |
| F5 | 首帧信息量足够 | 主体可辨认，非纯黑/糊白（黑场占比 <50%） |
| F6 | 身份锚一致 | 发型/脸型/胡须三项与角色库一致 |
| F7 | 字幕繁简统一 | 全片只用一种字形系统 |
| F8 | 与本镜功能一致 | 首帧能承担该镜"功能一句话" |

**签核**：R（角色）+ C（摄影）双签，D 复核。证据：2x 放大帧 + 本表逐项打勾。

## 五、缺陷 → 提示词根因 → 强制条款（这是本轮最关键的一张表）

| 实测缺陷 | 提示词根因 | 必须写进提示词的正向条款 |
|---|---|---|
| 玻璃倒影脸（16/17 镜） | 提示词写了 `glass display case` 且未限定玻璃上出现什么；否定句 `no reflected face` 反而召唤出脸 | 正向限定：`the glass carries only a soft sheen of the room light and the carved marks`（只描述"玻璃上是光与刻痕"，不提人脸） |
| 开场纯黑（镜 1） | 动作段只写"伏案写字"，未要求**主体可见**；首帧落在台灯边缘 | 加限定：`the man is clearly visible in frame from the first moment, the lamp lighting his face and hands` |
| 刻痕出现拉丁字母（镜 33 疑） | 只写 `carved inscriptions`，模型自由发挥出字母 | 必须写：`the inscriptions are wedge-shaped cuneiform marks pressed into clay`（正向锚定媒介与字形） |
| 繁简混排（26/31/32） | **不是提示词问题，是字幕资产问题**：ASS 里简繁混写 | 字幕单一真源：标题卡用繁体艺术字，正文一律简体（或反之），ASS 里逐字校验 |
| 唱歌嘴僵（历史问题） | 只写 `sings`，未规定口部动作 | `his lips shape each word, opening and closing several times` |
| 刻字闪烁（历史问题） | 只写 `carves`，未锁定字形稳定性 | `the carved marks stay fixed once cut, the wall pattern remains identical` |
| 场景被换成火厅（历史问题） | `scene="hall"` 用在博物馆镜 | 场景 token 必须与首帧一致；博物馆一律 `scene="museum"` |

**结论**：本轮首帧闸查出的 5 项里，**4 项能在提示词阶段拦掉**（倒影脸/开场纯黑/拉丁字母/唱歌嘴僵），1 项属字幕资产（繁简混排）。
→ 提示词闸必须增加"**正向锚定必备项**"，不能只检查否定句。

## 六、提示词闸升级（立即生效）

在 `Tools/preflight_gate.py` 增加**必备锚点检查**（缺一即拒）：

| 镜头类型 | 必须包含的正向锚 |
|---|---|
| 任何含文字/刻痕的镜 | `cuneiform` 或 `carved marks` |
| 含玻璃/展柜的镜 | `the glass carries only...`（玻璃上只有光/刻痕的表述） |
| 人物出场镜 | 明确的可见性描述（`clearly visible`, 主体+光位） |
| 唱歌镜 | `lips shaping each word` / `opening and closing` |
| 刻写镜 | `the marks stay fixed`（刻痕稳定） |

## 七、首尾帧闸的流程位置

- **S2（首帧）**：F1–F8 全过，R+C 双签，才允许提交 i2v。
- **S4（选优后）**：定片的**尾帧**过 L1–L5，E+D 签，才进 S5 剪辑。
- **S5（剪辑）**：每对相邻镜做"尾帧↔首帧"衔接判读（L5）。

→ 这三处是"视频一定错"的三个入口，任一缺失，后面全部白做。
