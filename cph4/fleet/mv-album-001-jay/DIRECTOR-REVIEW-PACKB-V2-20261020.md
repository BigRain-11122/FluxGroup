## 〇、本轮已判定的两件事（先清噪声，禁把假缺陷带进回炉）

**A1 音频真缺陷（已修，见 v3）**
- v2 实测：integrated **−12.4 LUFS** / true peak **+2.1 dBTP** / LRA 5.8（`ffmpeg loudnorm print` + `ebur128` 双证）→ **超 0 dBTP = 交叠削波**，手机外放会破音。这是全片唯一的硬技术缺陷。
- 修法=两遍式 loudnorm（I=−14, TP=−3.5, LRA=11，线上限幅 −3.5 dBFS，AAC 编码过冲余量留足），视频流 `-c:v copy` 零重编码：
  - 产物 `XQ-PACKB-ASSEMBLY-v3-c2157.mp4` 238.000s / 5712 帧 / 10247 音频帧
  - 复测 **−14.3 LUFS / true peak −2.2 dBFS / LRA 4.6**（ebur128 实测）→ 过 −14 LUFS ±0.5、峰值 ≤ −1 dBTP 双线
- 结论：**音频线 PASS（v3 起）**。

**A2「近黑死帧」是拼板假象（撤回）**
- 12 格 QC 条板判读曾报「119s 近全黑死帧」；按 X1950/2026-10-17 判例回归**原生分辨率**复核：119.0s 实为**借位剪影指星的夜戏**（手指指向画面唯一亮星点，75-85% 近黑但主体可读、无伪影）。
- 程序化定谳（4fps signalstats 全片 952 采样）：**无任何帧 YAVG<20**，最低 YAVG 27.44，均值 71.08；最长暗段 176.75s 处 6.25s（圣允蒙太奇夜段）。
- 结论：**该项撤回，不列为缺陷**；条板 JPEG q90 色相/亮度漂移误读，重申「眼闸 FAIL 先探针对拍」。

## 一、逐条修改指令（回炉单）

### R1 —— 歌名卡缺失（缺件·硬门）
- 现状：全片 40 段直切，**零字层**（装配脚本无 drawtext/ASS，`xq_packb_assembly_v2_c2156.py` 可核）。`TYPOGRAPHY-SPEC / R-20261013-mv-typography` 的「歌名卡必设计」未落。
- 修法：片头 0.000-3.0s 内做歌名卡——衬线（思源宋 SemiBold 系）+ **软暗投影**（禁硬描边）+ 0.25s/0.18s 淡入淡出；或压在 F0-01b 尾部（2.0-4.0s）。落 ASS 层 + `fontsdir` 显式，出片后**必多模态验字**（simsunb.ttf tofu 判例在案）。
- 验收：字层存在性 + 可读性 + 动画时长三查（CHK-T）。

### R2 —— 剪辑语言单一只剩硬切（CHK-E1 不过）
- 现状：装配件自述「straight cuts only」，40 段 39 个接点 **100% 硬切**；CHK-E1 要求剪辑语言 ≥4 类、硬切 ≤70%（程序计数）。
- 修法：本轮不加新素材，只换接法——在**情绪转折点**开 3 类转场：①叠化（如 4.0s 磁带→路景、232s 进尾板）；②虚化过渡（S3-20 夜段进出）；③动势硬切改「同向运动接」（S1-07→S1-08 已在，点名保留）。目标分布：硬切 ≤70%（≤27 个）、叠化 ≥6、虚化 ≥4、动势接 ≥3。
- 验收：剪辑语法表程序计数 + 逐接点截图对。

### R3 —— 片头信纸手写字是伪中文（焦点道具·必改）
- 证据（0.5s 原生帧）：纸面为**不可读的伪字**，笔画堆叠不成字；红字印刷同为糊块。信纸是片头焦点道具，中文观众一眼识破。
- 修法：二选一——①重生成 F0-01a 只留「手+纸边+笔尖」的浅景深特写（字面虚化出焦，规避可读性）；②改用可读短句（真实中文书写）+ 出图后 OCR/多模态验字。**禁**继续让伪字落在焦平面上。
- 验收：原生帧焦平面多模态验字 PASS。

### R4 —— 30.4s 云中「行走人形」读作拼上去的（中）
- 证据（30.4s 原生帧）：天空白雾恰好长成**迈步人形**（头/躯干/双腿俱全），无地面接触、无投影、雾密度近地反向（比地平线亮光更深）、无落日暖边、轮廓有光晕且颗粒被抹平——四条独立穿帮。
- 判读：MV 里作奇幻元素可接受（边缘软、色调合），但「太像人」会读成 AI 走神。
- 修法：重渲或换该帧——云形去人形化（打散为絮状/风蚀状），加落日侧暖透光，让雾在地平线处被空气透视洗淡；若保留人形则**明确叙事能指**（谁在走）并给足时长让观众接受。
- 验收：原生帧 + 播放态双查「不再像贴纸」。

### R5 —— 尾板磁带机芯读作非实物（需工艺保护·可不重烧）
- 证据（218.5s 原生帧）：实为**磁带（VHS 型）微距**，非摄影机/放映机——年代上更对（家用录像带/MTV 文化），但与「机芯」口径不符；机芯无第二盘、纸标签立在不该立的平面、轮齿融化。
- 判读：作尾板背景**可用**，条件是「压暗+颗粒+标题压字覆盖」。静态亮画面下细心观众 10-15s 内会看穿。
- 修法：尾段（218-238s）统一加暗部 crush + 16mm 颗粒 + 轻微门闪；子幕/字卡必须压在这块负空间上；**禁**切到更亮更清的同一镜。
- 验收：尾段三帧原生帧复核 + 成片亮度曲线不抬头。

### R6 —— 待确认项（不阻塞，但要回话）
- 蝴蝶品种（excerpt 末帧）非台湾紫斑蝶；若词义指向「蝶」意象，建议换紫斑蝶或做剪影弱化。
- 服装连续性：30s 段暗色上衣 vs 53s 段白 T——若是同日同程（自行车旅程单线），需给换装理由（时间跳跃字层/场景转场明示），否则读作连戏错。
- 蒙太奇窗 172-186s 为圣允 6 个 56 帧循环（S5-26/27/28 ×2），6.25s 暗段（176.75s 起）在手机小屏有「糊住」风险，建议窗内补一个暖调短镜或提亮 1-2 IRE。
