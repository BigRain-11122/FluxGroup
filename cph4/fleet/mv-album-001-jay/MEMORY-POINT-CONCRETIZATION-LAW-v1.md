## 一、三条法条

### 法条 1 · 记忆点考古先行（禁凭印象）

每曲进入剧本 vN 前，必须产出**记忆点考古表**（模板见 §三），四源取证、逐条带出处：

1. **受众第一金句**：跨平台独立复现 ≥2 处才可列为承重（出处写平台+标题/ID）。
2. **原版 MV 直接记忆锚**：画面/表演/造型/场面层面的具体记忆（导演、女主、标志性镜头），须有 ≥2 源或 4K 修复版画面直证。
3. **结构记忆点**：全曲最被反复致敬的段落（如《龙卷风》C 段「不知不觉→后知后觉」四字递进、尾奏渐弱）。
4. **时代物证**：受众反复提到的物件/场景（单车后座/双伞/复读机/同桌/草丛小屋），**这些是记忆点不是装饰**。

禁止用「我觉得观众会喜欢」替代证据；无证据的记忆点一律标 `待采证`，不得作为承重镜。

### 法条 2 · 三档具象化（脑中记忆 → 画面上必须看得见）

每个记忆点必须落到**可拍摄的具象形态**，三档任选其一并写明档位：

| 档 | 定义 | 例（《简单爱》单车后座） |
|---|---|---|
| **A 同框证物** | 记忆物与人物同框，观众一眼认出 | 后座绑着书包、她侧坐、手抓车座边缘 |
| **B 动作化** | 用动作把记忆点演出来（不是摆拍） | 上坡时她下意识抓住他腰侧衣角 |
| **C 环境化** | 记忆点作为世界的一部分反复出现 | 车铃、链条声、路面颠簸进音轨对位 |

**硬门**：每曲 ≥3 个记忆点完成具象化，且每个记忆点必须挂到具体 `shot id`（分镜表列起）——未挂镜=未完成。

### 法条 3 · 出戏闸（CEO 原话「不要自己太出戏」）

「出戏」= 观众从作品世界被拽出来。以下七条任一命中 = 出戏，回炉：

1. **世界错位**：材质/年代/地域与本曲世界不符（水墨/织锦类中国风套 2000 年台北校园）。
2. **记忆点被替换**：把大众记住的东西换成自己的设计（原版是「单车后座」，改拍成「地铁座位」=出戏）。
3. **人物不像那个人**：女主气质跑偏（清纯初恋脸→性感御姐）、主角年龄/身份与受众共识冲突。
4. **字面直译**（LYRIC-IMAGERY-LAW 已禁）：歌词有直升机就拍直升机。
5. **梗越界**：把戏谑梗当立意（《龙卷风》「快」的梗只能做文案彩蛋，不能做叙事轴）。
6. **叙事断裂**：镜头之间没有因果，靠字幕/歌词硬接（本律要求叙事与逻辑自洽：谁想要什么、为什么现在、付出了什么）。
7. **工艺抽离**：模型崩坏、字面漂移（纸飞机渲染成真客机）、穿帮（耳机/手机年代错位）。

**判据归属**：七条由导演席自审 + 受众心理席独立复核；L2 老粉「3 秒认得出」为最终外部刻度。

## 二、叙事与逻辑（CEO：「写好叙事和逻辑」）

记忆点不是拼贴。每曲剧本必须给出一句话的**叙事骨架**，且满足：

- **因果链完整**：起点欲望 → 阻碍 → 至少一次代价 → 落点（与歌词情感曲线同向，不允许镜头情绪与词义相反）。
- **记忆点服务叙事**：每个记忆点出现时，必须回答「此刻它为什么在这里」（例：双伞出现=她第一次接受他的庇护，而不是「因为歌词有雨」）。
- **不拍已发生的结果**：受众记住的往往是过程（"学着放弃"不是"已经放下"；"后知后觉"不是"风暴来袭"）——落点错位=出戏 6。

## 三、必携件（进剧本 vN 的门）

| 件 | 内容 | 门 |
|---|---|---|
| M1 记忆点考古表 | 四源取证 + 出处 + 承重/点缀分级 | 缺=禁进剧本 |
| M2 具象化落镜表 | 每记忆点→档位→shot id→「此刻为什么在这里」 | 记忆点 <3 或未挂镜=打回 |
| M3 叙事骨架一页 | 欲望/阻碍/代价/落点 + 与歌词时间轴对齐 | 因果缺环=打回 |
| M4 出戏自查单 | 七条逐条打勾（自查人+结论） | 任一未过=禁烧 i2v |

与既有四件套（意象转化表/四方联审/帧批复扫/导演签字）合并为**八件套**，同批归档。
