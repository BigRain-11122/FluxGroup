## 实测结论：装配层修不好这个问题（ASSEMBLY-CANNOT-FIX）

1. **尺度确实拉开了，但闸不变**：纸飞机包围盒宽度标准差 0.0951→0.1263（+33%）、极差 0.309→0.384；可母题闸判据是「plane-dominant 单数在 30s 内 ≥2」——推近后六单仍全部过 area≥2% / bbox≥16% 线，**SUSPECT run 仍为 6 单，判读完全一致**。闸对尺度不变，所以「推近」永远清不掉这条红旗。
2. **推近把问题放大了一点**：飞机占画面比从最高 6.6% 升到最高 9.4%，同一主体占的画面更大，同时城市信息被推进裁掉一部分——这是反效果的方向。
3. **镜像只改飞行方向，不改「又是它」**：隔单镜像确实让左右朝向交替（cx 极差 0.065→0.122），但观众读到的是「同一架纸飞机又来了」，不是「换了一个镜头」。
4. **病根可用数字钉死**：41.28 秒的块里，六单飞机合计 **32.62s＝79%**，块内非飞机素材只有 KN08(5.18)+KN09(2.20)=**7.38s**。所以任何删单方案都会留洞：
