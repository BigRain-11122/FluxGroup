# MV 认知基座 CANON-v1（2026-11-03）

> 这条线（bigstream-mv）的唯一认知入口：新会话先读这里，再读工序与闸。
> 只写结论与判据，数字与来源见文末指针（不复述正文）。

## 一、这是什么

- MV = **整片交付**：一首歌一条片，角色跨镜一致、转场是 MV/电影语法、四闸全过才能交给客户。
- **不是**：单镜头素材包、模板化快出、PPT 式图集。竞品都在做单镜，我们做整片。
- 唯一卖点：**整片一致 + 过闸可发**。客户买的是"能直接发"，不是"能再改的素材"。

## 二、市场事实

1. 传统档位贵：DIY 500–1500 美元；独立专业 2000–8000 美元；制作公司 1–5 万美元。
2. AI 工具已规模化（月费 8–27 美元、单支 credits 100–200 美元），但只解决单镜——整片仍要人工拼。
3. 空档在"跨镜一致 + 逐镜闸 + 可交付证据链"，这三件正是我们的产线强项。

（来源与链接：`cph4/fleet/market/bigstream-mv.md`，抓取 2026-11-03）

## 三、头部在做什么

- 单镜质量已不是壁垒；壁垒是**跨镜人物不漂**、**转场不出戏**、**逐镜可挑错**。
- 客户验收方式很朴素：静音看一遍，主线是否成立；有声音再看一遍，节奏是否成立。

## 四、我们曾经错在哪

- 把"修复"做成裁切放大（1.34x 推近）→ 被判抖音式放大，已全部撤回；重复镜只能重烧或换素材。
- 只用零件绿灯交付（某函数对不对）→ 用户一眼看出的问题闸没拦住；改法=观众级四件（逐镜/转场/稳定性/静音复述）。
- 日更闸卡指旧母版（v717）→ 每 5 分钟白跑一次，验的是错文件；卡必须指当前母版。

## 五、交付判据（机器可测，缺一不给客户）

| # | 判据 | 阈值 | 判在哪 |
|---|---|---|---|
| 1 | 交付闸 | VERDICT=PASS（重复上屏/近静止/死镜/接缝/冻结全 0） | mv_delivery_gate |
| 2 | 转场 | OPPOSE=0（逐切点方向余弦） | mv_transition_audit |
| 3 | 稳定性 | seam=0、freeze=0 | mv_stability_gate |
| 4 | 逐镜 | 暖度/饱和/运动/重复镜全部申报 | mv_full_audit |
| 5 | 观众级 | 静音看全片能复述主线 | 导演席签字 |
| 6 | 设计卡窗 | 片名卡/片尾出处卡必须先声明 `--card start:end`，否则 D2 必假红 | canon 声明 |

## 六、工序（机器可派的段，id 与工序表一字不差）

全表在 `cph4/fleet/ri/content/lines/mv.json`；两处不一致 `line_canon.py` 直接判 FAIL。

```
gate        交付闸：重复/静止/抖动/闪烁（强制 --card 卡窗）
transition  转场审计：逐切点方向余弦，OPPOSE 必须 0
stability   稳定性闸：seam / freeze 双 0
shot-audit  逐镜体检：暖度/饱和/运动/重复
packet      导演席拉片包：一页卷（成片+四闸+签字位）
accept      质量验收：缺一份闸回执就不算交付
```

MV 段白天不跑（本机白天让路），工序表用 `day_ok=false` 声明，只夜间窗执行。

## 七、成本与报价

- 我们的位置：每分钟 2–3 万元人民币级精品（对应海外独立专业档 2000–8000 美元/支）。
- 成本口径用**成片率**算，不用模型跑分；单支人工拼装 5–15 小时是竞品现实，我们的产线要靠闸把这段压下来。
- 对外只报"每分钟"口径，不承诺播放量。

## 八、失效条件

1. 连续 2 支片交付闸 FAIL 且原因同类（一致性/转场/重复镜）→ 停线修工序，不接新单。
2. 单支真实工时连续 2 个月高于报价可覆盖 → 停售该档，重定工序。
3. 客户连续 2 次退回同一问题 → 按退回项改判据，不解释。
4. 母版换代后闸卡仍指旧文件 → 立即停日更闸，这类错误会让报表全绿而实际没验。
