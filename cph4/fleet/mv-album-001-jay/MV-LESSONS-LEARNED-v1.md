## 一、人物与脸（最贵的坑）

| 教训 | 根因 | 已落的闸 |
|---|---|---|
| **纯文字描述脸买不到「像」**，天花板 7 分 | 类型词能买"是什么款"，买不到"是谁" | 走 LoRA 身份锁（jman）+ 骨相锚；≥9 才算锁住 |
| **参考图会把后期特征一起吸进来** | 官方参考图自带水印/字幕/马赛克，edit 类节点逐像素渗入 | 参考图必须过「无文字无特效」检查（v729 三张图全废实录） |
| **单人脸+暖光 = 一定看镜头**（J-24） | 模型先验：单主体暖光正脸镜必对焦观众 | 改背影/侧脸/手部；或双人构图；眼睛闭着也照样中招 |
| **手部四指粘连** | 手指数是高频缺陷 | 手部写死"食指单伸、其余四指收进掌心、手呈侧面"；或改构图避手 |
| **暗光遮挡下"看不清"被误判成"换人"** | 缩略图/低照度判读不可靠 | 换独立通道（多模态/逐帧）复核再下结论 |

## 二、文字与"必须是真的东西"

- **「必须是真的」内容不许交给文生图**（v730 石碑伪楔文实录）：模型把 `cuneiform` 当质感词，画出蝴蝶结状伪纹样。
  正法=先生成**真实像素**（真 Unicode 字表渲染）→ 再用 i2v 只加物理运动。
- **歌词具象名词必须意象转化**（J-23）：「直升机」→ 纸飞机；且**渲染层也会漂移**（纸机被画成真客机，舷窗金属漆）。
- **招牌/报纸/屏幕/书页** = 伪文字高发面，提示词里禁描述文字内容，画面用"clean unlettered surfaces"。

## 三、表演（AI 最薄弱）

- **写动作，不写情绪**：`he looks sad` → `his jaw stays set while his throat moves once`。
- **禁字面化**：叹气/大口呼吸/胸腔起伏**不许拍脸**（CEO 11-08 令）——用环境承载（水面晃/窗帘动/白气散）。
- **反应要有延迟**：先接收→后处理→再反应；同帧反应=AI 签名。
- **一镜一意图**：一镜两个意图=两个镜；一镜 1 主情绪 + ≤2 微手势，三个以上必抖。
- **短镜不演弧**：<3s 只给动作；4-6s 给一个完整微弧；8s+ 给"弧 + 一次回摆"。

## 四、构图与 i2v（生成端）

- **i2v 档位墙**：141 帧（5.9s）档保不住首帧构图（XQ19 并肩同坐被改成背靠背）；**压到 73 帧（≈3s）** 稳。
- **本机 16G 卡烧不动 >10s 的单镜**（实测三次压死 ComfyUI）——长镜必须拆。
- **krea2(12.24G) + qwen3vl_4b(4.88G) ≈ 17.1G > 16G**：默认模式跑到第 3 帧进程直接消失；
  正法=ComfyUI 起服 `--lowvram` + 步数 6，实测**更快**（22s/帧 vs 60s/帧）。
- **提示词词数预算**：STYLE 放句尾会被 CLIP 截断 → 画风漂移；须设总词上限并**优先保 STYLE**。
- **首帧若读作"模型摆拍布景"**，768P 直烧必崩 → 先 480P 验构图。
- **同首帧连续两版判负 → 第三版必须换首帧**，禁再换量化/种子空烧。

## 五、服装 / 调色 / 节奏（CEO 亲自抓过的三条）

- **服装（J-22）**：素 T 无配饰=路人感判负；必须落 2000 台式流行带（水洗牛仔外套+图案T+银细链+皮绳手环+腰系格纹），反韩化锚不破。
- **调色（J-21）**：每曲独立调性，禁共用默认链；暖橙一统已被推翻 → **分段调色**（黄中平线/邝盛线/古巴比伦琥珀/博物馆青灰）。
- **节奏（10-19 令）**：主歌 **2-3s 一镜**（硬上限）、副歌踩鼓点、前奏空镜留长、尾慢收；**匀速=AI 感判负**。

## 六、装配与交付（技术坑）

| 坑 | 正法 |
|---|---|
| `fade` 的 `st` 是**绝对时间戳**，`-ss` 后仍看源时钟 → 整段黑 | 链头加 `setpts=PTS-STARTPTS` |
| 单遍 `loudnorm` 保不住真峰（实测 -13.2 LUFS/+2.3 dBTP 削波） | 两遍 loudnorm + 限幅 + 出片自检 |
| 60fps 母版的静帧判据没归一 | 阈值按 `24/fps` 缩放 |
| 4K 3840×2192@60 超 H.264 L5.1 宏块率 | 显式声明 L5.2 |
| 中文字幕字体 tofu / 缺字 | 衬线降级序 思源宋→simsun.ttc→simhei；**生成后必须抽帧验字** |
| `ass=...:fontsdir=C:/...` Windows 上必炸 | 选项值整体单引号包裹 |
| 长镜/长批在会话里跑会被 5 分钟无输出取消 | pythonw 常驻 + 日志重定向；SKIP 断点续跑 |

## 七、闸与流程（治理面）

- **假阳性长期豁免 = 把闸变成噪声源**：12 份回执全 FAIL 却每次人工豁免，等于没有闸。正法=**只修判定，不长期豁免**。
- **子串匹配 = 假阳性制造机**：`silver-templed` 命中 temple、`piano room` 命中 `no `——场景锚/否定词一律用词边界正则。
- **缺专家的环节 = 返修出生地**：V5.4→V5.9 一日六版，①剪辑 ⑤版式 ⑥表演三席当时缺位。
- **修复轮预算**：呈 CEO 后修复 ≤2 轮必须到可呈态，第 3 轮前强制根因停线。
- **能机核的不靠人记**：预算（空镜/近特/主体）、镜长分布、服装锚、情绪副词、ID 块一致性——全部可程序化。

## 八、根因归纳（一句话）

> 过去所有的返修，**九成不是"模型不行"，而是"该在出生地拦的没拦"**：
> 该在提示词层写的（服装/表演/意象）没写 → 烧出来才发现；
> 该在设计层算的（镜长/空镜率/预算）没算 → 装配才发现；
> 该在闸里判的（假阳性/子串）没判准 → 闸失灵，只能人工豁免，豁免多了就没人看。

**所以本轮起的铁序**：要求表 → 分镜预算自检 → 过闸 → 烧 → 群审 → i2v → 调色量测/盲评 → 装配 → 成片闸。
每一站都有机器判据，不达标出不了站。
