# KN 768P 出生站闸门 C2177：闸门生产件补登记 + KN18-KN20 首检

## 本轮做了什么

C2171 立了「声明运镜 vs 实际推拉」闸门、C2176 把它的判决和帧摆在一起，但**生产脚本从来没进过仓**：
它是一次性临时脚本，跑完就没了。后果是波形每多落一个单元，闸门就少管一个单元，而且没人能重跑它。
本轮把它重建成入仓可重跑件 `kn_framing_drift_gate.py`，并对已经落盘的 20 个单元全量重跑。

## 换了量法，以及为什么

C2171 用的是「以帧0为参照做中心裁剪搜索」，我原样移植后**复现不出它的数**：KN17 它记 2.30x@10.0s，
移植版每一帧都只在 1.00x 取到最小残差。原因很直接——这类镜头里主体在动，中心裁剪匹配只在内容静止时才成立；
它那个 2.30x 落在片子末尾的空镜上（resid 23.25），量到的是低纹理噪声，不是机位。

改建改用 **Fourier-Mellin 对数极坐标相位相关**：幅度谱对平移不变，主体移动不进入测量，推拉体现为对数半径轴的位移。
再加两件：时间轴中值滤波（宽度5）杀掉低纹理帧上的孤立尖峰（原序列里出现过 4.91x、3.21x 这类明显失手的读数），
以及**±0.25 超出即标 unstable**。

判决口径保持不变（locked >1.15x = FLAT；push <1.10x = FLAT），但 push 的 FLAT 只在「稳定且 ≤1.03x」时下，
落在中间的记 **UNDECIDED** 交眼睛板。理由：这套估计器在内容重的镜头上噪声底就是几个百分点，
在这个底上判 FLAT 等于把旧闸门漏掉的量换成新闸门造的假阳性。

## 回归结果

对 C2171 有判决的 7 个单元（KN11-KN17）逐条重算：**verdict 差异 0/7**。

| 单元 | 声明 | 本轮实测 | 判决 | C2171 |
|---|---|---|---|---|
| KN11 | push | 1.00x | **FLAT** | FLAT |
| KN12 | mobile | 1.01x | NOT-JUDGED | NOT-JUDGED |
| KN13 | locked | 1.00x | PASS | PASS |
| KN14 | mobile | 1.00x | NOT-JUDGED | NOT-JUDGED |
| KN15 | locked | 1.00x | PASS | PASS |
| KN16 | pull | 1.00x | NOT-JUDGED | NOT-JUDGED |
| KN17 | push | 1.16x（原记 2.30x） | PASS | PASS |

数值不同、结论相同；KN17 的 1.16x 还带着一条单调爬坡（1.00→1.16 全程递增），是能站住的推。

## 新落的三个单元（本轮首检）

- **KN18**：声明 lateral slide（mobile，不判推拉），字幕带 PASS（cov 0.00）。画面是暖色光丝纤维材质。
- **KN19**：声明 travel alongside，PASS（cov 0.06/narrow 0.00）。画面＝纸飞机＋金色星点。
- **KN20**：locked，实测 1.00x 稳 → PASS；字幕带 cov 0.41 但 narrow=0.00 → PASS（带内亮块不成条，非烧字）。

三道闸（字幕烧字 / 运镜推拉 / 帧组成）本轮均无新增 (红)。

## 板面看出来的东西（机械闸管不到的那一层）

看 `KN-768P-GATE-BOARD-1-c2177.jpg`：

1. **KN17 全片没有主体**。三帧取 0.4s / 5.42s / 10.48s，分别是暗星野、银河弧、暖云——从头到尾只有天空。
   C2176 记的是「尾帧空镜」，实际是整条空。字幕闸 PASS、运镜闸 PASS（1.16x 推在星野纹理上），
   **两道机械闸全放行**。这不是闸门判错，是闸门没有这一面：出生站没有「声明主体是否在画」这道检查。
2. **纸飞机母题又出现了三次**（KN11 / KN19 / KN20），和 C2174 量到的「同一道具占 41s 块 79%」是同一条线。

结论：下一个该补的闸不是运镜，是**主体在位闸**（声明主体是否出现在采样帧里）。在此之前，KN17 这种件
只能靠人眼看板子拦，而板子是人做的环节——这正是「缺陷出生地拦截」要消掉的那种依赖。
