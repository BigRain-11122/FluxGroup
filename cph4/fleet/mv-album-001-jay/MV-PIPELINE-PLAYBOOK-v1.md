# MV-PIPELINE-PLAYBOOK v1 — MV 前后全链条工作流方法论（41 曲产线通用）

> 溯源：CEO 令 2026-10-15「好好理顺一个MV的前后生产链条和工作流，形成方法论，以后就快了」+「人物的表演也是硬伤…还不够精品，更不够top1」（O-20261015-1655·承 O-20261015-1700 后三波深研收口）。
> 定位：**链条总图**——把已立的全部闸/律/规格按生产顺序串成一条可复制流水线（每站=输入→动作→闸→产出→并行车道→提速杠杆）。本件只做流程编排与指针，**法条正身各归其典**（禁复述立法·查重律）。
> 消费面：每曲开工=S0 起跑；每站出口判据不过=禁进下站。41 曲滚动排产按此执行（星晴为 v1 首个全链试点曲）。

```
S0 曲目包 ─S1 立意剧本 ─S2 分镜四案 ─S3 KF 生产 ─S4 i2v ─S5 表演增强站 ─S6 装配 ─S7 画质链 ─S8 成片闸+发布 ─S9 复盘
   │           │            │            │         │          │            │          │            │
 词面校准    开工闸①-④     分镜审     提示词闸    视频闸    (新·选装)    装配检      成片闸       判例回灌
                                                     ↑                                        ↑
                                              帧闸(白名单签章)────────────────────────────→CEO 终审（唯一终点）
```

## S0 曲目包（1-2h·CPU·bm-a）
- **动作**：官方歌词双源落盘（lyrics/）→音源 ape→320k 转码→whisper 行级锚点→`lyric_calibration.py` 对齐（词面正身=官方·时序=whisper/LRC·无锚行标 [approx]）。
- **闸**：词面校准批验收（精确/approx/无锚计数落锚）。
- **产出**：anchors/<曲>-calibrated.txt/.json。**并行**：S0 与 S1 调研波并行（双轨律）。

## S1 立意剧本（开工闸①-④·CEO 零卡点=导演席定稿）
- **动作**：六轴逐句表→受众包（AUDIENCE-VOICE v1.1·≥6 角色面强制）→立意案（意象转化表必携·LYRIC-IMAGERY-LAW）→剧本 vN。
- **闸**：①剧本审（六轴/因果链/留白）②受众审（≥6 角色面实锚）③年代语法（ERA-MV-GRAMMAR 七律）④十席盲评 ≥9。
- **提速**：调研波（导演工艺/体裁矩阵/标杆）先行并行派单——立项即派，不等剧本。

## S2 分镜+四案（导演席+专席签字）
- **动作**：SHOTLIST（窗长 2-12s 散布·每镜运镜五槽 CAM 公式）+四案必携：选角案（CASTING-LAW·每曲独立 ID）+GRADE 案（GRADE-LAW·分曲调性）+WARDROBE 案（WARDROBE-LAW·年代衣橱+反韩化锚）+道具年代锚清单。
- **闸**：分镜审（先思后唱律/运镜考究四答/镜头预算表）+道具/调色/服装三席独立签字。
- **产出**：SHOTLIST-vN + 四案（无四案=禁开 KF）。

## S3 KF 生产（提示词闸+帧闸·GPU 主力 bm-c）
- **动作链**：词表组装器产 prompt 包 → lint 机核 → **提示词专家审闸**（PROMPT-EXPERT-GATE 十面·逐镜 verdict+改写稿·无 verdict 派单=烧制侧拒收）→ 导演席签发 → 试构图 672×384×4 种子看板 → **选汰律决赛圈**（重要镜种子 N≥8 取 2——世界第一差距①工艺差：Dor 50:2 选汰强度·R-20261015-mv-worldclass-benchmark）→ 正档 1344×768 → 十席两波帧审（≥9/席·任一 <7 回炉）→ **白名单签章**（签章后才准 i2v·帧闸铁律）。
- **提速**：试构图档 8 步/张（~10 分钟看板）；修复批=外科局部编辑优先（同病二连 t2i 重烧禁盲烧）。

## S4 i2v（视频闸·GPU bm-c 主力/bm-b 480P 备援）
- **动作**：白名单 KF→i2v 提示词包→**过提示词闸**→480P 短验（新镜型 2-3 分确认运动/主体/零崩）→INT8 768P 正片（批前抽检 2-3 条代表系→其余直烧·队列驻留律）→每 5 条回执+3 帧自检。
- **闸**：视频闸（逐镜画质/运镜执行/AI 崩坏）+asm_preflight 覆盖断言。
- **坑律**：起帧对抗动作禁写（要改先改帧·D1 律）；事件改状态（P-01）；低清验证件按 animatic 归档不入正典。

## S5 表演增强站（NEW·选装·根治「表演生硬」CEO 令）
> 正身=R-20261015-mv-performance-stack（工具栈选型+license+显存全档）·本节=流程位。
- **前置资产**：**表演参考片库**（真人歌手特写/口型/舞段参考片——工具之外真瓶颈·随曲建库·S1 期立项）。
- **口型站**（唱词镜）：LatentSync v1.5（8G·中文优化·bm-a 可跑）/v1.6（18G·bm-c 16G 夜窗）——成片后用人声干声重绘口型区。
- **表情迁移站**（特写表演镜）：LivePortrait（19.2k★·MIT·商用前须换 InsightFace 检测模型）——真人参考片表情/眼神/头动整体迁移到 KF 脸。
- **舞段/身体站**（表演段）：MimicMotion（72 帧档 bm-c 16G 正命中·bm-a 用 16 帧档）/MusePose 对照——姿态参考片驱动 KF 全身。
- **prompt 侧配合**（提示词闸 L 面）：情绪禁标签词→微行为外化链（低头+肩膀微颤+攥紧衣角式）；表演弧线镜间连续；参考片驱动镜=提示词只写增量。
- **排产**：重扩散活=夜窗 bm-c；夜窗试跑单三夜回填（10-16/17/18·R 件应用表）。

## S6 装配（CPU·bm-a 装配站）
- **动作**：asm_preflight（云引用计数=0 断言·全本地产单）→词级锚点字幕（思源宋体词级卡点）→**自动拍点**（librosa beats.json：BPM/downbeats→剪辑点吸附·最短镜头护栏 0.6-0.8s·副歌逐拍切/主歌 2 拍 1 切·人工锚校验位防半拍倍速误判——beat_this 备选）→xfade 单叠化→540P 代理预览剪（veryfast）→768P 终版全链精压。
- **闸**：装配检（桥长算术/音淡出词尾锚/调色→暗角→颗粒序/收片命名律/帧数断言）。

## S7 画质链（NEW·发行级收尾）
> 正身=R-20261015-mv-worldclass-benchmark §三（画质天花板配方）。
- **upscale**：Topaz Proteus 4K 主选（三源优化明含 AI-generated video·A 源）/Real-ESRGAN x4plus+GFPGAN 免费备选（动画线=AnimeVideo-v3）。
- **分曲风 LUT**：七套色向（慢板台式奶黑/中国风泛黄水彩/说唱高饱和/摇滚高反差单色/电子霓虹冷/悲情冷暖分离/快歌撞色——直取 genre-matrix 色彩列）。
- **颗粒遮瑕层**：16mm 颗粒=遮瑕武器（SIL4 破裂镜急救序=先颗粒掩再谈重生成·Dor 判例）——2001 曲风默认 35mm 细颗粒档。

## S8 成片闸+发布（CEO 终审=唯一终点）
- **闸**：成片闸（十席全审+盲评 ≥9+三律自审 <9 不过+年代穿帮三面+匀速/morph 程序化审计+音轨 -an 剥离断言）→ **CERTIFIED 才呈 CEO**（中间态零呈审纪律）。
- **发布**：AIGC 开门帧显著标识+平台勾选+双规格（横竖版决策·PUBLISH-CHECKLIST）+发布文案（讹传勘误表+禁真名红线）。

## S9 复盘（判例回灌律）
- 每闸收口→席位回报判例→EXPERIENCE-LEDGER 追加行（病→例→闸→日）→**判例必须落闸**（检查单→lint→QC 检项→脚本断言·能机核不靠人记）→复发=闸失效当窗升格。

## 并行车道图（三车道令）
- **云道**：参考组/多模态参考批（Seedance 2.5·配额窗内并行全量·>500 积分闸）。
- **本地 GPU 道**：bm-c 16G=KF/i2v/表演扩散（口型 v1.6/舞段）夜窗主力·bm-a 12G=480P 验证+口型 v1.5+装配站。
- **CPU 道**：S0 词面/S6 装配/S7 LUT/卡点（librosa）——24/7 与 GPU 零抢。
- **CEO 用机让路**：bm-a 工作日 09:00-19:00 pauseLite（AutoYield·machine-state v6）——重活全排夜窗+他机。

## 提速杠杆清单（「以后就快了」正身·每曲滚动复用）
1. **资产复用律**：参考片库/ID 块/LUT 套/词表锚词/判例库——每曲结束归库，下曲直取（禁重复造轮）。
2. **选汰律**：重要镜 N≥8 决赛圈（生成后策展范式）——一次性把构图选对，后段零返工。
3. **批前抽检+队列驻留**：同配方先烧 2-3 代表系过审→其余直烧（模型驻留连烧禁逐条重载）。
4. **代理档**：审看=540P 代理/480P 验证/q88 抽帧板——高清只烧一次。
5. **修复优先序**：外科局部编辑→换种子→换配方重烧（禁盲烧·重烧先 480P 复验）。
6. **闸前置**：提示词闸在烧制**前**拦语义病（烧后返工=10 倍成本）——CEO 效率令正身。
7. **正典包随单**：每站产出件=下站输入件（四案/白名单/verdict/beats.json 全链咬合·缺件禁开站）。
