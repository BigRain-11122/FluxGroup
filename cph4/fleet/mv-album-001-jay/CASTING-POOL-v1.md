## 一、怎么用（开案四步）

1. `python Tools/mv_casting_pool.py assign <曲名>` → 拿候选族（本曲已登记适配族）
2. `show <族id>` → 读四锚点预算与禁项，写进该曲选角案
3. `prompt <族id>` → 出自包含提示词（无真人名），据此烧候选板
4. 出片后硬闸：反向三问全 NOBODY（原文留档）→ 跨曲 cosine<0.4 → 同曲跨镜≥0.5 → 四锚点偏差≤5%

提交提示词前必跑 `python Tools/mv_casting_pool.py lint <提示词文件>`，命中真名即判负。

## 三、四锚点的用法（不是形容词，是比值）

每族预算写在 JSON `structure` 里，四项可机测：**眉形（眉峰位/眉尾斜率）· 眼距（瞳距/脸宽）· 鼻翼宽（/脸宽）· 唇形（上下唇厚比+口宽/脸宽）**。

判据：新脸相对**本曲族均值**至少 2 项偏离 ≥8%，才承认是独立脸；定脸后 468 关键点复测，与预算偏差 ≤5%。

## 四、合规三闸（机器可测，缺一不烧）

1. **名字隔离**：`mv_casting_pool.py lint` 全仓扫，真名/「同款」/「in the style of」命中即 FAIL
2. **反向识别**：同帧三问全 NOBODY，三答原文写回执
3. **独立脸**：四锚点 2 项 ≥8% 偏离 + 跨曲 cosine<0.4
