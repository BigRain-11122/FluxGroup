# MV 条线六席自主学习派工（2026-10-20·CEO 令「相关的技能和智能体或者经验，MV生成条线 各自去调研学习」）

> 背景：`cph4/skills/` 现有 MV 技能仅 `tw-mv-director`（导演席）+ `bigstream-expert-panel`（十席评审）；**调色/灯光/道具/剪辑/表演/选角 = 只有席位名，无技能、无独立学习件**——这是「席位存在但不会长本事」的结构缺口。
> 本批=六席各出一份学习件 + 一条技能补丁建议；产出落 `mv-album-001-jay/research/SEAT-<席>-20261020.md`。

## 一、统一交付规格（每席 ≤70 行·缺项=退回）

1. **本席 AI 病灶三条**：我们片子里真实出现过的失败（能给镜号/现象）
2. **可执行工艺 5-8 条**：每条=一句判据 + 一句怎么做（禁「要更自然」这类空话）
3. **来源分级**：A=一手（官方文档/导演原话/原片逐帧实测）｜B=二手可靠｜C=单源存疑；**GitHub 优先**（有现成轮子写名称+星数+license，无轮子写「无适配」）
4. **落到在产四曲的具体镜**：星晴/可爱女人/龙卷风/简单爱，每曲至少 1 条能立刻改的
5. **验收判据**：可机检或可盲评，不许「凭感觉」
6. **禁用清单**：本席必须避开的 AI 味写法/做法

## 二、六席分工

| 席 | 学习靶心 | 强制输入 |
|---|---|---|
| 表演指导 | AI 演员的意图/反应延迟/情绪弧；FACS-AU 校准 | `AI-ACTOR-PERFORMANCE-v2.md`、`PERFORMANCE-SPEC-v1.md` |
| 摄影灯光 | 2000 台式光比/单光源/夜戏/肤色；机位与动机 | `CAMERA-DIRECTION-v1.md`、`TONE-FINGERPRINT-W1-W2.md` |
| 调色 | telecine 底/年代色/逐段调色链；参考片逐帧实测 | `GRADE-LAW.md`、`星晴-GRADE-v1.md` |
| 剪辑节奏 | KTV MV 剪辑语法/卡点/变速/转场/呼吸 | `CRAFT-CEO-MV-INDUSTRY-v1.md` 六段模板 |
| 道具/年代考据 | 2000 台北/淡水物件谱·使用痕迹链·穿帮 | `QC-MASTER §9`、各曲年代锚清单 |
| 选角/面孔 | 亚洲年代脸谱/相似度门+辨识度门/每曲独立 | `CASTING-LAW.md`、`CHARACTER-LORA-STABLE-v1.md` |

## 三、纪律

- 禁改写剧本/正典；只出学习件 + 技能补丁建议（`SKILL-PATCH-<席>.md` 一节）。
- 未经实测的数字不入判据；厂商自述标明商业利益。
- 「调研完」≠「学会了」：每条工艺必须挂一个「本片可验证点」，否则判为书摘。
