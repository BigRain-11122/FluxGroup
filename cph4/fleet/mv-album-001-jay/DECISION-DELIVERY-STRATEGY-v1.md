# 导演决策：交付策略定案（2026-10-22）

> CEO 令：「科学决策，不要问我」。以下为定案，不再征求意见。

## 一、结论

| 决策 | 内容 | 依据 |
|---|---|---|
| **D1 质量档** | **int4 定为终版质量档**，int8 作废（文件截断 81.1%，无下载地址） | 实测 int4 在 768P 下脸/手/刻痕均达标；不为一个坏文件卡产线 |
| **D2 采购素材** | 由 9 条**缩到 3 条**：`P2 凿刃石屑`、`P5 水面无脸倒影`、`P8 空展厅` | 这三条承担"副歌加速度 / 句15 转译 / 段落呼吸"，不可替代；其余 5 条属"锦上添花" |
| **D3 回环镜** | `P9` **不生成**，直接复用开场镜做**同构图回路**（同机位同焦段 + 片尾压暗调色） | 结构回环的本质是"同构图再现"，复用现有素材即成立，且零成本、零漂移 |
| **D4 其余 5 条** | `P1/P3/P4/P6/P7` **延期到 v2** | 不做也能出片；做完 v1 再补，避免拖死主线 |
| **D5 交付口径** | 先出 **v600**（可发布候选），再迭代 v2 补素材 | 质量优先但不无限期打磨；有片可审才有迭代依据 |

## 二、时间盘（基于实测）

| 阶段 | 内容 | 预计 |
|---|---|---|
| 生成 | P2/P5/P8 三条（一次加载连烧，避免冷启） | **40–60 分钟** |
| 装配 | 115 镜 EDL + 46 推近 + 分段 copy | 30–60 分钟 |
| 检验 | release_gate + 逐切点目检 | 1–2 小时 |
| **合计** | | **3–5 小时**（顺利）/ 1 天（含返修） |

## 三、验收线（v600 交付必须全过）

1. 时长 234.25s ±1 帧、1344×768 / 24fps
2. 响度 -14 LUFS ±1、真峰值 ≤ -1.0
3. **非计划硬跳 ≤5、微叠化孤岛 = 0**
4. 镜长标准差 ≥1.8s，副歌均长 ≤1.6s，桥段 ≥4.0s
5. 逐切点 ±1.5s strip 目检 100% 覆盖
6. 五镜定片来自 ASSET-INDEX，无表外素材

## 四、风险与对策

| 风险 | 对策 |
|---|---|
| 三条素材又翻车（如 P4 的打火机） | 提示词禁用物件名词，用"画外光/画外声"；每镜 2 take 上限，复现即 BLOCK |
| 装配后节奏不达标签 | 优先保住"副歌快、桥段慢"的落差，必要时牺牲推近占比 |
| 检验出人脸漂移 | 回 S4 重拍该镜，不硬修 |

## 五、明确不做

- 不再追 int8
- 不再做"抹泥板边缘"类不成立的动作
- 不再用抽帧判 PASS
- 不再为一版反复重编码（一次成片只编码一次）
