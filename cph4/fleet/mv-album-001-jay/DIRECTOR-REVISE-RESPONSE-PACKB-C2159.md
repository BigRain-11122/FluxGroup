## 二、R4 取证结论：该镜**改图救不回来**，必须重渲

### 2.1 四条穿帮的机检化（把导演单的定性判读变成可复核事实）

1. **云层是「锁画幅」的贴片**：S1-07（30.000-38.125s，226 帧源）在全片中云形人物的**屏幕位置几乎不动**（约 x 0.17-0.42W / y 0.03-0.93H），而同一条镜头内相机从「天空背景」切到「麦田俯拍背景」（1.5s vs 4.0s vs 7.1s 三帧实测，地平线整体消失）。真实云不会随相机运动而原地钉死——这是「贴上去」的第一证据，也是**任何画面级修补都改不掉**的根因。
2. **亮/饱和不可分**：实测云区 luma 均值 159.7（p90 196.5）、天空区 157.3（p90 163.2），饱和度均值 0.236 vs 0.215 —— 云与天空在亮度与色度上几乎同分布，**任何基于亮度的 matte 都抠不出云**（我这轮先按亮度/饱和度试，框内只有 13.1% 像素过阈）。
3. **无地面接触、无投影、近地密度反向**（导演单原判，本轮在 4.0s/7.1s 原生帧复现）。
4. **颗粒被抹平**：云区高频能量明显低于同帧其他区域（软边 + 平滑），与周边 35mm 颗粒不连续。

### 2.2 画面级修补实测（三版，全部不足，证据留档）

做法（`cph4/fleet/mv-album-001-jay/c2159_r4_cloud.py`，纯 CPU numpy，零 GPU）：

- 画幅锁定椭圆掩模 → 掩模内做**长拖尾风蚀**（40+80+120 三次水平 box 叠加＝运动拖影剖线）+ 逐行风剪切（±34px）+ 顶部二次加长拖影（去「头部圆瘤」）；
- 用**归一化卷积**（半径 90）估出掩模下的背景，近地平线处按空气透视把雾洗向背景；
- 落日侧加暖边光（右缘 rim），最后补回胶片颗粒。

三版实测结果（`evidence-c2159/R4-BEFORE-AFTER-c2159.jpg`，2×2 原图/修补对照）：

| 版 | 结果 | 判定 |
|---|---|---|
| v1 亮度阈值抠图 | 掩模几乎没抠到云（云/天不可分） | 无效 |
| v2 椭圆掩模 + 短拖影 | 人形还在，只是发灰 | 不足 |
| v3 长拖尾 + 风剪切 + 空气透视 | 天空段读作"被风吹散的白絮"（可接受），**麦田段变成一块糊斑**（头/躯干/双腿轮廓仍在），等于把"贴纸"换成"污渍" | **不足，不采用** |

结论：**在 300×700px 的贴片上做画面级去人形，只能得到"软化"或"糊斑"，换不出真实云**。导演单给的修法（打散为絮状／风蚀状 + 落日暖透光 + 近地洗淡）本质需要**新素材**。故 v5 保持 S1-07 原样（不做半成品替换），R4 转入重渲工单。

### 2.3 R4 工单（下个 GPU 窗执行，条已备齐）

- 对象：S1-07 单镜重渲，原生 768P，种子带沿用 21000-21015（原 T1R1 带，不与已烧波冲突）。
- 提示词改法（相对现行锚）：**删「shaped like a young woman silhouette」这类"人形"指令**，改为「a low cumulus cloud whose whole mass slowly drifts alongside the riders, wind-eroded ragged edges, warm sun-side rim, thinning into haze near the ground」；人形能指**只保留在剪辑语义里**（本镜前后已有「云掉落→跟着跑」的歌词对位），不再让模型去画人体轮廓。
- 验收：原生帧 + 播放态双查（导演单口径）＋ 云区与天空的亮度可分性复查（若仍不可分，说明模型把它画成了同一层，直接判负）。
- 阻塞面：需 ComfyUI 起来 + 长烧承载（本机 GPU 长批一律走自愈 runner，禁裸 Start-Process）。
