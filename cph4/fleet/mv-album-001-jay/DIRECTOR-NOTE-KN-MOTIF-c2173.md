KN 768P 波 13 单落地时做了中间片（`media/mv-album-001-jay/interim-c2173/KN-768P-INTERIM-13of30-c2173.mp4`，77.17s，按歌曲真实时间轴摆放）。

把 14 单按剪序排成一张板（`evidence-c2173/KN-INTERIM-BOARD-c2173.jpg`）后确认：**KN06 / KN07 / KN10 / KN11 / KN12 / KN13 是六次「紙飞机 + 城市夜空」**，占用 37.22–78.50s 共 41 秒。

## 二、三道已有探针为什么都没报

| 探针 | 结论 | 为什么漏 |
|---|---|---|
| C2170 framemd5 逐帧哈希 | 0 对相同帧 | 画面确实一直在动，没有复读帧 |
| C2172 灰板 MAD（84×48） | 0 对同图，最近 KN07 vs KN09 = 0.133 | 阈值按「同一张图」调，同母题不同构图过不去 |
| C2173 dhash（8×8，8 采样） | 同构图仅 1 对（KN11/KN12，16 bit） | 城市灯点主导哈希，机身尺度/位置一变就不像 |

三条都成立，但都不是观众在问的那个问题。**观众不比较像素，观众只看到「同一个东西连着占满画面六次」。**

## 三、新增机检面（本轮落地）

`kn_motif_repeat_c2173.py`：取每单 45% 帧，量「最大的近白低饱和连通块」（=纸飞机）占画面比例与包围盒占比；
城市灯是许多小连通块，所以一个大白块 = 主体，一堆小白点 = 背景。画面里有人脸（最大肤色连通块 ≥2% 且宽度 ≥12%）则归人像，不参与母题连排。
判据：占比 ≥2% 且盒宽 ≥16% ⇒ PLANE；剪序 30 秒内出现 ≥2 个 PLANE 连排 ⇒ SUSPECT run。

实测（14 单）：KN06/07 一段、KN10/11/12/13 一段 = 2 个 SUSPECT run，与人眼读板完全一致；KN03/KN05 人像正确排除。
这是本波之后仍要跑的出生站闸（每单落地即测），零 GPU。

## 四、根因：母题是剧本里写死的，不是模型乱想

`kn_motif_prompt_c2173.py` 扫 30 单授权提示词：**21 单含 "paper plane"，其中 9 单明确是「纸飞机 + 城市」**（KN03/05/07/10/11/13/14/20b/29）。
另有两单是模型自己收敛过去的（KN06 提示词未写 city，KN12 未写 city，出来仍是城市夜航）。
即：剧本层母题密度过高（70% 单含同一道具），渲染层再生产生漂移复制。

## 五、决定（导演席）

1. **不在波中途重烧**。GPU 正在烧后续 16 单，重烧等于同一批算力付两遍，且这些单本身单帧质量合格（C2170/C2171/C2172 三闸通过）。
2. **装配层做差异化**，零 GPU：KN10–KN13 四连段用 1.12×–1.35× 分级推近（punch-in 各取不同起幅）+ 速度微差（0.97×/1.03× 交替），使四段起幅不同、机体大小成阶梯；KN06/KN07 保留原样（相隔 6.4s，机位差异已足够）。
3. **KN02 缺陷单已挂账重烧**（烧入字幕条 + 1.8× 推镜），等 GPU 释放后单独补烧，不在本波内插队。
4. **下一曲（XQ 下一波）分镜纪律**：同一道具/母题在整片提示词中占比 ≤1/3，且不得连续三单同机位同母题——这条入剧本 vN 四件套的意象检查（J-23 歌词意象闸的姊妹面：母题密度闸）。
5. **本闸接入收割轮**：30/30 收盘时 motif gate 必跑，SUSPECT run 只作为装配决策输入，不自动判死单（死单权在导演席）。
