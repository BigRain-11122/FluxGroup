# 全链路流程 v1 — 导演全程接入（2026-10-21）

> CEO 令：「好好梳理流程，导演全链路接入，不要最后才发现浪费时间」。
> 核心原则：**每个阶段都有导演闸与量化出口条件；缺陷在出生站拦，不许流到成片**。

---

## 一、流程总览（八站 + 一个终点闸）

```
S0 立意/分镜 → S1 提示词 → S2 首帧(KF) → S3 图生视频(i2v)
   → S4 选优定片 → S5 剪辑/节奏 → S6 调色字幕 → S7 合规 → S8 出品闸
```

每站的输入、产出、导演动作、机械闸、打回去向如下。

| 站 | 输入 | 产出 | **导演动作** | 机械闸（不过即拒） | 不过打回 |
|---|---|---|---|---|---|
| **S0 分镜** | 歌词/立意 | 镜头表（含每镜时长、景别、运镜、情绪） | 定节奏曲线：哪里快哪里慢；定"每镜要说的一句话" | 镜长标准差 ≥1.8s 设计值；副歌 ≤1.6s、桥段 ≥4s | 重排镜头表 |
| **S1 提示词** | 镜头表 | i2v/KF 提示词 | 逐镜检查：景别/光位/动作/年代锚是否服务那一句话 | `preflight_gate.guard()`：零否定句、token 合法、场景锚一致、首帧 sign-off | 重写提示词 |
| **S2 首帧** | 提示词 | KF 图 | **亲眼看 KF**：脸对不对、道具对不对、有无缺陷预埋 | 放大 2x 核：无倒影/无多手/文字可读/身份锚正确 | 重生成 KF |
| **S3 i2v** | KF + 提示词 | 480P 试片 | 看试片：动作成立吗？有没有崩？ | 单条 ≤2 分钟成本；480P 只做验证，不直接出高清 | 换种子/改提示词 |
| **S4 选优** | 多 take | 定片 | **按先定好的判据逐条打分**，不看"感觉" | 密集帧（0.2–0.33s）：脸零漂移、嘴部咬字、刻痕稳定、无新增元素 | 重拍（连烧 2 条复现→BLOCK 转方案） |
| **S5 剪辑** | 定片 + 时间轴 | EDL | **逐切点亲看**：这一步最容易被跳过 | 非计划硬跳 ≤5；微叠化孤岛 = 0；每切点 ±1.5s strip 目检 | 回 S4 或重排切点 |
| **S6 调色/字幕** | EDL 成片 | 调色+字幕版 | 抽 6 点看色温包络；逐字核字幕 | 同一色温包络；字幕 ≥6 点逐字一致；暗场字幕可读 | 重调/重排字 |
| **S7 合规** | 成片 | 合规版 | 确认五件套 | AIGC 标识/二创声明/词曲署名/转载出处/暗水印，逐项抽帧实读 | 补件 |
| **S8 出品闸** | 合规版 | 交付件 | **签双签**（导演+制监） | `Tools/release_gate.py` 全绿 + 暗水印全片 extract + 平台重压两级 | 回对应站 |

## 二、导演在每一站必须做的事（不能代签）

1. **S0**：写清楚"每一镜为什么存在"。写不出来的镜头＝该删的镜头。
2. **S1**：逐条过提示词闸。否定句、错误场景词、无锚点动作，都在这里拦。
3. **S2**：**亲眼看首帧**。首帧带什么缺陷，后面全是白烧（本轮 5 条 take 的教训）。
4. **S3/S4**：先定判据再烧，不烧完再想标准；连烧 2 条同缺陷就停。
5. **S5**：逐切点看。这是"最后才发现"的高发区——观众感知的跳帧全在这里。
6. **S8**：不签自己没亲眼看过的东西；数字齐了才签。

## 三、时间预算（防"最后才发现"）

| 站 | 预算 | 超时动作 |
|---|---|---|
| S0 分镜 | 1–2h | 直接定稿，不再优化 |
| S1 提示词 | 0.5h/镜 | 过闸即走 |
| S2 首帧 | 5min/张 | 2 次不过换构图思路 |
| S3 验证 take | 2min/条 | 不追求完美，只看方向 |
| S4 选优 | 3 takes 上限 | 复现即 BLOCK |
| S5 剪辑 | 2h | 只改被判负的点，不重排全片 |
| S6 调色字幕 | 1h | 统一 LUT，不逐镜精调 |
| S7 合规 | 0.5h | 模板化 |
| S8 出品闸 | 0.5h | 数字不过不签 |

**总原则**：任何一站超过预算 2 倍，立刻上报并降级范围（减镜头/减版本），不许无限打磨。

## 四、缺陷出生地路由（本轮新增，最重要）

| 缺陷 | 出生站 | 拦它的闸 | 不许出现的站 |
|---|---|---|---|
| 脸漂移 / 换人 | S2 或 S3 | S2 首帧核 + S4 密集帧 | S5 之后 |
| 唱歌没咬字 | S1（提示词无动作） | S1 闸 + S4 判据 | S5 |
| 刻痕闪烁 | S3（H3 系统性） | S4 密集帧 | S5 |
| 玻璃倒影脸 | S2（首帧自带） | S2 放大核 | S5 |
| 跳帧 / 重影 | S5（切点/微叠化） | S5 非计划硬跳 + 孤岛 | S8 |
| 字幕错位 | S6 | 逐字核 | S8 |
| 合规缺件 | S7 | 五件套抽帧 | S8 |
| 画质退化 | S5 装配方式 | 全片只编码一次 | S8 |
