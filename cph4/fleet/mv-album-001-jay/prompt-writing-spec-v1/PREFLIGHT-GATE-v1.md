# PREFLIGHT GATE v1 — 烧片前机械闸（2026-10-21 立）

> 缘起：mv0001 S9_profile 倒影脸整修，连烧 3 轮 4 条 take 全部白烧。复盘发现每一轮都违反了库里已有的规则，但**没有任何机制在烧之前拦住**。
> 本闸的作用：把"我记得要先检查"变成"不检查就提交不上去"。

## 一、四查（任一不过 → 拒绝提交，不许"先烧一条看看"）

| # | 检查 | 判据 | 机器可判 |
|---|---|---|---|
| ① | **首帧缺陷** | 首帧不得含本镜已知缺陷（倒影脸/多手/文字乱码/新增元素）；必须留**放大核验记录** | 半自动（需 sign-off 字段） |
| ② | **词表 token** | shot / angle / move / grade / texture 必须命中 lexicon 合法键；scene / light 必须命中且**与首帧事实一致** | ✅ |
| ③ | **零否定句** | 提示词命中 `no / not / never / without / avoid / don't` 即拒（否定词会把目标"叫出来"） | ✅ |
| ④ | **场景锚一致** | 如 scene=museum，提示词不得出现 torchlit / temple / mud-brick / godray / babylonian hall 等把场景带偏的词 | ✅ |

## 二、黑名单（BLOCKED 镜头：禁止再烧，只能换方案）

**烧之前必须查这张表。命中即拒——不再"换个种子试试"。**

| 镜 | 缺陷 | 状态 | 依据 | 出路 |
|---|---|---|---|---|
| `S9_profile`（mv0001 @42.22–44.00s） | 玻璃倒影人脸（违反 2026-10-12 倒影脸清除令） | **BLOCKED** | 2026-10-21 实测：原 KF 烧 2 条 / 首帧清洗后烧 2 条（含去玻璃语义版），**4 条全部复现**；同构图换种子无效 | 换镜（用同场景干净镜头）或换构图（新机位/新首帧）；**禁止继续在本 KF 上烧** |
| `S8_case`（mv0001 @40.22–42.22s） | 同上（较隐约） | 观察 | 与 S9 同一展柜构图，同源风险 | 若 S9 换掉，本镜可保留观察 |

**判定原则**：同一镜同一缺陷**连烧 2 条仍复现 → 立即 BLOCKED**，转方案讨论，不许无限重试。
（对应既有「无上限重制=配额黑洞」判例 C1426。）

## 三、用法

```python
import preflight_gate as G
fails = G.guard(shot_id="S9_profile", prompt_text=PROMPT, tokens=CFG,
                kf_verified=True, kf_note="2x crop 核过：玻璃区无五官轮廓")
if fails:
    raise SystemExit(fails)   # 拒绝提交，不得绕过
submit_to_comfyui(...)
```

`guard()` 的返回为 fail 列表；空列表才允许提交。
**绕过闸＝违规**，与"未经闸的 prompt 不许烧"同级。

## 四、与既有四闸的关系

本闸在**最上游**（提交前），管"该不该烧"；四闸管"烧出来的东西对不对"。两者不重复。
缺陷出生地拦截律的落地点就是本闸——**能在 1 秒查出来的事，不要用 2 分钟 GPU 去发现**。
