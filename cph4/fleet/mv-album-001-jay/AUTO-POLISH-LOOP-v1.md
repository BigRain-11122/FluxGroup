> 定位：**MV-PREPRO-MASTER 打磨循环的执行引擎**——把「审查→修项→织入」从导演窗手动触发升格为全自动化管线；引擎=云端 LLM（无头 Codely 代理·判官+执笔一体），本地 GPU 零占用（bm-c qwen3.6 本地判官=备援/便宜 lint 轮）。

## 一、管线结构（每曲一队列）

```
[触发] ──► [轮次] ──► [分层处置] ──► [收敛判定] ──► 冻结/再轮
```

1. **触发面**（三入口·任一即入队）：
   - **新正典落地事件**：任一 LAW/GRAMMAR/AUDIENCE-VOICE/评审判例更新 → 全部在产曲+待产曲触发一轮（今日实例：era-grammar 落地→星晴/可爱女人自动入队）。
   - **OS 循环班排程**：每曲每 6h 一轮常规打磨（M8 型队列行·循环班自动执行——bm-c 侧已验证的机制）。
   - **工序回灌**：KF/i2v/装配阶段暴露新病灶 → 判例落 EXPERIENCE-LEDGER 同时触发该曲一轮。
2. **轮次执行**（单轮=判官+执笔两段·云端代理）：
   - **判官段**：无头 Codely 代理持全套正典（24 项闸+七律+四 LAW+AUDIENCE-VOICE+该曲全部前期件）→ 逐件 verdict（PASS/修项·参数级）。
   - **执笔段**：**质感层修项自动织入**（措辞/标注/预算列/锚位核对/lint/表演注/道具细节——DIRECTOR-RULING §二 活稿面）；**结构层修项（场数/词窗/因果链/立意改动）一律升级导演席签章**——全自动只做质感层（导演拍板权不被自动化侵蚀）。
   - 每轮产物：verdict+diff 落 `reviews/auto-polish/<曲>-R<N>-<日期>.md`（可审计·AI 诚实律）。
3. **收敛判定**（禁无限轮·成本纪律）：**连续 2 轮零新修项+判官分稳定（±0.3 内）=收敛冻结**；未收敛上限 8 轮/件·超限升级导演席人工（说明卡点）。
4. **完美线**：冻结件须过 MV-PREPRO-MASTER 24 项全 ✓ 打勾表——**KF 点火闸=冻结证+打勾表双件齐**（缺一禁烧）。
