# AI 演员表演法 v2 + 表演-运镜耦合（导演席·2026-10-20）

> **CEO 令 2026-10-20**：「一定要抠演员的表演和运镜，这是AI最薄弱的，导演去研究怎么做好AI演员的表演」
> 定位：**增补**，不替代。表情的帧级机制沿用 `mv0001-handover/canon/PERFORMANCE-SPEC-v1.md`；镜内运镜五槽沿用 `mv0001-handover/canon/CAMERA-DIRECTION-v1.md`。本件补的是这两份都没管的**「戏」**——意图、时间、克制，以及表演与运镜怎么咬合。

## 一、诊断：AI 为什么演不出来（三个结构性缺失）

| 缺失 | 表现（我们片子里真实出现过的） | 根因 |
|---|---|---|
| **无意图** | 表情"对"但空：哭得像哭，看不出他在忍什么 | 提示词只给情绪形容词，没给"此刻他想达成什么" |
| **无时间** | 听到消息的瞬间，脸和身体同时反应；情绪一步到位 | AI 默认"同时、等速、完成态"，真人永远是**先接收、后处理、再反应** |
| **无克制** | 一镜里高兴+难过+沉思，脸在两种表情间抖 | prompt stuffing——矛盾向量同时求解，模型退回"抖动平均值"或冻结面具 |

**外部依据（如实标级）**：① GitHub `siwookwan/ai-acting-prompt`（MIT·0★·**方法论非工具**·核心=三层提示词+8 维表演公式+「情绪必须渐变不能跳变」）；② Hailuo 官方知识页（**厂商自述·有商业利益**·核心=减法治「1 个主导情绪 + ≤2 个微手势」·4-6s 窗·"突变在 5s 片里会像故障"·重摇 5-10 次取一条）。两条都未在我方片子上实测，本件按 A/B 协议验证后才升为硬门。

## 二、铁则六条（本件立法主体）

1. **写动作，不写情绪**：禁 `sad / happy / nervous`；写"他想干什么"+"身体在做什么"。`he keeps his jaw set while his throat moves once` 胜过 `he looks sad`。
2. **情绪必须渐变**：说前状态 → 哪个词/哪件事触发 → 说或做的时候眼睛/唇/手怎么动 → 落点状态。**禁一步到位**。
3. **反应延迟 3-8 帧**：先看/先听，身体后动。同帧反应=AI 签名。双人镜必写「谁先、谁后」。
4. **一镜一意图**：一镜只有一个"他此刻想要的东西"；两个意图=两个镜。
5. **减法治**：一镜 1 个主导情绪 + 最多 2 个微手势。三个以上=抖。
6. **停顿要有心理动机**：停顿=心里的话压住了嘴里的话，必须能说出"他在犹豫什么"；说不出=删掉这个停顿，别拿它当电影感。

**时长分配**（承接第 6 条）：<3s 的镜**只给动作不给情绪**（脸来不及演弧）；4-6s 才给一个完整微弧（起→转→落）；长镜（8s+）给"弧+一次回摆"。

## 三、8 维表演行（i2v 提示词单位·一镜一行）

| 维 | 写法 | 例（星晴·按 PLAY 前那一拍） |
|---|---|---|
| ①时长 | 本镜秒数 | 2.0s |
| ②意图 | 他此刻想达成什么 | *to put off the moment of pressing it* |
| ③情绪走向 | 从 A 渐变到 B（禁跳） | 平静 → 一点点舍不得 |
| ④触发 | 哪一动作/词引发变化 | 拇指碰到按键的那一刻 |
| ⑤面部动作+AU | 先写可见动作，再用 AU 钉强度 | 下颌松半分、下眼睑轻收（AU6 轻·AU17 轻） |
| ⑥视线与身体 | 看哪里、重心在哪 | 视线停在标签上不移动；肩线先落 |
| ⑦呼吸 | 呼吸相位（吸气/屏/呼） | 吸气一半屏住，按下后才呼出 |
| ⑧落点 | 结束时停在哪 | 手停住、肩落下、不动 |

**正反例**
- ❌ `He looks nostalgic and sad, slowly pressing play, emotional atmosphere.`
- ✅ `His thumb rests on the key without pressing. One breath in, held. Then the press—the shoulder drops only after the reel starts turning. He does not look up.`

## 四、表演-运镜耦合三条（本件新增·两正典之间原本缺这层）

- **C1 镜头动机来自表演节拍**：不是"这镜需要一个推"，而是"她抬头的那一刻，镜头才走"。运镜的 MOTIVE 槽（CAMERA-DIRECTION §三③）**必须是表演动作**，不是光线或气氛。
- **C2 强度反比律**：表演强（哭/喊/爆发）→ 镜头必须静（locked-off）；表演微（一次眨眼/一口气）→ 镜头可以缓移承托。**两个都强=崩区**（已有 H3 判例）。
- **C3 镜头不许比演员早**：预判式推近是剪辑层的事（cut on action 两帧重叠），镜内不许"提前凑上去"。到站时机=表演动作完成的同一拍或后半拍。

## 五、量化判据（机检·可写进片子闸）

| 判据 | 阈值 | 检法 |
|---|---|---|
| 反应延迟 | 双人镜 ≥3 帧、≤8 帧 | 光流在两张脸上的起始帧差 |
| 加速度非恒定 | 单镜内速度标准差 > 0 且存在缓入/缓出段 | 光流幅度曲线（平直=匀速=判负） |
| 眨眼存在 | 4-6s 脸镜 ≥1 次完整眨眼（或明确的"忍眨"） | 眼部开合曲线 |
| 意图可读 | 5 人盲看静音片段，"他在做什么/想要什么"≥4 人一致 | 抽检协议（下表） |
| 微手势数量 | ≤2 | 人工点数 |

**A/B 抽检协议**：同一 KF、同一模型、同参数，A=情绪词版 / B=8 维动作版，各烧 2 条 → 静音盲评（不给上下文）→ 记录"猜出意图"比例与"假"票。B 未显著优于 A = 本件该条不成立，回炉改法，不许照抄规则当成果。

## 六、落到在产四曲（导演实际怎么抠·每曲两镜示范）

**星晴**
- `F0-01b 按 PLAY`：意图=*to put off the moment*；关键=拇指悬停→按下→**肩在磁带转起来之后才落**（反应延迟在单人镜=身体落后于事件）；落点=手不动。
- `S3-18 数到三顿半拍`：意图=*to test whether she's still following*；顺序=他脚步先停 → **她 4-6 帧后才转头** → 他嘴角先动、眼神后到。禁两人同时转头。

**可爱女人**
- `KN04 掷出`：意图=*to throw it far enough to reach her*；动作链=手腕后拉→压腕→释放→**手指仍张着没收回**（余势）；机身带一帧 flinch，镜头不追。
- `KN24 灯窗初见`：意图=*to look without being caught*；顺序=视线先到→头慢半拍→察觉→**眼先移开、脸后转**（真人躲视线是眼睛快）。

**龙卷风**
- `C 段停手`：意图=*to keep doing something so he doesn't have to feel it*；动作=手一直在动→忽然发现手里的东西→放下→**手空了才停**；情绪落后动作一拍（先停，后崩）。
- `场 5 浅方形显形`：意图=*to make sure he's seeing it right*；身体=不前走近、只把重心往前压一点；视线钉住不动，呼吸停一拍。

**简单爱**
- `场 4 伞下`：意图=*to keep her dry, and to keep her*；顺序=她手伸出伞外→**他眼睛先看到**→手跟上拉回→她看他→他避开视线（心虚）。
- `场 7 她先伸手`：意图=*to not let the moment pass again*；他=**愣半拍（喉结一滚）→才扣紧**；她=手先到、眼睛后到（坦荡）。
