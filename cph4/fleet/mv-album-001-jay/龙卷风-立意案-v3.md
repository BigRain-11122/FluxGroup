> 判据来源：歌词官方正文（`lyrics/龙卷风.txt`）；原版 MV 考据 = 并行调研中（导演/女主/记忆点）。

## 一、先认错：v2 为什么是一塌糊涂

v2 的立意是「风暴过后的房间，他收拾残局」——它有三个硬伤，全是叙事层的，不是画面的：

1. **它把歌听成了挽歌。** 歌词最后四句是「不知不觉你已经离开我／不知不觉我跟了这节奏／后知后觉又过了一个秋／**后知后觉我该好好生活**」。「该好好生活」不是认命，是**主语第一次主动**。v2 把它拍成「承认它来过」，等于把结尾的主动性抹掉了。
2. **它废掉了原曲的双向运动。** 词里是两次同构的位移：「爱情**来的**太快就像龙卷风」（她来）／「爱情**走的**太快就像龙卷风」（她走）。同一阵风，两个方向。v2 只拍「走之后」，把「来」压成闪回碎片，观众看不到「来」的强度，就感受不到「走」的落差。
3. **它让男主全程被动。** 词里的「我」确实是被拖着走的（灵魂失控／被它拖着走／无处可躲），但那是**前半**。全曲唯一的转折就是最后那句。v2 把被动拍满 4 分钟，所以表演只剩「憋」和「静」，演员没戏可演——这就是 CEO 说的表演一塌糊涂的根。

## 二、v3 立意（一句话）

**同一个人，被同一阵风带来又带走；全片他只做对一个动作——自己走出去。**

- 前半（来）：她是天气，不是人。他所有镜头都是**被推着、被拽着、被光推着**——身体永远慢半拍。
- 中段（走）：同一套镜头语言反向重演（她来时的推镜，走时变成拉镜；她来时他伸手，走时他手停在半空）。
- 结尾（我该好好生活）：**废墟里那杯水停止震动、水面静下来，他伸手拿起杯子**——全片唯一一次主动（原版结尾=房间崩塌人被困，保留；只在这一处加层）。

## 二·补、结构：按周格泰公式重排（研究已回，非猜测）

调研结论（一手=放映週報专访，二手=2015 金曲报道）：周格泰的公式=**声音冷开场 → 一次错位 → 副歌断点（叙事接管）→ 不解释的物件/姿态收尾**，核心是「最响的地方留空」。

本曲重排为四拍：

1. **声音冷开场（0–20s，音乐未进）**：只有声音——风灌窗缝的呜咽、碎玻璃被踩的细响、椅子被扶正的木头摩擦。画面是他摸黑收拾。**歌第 20 秒才进来**，进来正撞上他捡起相框那一下。先给物理空间，再让音乐接管。
2. **一次错位（主歌 A → 副歌 1）**：不是「她走了我难过」，而是信息差——他以为在收拾她的东西，观众先看清：所有东西都是他自己的。她一件都没留下。（用动作揭穿：他把外套挂回衣柜，衣柜里只有他的衣服。）
3. **副歌断点（第一次「爱情来的太快就像龙卷风」）**：**音乐停 2–3 秒**，只剩风暴环境声；插一个无台词实拍瞬间——她的手从他掌心抽出去（只有手，没有脸）。音乐回来时已是「离不开暴风圈来不及逃」。这是全片唯一一次静下来，也是最贵的三秒。
4. **收尾（按原版保真 + 只加一层）**：房间崩塌、他困在废墟里（原版结尾，不换）。最后一下：那杯水停止震动，水面静下来，他伸手把杯子拿起来——全片唯一一次主动。镜头不跟出去，不给答案、不给字幕。

保真与升华的分界：保真=风暴的物理暴力感 + 她作为不可控外力的定位；升华=声音冷开场 + 副歌断点（原版没有、但符合原曲气质）。

## 三、与原版的保真层（考据已回·逐条锁定）

原版勘定（一手逐帧核看 + 媒体互证）：导演**邝盛**，女主**陈怡蓉**，2000 年《Jay》。四段叙事：①昏暗青绿调房间，他接一杯水（红连帽卫衣＋深色外套＋黑棒球帽）②荒野破木屋门廊、暗蓝灰压顶天空下张臂独唱 ③她长发被风吹乱、揪住他衣领把他推撞墙上（冲突段）④房间剧烈震动→书架倒塌、书本飞散→火焰与爆炸→定格空屋。

**必须保住的记忆点（老粉 3 秒认得出）**：
1. **一杯水**——饮水机与玻璃杯贯穿全片，震动的杯子像节拍器。这是原版最强的物件链，也是最省钱的张力计。
2. **红卫衣＋黑棒球帽**。
3. **蓝色漩涡天空里的坠落/漂浮**（原版全片没有实体龙卷风，用漩涡与室内崩塌替代——这一条必须继承，不要画一条真龙卷风）。
4. **她揪住他衣领推撞墙**（冲突段的具体动作）。
5. **吊裸灯泡下她靠在他肩头**（甜蜜闪回）。
6. **倒塌的书架与飞散的书、熊猫玩偶、泥地上的一束花、落地的挂钟**。
7. **结尾：废墟 + 静止的水杯**，男方被困在崩塌的房间里（关系毁灭）。

**修正上一版的越界**：本稿 v3 初版把结尾改成「他推窗出门」，那是换底不是加层——**撤回**。升华只做一处，且必须长在原版结尾上：废墟里那杯水**停止震动、水面静下来**，他伸手把杯子拿起来（全片他唯一一次主动），镜头不跟走。原版的「毁灭」保留，歌词的「我该好好生活」只落在这一个动作上，不给台词不给字幕。

**未具象的歌词**：原版没有对应「又过了一个秋」（只有枯草荒野弱对应）——这一处可以是我们加的一层（同一房间，季节变了），但只做一处，不铺开。

## 四、与歌词的对位（逐段→功能，不是逐句配图）

| 词段 | 叙事功能 | 表演指令 |
|---|---|---|
| 「爱像一阵风 吹完它就走／这样的节奏 谁都无可奈何」 | 定调：天气法则，人力无效 | 他站在风里，衣角先动、人后动（身体慢于环境半拍） |
| 「没有你以后 我灵魂失控」 | 失衡开始 | 手上动作开始出错（拿不稳、放偏） |
| 「黑云在降落 我被它拖着走」 | 被外力拖行 | 脚在地上被拖出半步，重心不由自己 |
| 「爱情来的太快…离不开暴风圈 来不及逃／我不能再想」 | 峰值：逃不掉 | 伸手抓——抓空或被甩开 |
| 「爱情走的太快…无处可躲／我不要再想你」 | 反向峰值：同构重演 | 同一机位、同一动作，方向相反 |
| 「不知不觉你已经离开我／不知不觉我跟了这节奏」 | 麻木期 | 动作自动化：收拾、走路、关灯，全是肌肉记忆 |
| 「后知后觉又过了一个秋」 | 时间过去 | 同一空间，季节变了（一件衣服/一束光） |
| 「后知后觉 我该好好生活」 | **全曲唯一的主动句** | 他先动：推窗、出门、不回头 |

## 五、这一版要解决的三件事（对 CEO 三条批评的直接回应）

1. **剧本**：从「氛围拼贴」改成「一次位移的两个方向 + 一次主动」。全片有一条可复述的故事线：*她像风一样来，像风一样走；他最后自己走出了门。*
2. **表演**：不再用「憋／静／沉」这类形容词，全改**可观察动作**（衣角先动、手抓空、机器式收拾、主动推门）。每镜给一个「起—承—转」动作，不许出现「站着不动看镜头」。
3. **流程**：本曲走一遍最新流程——D1 立意（本件）→ 原版保真核对 → D2 四列分镜（含表演三段式）→ 表演档位审 → D3 定帧 → D4 运动定稿 → D5 帧审 → D6 剪辑语法 + 代理剪 → D7 终审。**D1 没定稿前不许再出任何 KF。**
