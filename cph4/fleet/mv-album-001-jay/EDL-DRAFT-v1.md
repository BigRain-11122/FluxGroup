## 二、四个硬约束的算式结果

### ① 全片镜长标准差 ≥ 1.8s —— **PASS**

```
n = 115, d̄ = 234.25 / 115 = 2.037
σ = sqrt( Σ(d_i − d̄)² / (n − 1) )
  = sqrt( 419.4 / 114 )
  = sqrt( 3.679 )
  = 1.918 s      ≥ 1.8  ✓   (余量 +0.118)
```

### ② 副歌段平均镜长 ≤ 1.6s —— **PASS**

```
副歌1： 30.88s ÷ 20 镜 = 1.544 s  ≤ 1.6  ✓  (余量 −0.056)
副歌2： 30.74s ÷ 26 镜 = 1.182 s  ≤ 1.6  ✓  (余量 −0.418)
（两段分开计；合并校验 61.62s ÷ 46 镜 = 1.340s，同样 ≤1.6 ✓）
```

### ③ 桥段平均镜长 ≥ 4.0s —— **PASS**

```
桥段： 14.76s ÷ 3 镜 = 4.920 s  ≥ 4.0  ✓  (余量 +0.920)
```

### ④ 快段零叠化 —— **PASS**

```
快段（副歌1+2+3+4）= 20 + 26 + 18 + 8 = 72 镜
其中 trans 为 fade 的镜数 = 0            ✓
全片 fade 共 16 处：fade1.0 × 7（段落交界/起收黑）+ fade0.4 × 9（慢段、且两侧主体不同），
全部落在前奏/主歌/预副歌/桥段/尾声，无一处进快段。

## 三、副歌四级阶梯（N2 判 FAIL 项，已落地）

四遍副歌做成 **降—降—升** 的落差曲线，避免"第 2 遍走神"：

| 级别 | 时间窗 | 时长 | 切点 | 均长 | 推近占比 | 转场 | 对应情感值 / 功能 |

| 副歌 2 | 141.76–172.50 | 30.74s | 26 | **1.182** | 13/26 = **50%** | 全硬切 | 8/9/8 — 收紧，切点密度上提 30% |
| 副歌 3 | 187.26–205.10 | 17.84s | 18 | **0.991** | 10/18 = **55.6%** | 全硬切 | 句24 值10 — "一切又重演"最急，全片最快 |

**阶梯读数**：1.544 → 1.182 → 0.991 → 1.843
- 前三遍逐级加速，第 3 遍比第 1 遍快 **1.56 倍**；
- 第 4 遍比第 3 遍慢 **1.86 倍**，落差最大，落在句 24「一切又重演」的第二次出现上；
- 推近占比同步升到 55.6%（第 3 遍最密），第 4 遍降到 37.5%（少跳切、多全幅长镜）。

**第 3 遍的特殊做法**：18 切里只有 8 切来自 S4 已 PASS 的 E 镜头组

其余 10 切是**副歌 1/2 素材的"另一取景"复用**（C02/C03/C06/C09 的 punch 面）。
语义上这正是"一切又重演"——画面本身就是重演，不靠改写语义硬凑。

**三条代价，必须写进下游执行纪律**：

1. **分辨率账**：punch 有效像素仅 1002×573，回放到 1342×768 是 1.34x 上采样。

3. **跳切纪律**：full→punch 是同 take 跳切，**只能硬切**；一旦加叠化 = 同一张脸两层叠加的重影事故。

## 七、一处必须裁决的冲突（透明度声明）

```
窗口 172.50–205.10 = 32.60s
若其中 17.84s（187.26–205.10）做成 0.991s 均长 → 该段已有 18 切
则剩余 14.76s / (18 + k) ≥ 4.0  ⟹  18 + k ≤ 8.15  ⟹  k ≤ −9.85  （无解）

**本文的处理**：桥段按 `172.50–187.26`（14.76s / 3 镜 = **4.920s** ≥4.0 ✓）计；
`187.26–205.10` 划归副歌 3（0.991s）。原 205.1 边界的窗口实测值为 **1.552s**（21 镜 / 32.60s），**必然不达 4.0**。
