## 二、逐站通过标准（数值化）+ 签核

- 判据：一句话立意不含空词；受众画像可说出转发理由；负向清单 ≥3 条且具体到画面元素。
- 证据：`IDEA.md`
- 签核：**D**

### N1 文本六轴（D）
- 判据：逐句 7 列 **100% 填满**；情感值曲线 ≥2 峰 ≥1 谷；"只能感受"句 100% 有物象转译。
- 证据：`LYRICS-6AXIS.md`（抽样 ≥10 句复核）
- 签核：**D**

### N2 叙事结构（D）
- 判据：四律逐条 PASS；记忆点间隔 **≤60s**；每个转场能答"讲什么故事"（100%）；衔接三锚 100% 标注。
- 证据：`STORY-STRUCTURE.md` + 曲线图
- 签核：**D**

## 三、签核记录格式（缺记录＝未通过）

台账：`cph4/fleet/mv-album-001-jay/QA-SIGNOFF-LEDGER.jsonl`，每行一条：

```json
{"ts":"2026-10-21T16:05:00+08:00","version":"v5.19","station":"S5",
 "seat":"E","verdict":"PASS","criteria":{"offplan":3,"islands":0,"cuts_checked":72},
 "evidence":["release_gate.txt","cuts-strip/"],"note":"逐切点目检 72/72"}
```

规则：
1. **一签一条**，不许合并。
2. `verdict` 只能是 PASS / FAIL / CONDITIONAL。
3. `CONDITIONAL` 必须写清"条件是什么、谁在什么时候补"。
4. FAIL 必须写"打回哪一站"。
5. 签核人必须在 `note` 里写出**自己看到的数字**（复述对方数字不算独立审核）。
