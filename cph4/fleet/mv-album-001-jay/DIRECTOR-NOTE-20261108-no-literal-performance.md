# 导演席硬门：表演不许字面化（DIRECTOR-NOTE-20261108）

> 来自 CEO 2026-11-08 原话：「开幕的周杰伦男主叹气呼吸的镜头很丑，不要那么具象化，导演负责」

## 一、定谳

**叹气 / 大口呼吸 / 张嘴喘 / 喉结动一下** 这类生理动作，一旦让模型去画脸，就会得到一张
「半张嘴、眼神空洞」的丑脸——这不是模型不够好，是**这个动作本身不该被拍出来**。

和 J-23「歌词意象律」同一条法理：**歌词不能直译，表演也不能直译**。
情绪不是靠把器官动作用特写放大，而是靠环境与物件的响应去承载。

## 二、承载表（写死，后续所有曲目照此执行）

| 想表达 | 不许拍 | 怎么拍 |
|---|---|---|
| 叹气 | 脸特写＋张嘴／肩膀垂 | 桌上杯子里的水面晃了一下；窗帘被带起又落下；烟／白气在冷空气里散开 |
| 压住的呼吸 | 胸腔起伏／鼻翼 | 棉布被压出褶再回弹；他手里的东西轻微位移；指节先紧后松 |
| 想说话没说 | 嘴唇动／喉结 | 他对空画面的背景开口，声被环境吞掉；电线上鸟飞走；手在车把上松开一点 |
| 忍住不哭 | 眼眶红／泪光 | 灯在他脸上抖一下；他背对镜头，肩线保持完全静止 |

## 三、执行口径

1. 分镜表里出现「吸气／喘／胸腔起伏／嘴唇动」一律打回重写，**不许进 KF 提示词**；
2. 允许 `breath` 出现在**环境**上（`the window light breathing`、`the shadow breathing`），
   不允许出现在**人体器官**上；
3. 已按本门改写的：《简单爱》S07 / S20 / S38（见 SHOTLIST v1 对应行，已标「不拍…」）；
4. 新增曲目过导演席时，先扫这三类词，命中即打回。
