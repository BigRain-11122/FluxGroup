# 公众号训练规格 v1（2026-11-23，CEO 令：不出稿，先训到"像真正的团队"）

## 一、把"像"变成能算的东西

单篇像可以模仿；**一批稿的分布像，才说明学到了团队工艺**。故判据＝六维形态对照，
分母是真稿（方向不对称：我们要像它们，不是它们像我们）。

| 维度 | 含义 | 容差 |
|---|---|---|
| 标题长度中位 | 团队有稳定标题长度习惯 | ±35% |
| 标题含数字率 | 信息密度与"我数出来的"风格 | ±25pp |
| 标题问句率 | 悬念手法占比 | ±25pp |
| 开篇首句长度中位 | 钩子节奏 | ±50% |
| 小标题密度 | 结构分层习惯 | ±60% |
| 段落长度中位 | 手机阅读节奏 | ±50% |

两票否决（不参与加权）：
1. **AI 腔命中**：客服腔/公文腔/空承诺/并列套话，命中即不过；
2. **与真稿重合**：6-gram 重合块 >13 视为洗稿，不过。

容差**不是标准**：4 篇语料全是机构通稿，不是对标对象本人，故
`title_len_med / title_num_pct / title_q_pct / heads_med` 四维**已停用**，只报数不判生死；
仅保留 `lead_len_med` 与 `para_len_med` 两维参与判决。换语料后按留一法重标定。

> **2026-11-23 更新（六席审稿后）**：工艺规则改由 `GZH-CRAFT-v2.md` 定义，
> 四任务扩为**五任务**（补"承转句"与"整篇组装+自伤复检"），且"思想"已定义。
> 六维判据中 4 维**已停用**（语料未换成对标对象），只报数不判生死。

## 二、训练四任务（分开训，不混一个模型）

| 任务 | 料 | 模型档 | 判据 |
|---|---|---|---|
| 标题 | 真稿 title | 本地 4B，多采样 | 含数字/问句率落在容差内 + 人盲评"会点开" |
| 开篇 200 字 | 真稿 lead | 本地 9B | 首句长度分布像 + 盲评 ≥3.5/5 |
| 段落推进骨架 | heads 序列 | 规则抽取 | 小标题密度与顺序模式像 |
| 收尾 | 末 3 段 | 9B 或云 | 有明确人群适用/不适用 |

**明确不训**：整篇 1500 字。小模型写长文必崩，且整篇质量不能靠一次生成保证。

## 三、语料门槛（不到就不训）

1. 200 篇真稿（可用镜像源，标"镜像"）→ 才训标题模型。
2. 同作者 ≥10 篇 → 才能学"人设"，只看单篇学不到人。
3. 覆盖 ≥5 个作者 → 防止学成某一个号的复读机。

## 四、出稿闸（CEO 令）

1. 六维全部落在容差内；
2. AI 腔 0 命中；
3. 与真稿重合 ≤13；
4. **人盲评**：混进 3 篇真稿，看不出哪篇是我们写的，才算过。
   这条不能机检，也不许用模型自评替代。

## 五、当前进度（诚实）

- 判据器 `gzh_quality.py` 已上线，自检 7/7（含"只改标题长度必须红"的单维负控）。
- 未训任何模型。**不训的理由：语料不到 200 篇，训了也是浪费 GPU 且会误判方向。**
