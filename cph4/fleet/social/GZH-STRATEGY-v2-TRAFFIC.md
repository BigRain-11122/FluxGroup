# 汽车公众号 v2：流量与副业版（2026-11-23 立，取代 v1 的判据）

> CEO 定调（原话）：「我就赚点流量和副业钱，去做观众喜欢爱看的内容」。
> v1 是冲头部、赚品牌预算、做长期资产的打法，判据是"可复算 + 打开率 3%"，**慢**。
> v2 换目标：**阅读量 = 钱**，内容先让人想点开。

## 一、为什么"阅读量"在这条线上直接等于钱

公众号流量主**现行官方门槛是关注用户 100 人**（微信广告帮助中心原文；此前的"500"是旧门槛）。变现分三条并行：程序化广告（按展示/点击）、返佣商品（CPS 按成交）、互选广告（约定报价）。
所以 v2 的唯一核心指标是**单篇阅读量**，不是打开率、不是粉丝质量、不是品牌好感。
→ 内容的第一使命：**让人点开、看完、转发**。

## 二、观众爱看什么（汽车垂类的四种钩子）

1. **省钱**：「这 5 个配置我建议你跳过，理由和价差我都列出来」——损失厌恶最强，但不用"智商税"这类定性词（贬低竞品风险）。
2. **打脸/自嘲**：「我买了它，三个月后想砸了」——真人有瑕疵才可信。
3. **对比与排名**：「5 台车摆一起，只有 1 台敢买」——天然有立场，评论区会吵。
4. **揭秘/内部话**：「4S 店不会告诉你的 3 句话」——信息差本身就是内容。

四种钩子可以叠加，但**一篇只主打一种**，叠两种以上会散。

## 四、标题公式（每条标题必须命中 ≥2 个）

1. **数字**：5 台 / 3 句话 / 8000 元 / 4 种路况
2. **结论前置**：先说结论再说理由（"只有 1 台我敢推荐"）
3. **损失厌恶**：省了 / 别买 / 智商税 / 最不该
4. **身份指认**：月薪一万 / 家用 / 新手 / 装不了充电桩
5. **排除法**：删掉 / 剩下 / 只留

## 五、内容模板（1500 字以内，手机两屏读完）

1. **钩子 50 字**：一个具体场景或一句反常识，不铺垫。
2. **冲突 200 字**：大家以为 vs 我实际遇到。
3. **证据 800 字**：数据、经历、对比表——**至少一处是"我自己的"**（我的车、我朋友的车、我实测），这是可信度来源。
4. **结论 200 字**：明确建议 + **适用/不适用人群**（写清"什么人不该听我的"，最容易涨信任）。
5. **互动 50 字**：一个只有车主能答的问题（引导评论，评论数也影响推荐）。

## 六、合规红线（不写就会被封，这是唯一硬约束）

1. **不编销量、不引未核实数据**——2025-11 网信办处置的就是这类（易车榜、孙少军09）。
2. **吐槽产品可以，不骂企业家、不定性"诈骗"**——极端贬损类账号已被关闭。
3. **商单必须标"广告"**，不接要求改结论的单。
4. **不用"最安全/绝对/第一/一定/纯属"**这类绝对化与断言词（广告法第九条）。
5. **AI 参与写作必须标**：《人工智能生成合成内容标识办法》2025-09-01 施行，第十条要求发布时主动声明；微信已有 AI 声明功能，配图若为 AI 生成须图内标注。
6. **商单/带货必须显著标"广告"**：《互联网广告管理办法》第九条第三款，正文首屏即标，不得只放文末；另需留广告主资质与素材 ≥3 年。
7. **收入必须申报**：流量主与商单均属应税所得，未申报即偷税（陈震案的教训）。
8. 智驾内容只说"我这次遇到的失效场景"，不写"这车会撞/一定失败"；负面结论必须能出示证据（配置表/实测视频/检测报告/官方数据），拿不到就只写"我不推荐"。

## 七、副业变现路径（按启动难度排）

1. **流量主**：100 关注即可开通，之后按展示/成交分成——但它是**被动收入，不是第一目标**（单篇阅读换不了几个钱）。
2. **平台分发分成**（头条/懂车帝/百家号，有推荐流）：冷启动最快，单价低但能立刻跑起来——**这才是第一目标**。
3. **车品带货**：起步只做低客单消耗品（玻璃水/雨刷/充电线/胎压计），退货低；别碰脚垫座套（尺寸退货 20-40%）、贴膜改色（施工依赖）。达到单篇 3000 阅读再上。
4. **图文直发商单**：需粉丝量级，账期 30-90 天；接单前先要素材资质，且不接要求改结论的单。
4. 选车咨询/私域：后期再说，先攒阅读。

## 八、v2 判据（取代 v1）

1. **第 2 周内 100 关注**（开通流量主的现行门槛）；首月 500 粉是增长目标，两者不混。
2. **单篇阅读 ≥ 粉丝数 × 5%**（流量型内容应高于全行业 1–3% 的均值）。
3. **转发率 ≥ 2%**（衡量"爱看到愿意替你传播"）。
4. **月更 ≥ 12 篇**（订阅号一天一次群发，够用）。
5. **流量主月收益**记录在案，作为唯一真金判据。
6. **合规零事故**。
