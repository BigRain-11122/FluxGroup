# 全链路资源排布（2026-11-23，一机 32GB 统一内存）

> 背景：训练 + 双号会话 + 采集 + 发帖 + 本地模型同时跑，**swap 顶到 4.4GB**。
> 违反 CEO 硬规矩「本地算力在不触发 swap 的前提下用满」。本文件定"谁什么时候上"。
> 执行体＝`Tools/fleet/res_alloc.py`（launchd `com.fluxgroup.resalloc`，600 秒一拍），
> 会话入口已接闸：`user_agent.run_session` 见到降档直接不进。

## 一、三样资源，三种争法

| 资源 | 谁在抢 | 争法 |
|---|---|---|
| 统一内存 | 训练 / 本地模型 / 每个浏览器约 700MB | **只有它能逼出 swap**，是唯一硬约束 |
| 浏览器 profile | 会话 / 采集 / 发帖 | 同一时刻只能一个进程用（browserd 单线程） |
| 主控节拍 | 全部 | 主控第一任务是调度监督，不能被生产活饿死 |

## 二、优先级与时间表

优先级：**训练 > 发帖 > 会话 > 采集**。
但资产优先≠永远优先——训练独占夜间，白天必须把浏览器让给人味动作。

| 时段 | 班次 | 允许 | 理由 |
|---|---|---|---|
| 00–07 | `TRAIN-NIGHT` | 训练 + 发帖 | 没人看，训练吃满；发帖时效强、成本低 |
| 07–09 | `FULL` | 采集 + 双号 + 发帖 | 训练间隙，语料优先补 |
| 09–22 | `TRAIN+LIGHT` / `TRAIN-DAY` | 1 号轻量会话、或 1 会话+采集 | 白天要"像人"，但只留一个浏览器 |
| 22–24 | `FULL` | 采集 + 双号 + 发帖 + 复盘 | 一天里最后的补料窗口 |

## 三、五道判据（都能实测，超了就降档）

1. **swap ≤ 512MB**：超过 → 只许收尾（`DRAIN`）；**超过 2048MB → `DENY-NEW`**，不开新会话、不采集、不训新轮。
2. **浏览器 ≤1 个 profile** 在用；要开第二个必须等第一个退出。
3. **发帖 queue ≤60s**：抢不到 profile 就跳过本拍（已有机制），不产假慢样本。
4. **采集 ≥1 次/6 小时**：否则记 `BLOCKED-COLLECT` 报出来，不假装在采。
5. **模型驻留服从班次**：训练期只留 4B/embedding，9B 用前加载、用完即卸。

## 四、纠错：swap 是历史累计，不能当闸（2026-11-23 实测）

第一次跑就发现判错了：swap 4452MB 但**可用内存 15.6GB**——机器根本没在换页，
swap 只是之前的残留。拿它当唯一判据会把"训练与实战并行"永久锁死。

**已改为：前馈看可用内存（<800MB 全禁 / <1500MB 只收尾），swap 只作背景记录。**
改后判定＝`PARALLEL-1`（训练在跑 + 一条实战线在跑），这正是 CEO 要的并行。

## 四之二、并行时真正的瓶颈不是内存

可用 15.6GB 时开两个浏览器毫无压力；真正的瓶颈是 **browserd 单线程**——
两个平台同时点下去会互相排队（实测 post 排队 185 秒）。
所以并行规则是"训练常驻 + 一次只放一条实战线"，平台按 90 分钟片轮转，
而不是"同时开所有平台"。

## 四之三、旧处置记录（swap 4460MB 时曾判 DENY-NEW）

1. 闸已生效：**新会话进不来**，现有会话自然结束后不再重开 → 浏览器数量会自己降到 1 以下，内存随之回落。
2. **不停训练**：训练是资产，且它已经跑出留档（memer ckpt450，均分 +11.4/人味 +3.0）。
3. **暂停采集**：此时开采集只会再抢 700MB，让 swap 更高。
4. 观察口径：swap 回落到 512MB 以下 → 自动回 `TRAIN-DAY`（允许 1 会话 + 采集）。

## 五、这轮排布的代价（明说）

- 今天采集会是 **0 条**（L2 红），直到 swap 回落——这是正确取舍，不是又坏了。
- 发帖降到 **1–2 条/天**：昨天 16 条是"浏览器空着就一直发"，代价是排队 185 秒和 swap。
- 副动作（看/赞/投币/收藏/关注）继续，但只在 1 个号上，且受班次限制。

## 六、判据缺口（下一步做）

1. `res_alloc` 现在只做"算班次 + 落文件 + 会话侧执行"；**采集/训练侧还没读它**，需要各自加一行判断。
2. swap 是滞后指标：应该加"当前空闲内存"做前馈，避免等到换页才降档。
3. 双号并行只在 `FULL` 班次允许，其余时候强制串行——这条要写进 agent_daemon 的选号逻辑。
