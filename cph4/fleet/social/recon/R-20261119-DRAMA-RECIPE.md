# R-20261119 短剧/漫剧配方卡：《持械入宋：第十一季》

**为什么是它**：2026-11-16 红果 AI 漫剧热播榜 **第 1 名**（TOP10 第 1 位，来源凤凰网 i.ifeng.com/c/8y6CVL92WAL）。官方口径：全系列播放 120 亿、红果评分 9.5、约 1.9 万人评分、累计收藏 1141 万、单季最高热度 8206 万；11-15 第十一季上线，预约 486 万。**本片非我司素材，是外部在榜作品，B 站二传可访问件**。

## 一、拆解素材与测量口径（可复跑）

- 素材：`https://www.bilibili.com/video/BV1qQsE62EjJ`（《持械入宋：第十一季 第1-113集》二传合辑，8866s / 360p）。
- 实测切片：`0–300s`（季首）+ `4300–4600s`（季中），用 `Tools/recon/drama_recon.py`（逐帧 scene 分、多阈值标定 → 实取 0.30）。
- 容器实测：360×640 竖屏、h264、**30.0fps**（4919/164）、aac 44100Hz 2ch。原片分辨率**未测**（B 站已二次压缩，不作为头部口径）。

## 二、钩子（前 3 秒怎么抓）——实测

- 首切 **1.95s**、二切 **3.12s**：0–3s 内 **2 个硬切**，起手是"换马"蒙太奇。
- 首句字幕落在 **4.0s**：「第一次换马」→ 6s「第二次换马」→ 8s「第三次换马」**同句式递进**，用重复节奏制造"八百里加急"紧迫感，**不解释、不交代人物**，把"谁在急报"留成悬念。
- 前 3 秒画面变化实测：帧差均值 **0.0424**（64×114 灰度、0.1s 步长、归一化），远超 0.02 门槛 —— **无静图开场**。
- 人物亮相顺序：12s 时间地点卡 → 14s 使者名卡 → 20–22s 官员名卡「张元吉／鸿胪寺丞」。**12 秒立场景、14 秒立角色**，与 HEAD-BENCHMARK 的"3s 爆点 / 10s 立角色"基本吻合。

## 三、集结构（多长一集 / 几个反转 / 反转在第几秒）

- **集长**：官方口径每季 100 集、**单集 <120s**；二传合辑 8866s ÷ 113 集 = **78.5s/集**。两条口径都指向 **80–120s**。
- **段落分隔符 = 时间地点卡**，实测三张：`12.0s 七月二十七日 午后 京城`、`106s 傍晚 都亭西驿`、`132s 七月二十八日 下午`，间隔 **94s / 26s**。
- **一集一个完整谈判单元**（0–84s 收束）：蒙太奇悬念 → 驿馆客套（18–30s）→ 使者拒绝客套（38s「先沐浴更衣」）→ **信息反转 @60s**「秦凤路林昭／对我西寿保泰军司发动攻击」（观众得知主角已抢先开打）→ 官员妥协（78–84s）。
- **冲突升级 @144s**「回我一个从五品的都承旨，打发叫花子吗」。即 **单集 ≥1 个信息反转 + ≥1 次冲突升级**，反转落在集内 **50%–60% 处**（60s/84s ≈ 71%；以集长 120s 计约 50%）。
- **喜剧调剂**并入结构：96s「当务之急先洗澡」、88s「非要切磋几日」，间隔约 20–40s 一个信息增量。

## 五、字幕规格（字数 / 行数 / 停留）——逐帧量

- **行数恒为 1**：抽 8 帧实测全部单行，**单行 5/6/8/10/11 字**，最长 11 字（时间卡）。
- **字高**：台词 **20px @640**（=3.1%H，折 1920 制 **约 60px**）；时间卡 18–23px；单字步进 22–22.5px（=3.5%H）。
- **位置**：白字顶边全部落在 **71.4%H**（区间 71.4%–76.4%），即屏幕上部 3/4 处，**不在最底部**，给平台底部 UI 留出 24%H。
- **停留**：与台词同步（2s 抽样每格都有字，切点处换字），实测未出现"一句跨三镜"的拖尾。
- **响度**：季首 I=**-11.42 LUFS** / TP=**+0.68 dBTP** / LRA 6.80；季中 I=**-10.98** / TP=**+0.36** / LRA 9.20。比我们的 -14 LUFS 规格更"顶"，但 TP 过 0 会削波。

## 六、AI 痕迹自查（本片犯了什么 / 怎么避开）

1. **塑料脸**（20s 张元吉）：皮肤零毛孔、五官过度对称、颧骨高光均匀 → 判据看"毛孔是否在高光区消失"；避开法：关键帧保留 15% 皮肤纹理噪声与不对称高光。
2. **换马串脸**（4/6/8s）：三个驿卒脸型跳变幅度远超"不同演员"应有差异，8s 那人手臂与缰绳穿插关系错 → 避开法：群演也要专属人物资产（该团队官方口径即"所有出场人物都有专属人物资产，专门规避串脸、脸盲"）。
3. **道具比例/接触关系错**（157s 红袍对谈）：茶壶与桌面接触面悬浮、两人视线不共轴 → 避开法：对话镜强制"三点共轴"（眼线、桌沿、道具底边）二次核。
4. **长镜空转**（111–132s 20.77s）：人物几乎不动，只有烛光在抖 → 避开法：>6s 长镜必须写进分镜，且镜内要有 1 次可指认的动作或表情变化。
5. **字幕位置漂移**：71.4% 与 76.4% 两档并存 → 避开法：字幕模板锁死单一基线，不做行数自适应。

## 七、三条可直接执行的规格（做法 + 判据）

1. **开场三段式（0–4.5s）**
   做法：0s 进画面，0–3s 内做 2 个硬切 + 一句"第 N 次 X"递进式短句（≤6 字），4s 出首句台词字幕，12s 出时间地点卡，14s 出主角名卡。
   判据：`drama_recon.py` 在 0–3.0s 检出切点 **≥2**；首句字幕首帧时间 ∈ **[3.0, 4.5]s**；前 3s 帧差均值 **≥0.02**（本片 0.0424）。

2. **镜长双档 + 长镜配额**
   做法：文戏按 2.9s 中位排；打斗/战争段压到 1.8s 中位；每 5 分钟只允许 1–2 条 >6s 长镜，且必须写进分镜。
   判据：文戏 300s 窗口 **中位 2.5–3.1s、P90 ≤4.2s**；动作 300s 窗口 **中位 1.7–2.0s、P90 ≤3.9s**；`>6s 长镜数 ≤2 / 5min`；`<1s 占比 ≤9%`。本片实测 2.88/4.13、1.83/3.83、4 条/5min、6.1%/8.8%，全部落区间。

3. **字幕与时间卡模板**
   做法：单行不换行，超 11 字先改词再上屏；字高 3.1%H（1920 制 60px）、单字步进 3.5%H；白字顶边固定 71%H；时间地点卡与台词同字号、同一基线；混音先 `loudnorm=I=-12:TP=-1.5:LRA=9` 再 `aresample=48000`。
   判据：抽 20 帧量白字 bbox → **行数恒为 1**、字高 **55–65px@1920**、顶边浮动 **≤2%H**；`loudnorm` 复测 **TP ≤ -1.0 dBTP**（本片 +0.68/+0.36 属反面样本，照抄会削波）。

## 我验证了什么

- 用 `drama_recon.py` 在本机跑了两段 300s 真实素材，切点/中位/P90/最快最慢/响度/帧率/分辨率均为工具输出，非估计。
- 逐帧读了 0–180s 的字幕（两张 contact sheet + 8 张单帧），集结构、时间卡位置、反转秒数是读出来的。
- 字幕行数/字高/位置是用灰度阈值量白字 bbox 得到的像素值（@640），可复跑。
- 榜单身份与官方集数/成本口径来自凤凰网 + 百度百科 + 知乎报道，已注 URL。

## 我没验证什么

- **没测原片分辨率与码率**（B 站 360p 二压件）；没测红果端真实首帧与完播率。
- **没做 ASR 转写**（本机无 faster-whisper / mlx_whisper），台词靠抽帧判读，0–180s 之后的内容未逐句核。
- **集界未定死**：音频静音间隔实测 66.0/60.5/62.2s（4 处），与 78.5s/集 不吻合，判断二传合辑已重剪，故集长取官方口径 + 合辑均值区间，不取单点。
- **"几个反转"只证到 1 个信息反转 + 1 次冲突升级**（60s / 144s），更多反转未证；`<1s 占比` 与 P90 依赖 0.30 阈值，阈值变化会小幅移动。
- 未核对第十一季是否 100 集整（二传标 113 集）。
