# 简介 v3：宏观但不鸡汤（2026-11-24）

> CEO：「还是很土味，什么硅基智能体，未来出行，汽车未来设计等等，发散一下，
> 宏观一点，伟大一点，但又不鸡汤」。
>
> **为什么我一直土**：我用的全是**行业黑话**——「未来出行」「智能座舱」「硅基智能体」。
> 行业词 = 乙方话术 = 土。
> **不土的做法**：用**本质词**（移动 / 形状 / 时间 / 空间）+ **具体的宏观**（一百年 / 2025 年），
> 而不是「未来」这种虚词。

## 一、先划清「宏观」和「鸡汤」的界

| 鸡汤（要避免） | 宏观（要的） |
|---|---|
| 「未来已来」「改变世界」「热爱」 | **具体的年份 + 具体的判断** |
| 形容词堆砌（伟大/震撼/颠覆） | **承认困难**（最难重做/最尴尬的一代） |
| 只给愿景，不给事实 | **给一个可反驳的观点** |

**判据**：一句话如果**可以被反驳**，它就宏观；如果**无法反驳**，它就是鸡汤。

> 例：「未来出行更美好」——无法反驳，是鸡汤。
> 「2025 年的车是一百年来最尴尬的一代」——可以被反驳，是观点。

## 二、八个候选

### A｜历史定位（首推）

```
汽车是二十世纪最重要的发明，现在它正在被重做一次。
```

- **为什么宏观**：把它放进「世纪」的尺度里，不是「一个行业」。
- **为什么不鸡汤**：只说「正在被重做」，不承诺结果。
- **可反驳**：「重做一次」是真的吗？—— 有得吵，所以不空。

### B｜有来有回

```
一百年前汽车改变了城市，现在城市正在改变汽车。
```

- **为什么宏观**：一个世纪的双向因果。
- **为什么不鸡汤**：陈述事实，不含情绪。
- **可反驳**：城市真的在改变汽车吗（限行/充电桩/停车位）？—— 有据可争。

### C｜谦逊的时代感

```
我们花了一百年学会造车，接下来要重新学一遍。
```

- **为什么宏观**：一百年 vs 现在。
- **为什么不鸡汤**：承认「要重新学」，不是「我们已经领先」。

### D｜本质洞察

```
汽车是人类造过最复杂的日用品。
```

- **为什么宏观**：一句定义整个行业（复杂 × 日用品 的反差）。
- **为什么不鸡汤**：没有一个形容词，全是判断。

### E｜有画面

```
一百年后回看，我们会说：那是车开始不像车的时候。
```

- **为什么宏观**：站在一百年后回看现在。
- **为什么不鸡汤**：不给结论，只给一个未来视角。
- **呼应**：直接呼应名字「未量产」（还没定型）。

### F｜三问式

```
关于移动，关于形状，关于我们为什么这样出门。
```

- **为什么宏观**：三个本质问题，不是三个业务方向。
- **风险**：略文艺，可能显得空。

### G｜判断式

```
2025 年的车，可能是一百年来最尴尬的一代。
```

- **为什么宏观**：百年尺度 + 当下判断。
- **为什么不鸡汤**：**承认尴尬**，不是吹嘘。
- **风险**：略尖锐，可能得罪车企（但求职向反而加分）。

### H｜最简

```
看懂一台车，需要看懂一个世纪。
```

- **为什么宏观**：世纪尺度。
- **风险**：略像文案。

## 四、推荐：**E 版**

```
一百年后回看，我们会说：那是车开始不像车的时候。
```

**为什么是它**：
1. **最宏观**：站在一百年后回看现在（时空尺度的最大跨度）。
2. **最不鸡汤**：不预测未来，只描述一个「未来人怎么看现在」的视角。
3. **和名字「未量产」完全咬合**——「车开始不像车」= 「还没定型」= 未量产。
4. **有画面**：能想象出那本书的标题页。
5. **可反驳**：车真的开始不像车了吗？—— 有得吵。

**备选 A（更直接的历史定位）**：
```
汽车是二十世纪最重要的发明，现在它正在被重做一次。
```

**备选 G（更尖锐，求职向加分）**：
```
2025 年的车，可能是一百年来最尴尬的一代。
```

## 五、如果还想更狠

还有两条更极端的路：

| 路子 | 例子 | 特点 |
|---|---|---|
| **单句宣言** | 「车还没定型。」 | 极简，但信息量少 |
| **否定式** | 「关于车，我们知道的都过时了。」 | 有冲击力，但略狂 |
