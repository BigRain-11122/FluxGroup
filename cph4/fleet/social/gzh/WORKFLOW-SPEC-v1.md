## ① 选题

**标准**（已有 `TOPIC-SELECTION-SPEC-v1.md` 六条硬判据）：
1. 标题点名 ≥1 个可搜对象
2. 套三种句式之一（动作现场物 / 数字悬念 / 断言对比）
3. `opponent` 非空（谁不希望你知道）
4. `scene` 是具体物（禁"随着…的发展"）
5. `verify_before_write` 指具体页面
6. 不含 `forbidden_promises`

**分类**（`CONTENT-SYSTEM-v1.md`）：C1 技术拆解 40% / C2 设计拆解 25% / C3 数据解读 15% / C4 对比 10% / C5 行业 8% / C6 方法论 2%

## ② 标题

**实测**（42 号 11 篇）：
| 维度 | 数据 |
|---|---|
| 长度 | 中位 **23 字**（8–38） |
| 含数字 | **7/11** |
| 类型分布 | 数字 7 / 动作 5 / 问句 4 / 冒号 3 / 陈述 2 |

**标准**：
- **18–26 字**
- **必须含一个具体数字或型号**（3,000 TOPS / 43% / 2026 款）
- 不用「震惊体」「速看」「必看」
- 三种可用句式：
  - **动作 + 现场物**：「探访小米龙甲电池诞生地，这里有一座「影子工厂」」
  - **数字 + 悬念**：「3,000 TOPS 算力智驾芯片明年见，Momenta 的兄弟公司什么来头」
  - **断言 + 对比**：「好零件都买得到，为什么理想还要自研三电？」

**自检**：标题里能不能指出「读者要查的那个东西」？指不出就是空泛。

---

## ③ 开篇

**实测**：首句 22–73 字，**中位 30 字**

**标准**：
- **≤30 字**
- 先给**具体场景或具体物**，不给结论、不做背景铺陈
- **禁止**：「随着…的发展」「在…背景下」「近年来」

**四种可用开篇**（全是真实样例）：
| 句式 | 样例 |
|---|---|
| 场合 + 人 + 冲突 | 「在享界 V8 的发布会上，余承东凭借 L3 自动驾驶「争议发言」再次成为了主角」 |
| 时间 + 主体 + 动向 | 「2026 年，小米、理想等车企，都在争取更多电池产品的定义权」 |
| 具体日期 + 事件 | 「11 月 9 日，魏牌二代蓝山正式开启预售」 |
| 对话细节 | 「陶吉入职长安时，公司已经有了一个一千张 A100 的集群」 |

**判据**：读完第一句，读者能不能**想象出一个画面**？

## ④ 结构

**实测**：
| 维度 | 数据 |
|---|---|
| 段落数 | 5–151 段 |
| **平均段长** | **73–165 字，中位约 78 字/段** |
| 小标题 | 中位 **3 个**（范围 0–40，40 是 Q&A 体） |
| 小标题句式 | **断言式**（5% 疑问句） |

**标准**：
- **每段 60–90 字**（这是最重要的一条——长段落是阅读杀手）
- **3–4 个断言式小标题**
- 每个小标题下 **2–4 段**
- 小标题**禁止疑问句**，用短句断言：「毛利率涨了，利润却掉了四成」

**为什么段落要短**：手机屏 420px 宽，一行约 18 字，78 字 = 4–5 行 = 一屏内可读完。

## ⑤ 论证（密度）

**实测数字密度**：
| 文章 | 千字数字数 |
|---|---|
| 3,000 TOPS 芯片 | 24.2 |
| 理想 i6 拆车 | 29.3 |
| 坦克 500 | 29.3 |
| 享界 V8 | 25.7 |
| 探访小米电池 | 10.0 |
| 对话陶吉（Q&A） | 3.5（特例，对话体） |

**标准**：
- **每千字 20–30 个数字**
- 每 300 字至少 **1 个可核验细节**（数字/型号/法规条款/官方参数）
- 每个数字**必须带来源**（工信部公告/财报页码/官网配置表）
- 不许用「大概」「左右」「约」堆砌模糊表述

**为什么**：数字是可核验性的载体。没有数字的文章，读者无法验证，也就无法信任。

## ⑥ 结尾

**实测**：三种收尾
| 类型 | 样例 |
|---|---|
| 行业判断 | 「对 35 万级家用 MPV 市场而言，享界 V8 的意义不只是增加一个选项，而是把旗舰配置从高配专属变为全系标准」 |
| 回到具体 | 「在南昌，小米通过「影子工厂」与欣旺达动力一起做这些工作」 |
| 留悬念 | 「陶吉：如果它是一个数据驱动的事情，我觉得还是有机会」 |

**标准**：
- **给判断，不喊口号**
- **禁止**：「未来可期」「拭目以待」「这就是中国制造的力量」
- 三种收法选一：行业判断 / 回到具体物 / 留一个可讨论的问题
- **不加"关注我"式硬广**（公众号环境里很掉价）

## ⑦ 配图

**实测**：0–17 张，中位约 **8–10 张**

**标准**：
- **每 400–500 字一张图**
- 图必须**服务论证**（不是装饰）：界面截图、参数表、对比图
- 截图**局部放大到能看清字**
- 标注编号 ①②③ 对应正文
- **禁止**：表情包、花字、无意义配图

**我们的特殊要求**（HMI 视觉专业）：
- 界面截图必须标出版本号与日期（OTA 会变）
- 关键元素加红框/箭头
- 同一篇文章内的截图**统一尺寸比例**

## ⑧ 排版

**工具**：`Tools/fleet/gzh_render.py`（doocs/md，13.5k⭐）

**标准**：
- 主题 `grace`，主色 `#FF5A1F`
- 宽度 420px（手机屏）
- 正文 16px / 行高 1.75
- 小标题圆角灰底（工具自带）

**流程**：
```
article.md → gzh_render.py --preview → article.html + shot.png
          → 打开 html → 全选复制 → 粘贴进公众号编辑器
```

## ⑨ 发布

**标准**：
- **手动发布**（平台风控 + 个人号无 API）
- 发布前检查清单：
  1. 标题含长尾词（汽车 HMI / 汽车设计 / 智能座舱）
  2. 摘要 120 字内，含核心关键词
  3. 原创声明已勾选
  4. 封面图（900×383）
  5. 合集已选（对应 C1–C6）

**发布时机**（待验证）：
- 汽车类内容工作日 **早 8–9 点 / 晚 8–10 点** 阅读高峰
- 避开重大发布会当天（信息被淹没）

## ⑩ 复盘

**每篇发布后 48 小时看四个数**：
| 指标 | 判据 |
|---|---|
| **完读率** | ≥50% 合格（2026 权重第一，35%） |
| 打开率 | ≥5% |
| 分享率 | ≥2% |
| 留言数 | ≥3 |

**完读率低怎么查**：
1. 看后台「阅读完成度」曲线（在哪一段掉的）
2. 掉在开头 → 开篇不够具体
3. 掉在中间 → 段落太长/小标题不吸引
4. 掉在结尾 → 结尾太口号
