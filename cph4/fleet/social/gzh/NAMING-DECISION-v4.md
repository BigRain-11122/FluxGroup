# 命名 v4：未来设计方向（2026-11-24）

> CEO 令：「不要聚焦什么屏幕 智能座舱 太片面了 以后要聊的多了去了」
> 「一定要凸显未来科技 汽车未来的设计 前沿的设计 等等」。
>
> **v1–v3 的共同错误：都在「当下」里找名字**（车机 / 座舱 / HMI / 副驾）。
> 那些是「现在有什么」，不是「未来会怎样」。v4 转向**未来与设计**。

## 一、先认错：前三版都窄在哪

| 版本 | 名字 | 窄在哪 |
|---|---|---|
| v1 | 孙工看座舱 | 只有座舱 |
| v2 | 皮与像素 / 钢与像素 | 只有材质与屏幕 |
| v3 | 硅基副驾 | 只有副驾那一个位置 |

**共同病**：名字都在**描述「我做什么」**，而你要的是**「我在想什么」**。
设计师和资讯号的区别就在这——前者有**主张**，后者只有**范围**。

## 二、v4 的立意

> **汽车正在被重新发明。我在看它会长成什么样。**

这句话决定了三件事：
1. **未来**：不写「现在哪台车好」，写「车会变成什么」。
2. **设计**：从造型、交互、材料、空间、城市五个维度看，不只屏幕。
3. **前沿**：概念车、原型、实验室、跨界（建筑/产品/时尚）都是素材。

## 三、能聊什么（证明名字够宽）

| 维度 | 具体 |
|---|---|
| **造型** | 概念车、比例、曲面、品牌设计语言、设计史 |
| **交互** | 从按键到语音到脑机，界面如何演化 |
| **材料** | 新材料、可持续、可回收、变色、自修复 |
| **空间** | 座舱 → 第三空间 → 移动办公室/卧室 |
| **出行** | 自动驾驶、Robotaxi、飞行汽车、城市交通 |
| **跨界** | 建筑、产品、时尚、艺术如何影响汽车 |
| **哲学** | 人与机器、碳基与硅基、设计的伦理 |
| **历史** | 汽车设计百年，为什么长成这样 |
| **未来** | 2030/2040 的车会是什么样 |

**这就是「以后要聊的多了去了」——名字必须撑得住这张表。**

## 六、我的推荐

### 首选：**「未完成的汽车」**

一句话：**汽车还没定型，每一代都是草稿，我在看它会长成什么样。**

五条理由：
1. **有主张**（未完成 = 还在进化），不是描述范围。
2. **够宽**：造型、交互、材料、空间、出行、哲学全都装得下——「未完成」本身就是无限空间。
3. **有设计感**：「未完成」是设计术语（work in progress），同行一看就懂。
4. **未来感强**：指向未来，不指向现在。
5. **不落俗**：不像「车评」「观察」「笔记」，也不像「硅基副驾」那样绑死一个位置。

### 备选：**「未来的形状」**

- 更文学、更国际化（The Shape of Things to Come）。
- 但**不含「汽车」**，好处是更宽，坏处是可能被当成泛设计号。
