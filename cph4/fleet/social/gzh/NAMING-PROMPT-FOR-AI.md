# 给其他 AI 的取名提示词（2026-11-24）

> 用途：CEO 拿去别的 AI 求名字。下面代码块内**全部内容**可原样复制。

```markdown
# 任务

帮我给一个微信公众号起名。只给名字，不要写文章、不要做方案。

# 我是谁

我是一名**专职汽车 HMI 视觉设计师**（Human-Machine Interface，人机界面视觉设计）。
我的正职就是做汽车座舱里的界面、交互、视觉、动效、图形系统。

# 公众号要做什么

**主要目的是包装我自己**：立专业人设、拓展职业边界、积累个人品牌资产，**最终服务于求职**
（去车企 / 供应商 / 做独立顾问）。**流量和变现是次要的**，是副产品。

内容方向：**汽车未来的设计、前沿设计、未来科技**。
可以聊：概念车、造型与比例、交互演化（按键→语音→脑机）、新材料、第三空间、
未来出行（Robotaxi/飞行汽车）、设计与建筑的跨界、汽车设计史、设计哲学、AI 与设计的关系。

**注意：绝对不要窄化成「智能座舱」或「车机屏幕」**——那只是其中一小块，我要聊的多得多。

# 名字必须满足（硬要求，缺一不可）

1. **有设计师调性**——克制、有审美、有文化感。这是第一优先级，其他都让位。
2. **有记忆点**——念一遍就记住。短、具体、有画面、能当口头禅。
3. **2–4 个字**（微信限制 2–15 个汉字，但越短越好）。
4. **是一个「名字」，不是「描述」**——要有主张、有张力，不能是「某某观察」「某某笔记」这种说明自己的短语。
5. **能撑住「汽车未来设计」这个宽度**——不能绑死在某一个部位（屏幕/座舱/副驾）。

# 明确不要（这些我已经全部否掉了，别重复）

## 媒体腔（太俗）
- 孙工看座舱、智能车观察、汽车智能化笔记、车机审美
- 病根：用「看 / 说 / 评 / 观察 / 笔记」——这是资讯号，不是设计师。

## 太窄（只一个部位）
- 皮与像素、钢与像素、硅基副驾、HMI 观察
- 病根：绑死在「屏幕」「座舱」「副驾」，写不了别的。

## 描述性短语（没记忆点）
- 未完成的汽车
- 病根：6 个字、完整句子、无张力，念一遍记不住。

## 已被占用（查重实测，别推荐）
- 草稿（已注册）
- 未来的形状（已注册）
- 智能车观察（有 6 个近似号稀释）

# 好的记忆点只有三种来源（参考）

1. **内行暗号**：只有做过这行的人才起得出，外行会问「什么意思」
   - 例：壁纸 Wallpaper*、单片眼镜 Monocle
2. **时间反转**：用「还没发生」说「正在发生」，制造张力
   - 例：晚点 LatePost
3. **口语反差**：像朋友说话，敢说不好听的
   - 例：差评

# 不能违反的合规红线（2026 年新规）

2026 年网信办专项整治汽车自媒体（虚假测评、商誉诋毁已有人判刑）。
**名字不能带「打假 / 揭黑 / 真相 / 黑幕 / 难看」这类暗示**，否则第一个被当靶子。

# 输出格式

给我 **10 个候选**，按推荐度从高到低排序。每个包含：

| 名字 | 英文 | 一句话主张 | 为什么有记忆点 | 风险 |

要求：
- 「一句话主张」必须是一句完整的话，说明这个名字代表什么立场。
- 「为什么有记忆点」要具体（短？具体物？反差？），不要说「好听」「有感觉」。
- 「风险」要诚实（外行不懂？太文艺？可能被误解？）。
- 最后单独写一段：**你认为最好的 1 个是哪个，为什么**。
```

---

## 附：为什么这样写（给自己看的）

1. **先说身份和工作目的**——AI 才知道「设计师」和「求职」这两个约束。
2. **把「不要窄化」写成硬要求**——我前三版就是窄化，反复被否。
3. **列出全部已否方案 + 病根**——避免 AI 重复我踩过的坑。
4. **给出「记忆点三来源」**——不是让它自由发挥，而是给它**可操作的生成方法**。
5. **合规红线**——AI 不知道 2026 年新规，必须写进去。
6. **输出格式**——要求「一句话主张」和「为什么有记忆点」，逼它给出可判断的理由，而不是形容词堆砌。
