# 英文名方案：「未量产」的全球化命名（2026-11-24）

> CEO：「未量产 备选 并取一个英文 全球化」。
> 关键原则：**全球化品牌名不是翻译，是独立设计**。
> 直译 `Unproduced` / `Not Yet Produced` 又长又笨，国际场合没法用。

## 一、先看「未量产」的语义内核

| 层次 | 含义 |
|---|---|
| 字面 | 还没进入批量生产 |
| 行业 | 概念车 / 原型 / 预生产阶段 |
| **立场** | **我聊的是一台车还没定型时的样子**——比发布早 3 年 |
| 情绪 | 期待、未完成、正在成形 |

所以英文名要抓到的是**「还没发生」的张力**，不是「生产」这个词。

## 二、三个候选

### ① **UNBUILT**（主推）

> **还没造出来，所以我先聊。**

| 项 | 说明 |
|---|---|
| 字面 | 未建造、未建成 |
| 为什么好 | **7 个字母，全球都能念**（un-built）；建筑/设计圈常用（unbuilt project = 未建成方案），天然有设计师调性；**独特**——几乎没有品牌用这个词 |
| 语义 | 汽车「造」出来 = built，未量产 = **unbuilt**，比 unproduced 更短更有画面 |
| 风险 | 略偏建筑语感；但正是这点让它不像车评号 |
| 域名 | `unbuilt.design` / `unbuilt.auto` 可试 |
| 社媒 | `@unbuilt`（可能需要后缀） |

### ② **PROTO**（更科技）

> **Prototype 的前半段。**

| 项 | 说明 |
|---|---|
| 字面 | Prototype（原型）的缩写 |
| 为什么好 | **5 个字母，极短**；科技圈天然懂（prototype）；全球好念；有「还没定稿」的含义 |
| 语义 | 原型 = 未量产，直接对应 |
| 风险 | **太常见**（大量公司/产品叫 proto），域名基本被占，独特性低 |

### ③ **PRE-PRODUCTION**（最专业）

> **行业标准术语：预生产。**

| 项 | 说明 |
|---|---|
| 字面 | 预生产（汽车行业标准阶段名） |
| 为什么好 | **最专业、最准确**——车企内部就是这么说的；内行一看就知道你懂行 |
| 语义 | 完全对应「未量产」 |
| 风险 | **13 个字符，太长**，社媒 handle 和 logo 都难处理；不够「名字」 |

## 三、评分

| 候选 | 记忆点 | 全球化 | 设计师调性 | 独特性 | 长度 | 总分 |
|---|---|---|---|---|---|---|
| **UNBUILT** | 4 | **5** | **5** | **5** | **5** | **24** |
| PROTO | **5** | **5** | 3 | 1 | **5** | 19 |
| PRE-PRODUCTION | 2 | 3 | 4 | 3 | 2 | 14 |

## 四、推荐：**UNBUILT**

五条理由：
1. **语义最准**：汽车是「造」出来的（built），未量产就是 **unbuilt**——比 unproduced 短得多。
2. **设计师调性**：建筑/设计圈说「unbuilt project」（未建成方案），天然是设计师语汇。
3. **全球化**：7 字母，任何语言都能念，无歧义。
4. **独特性最高**：几乎没有品牌用这个词，不会撞。
5. **有张力**：unbuilt = 还没发生，正好对应「我比你早看到」。

## 五、中英文怎么配合

### 方案 A：中英并列（推荐）

```
公众号名：未量产
英文副标：UNBUILT
```
- 中文名做主体（搜一搜能找到），英文做**视觉标识**（头像、首图、作品集）。
- 例：头像下方小字 `UNBUILT`。

### 方案 B：英文主、中文副

```
公众号名：UNBUILT
```
- **不推荐**：微信里搜英文的人少，会损失自然流量。
