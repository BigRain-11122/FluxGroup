# 命名 v6：三种记忆点类型（2026-11-24）

> 已经否了 5 版。我不再堆候选，改为**给你三种「记忆点类型」各一个最强的**——
> 你先选类型，再定名字。这样比我盲猜快。

## 一、记忆点只有三种来源（这是全部）

| 类型 | 原理 | 真实案例 |
|---|---|---|
| **① 内行暗号** | 只有做过这行的人才起得出，外行会问「什么意思」 | 壁纸 Wallpaper*、单片眼镜 Monocle |
| **② 时间反转** | 用「还没发生」描述「正在发生」，制造张力 | 晚点 LatePost |
| **③ 口语反差** | 像朋友说话，敢说不好听的 | 差评 |

**「未完成的汽车」三种都不占**——它是**描述**（6 字、完整句子、无张力），所以没记忆点。

## 二、三种类型各一个（已查重）

### 类型 ①：内行暗号 —— **「油泥」**

> **汽车是油泥里刮出来的。**

| 项 | 说明 |
|---|---|
| 为什么有记忆点 | **2 字 + 具体物**。做过汽车造型的人一听就懂（油泥模型是核心工艺），外行会问「什么油泥？」——**这个问号就是记忆点** |
| 宽度 | 表面只指造型，但「油泥」是**所有设计的起点**，可延伸到任何形态 |
| 查重 | ✅ **可用**（近似：油泥大叔、AutoDesign 汽车油泥师俱乐部，无精确同名） |
| 风险 | 外行不懂；可能被认为只写外观 |

### 类型 ②：时间反转 —— **「未量产」**

> **这台车还没量产，所以我先聊。**

| 项 | 说明 |
|---|---|
| 为什么有记忆点 | **「未」+「量产」是错位组合**——量产是行业结束语，提前 3 年用它，制造「我比你早看到」的张力 |
| 宽度 | **最大**：概念车、原型、未来出行、设计趋势全在「量产之前」 |
| 查重 | ✅ **可用**（近似：未量产的生活、CCPC 量产车大赛） |
| 风险 | 「未」是否定词，可能被读成「没生产」；3 字，「产前」有轻微歧义 |

### 类型 ③：口语反差 —— **「车还没好」**

> **别急着买，车还没好。**

| 项 | 说明 |
|---|---|
| 为什么有记忆点 | **口语 + 敢说不好听**。像「差评」「晚点」，一句话就有立场，念一遍就记住 |
| 宽度 | 大：任何「还没做好」的设计都能写 |
| 查重 | 未查（3 字以上撞名概率低，但需确认） |
| 风险 | **最不专业**，可能被认为「不严谨」；但在设计圈，「车还没好」是共识 |

## 三、我个人的判断

**按你说的「设计师调性 + 记忆点 + 不要片面」，类型 ② 的「未量产」最平衡。**

理由：
1. **记忆点够**（错位组合，有张力）
2. **宽度最大**（不片面——所有「未来」都在量产之前）
3. **专业感在**（「量产」是行业词，资讯号不会用）
4. **有主张**（我比你早看到 3 年）

**如果你要更狠的记忆点、不在乎专业感 → 选「车还没好」。**
**如果你要更专业、能接受外行不懂 → 选「油泥」。**

## 四、如果三种都不对

那我需要你给**一个你喜欢的名字**（任何行业、任何领域），
