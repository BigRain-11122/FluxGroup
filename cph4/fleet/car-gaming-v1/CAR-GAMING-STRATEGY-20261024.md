# 车机游戏业务条线：战略执行方案 v1（2026-10-24）

> 依据：CEO 2026-10-24 令 + `CAR-GAMING-MARKET-REPORT-20261024.md`
> 主责：游戏公司（Biggame）｜协同：BigStream（内容/IP）、BigDomain（商业化）、BigLife（城市/IP）、CPH4（研究/合规）
> 性质：战略级业务条线（BU），不是单个项目

---

## 1. 战略定位（一句话）

**做「驻车场景的原生家庭娱乐」，用一套跨车企复用的产品底座 + 可售卖的适配能力，先拿到 OEM 合同，再收获用户规模。**

三条不做：
1. 不做手机游戏搬运；
2. 不做 3A/重度/需要高算力的产品；
3. 不自建分发平台、不做广告/IAA。

---

## 2. 业务结构：双轮 + 一个底座

```
                 ┌─────────────────────────────┐
                 │  产品底座（跨车企复用）      │
                 │  吸嘟嘟家庭版 + 车机适配层    │
                 └───────────┬─────────────────┘
                             │
        ┌────────────────────┴────────────────────┐
        │                                         │
   A 轮：自有产品（慢）                     B 轮：能力输出（快）
   买断/皮肤/章节扩展                      适配/移植/预装/联合运营
   建品牌、建资产、建用户                    养团队、拿合同、拿数据
```

- **A 轮**：吸嘟嘟家庭版（亲子、无失败、单屏家长协作、多屏扩展）。目标不是短期收入，是「上车样板 + 品牌 + 可复用资产」。
- **B 轮**：把 Unity/团结 的座舱适配能力产品化，接车企/平台的内容适配、移植、定制、联合运营。目标是把固定成本变成合同收入。
- **底座**：一套「车机适配层」（分辨率桶、输入路由、驻车闸、存档、音频守卫、多屏），所有产品共用。

## 3. 三阶段路线图

### 阶段 0：卡位（2026-10-24 → 2027-01-31，90 天）

| 周 | 交付 | 验收 |
|---|---|---|
| W1–W2 | 车机版可玩 demo（前 2 章、1920×720/1080、单屏协作、家长锁、无广告无付费） | 8295/8155 真机或等效设备跑通；录屏 60s |
| W2–W3 | 提交理想 × Unity 内容合作材料（产品介绍、Demo、适配说明、合规声明） | 进入对方评审流程 |
| W3–W4 | 比亚迪 OIP 开发者注册 + 上架材料 | 账号开通、测试包提交 |
| W4–W6 | 鸿蒙 NEXT 座舱适配预研（模拟器 3402×1620） | 能在模拟器启动首屏 |
| W6–W8 | 第二款产品立项（多屏派对/轻竞技，复用底座） | 立项书 + 可玩原型 |
| W8–W12 | 首个 OEM 合同谈判（适配/预装/联合运营） | 至少 1 份 LOI 或框架协议 |

**阶段 0 唯一硬指标：拿到 1 个正式的合作意向，而不是 DAU。**

### 阶段 1：上车（2027-02 → 2027-06）

- 吸嘟嘟车机版完成 1 家 OEM 上架（免费 demo 或买断，视版号进度）。
- 完成 2 个分辨率桶之外的扩展：2.5K/3K、超宽只读侧翼、竖屏。
- 建立「车机 QA 清单」：驻车闸、音频、存档、冷启动、30 分钟浸泡、手柄、多屏。
- B 轮签下 2–3 个适配/定制合同，覆盖团队固定成本。

### 阶段 2：规模化（2027-07 → 2028-06）

- 产品矩阵 3 款（亲子 / 派对 / 解压），共享底座。
- 覆盖 3–5 家 OEM 或 2 家聚合平台。
- 建立内容合作池：外部开发者用我们的适配层上车，我们抽成。
- 评估海外 AAOS / Google Play（家庭政策合规先行）。

## 4. 产品矩阵

| 优先级 | 产品 | 场景 | 状态 | 复用 |
|---|---|---|---|---|
| P0 | 吸嘟嘟家庭版（车机） | 亲子、充电等待、后排 | 已有 90 关资产 | 现有工程 + 车机适配层 |
| P1 | 多屏派对（暂名） | 家庭/朋友、服务区、露营 | 立项 | 底座 + 手柄/手机当手柄 |
| P1 | 解压轻游戏（暂名） | 等人、短停 | 评估 | 底座 + 美术管线 |
| P2 | OEM 定制小游戏 | 品牌活动/车展 | 按单 | 底座 + 快速定制流程 |

**产品原则**：
- 单局 90–150 秒，可中断，无失败惩罚；
- 首屏可点元素 ≤7，按钮 ≥76×76，正文 ≥28px；
- 一次开发，多分辨率/多车企复用；
- 所有产品默认支持「家长锁 + 儿童模式 + 无广告」。

## 5. 渠道打法

| 渠道 | 打法 | 关键动作 | 负责人 |
|---|---|---|---|
| 理想 × Unity | 以「家庭亲子」补商店品类空缺 | Demo + 一页纸 + Unity 内容合作对接 | BD + 制作人 |
| 比亚迪 OIP | 以「体量 + 开放生态」做首发规模 | 开发者注册、测试、D++ 专区、商务谈游戏类目 | BD |
| 华为鸿蒙 NEXT | 以「早期适配」换首发位 | 模拟器适配、原生包、参加开发者激励计划 | 技术 + BD |
| 小米 | 后排屏亲子场景 | 应用发布入口、家庭向包装 | BD |
| 蔚来/小鹏/极氪 | 品牌联名/定制 | 一家一家谈，不铺开 | BD |
| 聚合平台（YOCY 等） | 一次接入多车企 | 评估 SDK/分成/排他条款 | BD + 技术 |

**BD 纪律**：同一时间最多 3 条渠道并行；每条渠道必须有「下一步动作 + 日期 + 对方联系人」，否则降级。

## 6. 商业模式与定价

| 收入项 | 定价假设 | 触发条件 | 备注 |
|---|---|---|---|
| 车机免费 demo | 0 | 立即 | 用于 BD 与审核 |
| C 端买断 | ¥28–38（首发/标准） | 国内版号后 | 海外 $9.99–14.99 |
| 家庭包 | ¥58 | 版号后 | 含皮肤/相册主题 |
| 皮肤/主题 | ¥6–18 | 版号后 | 纯外观 |
| 章节扩展 | ¥12–18 | 版号后 | 内容型复购 |
| 适配/移植服务 | ¥20–80 万/款 | 签约 | B 轮主收入 |
| 预装/授权 | 按车型或激活量 | 签约 | 参考 Unity 模式 |
| 联合运营分成 | 流水 15–30% | 签约 | 车企自研 OS 常见低分成 |

**定价纪律**：不在没有版号的情况下出现任何国内付费入口；车机端支付走 OEM/二维码 H5，不自建支付。

## 9. 风险与止损

| 风险 | 止损条件 | 动作 |
|---|---|---|
| 90 天内无任何渠道进入评审 | 立即停 B 轮扩张 | 转「B 端纯适配服务」，保留产品底座 |
| 12 个月内无 OEM 合同 | 降级为项目制 | 不再投入自有产品新内容 |
| 版号超 12 个月 | 国内付费停 | 海外/车机 demo 为主 |
| 行车安全监管收紧 | 立即合规改造 | 全系 P 挡硬门 + 白皮书 |
| 单车企定制导致无法复用 | 拒绝该需求 | 复用率 <70% 的定制不接 |
