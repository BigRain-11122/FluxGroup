# MSG-20261027-1655 — clock v2 升级（bm-b / bm-c 一次性本地同步）

**触发**：CEO 令「机队之间毫秒对齐所有信息」。bm-a 已升级并实测（offset 0.0ms / precision ±0.5ms），但 bm-b、bm-c 的心跳仍是 v1（秒级、无 offset）。
**根因**：FleetLink pull 对根仓报 `updated-kept-local`——拉到新提交但保留本地改动，`Tools/nats/nats-heartbeat.ps1` 没被覆盖，所以升级不生效。

## 每台机执行一次（repo 根目录）

```powershell
git fetch origin main
git checkout origin/main -- Tools/nats/nats-heartbeat.ps1 Tools/nats/clock-probe-nats.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\nats\nats-heartbeat.ps1
```

## 验收

```powershell
Tools\nats\bin\nats.exe -s nats://100.110.185.62:4222 kv get FLEET_STATE state.<node> --raw
```

返回 JSON 必须含 `ts_utc_ms`、`seq`、`clock_offset_ms`、`clock_rtt_ms` 四个字段；缺一即仍是 v1。

## 说明

- 时间基准=bm-a 的 `clock.ask`（走既有 4222，无新端口/防火墙改动）。
- 精度上限=链路 RTT/2：同机 0.5ms，Tailscale 中继约 ±70–130ms。1ms 级只有在直连/同局域网才成立。
- 本机的 `FluxGroup-NatsHB` 任务下次触发（≤60s）自动带 v2 字段上链。
