## P2 · 主控容量采样与渲染自噬形成“自锁”

`lanes/bm-c.json` 在 23:04:00 写的是 `CAPACITY-BLOCKED-RAM ram 2.0/3.0 GB`、`lane_ok=false`。
但那一刻 **2.0GB 是本机自己渲染时的瞬时值**（stage 20GB 权重导致），不是机器没能力。

结果是死循环：渲染 → RAM 掉到 2GB → 主控判阻塞不派活 → 本机渲染完 RAM 回升 → 主控下一轮再采到空闲……但若此时队列里没有 bm-c 的卡，就变成“渲染时空、空闲时没活”。

**建议**：GPU 卡按 `min(ram_floor, 1.0)` 判定（`lane_capacity` 里本来就有这条），并对“本机正在执行自己声明的批”这一状态做豁免或标注，不要直接落到 `CAPACITY-BLOCKED-RAM`。
