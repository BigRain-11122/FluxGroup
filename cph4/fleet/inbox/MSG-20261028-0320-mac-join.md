# MSG-20261028-0320 — bm-m（M1 Pro）入列：Mac 上跑一条命令

**现状**：Mac 已到货并验收，但**还不在 Tailscale 机队里**（当前只有 bm-a/b/c），所以无法从 bm-a 远程安装。

## 在 Mac 上执行（一次）

前置：Tailscale 已登录、git、python3（Xcode CLT）、仓库 SSH key。

```bash
git clone git@github.com:BigRain-11122/FluxGroup.git ~/FluxGroup   # 已有仓库可跳过
cd ~/FluxGroup
bash Tools/fleet/bootstrap_mac.sh
```

脚本会：

1. 校验 git/python3/Tailscale（App Store 版也能识别）；
2. 拉取 main；
3. 用本机 `ComputerName` 和 `tailscale ip -4` 填 `Tools/fleet-nodes.json` 的 **bm-m** 并 `enabled=true`；
4. 发第一条毫秒心跳到 NATS（`FLEET_STATE state.bm-m`）；
5. 装三个 launchd：**心跳（60s）/ fleet-agent（常驻）/ caffeinate（不休眠）**；
6. 打印验收提示。

## 在 bm-a 验收

```powershell
Tools\nats\fleet-clock-report.ps1     # 应出现 bm-m，offset/precision 有值
python Tools\fleet\fleet_order_bus.py --send-file <utf8.txt> --lanes bm-m
```

`ack` 应出现 `cph4/fleet/cmd/<id>.bm-m.ack.json`。

## 主控切换

- 先让 bm-m 稳定跑 **24 小时**（心跳、ack、时钟）；
- 再把命令总线与看板切到 bm-m；
- **bm-a 保持热备不撤**，bm-d 入网后再定最终主控拓扑。

## 不做的事

- 不在 Mac 上跑 Windows 计划任务/S4U/FleetLink listener；
- 不让 Mac 接 GPU 生产（无 CUDA）；
- 不把主控切换与入列合并成一步，避免主控断档。
