## 一、本轮定谳：三个"越改越差"的反模式（实测教训，写进纪律）

1. **提示词里写禁语 = 磁吸**
   v3.4 写了「也不说"争取早日""尽快上线"这种客服话」→ 8 次采样 8 次都是"争取早日上线"。
   **正法：提示词只写正向要求；所有禁语只放机检闸（G1）。**

2. **给例句 = 逐字照抄**
   v3.5 用"坏例→好例"对照教具体感 → 模型把好例原句搬进回复（"那转场我拆成三段剪的，中间那段重拍了四回"）。
   与 10-14 "35B 照抄 persona 例句"同源。**正法：不写例句，写判据（"每条落到一件具体的事"）。**

3. **打分函数奖励什么，模型就学会什么（Goodhart）**
   - 奖励"语气词数量" → 满屏"吧啊哈哈"；
   - 奖励"工艺词/自述" → 句句"熬到凌晨两点"；
   - 奖励"锚词复述" → 养出"X确实挺Y"的空话万能回复（还能骗过闸）。
   **正法：打分只做减法（模板/空话/语气词超限/超长/跨条重复），不给任何词加分；具体性靠提示词，不靠打分。**

## 二、生产管线（v3.6 定稿）

```
评论 → 生成 4 候选（temp 0.8/0.9/1.0/1.1，think=false）
     → sanitize（剥思考段 / 脱整句引号 / 去 emoji）
     → 闸 G1-G15（含跨条复读 G7/G7b）
     → 过闸候选按"减法分"取最高 → 发送
     → 全 fail = 跳过该条（宁可少回不可尬回）
```

模型：本地 `qwen2.5:7b-instruct`（GPU 24 层，~1.5s/条）；4B（`qwen3.8:4b`）为低配回退，质量明显更差（见对照板）。

## 四、诚实的能力边界（不粉饰）

- **本地 7B 的天花板**：能稳定产出"B站中位数"回复——接梗、短、无客服腔、无泄漏；但**缺少锐度**，偶发空话（"确实挺炫的"）与答非所问。
- **闸测不出"好在哪"**：闸只能判"不烂"，判不了"漂亮"。7B 当裁判实测自相矛盾（pick 与理由打架），已弃用。
- **上限提升只有两条路**：① 换更大本地模型（14B/32B，需下载）；② 云端做"精修层"（本地出候选→云端改写一条，成本极低）。两条都需 CEO 定。

## 五、验收

- 机检：10 条真实评论 → **8/10 通过，2 条跳过**（无泄漏/无 emoji/无编造/无跨条复读）。
- 人检：对照板 `bili_before_after_v3_20261020.md`（v1 现行 vs v2 vs v3.1 vs v8 定稿）。
- 盲评口径（SPEC v2 沿用）：随机混入 3 条真人手写回复，CEO 挑不出=过关。
