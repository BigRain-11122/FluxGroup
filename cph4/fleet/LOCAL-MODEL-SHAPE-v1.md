# 本地大模型形态决策：小档常驻 + 大档批处理（LOCAL-MODEL-SHAPE v1）

> 令源：CEO 2026-11-17「科学梳理本地大模型，是加载大的聪明的用流水线的形式排单，还是并行加载小的够用的」
> 结论口径：不是二选一。**高频小任务用小档常驻并行提交；低频难任务用大档按批换入、串行跑完即卸；真正的并行在多机，不在单机。**

## 一 实测（2026-11-17 本机 MacBook，32GB 统一内存）

| 项 | 数值 | 说明 |
|---|---|---|
| 物理内存 | 32GB | wired 3.6GB，Pages free 曾低至 384MB→125MB |
| 常驻占用 | 9B@32k **9.9GB** + 4B@8k **6.6GB** = **16.5GB** | 已越过 `resident_gb_limit=16.0` |
| swap | 已用 2.6GB / 总计 4GB；Swapouts 6.1GB；Swapins 2.5GB | 不是"偶发"，是长期换页 |
| 解码速度 | 4B **39 tok/s**；9B **23 tok/s**（0.59×） | 同 prompt、预热后、只算解码段、取两次均值 |
| 并发 2 条 | 4B：单条 38.5 / **聚合 36.0**；9B：单条 23.0 / **聚合 21.6** | **并发不增吞吐**，只把延迟摊薄 |
| 冷加载 | 20-40s（正典口径，本轮未重复测） | 大档每次换入都要付 |

三条读法：
1. **单机没有"并行"这回事**：一个 GPU/内存池分时复用，聚合吞吐≈单条吞吐。所以"并行加载小的"在单机上买到的是"更多在飞请求"，不是"更多产出"。
2. **同时驻两个档是最差组合**：16.5GB 常驻 → 换页 → 4B 也被拖慢（本该 39 tok/s，换页时实测掉到 20）。
3. **大模型的价值在质量，不在吞吐**：9B 只在"给了证据+契约"的题上强于 4B（正典口径：本地 7B 是语感天花板，9B 判卷仍会跑偏），拿它干高频短任务＝用 2.5 倍内存换 0.59 倍速度。

## 二 正确形态（三层，不是二选一）

| 层 | 谁 | 形态 | 判据 |
|---|---|---|---|
| L1 规则层 | 纯 Python | 常开 | 数字/事实/红线/去重/配额一律不花模型（4B 算术实测全错） |
| L2 小档常驻 | `qwen3.5:4b-mlx`@8k + embedding | 常驻，`keep_alive=10m` 闲置即卸 | 分类/打标/风险/摘要/草稿候选；多线程提交（吞吐不增但延迟平摊） |
| L3 大档批窗 | `qwen3.5:9b-mlx`@8k，`keep_alive=2m` | **按批换入**：一轮把难任务攒成队列，串行跑完即卸 | 判卷/长文改写/创意文案/代码审查；一批 ≥5 条才值一次冷加载 |

优先级固定：P0 规则红线（不花模型）> P1 分类（4B）> P2 草稿（4B 多候选）> P3 精修判卷（9B 批窗）。

## 三 要不要上大模型的量化门槛

只有同时满足才为 9B 付 9GB + 1.7 倍慢：
1. 同题集上 9B 的**人工通过率比 4B 高 ≥15%**（实测法：同一批 20 条，人盲评两组，算通过率差）；
2. 该任务**不能靠规则+事实包解决**（能靠就先用规则）；
3. 内存总闸放行（swap <1GB 且空闲 >2GB）。

不满足就退回 4B + 事实包——这不是降级，是把钱花在判据上。

## 四 改配置不等于生效（本轮实锚）

把 `big` 从常驻集移出、ctx 32768→8192、keep_alive 10m→2m 之后立即复测，发现 **9B 被拉回、还多了 2B**（三个模型同时驻留 18.8GB、空闲内存 125MB）。原因：调用方按自己的 `keep_alive` 发请求，且主控脉启动时就把 `resident_set` 读进内存。

所以落地必须三件一起：
1. 改 `LOCAL-MODEL-POLICY.json`（已改：`resident_set=['resident','embedding']`、`big.num_ctx=8192`、`big.keep_alive=2m`）；
2. **收敛调用方的 keep_alive**（凡是显式传 `keep_alive` 的地方，按档位统一；`2b` 只许 1m 或 0）；
3. **重启主控脉**（否则它继续按旧常驻集把模型拉回来）。

判据：静置 10 分钟后 `ollama ps` 只剩 4B + embedding，且 `sysctl vm.swapusage` 的 used 回落、`Pages free` >2GB。

## 五 回滚

`git checkout cph4/fleet/LOCAL-MODEL-POLICY.json` 即回旧常驻集；`ollama stop <model>` 立即释放。
