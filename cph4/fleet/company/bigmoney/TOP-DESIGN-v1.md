> 业务审计正身=`cph4/fleet/ri/strategy/QUANT-AUDIT-20261103.md`，本件只答公司级 8 问并给出下一个产物。

## 1. 卖什么

**每月一份可复现结论 + 下月持仓信号 CSV**，配合 19.9 元/月算力包。
不代客实盘、不荐股、不承诺收益。卖点不是收益曲线，是"你能自己跑、自己验"。

## 2. 谁买

有量化兴趣但没算力的个人投资者（算力包客户）+ 内容受众转化。
对外成交与账号归 CEO；本司只出成品与可复现命令。

## 3. 第一件产物

`signal-<YYYYMM>.csv`：下月持仓清单，含生成时间、因子值、输入指纹，由 `Tools/fleet/quant_signal.py` 生成。
当前状态：**从未生成过**（回执 0 份）。这是全公司最贵的一个空白。

## 4. 谁判

机器：`quant_signal.py`（要求回测 JSON 含 positions/holdings/weights，缺字段写 BLOCKED rc=3，不编清单）；
结论段四件齐校验（样本区间 / 成本假设 / 失效条件 / 输入指纹）。
人判：无（策略对外前必须四件齐，缺件只许内部用）。

## 5. 哪台机干

日更 = bm-a（现况事实）；重批（多参数/长窗口）等 bm-d 入网。
本机（Mac）跑不了 quant 仓，本机只做闸与编目 → 任何"Mac 上跑量化"的卡都是假卡。

## 6. 钱与合规

- 不代客下单、不承诺收益、对外只讲历史回测。
- 报价口径固定 19.9/月，含"当月结论 + 信号 + 可复现命令"，不含实盘通道。
- 数据偏差必须声明（ETF 现存标的=幸存者偏差；2020–2023 段仅 5.81%）。

## 7. 停线条件

- 连续 2 个月交不出"四件齐的结论 + 信号 CSV" → 停线，不再对外宣称月度交付。
- 若为出结论而放宽四件（补假设、改样本）→ 视为造假，直接停。
- 股票面已判负，未换赛道前不得重启（复活需 bm-d 入网 + 新立项）。
