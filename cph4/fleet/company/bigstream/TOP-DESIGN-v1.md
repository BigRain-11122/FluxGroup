# BigStream · 公司级顶层设计 v1（2026-11-03）

> 顺序位 #2。理由：唯一今天就有真成片的公司，设计能立刻被产物验证。

## 1. 卖什么

竖屏成片：MV / 漫剧 / 短剧 / 短视频，统一规格 1080×1920 / 30fps / 有人声+BGM / 有字幕。
漫剧与 MV 是同一条链（关键帧→i2v→剪辑→配音→字幕），不是两条产线——CEO 已定谳。

## 2. 谁买

平台观众（B站/抖音/视频号）。账号、发布位、48 包商用授权在 CEO 手上；
在此之前，公司产出的**全部只是内部自证**，不得对外演示。

## 3. 第一件产物

`media/drama-out/drama-2026-11-03.mp4`：12s、1080×1920@30、48kHz、-14.6 LUFS、烧字幕，
八条判据全 PASS（`cph4/fleet/drama-dept-v1/qa/drama-2026-11-03-qa.json`）。
下一件：同规格 45–60s 两镜以上、带真实剧情钩子的样片。

## 4. 谁判

机器：`drama_quality_gate.py`（八条：竖屏/分辨率/帧率/音轨/响度/时长/前3秒动/镜长/字幕/采样率），
`quality_gate.py`（线级四闸：src/manifest/qa/gate）。
人判：导演席自决放行，CEO 巡视可否决。**机器 FAIL 的东西不许给人看。**

## 5. 哪台机干

关键帧与 i2v = bm-c（ComfyUI，本地 GPU）；
装配/编码/字幕 = bm-m（h264_videotoolbox 硬编 + GPU ASR，实测 12x 实时）；
配音 = bm-b（TTS）；重渲染缺位时排队等 bm-d。

## 6. 钱与合规

单集成本按 token 经济上限；优先本地。
真人形象/声音不做（民法典 §1019/1023 + 深度合成规定）：`asset_dataset_audit` 已把它做成机器闸。
成片不加 AI 标识，标识义务走发布时平台声明位；发布决定权在 CEO。

## 7. 停线条件

- 连续 7 天无新成片 → 停线自查（不是"在等素材"，是流程坏了）。
- 连续 3 条成片交付闸 FAIL 且无逐镜修复计划 → 降级为样片线，不占 P0。
- 出现"给 CEO 看半成品"一次 = 红线（CEO 2026-10-23 明文）。

## 8. 现状差距（盘上事实）

| 项 | 事实 | 差距 |
|---|---|---|
| 漫剧样片 | 12s／两条人声／八条判据 PASS | 时长与剧情深度不够，不足以证明产线能出正片 |
| MV v721 | 交付闸真判 FAIL：重复上屏 6 对、近静止 24 处、死镜 234.18s(13 帧) | 需逐镜修复，不是重拍全片 |
| 字幕 | 已从"人给/自申报"改为机器产出（`subs_asr.py`，GPU ASR） | 首跑即抓到 manifest 字幕与配音不符（「这份」vs「这次」） |
| 角色/音色 | P0 目标 8 角色 + 6 音色，可用 0 | 所有片子的角色一致性只能靠提示词硬扛 |
| 发布位 | 无账号/无授权 | 全部产物停在"能看不能发" |

## 9. 下一轮的具体动作

1. 出 45–60s 两镜以上样片：一镜对话、一镜反应，走 subs=auto 全链，八条判据 PASS 才算数。
2. MV v721 按"逐镜体检 + 修复计划"处理三类缺陷，修完重跑交付闸（不重拍）。
3. 角色一致性：等 asset-lib 的 characters 出第一套，先用一套角色拍第二条片子验证复用。

## 10. 不做什么

- 不做推拉静图（禁 Ken Burns）、不改道引擎渲染（漫剧不改 3D）。
- 不用短视频转场语法（白闪/放大缩小/抖动/贴纸），只用 MV/电影语法。
- 不在没有发布位时声称"可以发"。
