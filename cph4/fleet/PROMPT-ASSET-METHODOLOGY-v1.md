# 提示词资产方法论 v1（PROMPT-ASSET-METHODOLOGY-v1）

> **立据（CEO 令 2026-10-26/27 原话）**：「各种业务的提示词 既要兼顾生成质量，也要效率，并不断的积累经验和方法论」
> 适用面：BigStream（MV/漫剧）、Biggame（游戏素材）、Bili 运营线、3D/音频生成面——全业务通用，不按司分家。

---

## 〇、一句话立场

提示词不是文案，是**工程件**：它有预算（token/字数）、有版本、有实测收益、有复用面。写它要像写配置，不能像写作文。

## 一、双指标（质量 + 效率，缺一不可）

| 面 | 指标 | 口径 |
|---|---|---|
| 质量 | **一次过闸率** | 首次生成即过闸的比例（不过=重烧/重写） |
| 质量 | **命中率** | 关键约束（人物锚/场景锚/风格锚）实际出现在输出中的比例 |
| 效率 | **token 预算占用** | 实际 token / 模型硬上限（SD1.5 CLIP=77；i2v 词面按各家文档） |
| 效率 | **单件时延** | 同批同构 prompt 的中位耗时（模型驻留 + 批内复用） |
| 效率 | **重烧率** | 因 prompt 缺陷（非随机）导致的二次生成占比 |
| 效率 | **复用率** | 新任务中直接复用既有分段/词库的比例 |

**判据**：质量与效率冲突时，先算「重烧成本」——一次重烧（含排队+GPU 占用）远贵于多花 10 token 做对。**但超过模型硬上限的 token 一律是负资产**（静默截断=质量灾难，见判例 P-02）。

## 二、分层组装（所有业务同一结构）

```
[CORE 承重] 主体+动作+关系   → 3-8 个词，不可省
[STYLE 风格] 统一世界/材质/光 → 10-15 个词，跨批复用（STYLE_C 常量化）
[SCENE 场景] 环境+时代物证     → 超预算时才截尾（优先级最低）
[NEG 排除]   只放必须挡的      → 禁语清单只进机检闸，不进正向 prompt（判例 P-05）
```

**装配顺序固定为 CORE → STYLE → SCENE**：截断永远发生在尾部，把最重要的放前面，等于给截断上保险（判例 P-02 根因）。

## 三、效率手法清单（已验证）

1. **预算先算后写**：写完先跑 `Tools/prompt_budget_check.py`，超线就压 CORE 而不是砍 STYLE。
2. **同构批复用**：同批镜头共用 STYLE_C + 固定 seed 基（`seed = 92000000 + ep*100 + n + k*1000` 范式），保证跨镜风格一致、免调参。
3. **模型驻留**：同引擎批不逐条重载（ComfyUI 队列驻留），把效率花在批内而非重启。
4. **4 候选择优**（文本线）：同题多采样同 prompt 变温度，闸+打分选优，比单次重写便宜。
5. **低清先验**：i2v 新镜型先 480P 短验（2-3 分），过运动/主体/零崩再烧 768P 正片。
6. **模板缓存**：把已验证的整段 prompt（如 LIGHT7 七槽光句、PERF 微动作）做成可拼装件，禁每次重写。

## 四、经验积累机制（这是本条令的核心）

**载体**：`cph4/fleet/prompt-experience-ledger.md`（append-only·永不滚删）。
**回灌触发**（任一即写，不等复盘会）：
1. 一次生成事故（崩坏/漂移/截断/穿帮）定位到 prompt 层；
2. 一次调参把过闸率抬 ≥2 个百分点的改动；
3. 一次跨业务可复用的新结构（如"预算层""压缩锚"）。

**每条格式（五段，缺一不收）**：
```
P-xxx | 业务 | 现象（可复现描述） | 根因（机制级，不是"模型不行"） | 修法（可操作） | 前后量化
```
**反模式纪律**：只记"改了 prompt 变好了"无效——必须能说出**为什么**（模型机制/数据分布/预算约束）。写不出机制=还没搞懂，不许入库。

**回灌归属**：谁踩谁写；跨业务条目由调度席每月归并成「方法卡片」并入本文档 §三。

## 六、审计刻度（月度）

- 一次过闸率：MV KF ≥80%、漫剧 KF ≥85%、i2v ≥70%
- 预算超线率：0（超线=装配层 bug，非创作问题）
- 重烧率（prompt 缺陷类）：逐月下降，≥30% 降幅为达标
- 台账条目：每月 ≥3 条新增，其中 ≥1 条跨业务可复用
- 资产复用率：新任务 ≥50% 分段来自既有资产
