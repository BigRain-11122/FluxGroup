## 五、三条最容易踩的硬约束（先记住）

1. **三张 V100 必须装两颗 CPU**：x16 槽是 CPU1 的 Slot2、CPU2 的 Slot4/Slot6，只用一颗 CPU 时后半排槽不可用。
2. **BMC 刷到 3.xx 就回不去了**：降级回 2.xx 可能损坏 IPMI 模块。
3. **两个 4×SATA2（SCU）控制器只有一个能用于 RAID**，且 SATA2 与 SATA3 不能放同一个 RAID。
