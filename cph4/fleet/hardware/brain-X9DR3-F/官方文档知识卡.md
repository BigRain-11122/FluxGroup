## 二、上 V100 的三条硬规则（MNL p15 + p44 布局图）

1. **x16 槽位分布不均衡**：CPU1 只有 1 条 x16（Slot2），CPU2 有 2 条（Slot4、Slot6）。
   → **插满 3 张 V100 必须两颗 CPU 都装**（否则最多 1 张跑 x16，其余只能落 x8）。
2. 三张卡插 **Slot2 / Slot4 / Slot6**；Slot1/3/5 是 x8（可留作第 4 张短边卡或网卡）。
3. BIOS 里 **Above 4G Decoding = Enabled**（MNL p89 原文：*Select Enabled to decode a PCI device that supports 64-bit in the space above 4G Address*）——不开，大显存映射不全。

## 三、内存怎么插才不会点不亮（MNL p15 + 内存手册 p2–5）

**插入顺序（Fill First）**：每个通道**离 CPU 最远**的那条先插，即 DIMM slot 0，蓝色插槽；板上还印着 *ALWAYS POPULATE DIMMxA FIRST*（A1 优先）。

**混合规则（内存手册 p2 原文要点）**
- 全部必须 DDR3；RDIMM 必须是 ECC；UDIMM 可 ECC / 非 ECC。
- 不许混：RDIMM 与 UDIMM / LRDIMM 与其它类型 / ECC 与非 ECC。
- 每通道最多 8 个逻辑 rank；同通道混合物理 rank 允许，但 **4R+2R+2R 三根组合不支持**。
- 混电压 → 全按常规电压跑；混频率 → 全按最低频率跑；通道不平衡 → 性能下降。

**速度和插几条强相关（内存手册 p4，Socket R / RDIMM 双 rank）**

| 每 CPU 插双 rank RDIMM | 支持的最高频率 |
|---|---|
| 1–4 条 | 1866 |
| 5–8 条 | **1600** |
| 9–12 条 | 800 / 1066 |

> 本机实际：16 条 16GB（DDR3-1866 双 rank RDIMM）= 每 CPU 8 条 → **实际跑 1600**，不是 1866。这是规范上限，不是故障。

## 四、跳线定义（MNL p13 总表、p57–60 详述）

| 跳线 | 作用 | 默认 | 关键细节 |
|---|---|---|---|
| **JBT1** | 清 CMOS | — | 是**焊盘不是针**，断开 AC 电源、取下 CMOS 电池后用螺丝刀同时触碰两片焊盘；**会一并清掉所有密码** |
| JPB1 | BMC 使能 | 1-2 使能 | 关掉 BMC 后 IPMI 不可用 |
| JPG1 | 板载 VGA 使能 | 1-2 使能 | 2-3 禁用 |
| JPL1 | GLAN1/GLAN2 使能 | 1-2 使能 | 关掉后系统里看不到网口 |
| JPME1 | ME 恢复模式 | 1-2 正常 | 2-3 = ME Recovery（只保基础功能，可在线升级） |
| JPME2 | ME 生产模式 | 1-2 正常 | — |
| JWD | Watch Dog | 1-2 Reset | 看门狗复位 |

## 五、裸板台面开机：JF1 引脚（MNL p46–50）

| 引脚 | 定义 |
|---|---|
| **1–2** | **电源按钮**（1=Signal，2=Ground）→ 螺丝刀短接一下即开机 |
| 3–4 | 复位（3=Reset，4=Ground） |
| 5–6 | 电源故障 LED |
| 7–8 | 过热/风扇故障 LED（灭=正常，**常亮=过热，闪烁=风扇故障**） |
| 9–10 / 11–12 | NIC2 / NIC1 LED |
| 13–14 | 硬盘活动 LED |
| 15–16 | 电源 LED（15=3.3V，16=PWR LED） |
| 19–20 | NMI（19=Control，20=Ground） |

**供电**（MNL p13、p51）：**24pin（J22/JPWR3）+ 两个 8pin（JPWR1、JPWR2）必须全接**，官方明确"不接会失去主板与电源的保修"。8pin 定义：1–4 地，5–8 +12V。

## 六、板上指示灯（MNL p14）

| LED | 含义 | 正常状态 |
|---|---|---|
| **DM1** | BMC 心跳 | **绿色闪烁 = BMC 正常**（不闪＝BMC 没起来，先查 IPMI_LAN 与供电） |
| **LE1** | 待机电源 | 绿色常亮 = 待机电源正常（主板已吃到 5VSB） |

## 七、蜂鸣码与首查顺序（附录 A，MNL p105）

| 响声/LED | 含义 | 首查 |
|---|---|---|
| 1 短 | 正常，准备启动 | — |
| **5 短 + 1 长** | **内存错误：系统检测不到内存** | 内存是否插到底、是否在 A1、是否同规格；换单根重试 |
| 5 声 | 无 Con-In / Con-Out 设备 | 键盘/显示/串口/远程 KVM/SOL 都没检测到——查显示器与 KVM |
| 1 声长鸣不断 | **系统过热（IPMI 报 OH）** | 散热器是否压到位、风扇是否转、硅脂 |

## 十、常见问题 → 直接答案

| 你可能会问 | 答案（出处） |
|---|---|
| 三张 V100 能全速吗？ | 能，但**必须双 CPU**；x16 只有 3 条且 CPU2 占 2 条（p15） |
| 我的 16 条 1866 为什么跑 1600？ | 每 CPU 8 条双 rank RDIMM 的规范上限就是 1600（内存手册 p4） |
| 能不能只装一颗 CPU 点亮？ | 能点亮，但 CPU2 侧的 x16/x8 槽与它管的 8 条内存都不可用（p44 布局） |
| 不开机怎么先在台面上短接启动？ | 短接 JF1 的 1–2 针（p50） |
| BMC 灯不闪＝坏了吗？ | DM1 不闪说明 BMC 没运行，先确认待机电源 LE1 亮、IPMI_LAN 接线（p14） |
| 清 BIOS 密码怎么清？ | 断电+取电池+短接 JBT1 焊盘，会连密码一起清（p58） |
| 忘了 BMC 密码？ | 默认 ADMIN/ADMIN（p18–19）。改过又忘了：**官方手册未给明确重置流程**，常见做法是重刷 BMC 固件/恢复出厂设置——这是我的经验判断，不是官方结论 |
| 装系统前 BIOS 要改什么？ | SATA Mode=AHCI、Above 4G=Enabled、Quiet Boot=Disabled（排障期）（p76/87/89） |
| 断电恢复后想自动开机？ | Restore on AC Power Loss = Power-On（p76） |
| 最多能装多少内存？ | RDIMM 512GB / LRDIMM 1TB / UDIMM 128GB（p15） |
| 能不能用 E5-2600 v1？ | 可以；但 v2 需 BIOS ≥3.0（p15 注） |
