# 驱动说明（Windows 10 x64）· 超微 X9DR3-F

来源：Intel 官方下载中心（downloadmirror.intel.com），2026-11-23 取。
本目录已解压，文件名后面标了实际能用的子目录。

## 一、装驱动的顺序

1. 系统装完先开「设备管理器」，看黄色感叹号有哪些。
2. 先装**芯片组**（装完很多未知设备会自己消失）。
3. 再装**网卡**。
4. 其余（显卡）基本不用管——板载 Matrox G200 只是 BMC 的基础显示，平时用 IPMI 远程画面即可。

## 二、芯片组：Intel PCH C606

| 项 | 内容 |
|---|---|
| 包 | `SetupChipset_10.1.20658.8883.exe`（98MB，官方安装器） |
| 用法 | 双击运行；静默安装加 `-s -overwrite` |
| 说明 | 装的是 INF（让设备管理器认对名字、补上缺失的总线设备），不是"性能驱动" |

## 三、网卡：Intel I350（板载千兆）

| 项 | 内容 |
|---|---|
| 包 | `Wired_driver_31.3_x64.zip`（38.8MB，已解压到 `Wired_driver_31.3_x64/`） |
| **Win10 x64 用哪一层** | `Wired_driver_31.3_x64/PRO1000/Winx64/NDIS68/`（NDIS68 = Win10/Server2016 网络栈） |
| I350 对应的 inf | `e1r68x64.inf`（82575/82580/**I350**/I210 家族） |
| 一键安装 | `Wired_driver_31.3_x64/SetupBD.exe` |
| 手动安装 | 设备管理器 → 右键网卡 → 更新驱动 → 浏览我的电脑 → 指向 `NDIS68` 目录 → 勾"包括子文件夹" |
| 支持的系统 | Win10（21H2/1809 在官方 readme 列表内）、Win11、Server 2016/2019/2022/2025 |

## 四、没下但可能用到的两项（按需再取）

1. **Intel RSTe（C600 的企业版 RAID 驱动）**：只有当你要用主板 SCU 口组 RAID 时才需要；不用 SCU 就不用装，Win10 自带 AHCI 足够。
2. **Matrox G200 显卡驱动**：本机只在 BMC 的 KVM 里看画面，不需要本地显卡驱动。

## 五、校验

见上一层 `../驱动-MANIFEST.txt`（含各包 SHA256）。网卡 zip 与芯片组 exe 均已实测可下载自 Intel 官方镜像，不是第三方转载。
