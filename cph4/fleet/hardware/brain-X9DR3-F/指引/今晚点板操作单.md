# 今晚点板操作单 · 超微 X9DR3-F（算力大脑）

> 配套资料全在同目录。照着做，出问题看最后一节的"对号入座"。

## 一、动手前先确认件齐

- 主板外观：CPU 座针脚无弯、电容无鼓包、BMC 芯片区无烧痕（二手板必查）。
- 配件：2× CPU、DDR3 RECC 内存、散热器背板+扣具、24pin + 2× 8pin CPU 供电、V100 的 8pin 供电线。
- 图在 `../说明书/QRG-1259.pdf`（一页纸：所有跳线、接口、槽位）。

## 二、内存怎么插（最容易点不亮的一步）

1. 先只插 **CPU1 侧 1 根**，放在 CPU1 的 A1（离 CPU 最近的第一槽）。
2. 点亮、进 BIOS 认到内存后，再按 `../说明书/X9_DP_memory_config.pdf` 补齐：**每个 CPU 8 根、四通道均分**。
3. 铁律：16 根 DDR3 必须同规格（1600 与 1866 混插会降频甚至不认），先单条验，再满配。

## 三、第一次通电用最小配置

1. 单 CPU（CPU1）+ 1 根内存 + 24pin + CPU1 8pin。
2. 显卡不用插——板载 **Matrox G200** 直接给 VGA；显示器接主板 VGA 口。
3. 不加 V100、不接硬盘，先看能不能 POST。

## 四、第一次上电看什么

1. 电源风扇转、主板诊断 LED 有动静；等 30–60 秒（首次内存自检慢）。
2. 有画面 → 进 BIOS，第一件事看版本号是不是 **3.4**（不是就按第六节刷）。
3. 无画面 → 先看 IPMI：网线插 **IPMI 专用网口**（不是业务网口）。管理口就是**后面板左上方、USB 0/1 正上方那个孤立的 RJ45**，丝印 `IPMI_LAN`；靠右边、VGA 蓝口左边并排那两个是业务口 LAN1/LAN2（图和编号见 `../图解/后置面板-10个口编号-MNL-p2-18.png`）。插好后在路由器里找它拿到的 IP，浏览器打开看 BMC 是否活着。BMC 活着但没画面＝问题在主板/CPU/内存，不在电源。

## 五、BIOS 里必须改的几项

| 项 | 设成 | 为什么 |
|---|---|---|
| **Above 4G Decoding** | **Enabled** | 手册原文「Select Enabled to decode a PCI device that supports 64-bit in the space above 4G」——V100 显存要映射到 4G 以上，不开认不全卡 |
| SATA 模式 | AHCI | 装系统前定好，后改要重装 |
| Boot mode | UEFI 或 Legacy 按你装什么系统定 | 装 Win10 后别来回切 |

## 六、刷固件（版本对不上才刷，别没事刷）

1. **BIOS 3.4**：`X9DRi0.630/ami.bat` + `AFUDOSU.SMC`（DOS 启动盘）；或 `../管理软件/SUM` 里用 `sum.exe`。
2. **BMC 3.62**：`BMC_3.62/Windows1.22/wUpdate.exe`（有系统时）、`Linux1.21/lUpdate`、`Dos 1.21/dUpdate.exe`（无系统时）。
3. 顺序建议：先 BIOS 再 BMC；刷完断电重启一次再配置。

## 七、配 IPMI（今晚远程调试全靠它）

0. 不知道它的 IP 时，先跑 `../工具/bmc_discover.py`（ASF 广播 + 段内扫描）：与本机同二层就会回 Pong 并打印 IP。
   - 只看到网关、看不到其它设备 → 不是 IP 问题，是没接在这条链路上（查 IPMI_LAN 是否插线、是否插在同一个路由器的 LAN 口、板子是否通电）。
1. 默认 DHCP，先用路由器找地址；要固定 IP 有两条路：
   - 进 BMC 网页改（步骤见 `../说明书/X9_SMT_IPMI.pdf`）；
   - 或在系统里跑 `../管理软件/IPMICFG_1.38.0_build.260701/Windows/64bit/IPMICFG-Win.exe -m`。
2. 远程画面用 `../管理软件/IPMIView_2.25.0_build.260812_Windows.exe`（自带 JRE，Win10 免装 Java）。
3. 改完密码记得记下来——BMC 忘记密码要拆机清 CMOS。

## 八、装 V100 之前

1. BIOS 的 Above 4G Decoding 已开（第五节）。
2. 三张卡插 **槽 2 / 4 / 6**（三条 PCIe3.0 x16，手册 p11-14 有槽位图）。
3. 供电：每张卡的 8pin 单独一路，别串在一条线上。
4. 上卡后再进 BIOS/系统确认三张都认到，再谈驱动和 CUDA。

## 九、不点亮时对号入座

| 现象 | 先查什么 |
|---|---|
| 完全没反应、电源风扇不转 | 24pin/8pin 是否插到位；电源开关针脚（`../说明书/QRG-1259.pdf` 找 PW 针） |
| 风扇转、无画面、无蜂鸣 | 内存拔到 1 根、换槽位重试；确认 VGA 接的是主板不是 V100 |
| 有蜂鸣或诊断码 | 按蜂鸣模式查：连续短响多为内存，长响多为显卡 |
| 有画面但认不到全部内存 | 内存顺序/规格问题，回 `../说明书/X9_DP_memory_config.pdf` 核通道 |
| 网口两颗灯：左绿常亮 + 右黄闪 | 这是**网口灯**（板上只有 DM1/LE1 两颗绿灯）。左绿=100M 链路已建立，右黄闪=有数据在跑。插的是 IPMI_LAN ＝ BMC 在网正常（该口上限就是 100M），此时问题只是 IP 未知，不是硬件故障；插的是 LAN1/LAN2 ＝ 千兆口只跑 100M，先换线 |
| **黑屏 + 键盘灯能切 + 网上找不到 BMC** | 三者同源：本板 VGA 与 IPMI 都出自同一颗 WPCM450R（官方 p1-5「Nuvoton BMC Video Controller (Matrox G200)」）。按序查：①**JPB1 跳线必须 1-2**（2-3＝禁用 BMC，VGA 与 IPMI 会**一起**消失，p2-35）②LE1 绿常亮＝待机 5VSB 有电（p2-38）③DM1 绿闪＝BMC 心跳（p2-38，不闪＝BMC 没跑）④断电短接 JBT1 清 CMOS（p3-2）⑤官方 No Video 流程：拔掉全部扩展卡与线缆、听喇叭蜂鸣（p3-2 + 附录 A） |
| **风扇转、无画面、无蜂鸣（键盘也无响应）** | **先查 CPU 与 BIOS 是否匹配**：官方 p1-8 注「E5-2600**(v2)** 需要 BIOS **3.0 或以上**」。不匹配的典型表现就是「风扇转、无画面、无自检」。判法＝读 CPU 顶盖型号（有无 `v2` 后缀、是否 `Q` 开头 ES/QS 样品）+ 找板上 BIOS 版本贴纸；不匹配就借一颗 v1 点亮→刷 BIOS 3.4→再换回 v2（物料见 `../固件/BIOS_3.4_已解压/`） |
| 线插在 LAN1/LAN2 而不是 IPMI_LAN，还能不能进管理 | 能。官方 IPMI 网口默认 **Lan Interface = Failover**：专用口优先，但管理流量也可以从 **LAN1（共享口）** 走（p2-26）。所以「插错口」不足以让 BMC 从网上消失，找不到它指向 BMC 没跑 |
| BMC 灯不亮 / 拿不到 IP | 换网线换口确认是 IPMI 专用口（后面板左上、USB0/1 正上方那个孤立 RJ45）；BMC 需 30 秒起；仍不行查 JPB1 跳线（1-2 使能）与主板 BMC 供电 |
| 进系统后网卡是未知设备 | 按 `../驱动/驱动说明.txt` 装 I350 驱动（NDIS68 目录） |
