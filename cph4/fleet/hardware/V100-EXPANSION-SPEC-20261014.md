**CEO 优先级裁决（2026-10-14 午·两条原话）**：「接受慢点」+「不能装不了/不能回答质量出问题」→ 优先级定谳=**装得下 > 回答质量 > 速度**。执法三条：①专家卸载=同一份 GGUF 权重、输出逐 token 一致，只慢不缺不裁剪——「装不了」在 16G 路线不存在，且因显存压力释放，量化档可从现役 IQ3 升 IQ4_XS（质量反而上调）；②质量红线（禁项）=盲评/代码硬线降 4b-14b 档（30B GLM 编 API 前科）、IQ2/Q2 级暴力压缩、魔改卡静默坏块；③速度不再是任何一条车道的选型轴——32G 唯一优势（98.8 字/秒）就此失效，仅供捡漏。**35B 的存在范围收窄**：只服务两条质量硬线车道（代码代理+盲评/导演席判断），分类/lint/簿记/初筛照「合适就好」律走 bm-b 4b/小档（模型路由律 O-20261012-2225 原文执法）——大模型不必被所有活用满，但必须常驻可调。

**部署位定谳+准系统内存规约（CEO 问「带内存吗」·2026-10-14 收口）**：①**必须放人边→T7910 塔式定唯一主案**（R730XD 转阳台/储物间备选·塔式满载 ~40-55dBA 室内可接受）；②准系统默认**不带内存**（=机箱+主板+电源，CPU/内存/硬盘另算·部分商家带 U 准系统）；③带内存的两种形态：闲鱼公司退役整机（常带 CPU+内存，内存按低于散件现货折算=DRAM 危机对冲·但现在卖家倾向拆条单卖高价，带内存整机日益稀缺）vs 商家准系统（不带或按现货价加钱）；④采购规约：优先蹲带内存整机——**按单条折算价 ≤ 散件现货线（32G 2400/2666 RECC ≈¥810）即划算**，否则裸准系统+自配（内存先锁·30 天 +34% 在涨）；⑤到手内存四查：根数与承诺一致/同频同组（混频条全组降速跑最低档）/满通道（**双路每颗 CPU 各满 4 通道=8 根起步，单边插=带宽腰斩**）/ECC 开启+memtest86 过夜。

**混插定谳（CEO 问·2026-10-14）**：GPU 异构同板 ✓（一次自编 sm_70+sm_75 双架构覆盖·--tensor-split 手动分权）；**DDR3+DDR4 内存混插 ✗ 物理不可能**（防呆口+内存控制器各认一代·主板必须选边）。**DDR3 勘误**（前轮「破千元」部分撤回·CSDN 2026-09 实锚：32G DDR3 RECC ¥200→350·破千的是 DDR4——DDR3 涨后仍比 DDR4 便宜 2-4 倍/GB）：双路 C602 八通道 128G ¥1400 内=压价备选平台腿（省 ¥1500-2000≈半张卡），但吃 13 年老平台稳定税（双路待机 +50-100W·板龄风险）——按 CEO 稳定优先维持 T7910 主案。
