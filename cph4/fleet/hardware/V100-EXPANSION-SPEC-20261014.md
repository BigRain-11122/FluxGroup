# V100 捡垃圾扩算力方案 v1.0（2026-10-14）

**一句话结论**：V100 32G 值得捡，但只当「文字/LLM 车道专用机」——¥2000~3000 买 32G 显存（约 ¥60~90/GB，是 3090 显存单价的 1/3）。第一单活就是把 bm-c 上常驻的 35B 代码大模型整体搬过去，**bm-c 整张 16G 卡立刻还给 MV 产线**（关键路径最大单点提速）。图像/视频产线它干不了（缺新内核），那条线维持 3090 ≤¥4200 / A40 ≤¥5000 蹲价线不动。

---

## 1. 能干什么、不能干什么（先丑话后甜话）

### 能干（V100 的甜区，全吃带宽不吃新指令集）
| 活 | 实测/预估 |
|---|---|
| LLM 推理（GGUF Q4/Q8/FP16） | 900GB/s HBM2 ≈ 3090 级带宽。Qwen3.6-35B-A3B Q4 实测 **98.8 tok/s**（单流）、prefill 352 tok/s、峰值 27GB/206W（2026-07 实测源见 §10-4） |
| 30B 级稠密模型 | Qwen 32B Q4 18-25 tok/s；27B Q8_0 23.4 tok/s（占 29.2G） |
| 并发批（评审/调研/剧本） | llama.cpp `-np 4~8` 并发槽，35B MoE 多流聚合约 100-200 tok/s；vLLM 走 fork（§6） |
| whisper 大批量 | faster-whisper large-v3 FP16，约 10-20 倍实时，41 曲锚点批可整机托管 |
| RIFE 插值 / ESRGAN 放大 | 标准卷积无新指令依赖，可用（速度约为 3090 的 1/2~1/3，够 finishing 站分担） |
| FP16 老架构训练（SDXL 级） | 可以但不推荐主车道 |

### 不能干（硬伤，全是指令集/内核层面，改不动）
| 活 | 为什么不行 |
|---|---|
| Krea2 / Qwen-Image / Flux 系新 DiT 出图 | 无 bf16、无 FlashAttention-2、无 SageAttention → 能跑也是龟速，不进产线 |
| H3 INT8 i2v | INT8-ConvRot 内核不支持 sm70（Volta），bm-c 3070 能跑的配方 V100 装不上 |
| jman 系 LoRA 训练 | musubi-tuner 12G 配方全押 fp8_base/fp8_scaled，Volta 无 FP8 |
| CUDA 13+ | CUDA 13 已弃 Volta → 全环境**永久锁 CUDA 12.x + 580 系驱动** |

## 4. 三个方案

### 方案 A（推荐先试水）：单卡 32G 转接 + 二手 X99 主机 ≈ **¥4000~5500**
| 件 | 价（需闲鱼实核） |
|---|---|
| V100 SXM2 32G 裸模块 ×1 | ¥1800-3000 |
| SXM2→PCIe 成品转接板（特斯拉专用 8pin 供电款） | ¥300-600 |
| 配套涡轮/1U 散热器（≤16mm 高） | ¥100-300 |
| 二手 X99 主机（板 ¥150-300 + E5-2680v4 ~¥80 + 2×32G RECC DDR4 + 650W 金牌 + 箱扇） | ¥1500-2000 |
| 合计 | **~¥4000-5500** |

到手跑通验收：nvidia-smi 认卡 → llama.cpp 自编译 sm_70 跑 Qwen3.6-35B-A3B Q4 达 ≥80 tok/s → whisper 抽测 → 并发 -np 4 稳定 24h。

### 方案 B（A 好用后升级）：双卡 32G + NVLink ≈ **¥7000~9500**
第二张 32G 裸模块 + 双卡 NVLink 转接板（B 站开源款/成品 ¥600-1200）+ 平台换双路或 X299。**64G 显存 + NVLink TP2** → 可跑 72B Q4（硬决策档）+ vLLM 双卡批吞吐翻倍。单卡 35B 已覆盖 90% 需求，B 案不急。

### 方案 C（不推荐先动）：C4130 / NF5288M5 整机
- C4130 + **32G 卡 = iDRAC 硬件降频坑**（25% 频率锁，要刷固件破解，折腾税高）；+ 16G 卡即插即用但 16G 装不下我们的 35B 主活。
- 浪潮 8 卡整机（8×32G=256G）闲鱼估 ¥2.5-4 万，超「捡垃圾」预算。
- 结论：只在捡到**漏价含内存整机**时再议（DRAM 危机下整机内存有拆件价值对冲）。

## 5. 给现在的工作派什么活（job map）

1. **35B 代码大模型迁站（第一优先·立竿见影）**：bm-c 3070 现在常驻 Qwen3.6-coder（整卡近占满）→ 搬到 V100 32G（还能从 IQ3 升 Q4_K_M 更高精度档）。**bm-c 整张 16G 卡即刻还给 MV 产线（KF 烧帧/H3 i2v/LoRA 重摇）——这就是当前最大的单点提速**。
2. **评审/调研/剧本批全转本地**：十席盲评（剧本/帧审/成片闸）、决策委员会 T1、多角色九面调研（41 曲 × ≥6 面）、AUTO-POLISH 打磨轮、QC checklist 批跑——从云端 token/会话挤占改为本地常驻并发，云端只留硬决策。
3. **whisper 41 曲锚点+词面校准批**：整机托管，不再占 bm-a/bm-c。
4. **经验台账回灌 / 嵌入 / 长上下文批处理**。
5. **finishing 站分担**：RIFE 插值、ESRGAN 放大可移过来，bm-a 晚间让出更多窗。
6. **明确不派**：Krea2 KF、H3 i2v、LoRA 训练——留在 bm-c/bm-a/未来 3090。

## 7. 避坑清单（闲鱼验卡硬检项）

1. **金桥（mezzanine 连接器）磨损/氧化**：不识别或残血 → 洗板水+牙刷清洁 3 次再试（立创项目实测经验）。
2. **核心压碎**：SXM2 裸模块无盖，运输/装配压碎风险，到头保退谈清楚。
3. **要「包测试」件**：到手先 `nvidia-smi -q` 查 ECC 累计错误 / remapped rows / 温度墙。
4. **转接板供电**：8pin 必须特斯拉专用线（EPS），**插普通显卡线=烧卡**（开源项目原文警告）。
5. **C4130 整机**：32G 卡降频锁（§2）；非戴尔原厂卡 70W 锁。
6. **平台内存**：DDR4 涨价潮（同比 +775%，二手回收价翻了 8 倍，谷歌都在捡退役内存）——RECC 32G 单条 ¥400-800 且继续波动，**是平台里最贵的散件**，整机含内存时按拆件价值算账。
7. X99 主机挑板：双槽间距 + BIOS 老实认 Tesla；E5 无核显→无头跑或 10 元亮机卡。

## 8. 电费 / 噪音 / 部署

- 功耗：单卡 250-300W 满载、待机 ~20W；整机日均 ~150-250W → 电费约 **¥60-120/月**（24/7 常驻）。
- 噪音：ATX+涡轮 ≈ 一张 3090 公版涡轮，室内可接受；服务器整机（1U/2U）=jet engine，只能阳台/储物间。
- 建议部署位：独立新机不挂 bm-a（不动 CEO 用机电源）。

## 9. 采购纪律对照 + 待实核清单

- 双触发对照：**产能缺口=实锤**（bm-c 常驻 LLM 与 MV 产线抢卡 43h+、41 曲调研批在烧云端、whisper 批占机）；**价位**=V100 32G 已在弃件价区（这正是「AI 潮退拆机件」的提前兑现，不用等）。
- 图像/视频车道**不因本方案改变**：3090 ≤¥4200 / A40 ≤¥5000 蹲价线照旧。
- 物理动作（闲鱼下单）= CEO 一键下单域；我方出验收清单（§4-A）。
- **待闲鱼实核价清单**：① V100 SXM2 32G 裸模块现价与库存量；② 成品转接板现价（含 NVLink 双卡款）；③ RECC DDR4 32G 现价；④ C4130 准系统现价（只为记账）；⑤ X99 整机含 RECC 套餐现价。以上 2026-03~08 快照价会漂，下单前以当日实见为准。
