## 二、社区口碑摘要（为什么是它们）

- **V100 专用 kit 原话**：「Gemma 4 = 全显存跑，快而简单；Qwen3 = 更大更强，卸载部分专家到内存，要颗像样的 CPU」——本机 2680v2×2+128G DDR3 正合此需；kit 双卡篇明确「双 V100 = 35B 全驻留」；kit 同款 PSU 瞬态警告与 BOM 分线纪律互证。
- **48G 档社区共识**：Qwen3.6 系为该档总评首选（27B Q8「近无损最佳总选」/35B-A3B「单卡效率王」）；70B dense 老一代（Llama 3.3 Q4_K_M）被 2026 质量迭代取代；Qwen = 各 VRAM 档编码首选 + 中文第一（盲评/剧本/词锚全中文场景决定性）。
- **Qwen3.6 架构注**：Gated DeltaNet 混合注意力≈KV 缓存省 40%（262K 长上下文友好）·峰值比 Qwen3.5 慢 ~30%（101 vs 142 t/s）=能力换速度·llama.cpp 新栈起步（4 月新 rope 首日破 Docker 镜像·须新版）。
- **诚实边界**：本地 48G 档质量 ≈ 云端上一代旗舰（27B 平 Sonnet 4.5），**非 GPT-5.5/Opus 4.8 档**——十席盲评 35B 闸失真消除够用；最难任务仍走云端（思考路由律不变：量产本地 35B、深判本地 27B、创作正片云端）。
- **NVLink/拆分机制注（10-14 官方 multi-gpu.md 钉死）**：廉价 SXM2 转接板大概率不带 NVLink 桥——**正法=层切（llama.cpp 默认 `--split-mode layer`）**：按层分片、每卡持连续层、KV 随层分布、跨卡只传激活——官方原话「最兼容·**容忍慢互联**」=x4 电气转接板、零 NVLink、3+ 卡全无碍；张量并行（新 `--split-mode tensor`）=实验档且 **MoE/混合架构大面积硬失败**（官方失败清单：Grok/DeepSeek2/GLM-DSA/Jamba/Mamba 全族）+依赖 NCCL/快互联——35B-A3B（MoE+Gated DeltaNet 混合）不走此路；kit 的 NVLink 桥=加分项非必需（层切不吃互联）。

## 三、拆分机制定谳（速度口径诚实版）

- **层切=流水线并行非三卡并行**：单请求 token 逐卡接力——速度 ≈ 单卡全驻留当量（35B-A3B 仅 3B 激活·带宽账友好：Q4 档估算 70-120 字/秒），**不是 3×聚合带宽翻倍**；层切真优势=**批量吞吐王**（官方：「maximizes batch throughput」）——机队用法=十余 agent 并发打一台，正吃此优势。
- **三卡分工表**：35B-A3B **Q4_K_M 21G→两卡层切即驻留**（第三卡跑 Gemma 第二模型并挂）；**Q8 ≈37G→三卡层切**（此时不再并挂）；72B dense Q4 ≈40G→三卡层切（深判批处理·慢当量 10-15 字/秒级）。
- **双证据**：①bm-a 现役即跑同款 35B-A3B 且拆分难度更高（ik_llama 把 MoE 专家拆到 CPU 内存=GPU/CPU 异构拆分·GPU↔GPU 层切是降级难度）②V100 kit 双卡篇实测「双 V100=35B 全驻留」。
- **验收线（预注册·到货执法）**：`llama-server -m <35B-Q4> --fit`（默认层切）→ 双卡全驻留 ≥70 字/秒 + 3 卡 Q8 驻留跑通，各记一次实测回填。

## 四、对位现状（bm-a 现役）

bm-a 现役同款 35B-A3B IQ4_XS @36-38 字/秒 → 新机同模型 **Q4_K_M/Q8 全驻留**：速度 ×2-3 + 量化档升两级（IQ4_XS→Q8 近无损）= 质量闸升级，bm-a 释放为纯中枢。

## 五、Token 节省机制（CEO 令 10-14 晚「大幅省云端 token·不能大幅降智」·慢不怕→质量优先）

**原理一句话：省钱靠「量大头归零」，保智靠「刀刃仍付费+机器闸兜底」。**

- **①量产面全归本地（token 大头归零）**：代码代理/分类/草拟/校对/评审初轮——占量 90%+ 且**可机器验证**（代码有测试门禁、格式有检查器、评审有分数闸）——错误由闸拦下重试，不靠模型智商自觉。这批全走 bm-d 零 token。
- **②判断类默认升质量档（CEO「慢不怕」执法）**：委员会裁决/评审终轮/核心审查——默认 27B dense Q8+思考模式（慢 3-4×换更聪明），**存疑自动上抛云端复审**——escalation 阶梯=token 花费与本地失败率成正比，不再与总量成正比。
- **③天花板创作保留云端（量小不心疼）**：正片剧本/最关键创意=云端现役第一名档——本来一周几单，付费面从「全量按条」收缩为「只付天花板+失败重试」。
- **④降智监控双件**：a)到货验收=10 件真实任务盲测（本地 vs 云端各答·分数与差距记档呈 CEO）b)月度降智审计=抽样盲比+「CEO 否决归因于模型智商」计数——超阈即调路由（该类活回云）。
- **预期（预注册·实测回填）**：token 账单砍 **70-90%**（spec §10 口径=云端省 7-33M token/月）；质量保障链不变（十席盲评→导演席→CEO 终审三道闸照旧）。
- **执法注**：本节=思考路由律 v2 基底（量产本地 35B→深判本地 27B 上抛云端→创作正片云端）——**装机接线时写入 CEO-PROXY ROUND/BRIEF 正典生效**；当前 bm-a 35B 过渡期照 v1 路由跑。
