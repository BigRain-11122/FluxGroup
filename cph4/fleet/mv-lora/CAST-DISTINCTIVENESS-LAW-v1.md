# 角色特点律 v1（CAST-DISTINCTIVENESS-LAW）

CEO 令 2026-11-03：「训练都要有特点，不要人云亦云，女主男主路人NPC什么的，还有音色也要高清，没有杂音。」

一句话：**每个角色必须能被一句话记住，且必须与同片其他角色在三个维度上不同；音色必须过技术门。**

## 一、四类角色都要有特点

| 类 | 不许是什么 | 必须有什么（三件套） |
|---|---|---|
| 女主 | 通用网红脸、只换发型的同一张脸 | 结构锚（骨相）+ 记忆点（一句话能说出）+ 气质标签 |
| 男主 | 「帅」这种无信息量的形容 | 骨相 + 一个年代细节（发型/体态/习惯）+ 身份感 |
| 路人 | 一群人共用一张脸 | 每型一套骨相，且带职业/场景标签（学生/店员/工人/老人） |
| NPC | 「背景人」 | 职业 + 一个辨识道具或动作 + 与主角明显不同的年龄带或体型 |

**结构锚字段**：脸型 / 眼型 / 鼻 / 唇 / 发型 / 体型，六项里至少写清三项；脸型、眼型、发型三项必须带限定词（例如 `long narrow face`、`wide-set dark eyes`、`bob cut blunt at the ends`），不许只写 `beautiful face`。

## 二、跨型不撞脸（硬门）

- 判据：同片内任意两个角色，**（脸型, 眼型, 发型）三元组不得相同**。
- 三元组相同 = 只是换了衣服，判不合格，退回重写。
- 允许同一脸型在同一片里出现两次，但眼型与发型必须都不同，且气质标签必须不同。
- 群演（extras/crowd）**禁止一个 LoRA 覆盖所有路人**：至少拆 3 型（不同年龄带或体型），否则远景一眼看出是复制人。

机检：`python Tools/cast_distinct_check.py --all`（查三元组唯一性 + 结构锚字段数；不合格 rc=2 且不烧卡）
自检：`python Tools/cast_distinct_check.py --selftest`（撞型必须被判出、不同型必须放行；这是负控，闸改动后必跑）

**能力边界（诚实标注）**：本机判据只看**文本**，证明"提示词描述得不同"，不等于"出图后真的是不同的人"。
图像级不撞脸需要人脸嵌入模型（ArcFace/insightface）算余弦距离，本机未装，因此
**图像级相似度判不了 → 由下方人眼三问兜底，不许声称机器判过脸**。

人眼必过（机器判不了，呈片前导演席过一遍）：
1. 遮住衣服只看脸，能不能分清这是谁；
2. 说一句话形容这个人（说得出=有特点，说不出=人云亦云）；
3. 与上一支片的女主并排看，会不会串脸。

## 三、音色高清无杂音（硬门·2026-11-04 按实测重写）

**分两档，别混着判**：素材档判「有没有硬伤」，成片档判「能不能交」。

### 3.1 素材档（`--profile source`，TTS 原始输出）

| 项 | 门槛 | 依据 |
|---|---|---|
| 采样率 | ≥ 22050 Hz | 2026-11-03 实测本机云端 TTS 下限即 22050（火山 22.05k/24k），低于此高频被切 |
| 峰值 | ≤ -0.1 dBFS | 顶到 0 即削波 |
| 削波样本占比 | ≤ 0.02% | 同上 |
| DC 偏移 | ≤ 0.005 | 直流偏置会吃掉动态范围 |
| 时长 | ≥ 0.3 s | 近乎空文件不可判 |

**只报告、不判决**（测不准的项目不许进闸）：
- 底噪（最静 0.5s 窗）：无静音段时"最静窗"仍是语音，会把底噪高估；
- SNR（窗口 p90/p10）：连续语音上系统性低估，实测本机 10 条真实 TTS 中位仅 15.2 dB；
- 素材响度：装配链统一 loudnorm，素材响度无意义。

### 3.2 成片档（`--profile delivery`，交付前）

| 项 | 门槛 |
|---|---|
| 采样率 | 48000 Hz |
| 有损码率 | ≥ 192 kbps |
| 响度 | -14 LUFS ±1（与装配链 loudnorm 同一把尺） |
| 真峰值 | ≤ -1 dBTP（转码不留削波余量就等着爆） |
| 削波样本占比 | ≤ 0.01% |
| DC 偏移 | ≤ 0.002 |

### 3.3 标定记录（2026-11-03 实测，不许再用"感觉"定阈值）

- 样本：`media/BigStream` 真实云端 TTS + 成片音轨，共 10 条
- 实测分布：采样率 22.05–24 kHz｜码率 47–59 kbps｜峰值 -23.2…-0.01 dBFS｜
  底噪 -58…-17.4 dBFS｜SNR 12.2–31.5 dB｜LUFS -48.5…-16.2
- 第一版阈值（44.1k/192k/SNR30/底噪-55）**会把 10/10 真实素材全判负 = 废闸**，
  与 ai_smell_gate 首版判死 32 张真人的病同源，故按数据重定。
- 结论（生产事实，不是测量误差）：**现有云端 TTS 属低档素材**（24k/48kbps）。
  要达标就得改 TTS 出档设置或换供应商，这是产线决策，不是把闸调宽能解决的。

### 3.4 已验证（正反样例，缺一不算数）

| 用例 | 期望 | 实测 |
|---|---|---|
| 48k/类语音/有停顿 | PASS | PASS（底噪 -68.7、SNR 58.7、f0 210.5） |
| 22050+削波 38.9%+DC 0.009 | FAIL | FAIL（5 条理由全中） |
| 真实 TTS 6 条 | 顶头的判负、其余放行 | 5 PASS / 1 FAIL（huayan 峰值 -0.01 dBFS 顶头） |
| 成片档 -14 LUFS | PASS | PASS（-14.03 / TP -8.63） |
| 两个角色同 voice_id | FAIL | FAIL（撞音 1 组） |

## 四、音色要有特点（不许所有角色一个声音）

- 每个有名字的角色必须绑定独立 voice_id，**同一 voice_id 不得复用于两个有名字的角色**（群演可共用，但须标注 `shared_ok`）。
- 角色之间音色指纹须可辨：中位基频（f0）相差 ≥ 12%，或音色族（少年/御姐/大叔/老人）不同。
- 音色指纹（中位 f0 / 语速 / 频谱质心）由 `voice_hd_gate.py` 一并输出，入台账。

## 五、执行顺序

1. 写角色提示词 → 跑 `cast_distinct_check.py`（不合格不烧定妆图）
2. 定妆图 → AI 味闸 → 人眼三问（遮衣认脸/一句话/不串脸）
3. 训 LoRA → gate
4. 配音 → `voice_hd_gate.py`（不过不放行）→ 人耳复听

## 六、适用范围

MV、漫剧、短剧、游戏角色资产，全部适用。任何一条产线跳过本律 = 违令，回执判 BLOCKED。

## 七、失效条件（什么时候这条律不算数）

1. **不露正脸的角色**（背影 / 剪影 / 画面内脸宽 <8%）：三元组判据不适用，改用体态 + 服装 + 道具辨识；
2. **真人出演**（非生成）：不套本律，走肖像与授权通道；
3. **同一角色跨片复用**（同一 LoRA 客串）：只校验"是否与同片其他角色冲突"，不要求重新选题；
4. **群演远景**（人数 >20 且平均脸宽 <3%）：允许复用，但必须换服装色系，且不得出现在近景；
5. 音色档判据在**无静音段素材**上不成立（底噪/SNR 不可测，已降为报告项）。
