## 轮换规则（机器判）

- 相邻两支 MV 不得同型（读 `cph4/fleet/mv-lora/LORA-REGISTRY.json → casting_rotation`）。
- 同型再启用必须换种子与 ID 块（脸不同，型相同）。
- 每型 LoRA 独立命名 `her_T0X_rN`，训过 gate 才入册。
