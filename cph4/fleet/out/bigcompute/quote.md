# 算力服务 · 报价（DRAFT · 价格留空，等 CEO 拍板）

> 机器不填价格。本文只给成本项、毛利公式与建议区间的方法；具体数字由 CEO 决定后回填。

## 一、成本项

| 项 | 口径 | 状态 | 说明 |
|---|---|---|---|
| 机器折旧 | 按各机购入价与折旧年限摊到小时 | 待财务口径 | STATIONS 只有硬件型号，没有购入价 |
| 电费 | 功率 × 运行小时 × 电价 | 待财务口径 | 无电表读数，不按经验值填 |
| 模型算力占用 | 单次推理时长 × 占卡比例 | 可测 | BRAIN-STRESS 有实测吞吐，可按任务量折算 |
| 人力复核 | 人判件数量 × 单件分钟 | 可估 | 回执里 judge=manual 的件数可直接数 |

## 二、毛利口径（唯一算法）

```
单件成本 = 机器折旧 + 电费 + 算力占用 + 人力复核
毛利率   = (单价 - 单件成本) / 单价
```

口径只此一处：报价单、物料、对外话术都引用这条公式，不许各写一份。
