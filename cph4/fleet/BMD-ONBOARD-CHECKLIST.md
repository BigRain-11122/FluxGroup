# bm-d 入网前置清单（不用等装机就能准备的部分）

> 装机是 CEO 的物理件；本清单里的东西现在就能做完，装好当天按单执行即可。

## 一、模型清单（起服要挂什么）
1. 主力：35B coder（现驻 bm-a:8090），迁入后作为唯一 LLM 服务。
2. 轻量：4B（Mac 现役），迁入后 Mac 只留 embedding。
3. embedding：0.6b（资产检索用）。
4. 向量/重排：按需，默认不常驻（省显存）。

## 二、服务参数（起服照抄）
- 端口：8090（与现状一致，代码零改动）。
- 并发槽：10–16（48G 显存，按实测调）。
- 上下文：默认 8k，重活 32k。
- 禁用 Ollama（Volta 已被新版弃用），用 llama.cpp / ik_llama。

## 三、迁移顺序（装好后按序做）
1. bm-d 起服 → 探活 → 写 `cph4/fleet/nodes/bm-d.json`。
2. bm-a 35B 停服 → 改指向 bm-d。
3. Mac 抽检改调 bm-d → Mac 只留 embedding。
4. 回测重批迁 bm-d → 与旧结果比对（误差 <1%）。

## 四、回滚（任何一步失败就退回）
1. bm-d 起不来 → bm-a 35B 照旧跑，不动其它。
2. 迁移后性能不达标 → 保留双跑一周，再决定。
3. 不做"半迁移"：要么完整切，要么全退回，避免两处状态不一致。
