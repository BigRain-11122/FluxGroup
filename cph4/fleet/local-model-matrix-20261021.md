# LOCAL-MODEL-MATRIX v1.2 — 机队本地模型矩阵与分层用云线（2026-10-21）

> 令源三条（本件全部判据的排序基准，冲突时以最新一条覆盖）：
> ① 13:3x「我希望本地算力之后满负荷运转开展业务，搞不过来的时候在我的额度范围内，你调用云端模型接入，然后你推荐一下本地适配的模型，最好用你 QWEN 最新的」；
> ② 二次「我不在乎慢，反正 7X24 小时，但不能错或者反复思考做无用功」→ **精度优先 + 反返工**；
> ③ 三次「你要分层次，尽量少用云端，多用本地」→ **分层优先阶梯 + 云端最小化**。
> 性质=接管准备件（规划态·装机动作候接管令）。模型版本=2026-10-21 web 检索快照，**装机前必再跑一次新鲜度闸**（BRIEF §二.12 当日源律）。

## 一、选型总原则

1. **全 Qwen 开源系**（Apache-2.0 商用可，CC 授权链无风险）；按卡适配，不按"最大最好"。
2. **MoE 优先**：30B/35B-A3B 激活仅 3B 量级，推理计算量≈同级 Dense 的 1/10——消费级与退役卡跑"30B 级能力"的唯一现实路线；部分卸载+高主频大容量 RAM 是修旧病（全专家 CPU 卸载=398 token 跑 5 分钟）的正解。
3. **精度优先律（令②）**：取该机显存**装得下的最高档**；速度不构成淘汰线——慢由 7×24 满负荷窗吸收，**错才致命，因为错=重跑=真慢**。降档只允许因显存硬约束，且须注明是约束非选择。
4. **零 token 优先律（令③第一级）**：能用规则、脚本、门禁、校验器判定的，**一律不进模型**——编译门禁、格式 lint、字段校验、去重比对、命名合规=纯 CPU 件。模型只吃"非判不可"的那部分，这是最省云的一刀。
5. **反返工三件**：①**先验 kernel 再下权重**（20-40G 权重下完才发现跑不动=最贵返工）；②**版本钉死不乱升**（Volta 钉 CUDA ≤12.9 + R580，安全更新到 2028-10）；③**整批切档、禁逐单换模型**（换档=重载几十 G，深判档攒批一次切）。
6. **禁魔改/去限制变体包进产线**（Uncensored / ReAligned / abliterated / 自剪枝量化类）——对外内容生意（B 站、上架、短剧漫剧）的账号与主体风险，且能力对不上官方基准=验收无据。只取 Qwen 官方仓或头部社区量化（unsloth Dynamic）标准档。
7. **验收=质量一次过 + 日产能入册**：固定回归题组（数学/代码/长上下文回忆各一组）**一次答对**=PASS；速度折成「一天排得完多少件」只用于排产节奏。**旧「≥20 字/秒才准接产线」淘汰线作废**（沿 V100-P0「31.6 字/秒 PASS」判例法作废止留痕）。读数诚实入册，禁抄社区数字当承诺值。

## 二、分层优先阶梯（令③的执行面·全集团用模型唯一顺序）

**任何一件活要动用智能，必须从 L0 往下逐级走，每级留痕（谁在哪级答的、置信/自评、耗时），不许跳级。**

| 级 | 载体 | 干什么 | 云端消耗 |
|---|---|---|---|
| **L0** | 脚本/门禁/校验器（bm-a 夜窗 + bm-d CPU + bm-b CPU） | 编译门禁、lint、字段与格式校验、md5/查重、命名与合规正则、台账转单、阈值判定 | **零** |
| **L1 快筛** | bm-b Qwen3.5-4B/2B（含小 VL）·8G 全驻·24/7 | 批量分类、POOL 分诊、格式归一、初判 QC、明显错帧/明显合格二分筛 | 零 |
| **L2 量产主力** | bm-d V100×3 35B-A3B **Q8 三卡层切**·24/7 单实例常驻 | 草拟、转写、审校、代码、digest、十一面初筛、L1 存疑件复判 | 零 |
| **L3 本地深判** | bm-d 27B dense **Q8 攒批整档切**（日/半日一批） | 委员会初裁、评审终轮、关键审读；**慢不怕，一次对** | 零 |
| **L3.5 本地多模态** | bm-a 夜窗 Qwen3.5-9B 原生多模态（Ada 12G FP8 路径可用）·+bm-c 拼板后交判 | MV/漫剧帧级 QC 复判、拼板目测、角色一致性核对 | 零 |
| **L4 云端** | 千问系 API（并发帽 <8·每机 ≤2） | **仅三种**：①L3/L3.5 本地答不出或自评不过并留痕；②>32K 长上下文单请求（本地无 ctx 位）；③天花板创作正片（量小） | 按积分 |

**云端最小化硬闸（令③可执行化）**：①判图/分类/草拟类**本地消化率目标 ≥90%**，月度抽账，低于线=路由错配要修；②升云必须先出示 L0-L3 的留痕，**跳级上云=违规单**，不是效率问题；③云端每笔留「谁批/为什么/花了多少」；④月度云端消耗对账入 SLI-8 周趋势——CEO 额度是约束面，不是默认面。

**升云三判据修订（覆盖 v1.0 口径）**：本地积压 >2h **且排产无解** / 该能力本地确无位 / 本地质量回归不过。**「速度不达标」不再构成升云理由**（令②：慢可排产，不能算错）。

## 五、诚实边界与撤销留痕

- **撤销 v1.0/v1.1「VL 判图常态走云」改判（令③覆盖）**：判图能力本地有路——小 VL 在 bm-b 做 L1 二分、Qwen3.5-9B 多模态在 bm-a 夜窗做 L3.5 复判，云只留疑难。代价如实呈：判图吞吐受夜窗限制、排队会慢，属"慢可接受"范围；且 9B-VL 判图质量 ≈ 云端旗舰之下的**初判可用档**，终审仍留人/留云。
- **撤销 bm-d「vLLM TP2 + GPTQ-Int4 双实例 + 第三卡 VL」旧条**：①vLLM 自 0.20 后弃 sm_70，且 Windows 不原生支持，而 bm-d 装机案=Windows+R580；②Volta 上 GPTQ-Int4 各家读数互相冲突（有源称支持、有源称不支持），未本机验不信；③张量并行在 PCIe 转接上双卡实测仅 +13.06%、流水线并行 −2.06%=无收益。正解=llama.cpp 层切（官方口径"容忍慢互联、maximizes batch throughput"）。
- **撤销「快档并挂」（Gemma 26B Q4）**：动机是求快，已随令②失效；保留为**单卡期（#2/#3 未到）过渡主力**。
- **48G 单实例常驻的代价如实呈**：并发靠层切批量吞吐兜，单请求会慢——按"慢可忍、错与返工不可忍 + 少云"三令取舍，此为定案。
- 版本情报为 2026-10-21 检索快照：Qwen3.5 系列 2026-02-16 起分批开源（35B-A3B 已开源·混合注意力+原生长上下文），3 月补 0.8B/2B/4B/9B 端侧小系（⚠️单源待官方 repo 校验）；3.6/3.8 持续放权重。**Qwen3.5-9B 是否含可直接部署的多模态权重、以及 sm_70/Ada 上的 VL kernel 覆盖，装机前必实查**——若本地无位则 L3.5 回落云端并记为「本地无该能力位」合规支出。
- 速度数字全部"待本机实测"，矩阵不给承诺值；本件未启动任何下载/安装/服务动作（接管待命令维持）。

## 六、装机顺序（接管令后执行·反返工排序）

1. **bm-d 先验软件再下权重**：自编 sm_70 llama.cpp/ik_llama → 最小模型跑通 Gated DeltaNet 混合注意力（新架构需较新版 llama.cpp，sm_70 kernel 覆盖是未验风险）→ **才**下 ≈37G Q8 → 三卡层切驻留 → 质量回归+日产能双验。
2. bm-a：装 Qwen3.5-35B-A3B（Q5_K_M 起、试 Q8）→ 部分卸载调参（batch 2048/KV q8_0/8 线程=既有实测法可复用）→ 回归一次过 → :8091 起服务；随后试装 9B 多模态判图位（同端口族另起）。**旧 35B-A3B 端点直接换掉**（qwen3.6-35b-a3b 为旧代口径）。
3. bm-b：Q5_K_M/Q6_K 全驻（8G 内最高档），替换 qwen2.5:7b 位（bili-ops 提示词随 v3 定稿重校）；L1 快筛队列接进 POOL。
4. bm-c：Qwen-Image-2.1-Turbo 试烧（POOL-0021 卡位=此件）。
5. 全机：登记进 resource-chain §9.1 车道表；**每型号只在本件记一档，他处引用不复制**（防四处口径打架=反复改的源头）。

## 七、V100 硬件侧约束（社区活跃≠新链路可派·证据补档）

- 红利面：16G SXM2 裸模块 ¥400-600、套装约 ¥880，给 900GB/s HBM2 带宽；MoE 只激活 3B 量级、瓶颈在带宽不在算力，正好对胃口。第三方逐链接二手普查将「V100 16GB SXM2」列为低成本 FP16 第一优先型号（BOM ¥950 锁源判为合理中带价）。
- 倒计时面：CUDA 13（2025-08）不再为算力 <7.5 做离线编译，出新二进制须停 CUDA 12.9 + R580（LTS 到 2028 年中）；PyTorch 2.11 起从 CUDA 12.8 builds 移除 Volta；缺 BF16/FP8/FlashAttention-2（只有 FA-1、需源码编译指定 arch）。
- 执法推论：**bm-d 只当文字大脑，任何新视频/多模态链路不派它**；下单前必过实时锁价轮（10-17 报道 32G 版已较原价普涨约 1400 元，池子在往上抬）。
