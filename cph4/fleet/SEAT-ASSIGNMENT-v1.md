# 席位编成 v1（2026-11-06 · 六席 · 一席一机一产物）

> 原则：不新建能力，把已经在跑的散件**归口到席位名下**，每个席位绑定一台机、一个节奏、一种产物格式、一条停止条件。
> 判据：席位有产物（文件+时间戳）才算在跑；只有"已巡检/已关注"等于没有这个席位。

## 一、监督席（主控的第一职责）
1. 输入：各机心跳（FLEET_STATE）、lanes/*.json、queue-receipts/、闸报告
2. 四信号：产出年龄 >24h / 回执缺失 / 闸红灯 / 机器停机
3. 产物：`cph4/fleet/oversight/<date>-<hhmm>.md`，一页，三列：线—归属机—状态
4. 停止条件：连续 3 天零告警且产出年龄全 <24h → 降频到 2 小时
5. 第一件产物：明早 09:00 一张真实一屏

## 二、回收席（家底实测 22.97GB / 40,684 文件）
1. 五类回收对象：整包重复、孤儿文件、超期中间件、未登记资产、超过 N 天未引用的原片
2. 产物：`cph4/fleet/gc-reports/<date>-reclaim.md` = 构成图（哪类占多少）+ 待删清单 + 预计释放
3. **边界：只出清单不自动删**；执行删除需 CEO 或既有规则授权（不可逆动作）
4. 停止条件：连续两周无可回收项 → 降为月度
5. 第一件产物：本周一份 22.97GB 构成图

## 三、生产席（已在跑，只补缺口）
1. 就是 lanes + PRODUCTION-QUEUE + queue-receipts，不新造
2. 每条线每天要么有产物，要么有"为什么没有"的原因行
3. **缺口**：bigcompute / bigdomain / bighouse / biglife 四条线 `lanes=[]`，没有执行机
4. 停止条件：某线连续 7 天无产物 → 自动挂起（已有规则）

## 四、出厂席（今天已经立了一半）
1. 归口：58 个质检脚本 + 今天定的三件套（成片三检 / 双路定格并集 / 出片带 cutindex / VMAF）
2. 产物：每片一份 `qa-<version>.json`，没有它不许叫"完成"
3. 停止条件：连续 20 片零修复 → 可降为抽检
4. 第一件产物：v724 的 qa 报告（含真峰值是否已修）

## 五、雷达席（分三条线，共用一个出口）
1. 工具雷达：GitHub 新库/更新（已有 radar-daily-sweep.ps1）
2. 信息雷达：竞品榜单、平台规则变化、行业动向（recon 线供料）
3. 模型雷达：本地模型更新与换档（已有 model_radar.py）
4. 出口统一：每天一条「值得试的 1-3 件」，每周一份「本周试了什么、结论是什么」
5. 判据：**必须有试用结论**，收藏夹式汇总不算产物

## 六、创新席（唯一真缺的）
1. 动作：每周 2 个可验证的新尝试（新工具接进产线、新格式、新玩法）
2. 判据：48h 内出**可看样片或可玩原型**；写文档、画路线图一律不算
3. 素材来源：直接吃雷达席每周输出（形成闭环）
4. 停止条件：连续两周两个尝试都无有效结论 → 停席并把配额还给生产

## 七、跨席规则
1. 一席一机，避免抢资源；主控只跑轻量（监督/雷达），不跑生产
2. 每席产物必须是文件 + 时间戳，不接受口头"已关注"
3. CEO 只看监督席的一屏，其余四席不直接打扰
4. 席位连续 7 天无产物 = 自动挂起，不解释
5. 席位之间只通过文件/总线交接，不互相开会议

## 八、要 CEO 定的两件
1. 回收席的**删除权**：现在只出清单；要不要给"重复副本直接删"的授权（不可逆）
2. 创新席的**算力配额**：每周两次样片要占 bm-b/bm-c 的 GPU 窗口，要不要给固定时段
