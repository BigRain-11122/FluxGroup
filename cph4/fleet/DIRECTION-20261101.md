# 方向盘 2026-11-01（主控大脑定案·7 天窗口）

规则依据：CEO 11-01「多调研、多统筹、多想方向、多派单、多监督」+ 同夜「自决推进、不许等」。
每条线只回答三件事：**现在真实状态 / 下一步唯一产物 / 谁在哪台机上做**。没有可交付物的线一律判「缺方向」，由本盘定案，不许继续空转。

## 一、全局判断（先看盘子再动手）

| 事实 | 含义 |

## 三、派单原则（写进流程，不靠我每次记）

1. 每条线在「到期无产出」时，**先查本盘的下一步产物**，按它派卡；没有定案才退回只读证据卡。
2. 卡片一律带可核验的 deliverable 与 accept，跨机卡 `cwd` 留空。
3. 同一线同日只派一张生产卡，避免自己跟自己抢机器。
4. 长线定案卡由大脑出（本文件），不由机器生成——机器不发明方向。

## 四、本盘明确的「不做」

- 不在 bm-c 内存 < 8GB 时派任何出片/渲染。
- 不在 bm-a 白天（09–19）派重活。
- 不为「填满队列」造无产物的卡；缺方向就写进本盘第五节。

## 五、长线定案（本盘已判，CEO 巡视可否决）

1. **bigcompute → 不单独立项**：并入机队算力池（bm-d 入网后作为算力供给），理由是它没有独立商业面，单独立项只会继续产出无人消费的文档。否决窗：CEO 若认为它是产品线，一句话改回。
2. **bigdomain → 最小闭环＝「注册→化身→参观端开门帧」三件**：先做 census 注册到一个可参观的门，不做世界观扩写。首件可交付物＝一屏可截图的门。
3. **biglife → 最小闭环＝census 可跑**：注册/计数/一屏可读，不碰生命体征十二条的对外表述。
4. **bighouse → PARK**：至今无真实需求证据，先停止占用注意力与队列，保留正典不动。恢复条件＝出现具体需求（谁要住、要什么）。
5. **MV 发布窗口**：v718 收口后**不自动进发布包**，等全闸结论出来由本盘判断是否需要第三次重烧；发布动作本身仍归 CEO（对外发布属保留闸）。

## 六、本盘的自我约束

- 方向由本盘定，但**定案必须落到「谁在哪台机上交付什么」**，否则等于没定。
- 每条定案都带否决窗：CEO 一句话即可推翻，推翻即回滚，不用重新讨论流程。
- 派单看产能不看愿望：bm-c 内存不足时不派重活，bm-a 白天不派重活，宁可等夜窗也不塞假活。
